30P30N coordinates in nominal stowed-chord units
================================================

Raw profiles from linuxguy123/30P-30N-Validation-Case (main), GPLv3.
Source paths: 30P-30N-{Slat,Main,Flap}-raw.dat.
Nominal reference chord is 1; deployed extent is about 1.216241.
These files preserve the original coordinates. They differ in normalization
from the older 30p30n directory and must not be compared without registration
to NASA TP-3496 geometry or to a different flap rigging.
