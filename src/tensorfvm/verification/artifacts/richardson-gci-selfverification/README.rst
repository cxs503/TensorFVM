Richardon/GCI 验证工具的自验证与环形 Poiseuille 应用
=====================================================

结论先行
--------
本仓所有「observed order = N」的判据此前都来自
``tensorfvm.verification.core.observed_orders``：它只做相邻两网格的差分比值，
(a) 只对「极限为零」的量（误差）成立，(b) 无法处理不等加密比，
(c) 不检查序列是否落在渐近区，(d) 不给出外推极限与不确定度带。
本单新增 ``tensorfvm.verification.richardson``（三网格 Richardson 外推 +
Roache GCI，支持不等加密比、渐近区判据、2 网格 3.0 安全因子回退），
并用闭式合成数据**先验证工具本身**，再把它用在已合并的环形 Poiseuille 后端上。

工具自验证（合成数据，闭式已知）
--------------------------------
数据 ``f(h)=1+0.7 h^p``，保险因子与加密比均为输入；判定量是
``|p_obs-p|`` 与 ``|f_extrapolated-1|``。

* p=1 / 1.5 / 2 / 3，等加密比 r=2：``|p_obs-p|`` ≤ 2.7e-13，
  ``|f_extrapolated-1|`` ≤ 1.1e-16（双精度舍入级）。
* 不等加密比 r=1.6, 2.5（同一组 p）：``|p_obs-p|`` ≤ 1.9e-12，
  外推误差 ≤ 8.9e-16。旧 ``observed_orders`` 在这种情形下只能给出
  **每个网格对各自的阶**，无法合成单一阶数。
* 旧工具在本该暴露的两种情形里保持沉默：
  1) 把原始积分量 Q(h) 直接喂给它（Q 的极限非零），相邻对给出
     ``0.0306 / 0.0592``（真值 p=2），既不报错也不自洽；
  2) 符号交替序列 ``(0.1, 0.08, 0.09)`` 仍返回两个有限数，
     新工具给出 ``convergence='inconsistent'``、``order=nan``、
     安全因子回退 3.0。

误差判定（逐项，显式回答是否 <3%）
-----------------------------------
* 工具对合成数据的阶恢复误差：2.7e-13（绝对），**是 <3%**。
* 工具对合成数据的外推极限误差：1.1e-16（相对），**是 <3%**。
* 环形 Q 的细网格误差：0.0264%（256×64），**是 <3%**。
* 环形 Q 的 Richardson 外推误差：2.02e-06（256×64 三网格），**是 <3%**。
* 阶数判定 vs 形式二阶：``|p_obs-2|/2`` = 0.52%（细三网格），**是 <3%**。
* 对闭式流量，GCI 带在两组三网格上均覆盖真值（coverage=True），
  效率指数 < 1（带偏保守），无基准缺失项。

注意点与局限
------------
* 3% 单网格门在**全部四个网格**上都通过（含最粗的 32×8，1.64%），
  因此「单网格误差 <3%」不能证明离散已收敛；本工具给出的 0.0264% 与外推
  2.02e-6 才是有信息量的陈述。这与既有「闸门非信息量」判例一致。
* GCI 是**对细网格离散热散误差的估计**，不是对参考解误差的界：
  合成负控中 h_max=0.4 时它虽覆盖真值，但外推偏差 2.1e-3 远大于带半宽，
  说明带外推值不能宣称同等置信度。本报告一律把覆盖性作为唯一 GCI 断言。
* 阶数求解假定误差主项为单一 ``C h^p``；符号交替序列会退化为
  ``inconsistent`` + 安全因子 3.0，属保守降级而非修复。
* 环形案例只覆盖扩散算子与质量守恒，不含对流/湍流/自由液面，
  结论不外推到一般三维 Navier–Stokes。
