# Annular Poiseuille: grid-convergence verification of the production backend

Status: **verification increment (evidence, not physical validation)**.
Module: `src/tensorfvm/verification/annular_convergence.py`. Evidence bundle:
`src/tensorfvm/verification/artifacts/annular_grid_convergence.json` + `.png`, regenerated by
`OMP_NUM_THREADS=1 PYTHONPATH=src python scripts/verify_annular_grid_convergence.py --levels 4`.
Tests: `tests/test_annular_grid_convergence.py` (12 tests).

## 1. Why this study exists

`tensorfvm.annular` (backend `annular`, exact reduction of fully developed axial
laminar flow between concentric no-slip cylinders) was already compared against
its closed form — but only on **one** grid, inside a **3%** relative-L2 band
(`verification/engineering.py`, `verification/engineering_audit.py`).

A single-resolution comparison cannot tell these two worlds apart:

* the discretisation is second order and the 3% band is merely loose, or
* the discretisation is first order / inconsistent and 3% happened to be met.

Both worlds pass the same gate, and a user sizing a production mesh from that
gate inherits the ambiguity. Missing pieces were: an observed order of accuracy,
a Richardson extrapolation, a grid convergence index (ASME V&V 20 / Celik), and
an *independent* check of the reference solution itself.

## 2. Case and setup

| item | value |
|---|---|
| geometry | concentric annulus, inner radius R_i = 0.05 m, outer radius R_o = 0.10 m |
| physics | fully developed laminar axial flow, u = u(r) only; exact 2-D cross-section reduction |
| driving | imposed axial pressure gradient dP/dz = -G, G = 0.01 Pa/m |
| fluid | mu = 1.0 mPa·s, rho = 1000 kg/m³ (as in `AnnularConfig`) |
| exact solution | u(r) = G/(4 mu) [R_o² - r² - (R_o²-R_i²) ln(R_o/r) / ln(R_o/R_i)] |
| exact flow rate | Q = pi G/(8 mu) [R_o⁴ - R_i⁴ - (R_o²-R_i²)²/ln(R_o/R_i)] = 4.947382e-05 m³/s |
| discretisation | production fitted diffusion kernel on polygonal annular cells, full sparse CG (scipy), no ring averaging, zero initial velocity |
| grid sequence | 32x8, 64x16, 128x32, 256x64 (n_theta x n_r), uniform refinement ratio r = 2 |
| residual gates | production gates untouched (relative linear residual <= 1e-11 target, true residual re-evaluated) |

## 3. Independent validation of the reference (anti self-reference step)

The closed form is re-derived by a second-order finite-difference solution of the
**differential** statement `d/dr (r du/dr) = -(G/mu) r` with u(R_i) = u(R_o) = 0:

| FD points | FD spacing (m) | max abs deviation (m/s) | max rel deviation |
|---|---|---|---|
| 301 | 1.667e-04 | 1.586e-09 | 5.009e-07 |
| 601 | 8.333e-05 | 3.965e-10 | 1.252e-07 |
| 1201 | 4.167e-05 | 9.912e-11 | 3.131e-08 |

Observed orders of these FD differences: **1.99996** and **2.00006**. The gap is
therefore FD truncation, not a wrong formula. Additional exactness checks:

* differential identity `d/dr (r du/dr) + (G/mu) r = 0` residual: 2.27e-13 (relative to |G r/mu|).
* flow rate closed form vs 1201-point quadrature of the same profile: 6.89e-07 relative.

So the reference used below is independent of the solver and of its evaluation points.

## 4. Production solver results

| grid | h (m) | cells | rel. L2 err | rel. L∞ err | flow-rate rel. err | inner-wall traction err | outer-wall traction err | area err |
|---|---|---|---|---|---|---|---|---|
| 32x8 | 6.250e-03 | 256 | 2.6402e-02 | 4.0424e-02 | 1.6419e-02 | 1.1409e-02 | 3.246e-03 | 6.413e-03 |
| 64x16 | 3.125e-03 | 1024 | 6.6953e-03 | 1.0845e-02 | 4.1999e-03 | 2.8642e-03 | 8.076e-04 | 1.606e-03 |
| 128x32 | 1.563e-03 | 4096 | 1.6797e-03 | 2.8125e-03 | 1.0560e-03 | 7.1681e-04 | 2.017e-04 | 4.015e-04 |
| 256x64 | 7.813e-04 | 16384 | 4.2030e-04 | 7.1510e-04 | 2.6437e-04 | 1.7925e-04 | 5.040e-05 | 1.004e-04 |

All levels satisfy the production gates: true relative linear residual
3.1e-14 / 7.3e-13 / 3.1e-12 / 8.0e-12 (target 1e-11, re-evaluated, not recursive),
axial momentum force balance <= 2.9e-15, CG iterations 8 / 17 / 36 / 77.

### Observed order of accuracy

| functional | pairwise orders (coarse→fine) | least-squares log-log slope | verdict |
|---|---|---|---|
| velocity, volume-weighted L2 | 1.9794, 1.9949, 1.9987 | 1.9914 | second order |
| velocity, L∞ | — | 1.9410 | second order |
| inner-wall traction | 1.9939, 1.9985, 1.9996 | 1.9975 | second order |
| flow rate Q (triple-grid, finest triple) | p = 1.9897 (consistent with coarser triple: yes) | — | second order |

Approaching exactly 2 as h → 0 is the signature of an asymptotic second-order
fitted-kernel diffusion discretisation; a first-order or inconsistent scheme
would pin the slope near 1 regardless of resolution.

### Richardson extrapolation and GCI

Finest grid (256x64), functional Q:

* Richardson extrapolated Q = 4.9473717e-05 m³/s, exact Q = 4.9473817e-05 m³/s
  → **relative deviation 2.02e-06**.
* GCI (Fs = 1.25) on the finest grid: **3.33e-04** relative.
* The extrapolated value falls inside its own discretisation band
  (2.02e-06 <= 3.33e-04): the exact value is reproduced to the accuracy the
  extrapolation claims.

Consequence for mesh sizing: on the 128x32 grid the discretisation error is
1.68e-03 (0.17%), i.e. the legacy 3% band is met already on **32x8** (2.6%).
The 3% gate therefore conveys no information about mesh adequacy for this case;
the GCI does: a 1% velocity budget needs roughly n_r >= 32 (h <= 1.56e-3 m),
a 0.1% budget roughly n_r >= 64 — both far below the default 256x64 production
resolution, which sits at ~4e-04 relative error.

## 5. Not covered (honest scope)

* This is **verification**, not validation: the annular case is an exact
  reduction of a 1-D axial flow. Nothing here transfers to general 3-D
  Navier-Stokes, curvature-driven secondary flow (Dean vortices), turbulence,
  two-phase flow, or GPU paths.
* Only the scipy linear backend is exercised in the committed evidence; the
  `torch-cg` path shares the operator but is not part of this study.
* Eccentric annuli, non-conforming meshes and roughness are outside the case.
* The order study reports the error of the *fitted* diffusion kernel as
  currently merged; it does not claim optimality of that kernel.

## 6. Error judgement vs baseline (explicit)

| key quantity | baseline | observed deviation | < 3%? |
|---|---|---|---|
| velocity field, 256x64 | closed form (independently FD-checked, 3.1e-8) | 4.20e-04 | yes |
| flow rate Q, Richardson-extrapolated | exact Q | 2.02e-06 | yes |
| inner-wall traction, 256x64 | exact analytic traction | 1.79e-04 | yes |
| closed form itself vs independent FD BVP | FD of the differential statement | 3.13e-08 | yes |

All four quantities are far below 3%; the binding limitations are the
single-backend scope and the reduced-physics case, not accuracy.

## 7. Reproduce

```
OMP_NUM_THREADS=1 PYTHONPATH=src python scripts/verify_annular_grid_convergence.py --levels 4   # writes the JSON + PNG
OMP_NUM_THREADS=1 python -m pytest tests/test_annular_grid_convergence.py -q                     # 12 tests, ~5 s
```

Wall-clock note: single-threaded runs take a few seconds in total. With default
multithreaded BLAS on a heavily loaded host the same solves were observed to
degrade by three orders of magnitude, so the script and tests pin one thread.
