## 2. 独立复核做了什么（不借用交付方判据）

1. **自己的解析解**：`u=G/(2ν)y(H−y)`、`Ū=GH²/(12ν)`、`τ_w=ρGH/2`、`f·Re_Dh=96` 全部由审计脚本
   独立写成（不从 `analytic_reference()` 取值），并先验证 `G = 12νŪ/H²` 与交付的 `body_force_m_s2=0.12` 一致（差 0）。
2. **从原始剖面重算误差范数**：`profiles.csv` 的 64 行 → 重算 `velocity_l2 = 2.441406e-04`、
   `velocity_linf = 2.441406e-04`，与交付**逐位相同**（相对差 0.0）；`error_m_s` 列与审计重算的最大偏差 0.0。
3. **门控算术复算**：对 17 算例 × 全部指标用 `rel = |computed−ref|/|ref|`（ref=0 时取绝对值）重判
   `passed = rel < tolerance`，与交付的 163 个 `passed` 标志 **零不一致**；`all_gated_passed`
   复算 = true（14 个受门算例），3 个粗网格（`16x8/16x16/16x32`）按 `PLAN` **事先**声明为 gate=False（非事后挑数）。
4. **计划外新算例**（不在交付 PLAN 内）：`nx=12, ny=48, Re_H=250`。
   - half-cell：`velocity_l2/peak = 4.3403e-4`（= (Δy/H)²，与交付的 Re 无关性一致）、
     方案自身壁面通量闭合 `|Στ−ρGH|/ρGH = 3.8e-13`、`max|div u|·H/Ū = 0`；
   - quadratic：剖面相对 L2 = **2.2e-13**（机器精度）、三点拟合闭合 3.7e-13。
5. **伪时间步独立性**（自己跑）：同算例 `Δt = 1 / 5 / 25`，`max|u_Δt − u_Δt=1| ≤ 9.5e-12` → 定常解不是 Δt 调出来的。
6. **报告六段 + 数字对表**：`REPORT.md` ①—⑥ 与「误差判定」段全部在位；§4 表内 8 个引用误差数与
   `benchmark.json` 的 `relative_error` 逐一比对全部一致（最大相对差 < 0.5%，仅因报告保留 7 位有效数字）。
