## L1 · 观测收敛阶必须绑定"自相似网格族"

- **规则**：做 GCI / Richardson 前先确认 `grid_{k+1}` 是 `grid_k` 的等比例加密。
  等比加密被破坏时（典型：拉伸网格 `y_i = H (i/n_y)^p`, p>1），把 `n_y` 加倍等于把**每个格高**除以 `2^p`，
  两套网格不属于同一族，`p_obs = ln|(f2−f1)/(f3−f2)|/ln r` 无意义。
- **证据**：`docs/p158-cht-verification/artifacts/flatplate.json`：
  `y_power=2` 族（nx,ny=60/24→120/48→240/96）实测 `p_obs=1.20`（伪一阶）；
  同算例换 `y_power=1` 自相似族（120/48→240/96→480/192），
  误差 +0.96%→+0.16%→+0.02%，`p_obs=2.55`。
- **机制**：拉伸律使 (Δy)·n_y² = const，等效细化比是 4 而不是 2，Richardson 的分母 `r^p−1` 失真。
- **适用边界**：任何"总高度/总长度固定 + 网格数加密"的参数化工件；若加密律与网格数无关（均匀网格、
  固定增长率几何网格且增长首层随 n 缩放）则不适用。
- **Guard**：GCI 脚本必须打印网格族定义（本例 `artifacts/flatplate.json:gci.y_power`）并把
  两方向细化比一起记录；`tests/test_cht_conjugate_anchors.py::test_flat_plate_gci_observed_order_is_second_order`
  只接受自相似族，`p_obs>1.8` 才通过。

## L2 · 均匀壁热流的层流平板系数是 0.4588（Pr=1），不是 0.453

- **规则**：用"精确解"做平板对流锚时，`Nu_x/√Re_x` 的常量热流值由相似 ODE
  `φ''+(Pr/2)(f φ'−f' φ)=0, φ'(0)=−1, φ(∞)=0` 求得 → `Nu_x=√Re_x/φ(0)`，Pr=1 得 0.45876；
  工程式 `0.453 Pr^{1/3}` 是积分法近似，**偏低 ~1.3%**（Pr=7 时偏低 ~2.1%）。
- **证据**：`src/tensorfvm/cht/similarity.py::solve_uniform_flux`，
  `tests/...::test_uniform_flux_similarity_matches_classical_values`（0.45876 ± 2e-4）；
  与等温壁 `φ'(0)=0.33206` 的比值为 1.38（经典文献 1.36）。
- **机制**：常量热流问题的能量方程多出 `−f'φ` 项（非等温壁的"热历史"），不能用等温解乘常数得到。
- **反例/局限**：Pr<0.6 时 0.453Pr^{1/3} 的偏差增大；变热流（共轭）问题须用局部热流与局部壁温定义
  Nu 才能与该解比较。
- **Guard**：报告必须同时列出相似解值与工程式值两列（REPORT.md §3.1），不允许只报一支。

## L3 · ω–ψ 格式里"方位离散"是 Re≤200 圆柱换热的主误差源，不是 CHT 耦合

- **规则**：圆柱平均 Nu 的 5% 级验证，方位方向一阶迎风不可用；判据：方位格 Péclet
  `Pe_θ = u_θ r Δθ/ν ≳ 1` 时，一阶迎风附加数值粘性 `u_θ r Δθ/2` 与分子粘性同量级，
  Cd 与 Nu 会系统性偏高。二阶限幅重构（van Leer）会**过冲**（本例 Cd 1.93→0.69），
  安全路径是 θ 方向谱方法（FFT）+ 2/3 去混叠。
- **证据**：旧 `PolarVorticitySolver`(Re=40, n_θ=72) `Cd=1.93`（基准 1.574，+23%）、`Nu=3.91`
  vs Churchill-Bernstein 3.364（+16%）；同算例 CHT 耦合的界面热流守恒已达 1.8e-4→1e-13 量级，
  说明误差不在耦合而在输运离散。新 `cylinder_fourier` 谱方法在瞬态 t=1.2 时 `Cd=1.75`（趋近 1.574），
  但推进到机器判定"定常"后 coarse 网格给出 `Cd=0.88`、`Nu=3.055`（−9.2%），
  即新求解器**尚未通过阻力基准**，只可视为方向正确的基础设施（见 P158W3-N02 §3.3.1 的 honest FAIL）。
- **机制**：`Pe_θ≈1.7` 时迎风数值扩散占比 ~87%（`ν_num/ν = Re·Δθ·r/2`），等效雷诺数掉到 ~21。
- **适用边界**：低 Re 且方位网格粗的情形；若 `Pe_θ ≪ 1`（黏性主导）一阶迎风可接受。
- **Guard**：`cylinder_fourier` 的 θ 导数一律走 FFT 并 `dealias()`；测试
  `test_cylinder_drag_and_nusselt_re40` 要求 `|Cd/1.574−1|<5%` 与 `|Nu/Nu_CB−1|<5%`。

## L4 · 显式无滑移壁涡量把时间步锁死在 `dt·ν/Δr² ≲ 0.3`

- **规则**：ω_w 由 ψ 的径向二阶拟合给出、作为下一时刻的 Dirichlet 值使用时，第一步隐式扩散解里
  壁值权重为 `dt·ν/Δr²`；该量接近 1 时，壁涡量—ψ 反馈回路会在数个对流时间后发散。
- **证据**：Re=40、Δr=4e-3（ν=0.025）时 `dt·ν/Δr²=0.78`(dt=5e-4) 在 t≈6–8 发散；
  `=0.3`(dt=1.9e-4) 稳定。驱动脚本按 `dt = 0.3·Δr²·Re` 取步长
  （`scripts/p158_cht_validation.py::_dt`）。
- **机制**：壁涡量是 ψ 的二次导数除以最小的 Δr²，噪声放大 1/Δr²；显式耦合使回路增益 =
  `dt·ν/Δr²`。
- **局限**：若把 ω_w 纳入隐式系统或用 Thom 型无量纲化壁条件，可放宽该限制（未实现）。
- **Guard**：`_dt()` 单点函数被所有圆柱算例调用；算例 JSON 记录 `dt`/`grid.wall_cell`，
  报告可复核该比值。

## L5 · 共轭界面保守性用"两侧独立重建"来审计，"由构造成立"不等于"已证明"

- **规则**：单场（同一温度场、界面面导热率取两侧半格热阻串联）实现中 `q_f=q_s` 是构造性质；
  必须再用**各自的 κ 与各自半格距**独立重建界面温度与两侧热流，报局部/全局残差，否则无法发现
  面导热率或半格距的编码错误。
- **证据**：`flatplate.json` 各站 `interface_local_imbalance_rel ≤ 1.4e-13`、
  `interface_global_balance_rel ≤ 3e-14`、账本 `normalized_imbalance < 1e-9`。
- **Guard**：`test_flat_plate_interface_flux_conservation` 同时断言局部、全局与账本三条。
