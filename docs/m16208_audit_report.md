# m16208 交差审计报告：CASE-FVM-DAMBREAK-STOKER

## 1. 案例介绍

**物理背景**：一维浅水方程（Saint-Venant）溃坝问题。Ritter (1892) 给出干床精确解（稀疏波），Stoker (1957) 给出湿床精确解（稀疏波+激波）。

**几何与参数**：
| 参数 | Ritter (干床) | Stoker (湿床) |
|---|---|---|
| h0 (上游水深) | 1.0 m | 1.0 m |
| h1 (下游水深) | 0.0 m | 0.5 m |
| g (重力) | 9.81 m/s² | 9.81 m/s² |
| 坝位置 | x=0 | x=0 |
| 计算域 | [-4, 6] | [-4, 6] |
| 无量纲时间 t* | 2.0 | 2.0 |

## 2. 方法

**求解器**：TensorFVM 新增 `shallow_water` 模块（1268 LOC）：
- `swe1d.py` (296行)：一维有限体积求解器，MUSCL重构+minmod限制器+HLL黎曼求解器+SSP-RK3时间积分
- `dam_break.py` (668行)：算例定义、度量计算、网格收敛/参数敏感性研究
- `exact.py` (246行)：Ritter/Stoker 闭式精确解

**验证流程**：
1. 闭式解认证（机器精度残差）
2. 守恒律验证（质量漂移 <1e-13）
3. 正性验证（h≥0，无裁剪）
4. 单调性验证（0内部极值，TV比≤1.001）
5. 5%容差验收（波前/激波/水位阶跃/深度L1）
6. 网格收敛研究（5档分辨率，n=100~1600）
7. 参数敏感性（7种变体）

## 5. 注意点

**已修复的缺陷**：
1. MUSCL外推中 `½h'` 应为 `½Δx·h'` → 导致 h/h0=1.24 伪峰
2. SSP-RK2+二阶重构 → 光滑场被抽干，改用SSP-RK3
3. 粗网格(n=100,200)近激波单元有1个极值，n≥400消失

**局限**：
- 浅水模型本身是近似（静水压、无粘性、无床面摩擦）
- 仅1D、平底床
- 干床波前度量有2-3%固有偏差（尖端抹平），非网格收敛量

**平台缺口**：
- `tensor_benchmark_cases` 表中无此锚点记录
- `tensorbench_results` 无独立复算行 → L4平台门显示 CLAIMED_NOT_PROVEN
- 这是平台基础设施缺口，非任务缺陷
