## ① 案例介绍

物理: 两块平行平板，下壁以 `u(0,t) = U0 cos(ωt)` 振荡，上壁静止，展向/流向周期，
无体积力，流速只有流向分量且只随 `y` 变化 → 线性 Stokes 第二问题（Stokes 1851；Lamb §345；
Batchelor 1967 §4.6）。

| 量 | 值 |
|---|---|
| 通道高 H | 1.0 m |
| 运动黏度 ν | 0.01 m²/s（μ=0.01 Pa·s, ρ=1 kg/m³） |
| 壁面振幅 U0 | 1.0 m/s（Re_H = U0 H/ν = 100，层流） |
| Womersley 数 W = H/δ | 2 / 5 / 10（δ = √(2ν/ω)） |
| 网格 | nx=4（流向均匀，周期），ny=64；流向、壁法向均匀 |
| 时间步 | dt = T/200，T = 2π/ω |
| 壁面闭合 | `half-cell`（默认，一阶壁面通量）/ `quadratic`（三点二阶，仅用于空间收敛研究） |

精确解（有限通道，闭式）:

    u(y,t) = Re{ U0 sinh(k(H−y))/sinh(kH) · e^{iωt} },  k = (1+i)/δ,  δ = √(2ν/ω)

`k² = iω/ν` 即动量方程本身，两个壁面条件自动满足；bulk 与壁面切应力同为闭式：
`U0(cosh kH − 1)/(k sinh kH · H)`、`τ_w = μ Re{−U0 k coth(kH) e^{iωt}}`。

## ② 怎么做的

1. **能力补全**（`channel_periodic.py`，最小改动）: 运动壁只改变壁面 ghost 值
   `u_g = 2u_w − u_0`（half-cell）/ `u_g = −2u_0 + u_1/3 + (8/3)u_w`（quadratic），
   代入隐式扩散的壁行后成为一个常源项 `coef·u_w/dy²`（coef = 2ν 或 (8/3)ν）；
   `wall_shear` / `dissipation` 同步减去 `u_w`，保持离散动量守恒口径一致；
   `wall_velocity_m_s` 为持久状态（`set_wall_velocity`），默认 (0,0) 时逐位复现历史齐次壁结果。
2. **顺带修一个性能缺陷**: 每步三对角求解原为 Python 逐行 Thomas（ny=64 时 ~11.7 ms/次，
   每步 3 次 → 步成本 ~40 ms），改为 LAPACK 批量求解（0.94 ms/次，n>256 自动回退 Thomas，
   实测交叉点 ~n≈300）。等价性有专测（相对差 1.4e-16）。步成本 40 ms → 5.6 ms，
   `tests/test_channel_periodic.py` 43 s → 23 s、`test_pulsatile_channel.py` 53 s → 21 s。
3. **验证驱动**: 19 条判据**先声明后跑**；闭式解自身用数值微分独立复核（A1/A4），两个极限
   （A2/A3）与教科书半无限关系（A5/A5b）独立成判据；生产求解器从静止启动到周期稳态
   （判据：相邻两周期末剖面变化 ≤ 1e-4·U0）再采样一个周期 10 个均匀相位，
   按周期包络归一算 L2 误差；B8/B9（时间/空间收敛）改由闭式初值启动，
   只量一个周期的演化误差（避免启动瞬变污染阶数）。图由驱动自动生成。

## ⑤ 注意点（踩坑与局限）

1. **单步收支不能用采样点算**: 离散动量收支是"一步一次"的恒等式；用相隔 20 步的采样点算
   `dŪ/dt` 会得到 O(Δtω) 的假残差（实测 2–9%），改成逐步记账后降到 3.8e-15。且必须把**两侧**
   壁面通量都算进去（漏掉上壁时 W=2 假残差 9.3%，W=10 只剩 9e-6 —— 误差随 δ/H 变小，正是漏项特征）。
2. **启动瞬变很慢**: 通道最慢模态 `exp(−νπ²t/H²)`，5 个时间常数 ≈ 93 s；W=10 时要 ~30 个周期
   （6000 步）才到 1e-4·U0 周期稳态。故收敛研究改用闭式初值（B8/B9），B1–B3 仍从静止启动。
3. **空间阶数被两件事污染**: 默认 `half-cell` 壁面闭合是一阶（仅壁面通量处），且 dt/T=1/200 的
   时间误差（7.6e-3）与 ny=64 的空间误差同量级 —— 第一次测得的空间阶只有 0.134（假 FAIL）。
   改为 `quadratic` 闭合 + dt/T=1/1000 后阶数 0.662。
4. **相位口径**: `μ ∂u/∂y` 与教科书「τ = ρU0√(νω)，相位 +45°」差一个 180°（后者是**平板受的力**）。
   判据 A5b 明确按平板反力口径写，避免把符号约定当成物理错误。
5. **Alexander 型局限**: 仅层流、x 均匀、不可压缩、常黏度；壁面为单频正弦驱动，
   未含多频/随机驱动；`v` 被钉在零，故不含流向非均匀（行波）或壁面法向运动。
6. **性能改动的影响面**: `_tridiagonal_solve` 与 `_thomas` 在 n≤256 走 LAPACK、n>256 回退 Thomas；
   两实现的等价性、以及既有 channel/pulsatile 全部回归测试均绿。
