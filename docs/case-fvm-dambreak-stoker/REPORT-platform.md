# CASE-FVM-DAMBREAK-STOKER 高分辨率延伸（n = 800…6400）：误差收敛性、估计子地板与 F9 切分穿点

## 5. 注意点
* F9 是**有条件通过**：穿点处靠已声明的十进位重试阶梯救回，阶梯用尽后检测器按设计整体失效（`plateau_unbounded`，全 NaN），届时必须先改判据再上网格。
* `fan_grad` 的排除窗口必须是**物理半宽**；只用固定单元数窗口时细网格会被跳跃抹平污染，诊断会假报“比值仍在切分之上”。
* `x_f(t)` 序列的观测阶显著低于一阶：该量由波前读数估计子主导，故本包只主张 `depth_l1` 的一阶，不主张序列阶次。
* 5 % 门在 n ≥ 3200 上几乎无判决力（误差已降两个数量级），属回归防护而非精度标定。
* n = 12800 只有合成解析剖面复核，求解器未跑：**未运行项**，不是通过项。
