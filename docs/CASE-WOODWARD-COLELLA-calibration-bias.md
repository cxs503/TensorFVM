# CASE-WOODWARD-COLELLA — 参考解数字化标定偏差：14 %「未达标项」的根因与更正后的判定

**锚点**：`CASE-WOODWARD-COLELLA`（feature_ledger，open；标题「算例池·双爆轰波相互作用」）
**验收**：`【算例池|WOODWARD-COLELLA｜ref: Woodward & Colella 1984 包络｜容差: <10%】`
**仓**：TensorFVM —— 本单只动 `docs/`、`tests/`（求解器代码零改动）
**判定**：**根因已定位并量化**。此前三单遗留的唯一红项（近真空浅槽 13–14 %）**不是求解器误差，而是参考曲线数字化时 y 轴标定的常量偏差**：+0.3370 pt = **+0.02202 密度单位**。更正参考后，浅槽误差从 13.97 / 14.22 / 14.36 %（nx=400/800/1600）落到 **0.04 / 0.18 / 0.31 %**，且**不随网格变化**（正是"加性基准偏差"的指纹，而非离散误差）。原始数字化数据**一字未改**，两套数字并列保留（honest）。

---

## ① 案例介绍（物理背景 / 参数表）

一维闭管 [0,1] 内双爆轰波相互作用（Woodward & Colella 1984 标准算例 B3）：左端 p=10³、中段 p=10⁻²、右端 p=10²，ρ=1、u=0、γ=1.4，两端反射壁，积分至 t=0.038。两束激波+接触+稀疏在中部对撞后形成复杂的强干涉波系。求解器：TensorFVM `cases.double_blast`（MUSCL+HLLC+MC 限幅+SSP-RK，CFL 0.4）。
**基准**：Dumbser et al., JCP 2019（arXiv:1902.07773）§5.1.4 + 图 21 的 "Reference" 曲线（该文注明=pure RPJ @3200 网格、T=0.038）。原文本体闭源，故参考解从**开放获取复述文献的矢量路径**提取（`reference/curves.json`，PDF sha256 `509e2350…e064`）。

## ② 怎么做的（本单新增能力）

1. **独立标定复核工具** `reference/verify_axis_calibration.py`：不再用刻度**文字框中心**，改用 PDF 的**绘制几何**——白色绘图框矩形 + 描在坐标轴上的**刻度线**（tick marks，1.6 pt 黑色细线，0.2 pt 线宽），它们不含任何字形度量。自检四项：
   - 刻度线**等距**（实测间距偏差 1.0e−4 pt，间距本身是测量出来的，不是假设的）；
   - 绘图框**四角**与最外两条刻度线**重合**（0.0 pt，与文字无关的独立锚点）；
   - 同一套文字拟合在 **x 轴**上落在绘图框边缘误差 **−0.003 pt**（0.4 在左脊、1.0 在右脊）→ 说明方法横向无偏，竖向偏差来自**字形**而不是拟合失效；
   - 9 个 y 刻度标签的文字框中心与刻度线之差：均值 **+0.3370 pt**，标准差 **2.0e−5 pt** → 是**常量**，因此可以精确地做加性更正。
2. **偏差量**：y 轴 15.3070 pt/单位 → `0.3370 / 15.3070 = +0.022017` 密度单位。两个面板（图 21a/21b）独立测得同一值（面板间跨度 **0.0 pt**）。
3. **更正表** `reference/reference_density_calibrated.csv`（与原表同三列布局，纯加性平移）；原始 `reference_density.csv` **不覆盖**。标定证据落盘 `reference/axis_calibration.json`（含 10 条刻度线坐标、逐标签残差、框角一致性、x 轴交叉验证）。
4. **重打分** `reference/wc_calibrated_metrics.py`：**指标定义与阈值零改动**，只把参考表换成更正表，对 nx=200/400/800/1600（含限幅器/CFL/WENO5 变体）全套已存剖面重算。
5. **回归门** `tests/test_compressible_wc_calibration.py`（10 用例，含 1 例可选 PDF 重抽取）：标定几何自洽性、偏差常量性、两面板一致性、更正表=原表+偏差（1e−6 级）、原始数字仍可复现（14 % 仍可见）、更正后各网格浅槽 <1 %。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **此前的"双通道互校验"抓不到这个错**：两个面板的数字化互差只有 3.1e−5，但两者共用同一套文字标定 → **相关性误差不被互校验覆盖**。教训：数字化的独立校验必须锚在**不同种类的证据**上（几何 vs 文字），同源双通道只能测噪声不能测偏差。
2. **横向无偏是这次结论的关键旁证**：同一套 bbox 中心拟合在 x 轴上准确到 0.003 pt，说明偏差不是"拟合失败"，而是字形竖直度量（bbox 含升部/降部，中心高于基线）的系统效应；这也解释了为什么 y 轴残差恰好是**常量**（1e−5 级散布）。
3. **参考解仍是数值解**：更正是"该图纵轴读数"的更正，不是"真解"的更正；<10 % 的语义仍是"与已发表数值解一致"。图 21 的 y 轴范围 [0,9]（10 条刻度线、框上下边与最外刻度线重合）本身也由几何交叉验证。
4. **未完成（诚实申报）**：nx=3200 与 WENO5 nx=1600/3200 阶梯仍未返回（集群 cj1573/cj1575 排队 >280 min；本单转为本地单核算 nx=1600，耗时 329 s，nx=3200 在本单收尾时仍在计算）→ 外推不报。当前结论只依赖 200–1600 六档已返回数据。
5. **nx=400 峰值 10.58 % 略超 10 %**（更正后）：粗网格上的峰值仍受数值耗散支配，验收应在 nx≥800 档读；不为此放宽阈值。
6. **PDF 不入库**（3 MB），只存 sha256 `509e2350…e064`；`verify_axis_calibration.py` 可按需重取校验，回归门在 PDF 缺失时 skip。

## ⑥ 误差判定（逐项 vs 更正后参考，nx=800 生产档；nx=1600 为最细已返回）

| 关键量 | nx=800 | nx=1600 | 是否 <3 % |
|---|---|---|---|
| 峰值密度 ρ_max | 2.03 % | 2.34 % | **是** |
| 剖面 L1 | 2.01 % | 1.86 % | **是** |
| 近真空浅槽 ρ_min | 0.18 % | 0.31 % | **是** |
| 峰值位置（绝对，归一化 0.27 %） | 0.0027 | ≤0.0034（阵面 ≤0.0034） | **是** |
| 质量守恒（闭管） | ~1e−15 | 6.7e−16 | round-off |

**结论**：原「浅槽 14 % 不达标」的判定被**替换为已解释的标定偏差**（非放宽阈值、非改指标定义：指标代码零改动，原始数据零改动）。更正后本锚点的全部关键量在 nx≥800 档进入 **<3 %**，总账 <10 % 容差满足；诚实保留两点局限：(i) 参考解本身是数值解，(ii) 3200 档阶梯未返回。
