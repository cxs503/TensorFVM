## ① Problem setting and the benchmark source

Two-dimensional lid-driven cavity: unit square `[0,1]²`, no-slip on three walls, tangential lid velocity `U = 1` on `y = L`; incompressible Navier–Stokes, `Re = U·L/ν = 1000` ⇒ `ν = 1e-3`, `ρ = 1`. The Ghia solution at this Re is steady (single primary vortex plus corner eddies), so the target is a steady state.

Reference: **U. Ghia, K.N. Ghia, C.T. Shin, *J. Comput. Phys.* 48 (1982) 387–411**, Table I (u along `x = L/2`) and Table II (v along `y = L/2`). The values used here are the committed transcription in `src/tensorfvm/lid_cavity_reference.py` (self-checked by `tests/test_ghia_reference_consistency.py`), read at render time.

## ② Method and implementation

Staggered MAC finite-volume discretisation of `∂u/∂t + ∇·(uu) = -∇p/ρ + ν∇²u`, `∇·u = 0`: conservative van Leer (harmonic TVD) face reconstruction, explicit projection, pressure Poisson with pure-Neumann walls solved by an orthonormal DCT-II diagonalisation (compatibility `Σ div u* = 0` enforced by subtracting the mean), mirror ghost for the moving lid. Code: `src/tensorfvm/lid_cavity.py` (`LidCavitySolver.tendencies`, `.solve_pressure`, `.step`, `.run`), scoring in `score_against_ghia`/`ghia_acceptance` in the same module.

Round-2 additions are cost and evidence, not physics (`scripts/run_cavity_re1000_m15458.py`): grid continuation with bilinear prolongation of the cell-centred velocity, per-case checkpoints, a cold-start run on the same grid to prove continuation does not change the steady state, and a per-resolution 5 % verdict (`judge_5pct`). Method survey and selection: `docs/CASE-CAVITY-RE1000-FVM/method-selection.md`.
