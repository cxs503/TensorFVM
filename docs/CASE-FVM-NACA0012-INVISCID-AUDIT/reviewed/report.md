===============================================================

结论摘要
--------

Cl(α=2°) 计算值 **0.241279**（400 面板/侧 = 800 面板；法向残差 2.3e-15，Kutta 残差 4.4e-16）。

* 对薄翼理论精确 2πα = 0.219325：**+10.01%**；对卡片值 0.2198：**+9.77%**。
  **> 3% → 判据不通过（honest FAIL）**。
* 该偏差不是数值误差，而是 **12% 厚度效应**：无粘（位流）解对对称厚翼型的升力斜率高于零厚度极限。
  厚度扫描给出近线性 Cl/Cl_thin ≈ 1 + 0.83 (t/c)（§5.2），与 Joukowski 对称翼型精确解
  Cl_α = 2π(1 + m_a/a)（几何关系 t/c ≈ 1.24 m_a/a ⇒ 斜率修正 ≈ 0.8 (t/c)）同斜率。
  ⇒ 本算例的判据（对标零厚度极限）与算例几何（12% 厚度）不自洽，见 §6 F-A。
* 与 Abbott & von Doenhoff (1959) 原表数值的对照 **未能完成：原文数值未取得 → WITHHELD**（§1）。

① 问题与参考出处
----------------

物理问题：NACA 0012（对称四位数翼型，t/c = 12%），无粘不可压绕流，α = 2°，求 Cl。
无粘问题的解由「无穿透 + 后缘 Kutta 条件」唯一确定。参考量（题目卡片）：

* **薄翼理论**：Cl = 2π·α，α = 2° ⇒ 2π·(2π/180) = **0.219325**；卡片标 0.2198
  （相对精确值 +0.22%）。出处：Glauert 薄翼理论，见 Abbott & von Doenhoff,
  *Theory of Wing Sections*, 1959（卡片给定 DOI 次级标识 10.1017/s0368393100116724）。
* **Abbott & von Doenhoff 1959 的 NACA 0012 数据（M = 0.3，无粘）**：
  **未取得原文表/图数值 → WITHHELD**。本机网络只放通部分域名（crossref 200、
  airfoiltools 200、pypi index 200）；NACA TR 824 原文在 NTRS 返回 403 Forbidden，
  archive.org 与 GitHub raw 不可达（Connection refused / reset），pip 源不提供
  XFOIL/NeuralFoil 类包。**不伪造任何 Abbott 数值**，该项对照留空并标 WITHHELD（摩擦 F1）。

判据（卡片）：|Cl − 0.2198| / 0.2198 < 3%，指标 Cl(α = 2°)。

② 方法与实现
------------

实现文件：`src/tensorfvm/panel_airfoil.py`（新增模块），复用 TensorFVM 既有面板族
（`panel_potential` 的面板数据结构/源核思路、`body_fitted._naca4_profile` 的 NACA 四位数几何）。

方法：**常值源 + 单一常值涡的二维升力面板法**（Hess & Smith 1967；Katz & Plotkin 2001 ch. 11）

* 未知量：N 个面板源强度 σ_j + 1 个全场统一涡强度 γ（共 N+1）。
* N 个 Neumann 条件（面板中点 V·n = 0）+ 1 个**等压 Kutta 条件**：
  后缘上、下表面面板等压，写作 V_t(first) + V_t(last) = 0
  （闭合遍历切向在上表面朝上游、下表面朝下游，等压在切向投影上反号）。
* 影响系数：非奇异面板用 **4 子段 × 8 点 Gauss–Legendre** 积分精确 2-D 核
  `(r−r')/(2π|r−r'|²)`（涡核为其 90° 旋转）；自面板用解析极限（源 +σ/2 沿外法向、涡 +γ/2 沿切向）。
  *先试闭式影响系数（Katz & Plotkin 10.20–10.23）*：张角分支在近场复现出错误符号（圆柱速度反号），
  逐分支排错成本高于改回细分求积，故保留求积路线，由圆柱解析解与面板加密两条判据验证（§5.4、§5.1）。
* 两条独立力通道：面板压力积分 Cl = −∮Cp·n_y ds / c（报告值）与环量 2Γ/(Uc)
  （`AirfoilPanelResult.cl_joukowski`，仅作内部一致性参考）。
* 无量纲化：c = 1、U = 1、ρ = 1 ⇒ q = 1/2；α 正为抬头，来流 (cosα, sinα)。

为什么不用仓库里的 `body_fitted`（SIMPLE）：它是**粘性**求解器，无粘极限（ν→0）数值上不可达——
升力将由数值耗散而非 Kutta 条件决定，Re 取多大都没有可判定值；仓库无无粘/欧拉二维翼型分支
（摩擦 F2）。故本轮新增面板法，不改既有求解器。

近线性：Cl/Cl_thin ≈ 1 + 0.83 (t/c)（0.02→0.795/t/c，0.15→0.837/t/c）。
Joukowski 对称翼型精确解 Cl_α = 2π(1 + m_a/a)，其 t/c ≈ 1.24 m_a/a ⇒ 斜率修正 ≈ 0.8 (t/c)，

**5.3 Kutta 条件形式**：线性等压（V_t1 + V_tN = 0）与一维求根真等压
（|V_t1| = |V_tN|，brentq 扫描 γ ∈ [−0.4, 0.4]）在 N=200 给出同一解（Cl = 0.24115 两者一致，
唯一根），故线性化不引入偏差。Morino/驻点形式在本几何上使方程近奇异（Cl 爆到 1e10），已弃用。

⑥ 失败模式、工件与生态摩擦
--------------------------

**失败模式（如实记录）**

* F-A **判据未通过**：Cl 与薄翼理论差 +10.01% > 3%。根因是判据不适用于 12% 厚度翼型
  （薄翼理论是零厚度极限），由 §5.2 厚度标度独立佐证。若判据改为「vs 含厚度位流参考」，
  本实现足以支撑 <1% 对标——缺的只是可信的原文数值（WITHHELD）。
* F-B 薄几何（t/c = 0.02）在 N=400（200/侧）时给 0.1090（半个理论值），加到 N=800（400/侧）才收敛到
  0.22282。⇒ 薄翼型的上下表面近邻面板需要更细的面板/求积，低分辨率下等压行退化。这是实现适用范围边界。
* F-C 后缘面板速度不收敛（见 §5.1），不影响 Cl；已量化。
