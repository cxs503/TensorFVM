## 1. 案例介绍（物理背景 / 几何 / 参数）

差热方腔（differentially heated square cavity）：边长 `H = 1` 的二维方腔，
左壁热 `θ = +0.5`、右壁冷 `θ = −0.5`、上下绝热、四壁无滑移，Boussinesq 浮力。
以自由落体速度 `U = sqrt(gβΔT H)` 与 `H` 无量纲化：

```
du/dt + div(u u) = -grad p + sqrt(Pr/Ra) lap(u) + θ e_y
dθ/dt + div(u θ) = lap(θ)/sqrt(Pr Ra)
```

| 参数 | 值 |
|---|---|
| 普朗特数 `Pr` | 0.71 |
| 瑞利数 `Ra` | 1e5、1e6 |
| 网格 N（每边单元数） | 16 / 32 / 64（Ra=1e5）；32 / 64（Ra=1e6） |
| 基准 | de Vahl Davis (1983)：`Nu = 4.519`（Ra=1e5）、`8.800`（Ra=1e6）；`|ψ|max = 9.111`、`16.750` |
| 验收门 | `|Nu − Nu_ref|/Nu_ref ≤ 3 %`（`docs/benchmarks/incompressible-verification.md`） |

**要判的问题**（来自该文档 §2.1 与 `docs/verification-gap-audit-m7555.md` §2.2）：

> NC `Nu` error, Ra = 1e5 (N32) | +3.4 % | < 3 % | **FAIL** (marginal)
> NC `Nu` error, Ra = 1e6 (N64) | +3.1 % | < 3 % | **FAIL** (marginal)

两条边际 FAIL 都只有单网格证据，无法区分 (a) 网格截断（加密即消除）与 (b) 离散算子偏置（加密不消失、必须改格式）。

## 2. 怎么做的（方法 / 流程 / 工具链）

1. **同一求解器复算**：`incompressible_benchmarks.natural_convection`（交错 MAC + van Leer 限制的
   有限体积，与归档证据同一代码路径），`cfl = 0.25`，`tolerance = 1e-7`（逐步速度变化），
   `max_steps = 400000`。N=16 复算得 `Nu = 5.1151`，与归档 `raw_natural_convection_Ra1e+04…`
   同网格值逐位一致（复现性证据）。
2. **两种独立的壁面热流估计量**（新增，`src/tensorfvm/verification/natural_convection_gci.py`）：
   - `half_cell`：`Nu = (θ_w − θ_P1)/(h/2)`——即离散能量方程所用的通量，但对真解的截断误差为 `O(h)`（`−θ''h/4`）；
   - `quadratic`：过「壁面值 + 前两个单元平均值」的二次重构，`b = (3A − B/2)/h`
     （`A = θ_P1 − θ_w`，`B = θ_P2 − θ_P1`），`Nu = −b`，二次剖面精确、对光滑场 `O(h²)`。
   两者之差是**估计量截断**的量度，从而把「后处理误差」与「流场误差」分开（这是本单要证伪的第一个假说：
   「边际 FAIL 只是后处理一阶差分造成的」）。
3. **收敛诊断**：三网格 Richardson + Roache GCI（复用仓内 `verification/richardson.py`，
   理论阶 2），给观测阶 `p`、外推极限 `Nu_∞`、GCI 带与 `convergence` 标签；
   序列非单调时**不**给出外推（诚实降级）。
4. **稳态审计**：每算例记录残差历史、`converged` 标志、步数、`dt`、最大散度（`fig3`），
   欠收敛算例不得作为网格收敛证据引用。
5. 全部数字由 JSON 程序化注入报告；图由 `summary.json` 渲染。

## 3. 计算结果（数字表，全部来自 `summary.json`）

### 3.1 Ra = 1e5

| N | Nu（half-cell） | 误差 vs 4.519 | Nu（quadratic） | 误差 | `\|ψ\|max` | 误差 vs 9.111 | 收敛 |
|---|---|---|---|---|---|---|---|
| 16 | 5.1151 | +13.19 % | 5.9078 | +30.73 % | 11.330 | +24.4 % | 是 |
| 32 | 4.6721 | +3.39 % | 4.7807 | +5.79 % | 9.816 | +7.7 % | 是 |
| 64 | **4.5591** | **+0.89 %** | 4.5717 | +1.17 % | 9.622 | +5.6 % | 是 |

观测阶（32/64/128→16/32/64 三点均匀加密）`p = 1.97`（单调序列，落在渐近区）；
Richardson 外推 **`Nu_∞ = 4.5205`，vs de Vahl Davis 4.519 误差 +0.03 %**，GCI 带见 `summary.json`。

### 3.2 Ra = 1e6

| N | Nu（half-cell） | 误差 vs 8.800 | Nu（quadratic） | 误差 | `\|ψ\|max` | 收敛 |
|---|---|---|---|---|---|---|
| 32 | 9.7781 | +11.11 % | 11.1104 | +26.25 % | 19.741 | 是 |
| 64 | **9.0701** | **+3.07 %** | 9.2606 | +5.23 % | 17.111 | 是 |

只有两网格，**不能**算观测阶，也不给外推（诚实：N=128 的补算本单未完成，见 §5）。

### 3.3 估计量截断（`Nu_quad − Nu_half`，Ra=1e5）

| N | 差值 | 相对 |
|---|---|---|
| 16 | 0.7926 | 15.5 % |
| 32 | 0.1086 | 2.3 % |
| 64 | 0.0125 | 0.27 % |

差值按 `~O(h²)` 衰减（比 7.3 → 8.7），而 half-cell 的误差 13.19 % → 3.39 % → 0.89 %
按 `~O(h²)` 收敛到基准——**结论：一阶差分并非误差主项**，本单的假说「边际 FAIL 是后处理截断」
被否定（见 §6 负面结果）。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **只有单网格的证据不足以判 FAIL**：Ra=1e5 在 N=32 是 +3.39 %（FAIL），N=64 是 +0.89 %（PASS），
   判据的结论完全由网格决定。验收表应写「**网格要求**」而不是只写一个 FAIL。
2. **`Ra=1e6, N=64` 的 +3.07 % 仍未清偿**：两网格无法给阶，外推不可信；需要 N=128（甚至 96/192 序列）。
   该算例单核 N=64 约 65 s，N=128 约 15 min 量级，本单受 shell 单次 120 s 时限未完成——
   **如实记为未完成**，不当作已通过。
3. **`|ψ|max` 的误差远大于 Nu**（N=64 时 +5.6 %）：流函数极值位于低梯度区、对网格更敏感，
   不宜与 Nu 用同一个 3 % 门，建议单独设门（如 10 %）。
4. **二次重构在粗网格上更差**（N=16 时 Ra=1e6 的 `quad` 是 +61 %）：边界层内剖面不光滑时高次重构放大噪声，
   只有当 `h ≪ δ` 才更准；报告两者而不只报好的那个。
5. 适用范围：`Pr = 0.71`、`Ra ≤ 1e6`、稳态层流、均匀网格；不适用于湍流/非定常震荡分支。

## 6. 误差判定（关键量 vs 基准，逐项）

| 量 | 值 | 基准 | 误差 | 是否 < 3 % |
|---|---|---|---|---|
| Nu (Ra=1e5, N=64, half-cell) | 4.5591 | 4.519 | **+0.89 %** | **是** |
| Nu (Ra=1e5, Richardson 外推) | 4.5205 | 4.519 | **+0.03 %** | **是** |
| Nu (Ra=1e5, N=32) | 4.6721 | 4.519 | +3.39 % | 否（旧 FAIL，已定位为网格不足） |
| Nu (Ra=1e6, N=64, half-cell) | 9.0701 | 8.800 | +3.07 % | 否（**未清偿**，需 N≥128） |
| 观测收敛阶 (Ra=1e5) | 1.97 | 2（van Leer 二阶） | −1.5 % | 是 |

**负面结果/假说否定**：「边际 FAIL 由一阶半单元壁面差分（后处理截断）造成」——**否定**。
证据：二次重构（后处理二阶）在同网格上并不更接近基准（N=64：4.5717 vs 4.5591），
而 half-cell 误差按 `p≈1.97` 收敛到基准；误差主项是流场在壁面边界层内的离散误差，与后处理阶无关。

**建议新条目（供总账）**：`VERIFY-FVM-NATCONV-GCI`（域：FVM 验证面）——
验收：①Ra=1e5 `Nu` 在 N≥64 上 `≤3 %`（已达成 +0.89 %）；②Ra=1e6 `Nu` 在 N≥128 序列上给观测阶与外推，
外推误差 `≤3 %`；③两 Ra 的 `|ψ|max` 单独设 10 % 门并清偿。
