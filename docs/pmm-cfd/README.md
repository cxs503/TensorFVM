### 1.1 几何必须先过门（本轮发现的问题 1）

仓内 `tensorfvm.kvlcc2_geometry.KVLCC2HullOffsets` 自述为 "simplified/approximate"。
把它的型值表沿 x、z 双向积分得 **Cb = 0.6355**（目标 0.708，偏低 10.2%）、**Cwp ≈ 0.745**（目标 0.90）。
按平台规则「几何必须先验证 Cb/L/B」，该表**不能**直接进 CFD。

因此本轮重建了参数化船型 `KVLCC2Hull`（平行中体 + 抛物型艏艉进水段 + 超椭圆剖面族），
用**只依赖几何形状参数**的三重单调二分标定（不拟合任何水动力结果）命中公开积分量：

| 量 | 计算值 | 目标 | 偏差 |
|---|---|---|---|
| Cb | 0.7095 | 0.708 | **+0.20 %** |
| Cwp | 0.9012 | 0.9005 | +0.08 % |
| LCB | −1.715 % L | −1.688 % L | −0.027 % L |
| ∇ | 1.5897 m³ | 1.5865 m³ | +0.20 % |

离散（体素/型线离散）收敛另测：Cb(120×60×40) = 0.7139 → Cb(240×120×80) = 0.7121 → 解析值 0.7094。
**几何门判据（Cb 偏差 ≤ 0.5 %、L/B/T 精确、LCB ≤ 0.05 % L）：PASS。**

## 2. 怎么做的（方法与工具链）

1. **几何**：`KVLCC2Hull`（参数化、可标定、积分自检）→ 型线/剖面输出、体素化。
2. **剖面水动力（REAL）**：椭圆剖面 2D 势流附加质量 `m = ρπT²`/单位长度
   （Lamb 1932, art. 71；双体镜像不改该值）→ 细长体条带积分
   `Y = ∫ dF`, `N = −∫ (x−L/2) dF`。
   3D 长椭球解析解 `spheroid_added_mass`（Lamb art. 114）作为独立校验：
   球极限 → 0.5·ρ∇、细长极限 → 1.0·ρ∇，均已通过测试。
3. **粘性阻尼（EMPIRICAL，明确降级）**：横向绕流阻力 `0.5ρCdT(x)v|v|`，`Cd = 1.0`（经典条带常数）。
   **没有求解粘性流场**，这是本轮最主要的物理缺口。
4. **PMM 运动学**：纯横荡 `y=A sin ωt → v = Aω cos ωt`（沿 x 均匀）；
   纯首摇 `ψ=A sin ωt → r = Aω cos ωt, v(x) = (x−L/2)r`（线性剪切）。
5. **导数提取（REAL，机器自检）**：末 3 个周期最小二乘一阶谐波
   `Y = Y_cos cos ωt + Y_sin sin ωt`：
   `Y_v = Y_cos/(Aω)`, `Y_v̇ = −Y_sin/(Aω²)`（首摇同理给 `Y_r, Y_ṙ, N_r, N_ṙ`）。
   提取器用**合成信号注入真值**验证：恢复误差 < 1e−6（相对），并验证 3ω 倍频噪声不串入一阶谐波。
6. **三条扫描**：振幅 A/L = 0.005/0.01/0.02；站位积分 21/41/81；外加参考数据一致性审计。

工具链：Python 3.11 + numpy 2.4（无外部 CFD 依赖）；`pytest` 23 项全通过；
图由 `scripts/pmm_report_figures.py` 程序化生成（数据零手抄）。

### 3.3 关键审计发现（本轮最有价值的确定性结论）

仓内 `tensorfvm.simman2021_reference` 的**导数表与其自身漂移表自相矛盾**，且量级物理不可能：

1. **一阶一致性**：漂移表一阶拟合给出 `∂Y'/∂v' = −0.131`、`∂N'/∂v' = −0.053`，
   而导数表给 `Y_v' = −0.037`、`N_v' = −0.0084`，比值 **3.54× / 6.28×**。
   两表用同一无量纲化、同一工况，不可能同时成立。
2. **附加质量物理不可能**：由 `Y_v̇' = −0.0125` 反推 `m22 = 104.5 kg`，
   即 **m22/(ρ∇) = 6.6 %**；势流理论对油轮给出 **50–100 %**（细长体 `ρπT²L` 本船为 1.618·ρ∇，为上限）。
   参考值比理论下限小一个量级以上。
3. 由此：**任何以该导数表为"基准"的 PMM 验证（含仓内 `pmm_virtual_test` 的校准式实现）都是循环论证**——
   其力模型系数直接取自参考表（`KVLCC2ForceModel._calibrate`），所报"吻合"不构成证据。

## 5. 注意点（踩过的坑、局限、适用范围）

### 5.1 本轮失败并回退的两个 CFD 引擎（留证，勿重复踩）

1. **3D 双体势流（浸入边界/阶梯壁面 Neumann 通量）附加质量**
   * 球解析检验（精确 0.5ρ∇）：初版 Dirichlet 钉死体表势 → 退化到平凡解 φ≡ψ（错）；
     改扰动势 + 壁面通量后仍只有 **0.4×解析值**且衰减指数不对（应在 (a/R)³ 收敛）；
   * 根因未查清（阶梯法向 vs 真实法向、面值插值、盒尺度截断三者耦合）。**未发布。**

2. **2D 不可压 NS（伪谱 + Brinkman 罚）受迫振荡剖面力**
   * 验证算例 1（椭圆势流附加质量 `ρπb²`）：曾读到 −1.6 % 的"吻合"，后确认是**伪吻合**
     （用的是错误解析式 `ρπa²`，且力估计含内域惯性假项）；
   * 验证算例 2（Stokes 第二问题：`τ = ρU√(νω)`，相位 +45°）：罚冲量法给 **36×** 偏大、
     相位 **−91°**；全域动量法（周期盒 `F = −dM/dt`）被**闭盒排流**污染（4–7×）。
   * 结论：**罚浸入体 + 周期盒**的力的量测需要更细的界面处理与盒尺度收敛研究，
     单会话内未能闭合。**未发布。**

### 5.2 条带模型的固有局限（决定了 C1 必然 FAIL）

- 剖面对称 → 纯横荡下 `N_v ≡ 0`、纯首摇下 `Y_r ≡ 0`：**纵向不对称/艏艉升力/艉部分离完全缺失**；
- 无 3D 流动 → 有限长修正缺失（细长体 `∫ρπT²dx` 比 3D 实际值高约 2×）；
- 粘性部分只有单一 `Cd`，无 Re 依赖、无分离演化；
- 因此本模型**不能**用于操纵性预报，只能做量级/趋势与提取链验证。

### 5.3 适用范围

`pmm_cfd` 当前的可用部分：几何重建与门检、剖面附加质量的解析值、PMM 运动学、
导数提取与审计工具链。**不可**用于工程导数交付。
