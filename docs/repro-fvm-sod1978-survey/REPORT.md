## ① 案例介绍

Sod (1978) 是一篇**综述**：它的内容不是某一个格式，而是若干经典格式在同一个激波管上的
横向对比。此前该锚点的四轮工作（`sod1978.py` 收敛性 / `sod1978_contact_limit.py` /

## ② 怎么做的

新增 `src/tensorfvm/verification/sod1978_survey.py`，按论文所 survey 的格式**原样**实现五种格式
（无限制器；除 Godunov 外不含任何近似黎曼解）：

| 格式 | 更新式 | 设计阶 |
|---|---|---|
| Lax-Friedrichs (1954) | U_i' = ½(U_{i−1}+U_{i+1}) − Δt/(2Δx)(F_{i+1}−F_{i−1}) | 1 |
| Rusanov (1961) | 面通量 ½(F_i+F_{i+1}) − ½·a_local·(U_{i+1}−U_i) | 1 |
| Godunov | 每个面取**精确**黎曼解在 ξ=0 的状态作通量（Toro 压强函数二分求 p\*） | 1 |
| Lax-Wendroff（Richtmyer 两步） | 半步预测 + 校正，面通量取 t+Δt/2 | 2 |
| MacCormack | 前差预测 + 后差校正 | 2 |

公平性设置（写作前固定，运行后未做任何调整）：

- 五种格式全部写成**通量差分形**，同一网格、同一条 CFL 规则（每步按全局 max(|u|+c) 重算 Δt，最后一步裁剪到精确落在 T），因此比较的是空间算子；
- 判据阈值写死在模块顶部 `THRESHOLDS`，并在**任何运行之前**落入工件 `thresholds_declared_before_run`；
- 参考解来自 `sod1978.exact_sample()`（自带 NumPy 精确黎曼解，且已被 `sod1978_oracle.py` 用 8 道结构无关的检查独立验证），不用被测格式自证；
- 阶数判据用**精确**光滑解：p、u 均匀、ρ = 1 + A sin(2π(x − u₀t)) 是 Euler 方程的精确熵波解（p 为常数时动量/能量方程退化为质量方程的倍数），不是线性化，参考解在任意时刻、任意振幅都成立；
- 守恒判据 S1 用**通量预算**而不是总量漂移：开放域里动量本来就不守恒（两端压强做功），所以记录 sum(U(T)) − sum(U(0)) + Σ_steps (Δt/Δx)[F(U_last) − F(U_first)] = 0，这才是「通量差分形」这个性质的严格表述。

## ⑤ 注意点（含本轮的自身缺陷修正）

- **没有解析原论文 PDF**。本轮的「论文数字」不是从 pdf 里抄的：格式定义按论文所述实现，判决量全部相对**独立精确解**测量；论文的定性主张（一阶扩散大、二阶不单调）被转成量化判据，而不是「和某张表对一对」。这是本轮诚实边界，写在明处。
- Lax-Friedrichs 与 Rusanov 数学上**同族**（LF = Rusanov 取全局最大扩散系数 Δx/Δt）。实测二者 L1(ρ) = 4.2492e-02 vs 2.4847e-02、接触厚度 16.38 vs 16.57 cells：在本问题上几乎重合，说明「扩散系数取全局常数还是局部」不是这两个数差异的来源——这一点用数字说出来，比复述教科书身份更有信息量。
- **判据度量在开发中被修过两次，如实记录**：(1) S4 最初只用 ρ 的越界衡量单调性，实测 Lax-Wendroff 的 ρ 越界为 %s（几乎为 0），而它的 u/p 在激波后有可见振荡——密度单场不足以刻画单调性，故改为 ρ/u/p 三场按各自精确值域归一化后的最大越界（阈值未动）；(2) 接触厚度最初取「最外侧」的一对等值穿越点，对振荡解会把厚度放大一个量级（把 LW 报成 30+ cells），故改为取接触两侧最近的穿越点。两次都是**度量缺陷**，不是阈值调整，修正后的数字全部重算。
- MacCormack 的 honest FAIL：纯格式（无人工粘性）在 nx=100、CFL=0.4 下于 t = 0.0216 丢失正性（p ≤ 0），因此不计入 S1/S3/S4 的判据——这恰好是综述里对非单调格式要加耗散的理由，本轮把它当**结论**记录，而不是当实现缺陷掩盖。
- S4 的度量分两类，理由要写清：一阶单调格式的有界性是对**守恒量**说的，故用 ρ 的越界（三格式实测 0）；但**原始量** u = (ρu)/ρ 是两个有界量之比，会越出精确值域（Rusanov 1.59e-03、Godunov 1.32e-02，Lax-Wendroff 3.43e-01），这是被测量出来的事实，不构成「一阶格式不单调」的反例，也不拿它当判决量。
- 阶数判据用**光滑**熵波，不拿激波管本身量阶：TVD/单调格式在间断上不可能达到设计阶，把两者混在一张表里是常见的错误归因。
- 接触厚度对本问题只在两侧平台可分辨时有效；nx 很小时会饱和在 1–2 cells。
