# FVM verification surface for incompressible internal flow

Generated by `tensorfvm.internal_flow.report` on 2026-11-07T10:05:16Z from the ledger `outputs/internal-flow-verification/summary.json`.  Every number below is injected from that ledger; the PNG files next to it are the figures.

Three classical laminar benchmarks, computed with an independent staggered-MAC finite-volume solver (`tensorfvm.internal_flow.mac.StaggeredMAC`, van Leer limited convection, DCT/FFT pressure projection) that shares no code path with the LBM verification chain:

1. backward-facing step, expansion ratio 2 -- reattachment length, wall friction distribution, mesh sequence, and both Reynolds-number conventions ($Re_H=400$, which is the literature convention, and the literal $Re_H=800$);
2. planar sudden expansion, $AR=4$, $Re_D=100$ -- reattachment length, loss coefficient vs Borda-Carnot, static-pressure recovery vs the momentum balance;
3. differentially heated square cavity, $Pr=0.71$, $Ra=10^4,10^5,10^6$ -- mean Nusselt number vs de Vahl Davis (1983).

## 1 Cases and parameters

**Backward-facing step.**  Domain $22H \times 2H$ ($H$ = step height = inlet channel height), expansion ratio 2, fully developed parabolic inlet over $y\in[H,2H]$, no-slip walls, zero-gradient outlet.  Reynolds number $Re_H=U H/\nu=400$ in the primary run ($Re_{D_h}=2Re_H$ is the inlet hydraulic-diameter count used by Armaly *et al.* and Gartling; see 3.1 and 3.1b). Meshes H/10, H/20; CFL 0.4.

**Planar sudden expansion.**  Symmetric expansion from $h_1=D/4$ to $D$, uniform inlet $U_{in}=1$, $Re_D=U_{out}D/\nu=100$, length $12D$, no-slip walls, zero-gradient outlet. Meshes D/20, D/40; CFL 0.45.

**Natural-convection cavity.**  Unit square, hot left wall ($\theta=+1/2$), cold right wall, adiabatic top/bottom, Boussinesq buoyancy with free-fall scaling ($\nu=\sqrt{Pr/Ra}$, $\alpha=1/\sqrt{Pr Ra}$), $Pr=0.71$.  Meshes: $Ra=1e+04$: 32/64, $Ra=1e+05$: 48/96, $Ra=1e+06$: 64/128; CFL 0.45.

## 2 Method

* staggered MAC grid, conservative flux-form convection with van Leer (harmonic TVD) face reconstruction for $u$, $v$ and $\theta$;
* compact central diffusion, no-slip walls by mirror ghosts, wall shear from the same ghost (so $C_f$ and $Nu$ use the same discretisation as the momentum/energy fluxes);
* projection with a homogeneous-Neumann pressure Poisson problem solved by the orthonormal DCT-II diagonalisation of the cell-centred Laplacian; the transforms run through FFTs (`_dct.py`, verified against the dense matrix to 1e-13);
* channel cases add a global outflow-flux correction so that the discrete compatibility condition holds to machine precision;
* explicit forward-Euler pseudo-time marching to a steady state; grid sequencing initialises each finer mesh from the coarser solution;
* steady state is declared from the velocity residual (cavity) or from the stationarity of the reattachment length / loss coefficient (step, expansion), whichever is the slow quantity.

## 5 Notes, limitations, applicability

**Wall-clock budget of the meshes.**  The study is an explicit projection solver (CFL/diffusion-limited time step), so the cost grows with the number of steps to a steady state and with $n^3$ in each direction.  The mesh sequences that were affordable in this run are listed per case in section 3; where the finest requested mesh ($H/80$ for the step) is absent the row is missing rather than interpolated.

**Explicit diffusion limit.**  The step size uses $0.18 h^2/\nu$ instead of the textbook $0.25 h^2/\nu$: with the mirror-ghost wall treatment the near-wall diagonal is $3\nu/h^2$, and a straight channel run at $h^2/(4\nu)$ is measurably unstable (`tests/test_internal_flow_mac.py` pins the stable branch).

**Outlet.**  The channel cases use a zero-gradient (Neumann) pressure outlet plus a uniform outflow-flux correction that makes the discrete compatibility condition hold exactly.  The last cell column therefore carries the residual of the projection instead of the interior; that column is excluded from the reported divergence and the friction samples near the outlet are noisier ($C_f$ at the BFS outlet oscillates by a few $10^{-3}$).

**Grid sequencing.**  Every finer mesh starts from the prolonged steady state of the coarser one.  This changes the cost of the study, not the converged solution (the equations being solved are unchanged; `test_prolongation_preserves_a_linear_profile` covers the operator).

**Backward-facing step: two normalisations.**  $L_r$ is reported both in step heights and in downstream-channel heights ($H_{out}=2H$).  The literature value (Gartling 1990) and the campaign target are in downstream-channel heights; mixing the two conventions is the usual way to be off by exactly a factor of two here.

**Sudden expansion: which $K$.**  $K_{{raw}}$ is the flux-weighted total-pressure difference between the inlet and outlet planes; it contains the wall friction of the whole downstream length.  Borda-Carnot neglects all wall friction, so the comparison is made with $K_{corrected}=K_{raw}-K_{friction}$, where $K_{{friction}}$ comes from the *resolved* wall shear through the momentum balance (no developed-profile assumption).  $K_{{fitted}}$, obtained by extrapolating the linear total-pressure decay back to the step plane, is reported as a cross-check: it is more sensitive to the fit window and to the outlet noise.

**Sudden expansion: not mesh converged.**  At $D/40$ the two wall bubbles are still asymmetric (bottom and top $L_r/D$ differ by a factor 2.9 in the table of section 3.2) although the geometry is symmetric -- the block stopping rule fired before the second bubble had settled.  Together with the $D/20\to D/40$ change of $L_r/D$ (3.48 -> 2.47) this says the expansion case is *not* mesh converged, which is why neither its loss coefficient nor its recovery coefficient passes the 5% band; both are reported as honest FAILs rather than averaged away.

**Natural convection: sub-3% at $Ra=10^6$ needs the fine mesh.**  At $Ra=10^6$ the thermal boundary layer is thin, so the coarse mesh over-predicts $\overline{Nu}$; the sign of the mesh effect is physical (the wall-normal gradient is evaluated with a half-cell difference) and it is the reason the finest mesh is the reported value.

**Streamfunction/velocity references.**  *Updated by m16902.*  These were labelled an "unverified transcription" that "disagrees with a physically consistent ``|psi|_max`` by a factor ~3". That diagnosis was wrong twice over: (i) ``u_max`` and ``|psi|_max`` are different quantities (their ratio is 0.313 here), so a factor ~3 is expected; (ii) ``NaturalConvectionCase.diagnostics`` took ``argmax`` of the *signed* streamfunction, whose primary vortex is negative, so it returned ``psi_max ~ 0`` at a corner zero of ``psi``. With that defect fixed (m16902) the anchors agree with the de Vahl Davis acceptance family within 1 % at ``Ra = 1e3`` and ``1e4`` (``|psi|_max = 5.106`` at n=32 and ``5.082`` at n=64 vs 5.071; ``u_max``/``v_max`` 0.15-0.35 %). See ``docs/verification-cavity-anchor/{{REPORT.md,summary.json}}`` and ``docs/VERIFICATION_DEBT_LEDGER.md`` D15. The reference *variant* registry lives in ``src/tensorfvm/verification/reference_families.py``.
