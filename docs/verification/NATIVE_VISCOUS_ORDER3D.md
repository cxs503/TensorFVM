# NativeViscous3D 精度阶审计：线性精确、内部二阶、Dirichlet 壁零阶

审计对象：`tensorfvm.native_viscous3d.NativeViscous3D`（`native_collocated3d` /
`native_rans3d` / `native_sst3d` 实际装配的黏性算子及其
`momentum_diffusion_matrix`）。

工具链：`src/tensorfvm/verification/native_order3d.py`（制造解 + 三套测量）、
`scripts/audit_native_viscous_order3d.py`（跑表出图）、
`tests/test_native_viscous_order3d.py`（把实测结论钉成回归）。
产物：`runs/native_viscous_order3d.json`、`runs/native_viscous_order3d.png`。

## 1. 制造解与测量口径

单位立方体剖成 n³ 六面体（面全部三角化，`triangulate_faces=True`），家族 n=4/8/16，
两种几何：`warp=0`（正交）与 `warp=2`（顶点正弦扰动 12%，非正交）。黏度 μ=1.3，
全边界 Dirichlet、边界数据取制造解精确值。

制造解：

    u = ( sin(πx) cos(πy/2) e^z ,  cos(πx/2) sin(πy) e^{-z} ,  sin(πx) sin(πy) z )

解析应力 τ = μ(∇u + ∇uᵀ − ⅔ tr(∇u) I)，解析散度
div τ = μ(∇²u + ⅓∇(div u))。解析式本身用中心差分独立复核（相对误差 <1e-7，
见 `test_analytic_stress_divergence_matches_finite_differences`）。

三套测量：
① **截断**：`(1/V)Σ_f τ_h·S_f` vs 解析 div τ 在单元中心，拆成内部单元 / 贴壁单元；
② **面牵引**：面牵引相对于解析 τ·S 的每单位面积误差（内部面 / 壁面），
   以及壁面法向导数 ∂u/∂n（决定壁面剪切）；
③ **解**：解 Dirichlet 扩散问题 div τ(u)=0（精确边界数据），与制造解比较。

## 2. 实测结果（warp=0，μ=1.3）

| 量 | n=4 | n=8 | n=16 | 阶 |
|---|---|---|---|---|
| 仿射场面牵引相对误差 | 4e-16 量级（测试断言 <1e-12） | — | — | 机器精度 |
| 截断 L2（全单元） | 3.161 | 2.548 | 1.960 | 0.31 / 0.38 |
| 截断 L2（内部单元） | 1.204 | 0.2803 | 0.0879 | **2.10 / 1.67** |
| 截断 L2（贴壁单元） | 3.348 | 3.342 | 3.187 | **0.003 / 0.07** |
| 截断 L∞（贴壁单元） | 6.826 | 7.953 | 8.397 | 误差反而增大 |
| 面牵引相对误差（内部面） | 11.53% | 4.56% | 2.18% | 1.34 / 1.07 |
| 面牵引相对误差（壁面） | 13.74% | 6.92% | 3.55% | 0.99 / 0.96 |
| 壁面 ∂u/∂n 相对误差 | 6.19% | 2.76% | 1.35% | 1.17 / 1.03 |
| 扩散解 L2（相对场幅） | 0.380 (17%) | 0.358 (14%) | 0.352 (13%) | **0.086 / 0.025** |
| 扩散解 L∞ | 0.841 | 0.870 | 0.892 | 不降 |

非正交（warp=2）：解 L2 = 0.348(n=8) → 0.341(n=16)；内部单元截断在 n=16 恶化到
1.173（正交网格同网格 0.0879），即非正交修正把内部精度从二阶拉到接近零阶。

负控（一维场 u=(sin πx,0,0)，排除三维耦合与体积项）：解 L2 = 0.2531 → 0.2377 →
0.2337（阶 0.09 / 0.02），与三维结论一致，不是三维特例。

## 3. 定因

- 算子在**仿射场**上机器精度精确（线性精确），故不是索引/符号/体归一错误。
- 但与解析值相比**面法向导数只有一阶**（6.19%→2.76%→1.35%）。原因是闭包
  `g_face = interp(g_cell) + (S/(S·d)) (Δu − d·g_cell)`：括号内两项差正是曲率项
  O(h²)，除以 |d|~h/2 后只剩 O(h)，曲率未被模型化。
- 面通量误差 ε~O(h)·(单位面积量) 除以控制体 V~h³ 即 O(1)：**贴壁单元的局部截断
  误差是零阶**，这正是贴壁截断 L2 在 3.25 附近不降、L∞ 反而增大的机制；壁面通量
  一阶不一致 → Dirichlet 扩散解不收敛（阶 0.09/0.03，L∞ 增长）。
- 内部单元看似二阶，是同一单元相对两面上的一阶误差相互抵消（求和按相反符号）
  的结果，不是通量本身的二阶性。

## 4. 影响与适用范围

- 壁面剪切/摩擦阻力类量：一阶收敛（可用，但需网格足够密，且不能指望二阶外推）。
- 以 `momentum_diffusion_matrix` 作 Dirichlet 扩散/隐式黏性步时：**无可测收敛阶**，
  精细网格不会自动减小误差（本算例卡在 13%~17% 场幅）。RANS/SST 求解器里该算子
  的精度上限由此决定，任何精调网格的高 Re 结果都应带这一保留。
- 非正交修正方向已知有缺陷（m2431/m2506/m2505 系列）：本单进一步给出定量后果。

## 5. 未做 / 建议下一步

- **未改默认实现**：修复需要二次重构（壁面用二次重构或镜像点补曲率项，
  内部面用二次/最小二乘二次梯度），属结构改动，不在验证单范围内。
- 建议单：`壁面曲率修正的二次重构闭包 + 二阶通量认证`，验收判据=壁面通量二阶、
  扩散解二阶、正交/非正交两支同时达标，且仿射精确性不退化。
- `tests/test_native_viscous_order3d.py` 中两条 `xfail(strict=True)`
  （贴壁二阶、扩散解收敛）是修复完成的检查线：XPASS 会红，提醒摘标记。

## 6. 误差判定

本单判据是**收敛阶**与**相对误差**并列，逐项：

| 关键量 | 基准 | 结果 | 是否 <3% |
|---|---|---|---|
| 仿射场面牵引 | 解析 τ·S | 机器精度（<1e-12 绝对） | 是 |
| 内部单元截断 | 解析 div τ | 相对场幅 n=16 时 0.0879/50.5 ≈ 0.17% | 是 |
| 贴壁单元截断 | 解析 div τ | 3.19/50.5 ≈ 6.3%，且不随 h 下降 | **否** |
| 壁面 ∂u/∂n | 解析梯度 | 1.35%（n=16） | 是（但仅一阶收敛） |
| Dirichlet 扩散解 | 解析 u | 13%（n=16，0.352/2.62） | **否**（且阶 0.03，不收敛） |

诚实结论：算子在线性场与内部通量上已达标，但**壁面闭包零阶一致、扩散解不收敛**，
这是已合并能力的真实精度上限，不能当作"已验证工程 CFD"使用。
