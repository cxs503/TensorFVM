## 1. 黏性项的离散耗散性问题

在原 9,068 单元 SUBOFF 网格上只构建 `NativeViscous3D`，所有边界设置为零速度 Dirichlet，常黏度 μ=1，不启用对流、压力或外力。
令 A=−Dτ 为积分黏性算子，半离散黏性方程为 M du/dt=−Au，M 为正的单元体积对角矩阵。
因此离散动能 E=uᵀMu/2 的瞬时变化率是 −uᵀAu。

为寻找反例，用正交扩散对角归一化 A 的对称部分，得到 Rayleigh 商 −0.24579039；对应样本满足：

- uᵀAu = **−0.24579039095169258**；
- 独立从共享面黏性牵引积分得到 dE/dt = **+0.24579039095169264**；
- 归一化对称算子的特征残差约 **2.39e−9**。

[计算记录](after/viscous-energy.json)与[完整速度样本](after/viscous-energy-witness.npz)可以重复验证。
这证明当前离散黏性算子不满足所有速度场上的离散耗散性；不是 SST 或壁面函数调参产生的现象。
**对称部分的负方向不等于完整 NS 算子的增长特征值，也不能独自证明它是 SUBOFF 失稳的根因。**
样本未要求满足不可压缩约束；这里检查的是黏性子算子本身。未通过截断负特征值或修改结果来掩盖问题。

## 2. 松弛系数污染稳态解

原 `_simple_momentum` 同时把松弛后的对角倒数用于迭代速度响应与 `_system` 的稳态 Rhie–Chow 通量。
这导致本应控制迭代过程的参数改变待求的稳态离散方程。
该问题此前曾作为实现限制记录，但没有满足松弛参数不改变稳态目标的要求。

27 单元偏斜网格、相同非均匀体力的 Stokes 问题，分别取速度松弛 0.3 和 0.8，均按原方程门槛收敛至 1e−9：

| 指标 | 修复前 | 修复后 |
|---|---:|---:|
| 两例速度场相对差异 | 0.182242762 | 2.15237e−10 |
| 两例压力场相对差异 | 0.020478644 | 4.03423e−10 |
| 迭代次数 0.3 / 0.8 | 76 / 78 | 81 / 78 |

[修复前记录](before/relaxation-dependence.json)、[修复后记录](after/relaxation-dependence.json)。
稳态通量现在使用未松弛的动量对角响应，SIMPLE 速度增量仍使用松弛后的响应；上一轮 C−BDG 压力响应一致性修正保留。
这修正了稳态目标定义，不代表整个混合网格算法已稳定；新的 SUBOFF 启动仍未通过压力线性残差门槛，见第 4 节。

## 3. 中断后的壁面剪切与 y+ 输出滞后

Spalding 壁面阻力在外迭代开始时线性化。动量更新之后如果被速度保护或其他回调中断，原 `forces()` 仍使用冻结系数乘以新的速度，并把结果当作当前壁面律牵引。

对上一轮保存的 `verification-simple-pressure-response/cp-matched-response` 原场重新执行壁面本构计算：

- 壁面切向牵引向量相对差异 **24.3269%**；
- 最大 y+：历史记录 **473.6928**，当前速度对应的壁面律为 **834.5663**；
- 轴向切向力由 0.000942954 变为 0.000952084；局部牵引差异并不等于总阻力差异。

[同原场复算记录](before/suboff-stale-wall-force.json)。这些仍是未收敛场，没有物理精度资格。
修正后 `forces()` 无副作用地重算当前壁面律的切向牵引，保留法向黏性牵引；
`linearized_anisotropic_stress_traction` 另存用于线性求解的冻结牵引。当前本构牵引用于力积分及 y+。
中断回归中，报告值与直接调用壁面律的相对差异为 **0**，且求解器矩阵和状态不被力计算修改。

## 4. 失败线性候选值污染已接受状态

SIMPLE 原来在更新 u、p、q 后才检查线性真残差。如果检查拒绝，历史和回调没有记录该步，但场变量已经改变。
这使“0 个完成步/仅初始化”与保存的原场发生矛盾。

本次 SUBOFF 启动复测同时暴露该问题：压力线性相对残差约 **5.46047e−8**，超过门槛 **1e−9**。
检查顺序修复前，失败候选值已经写入，max|u|/U=1245.325，max|pi|=1120.367；修复后保持初始速度 U=1、pi=0 和投影后的初始通量。

- [历史失败候选值与说明](rejected-candidate-before-transaction-fix/audit-note.md)。
- [最终版本启动记录](suboff-state-preserved/report.md)：**0 个被接受动量步，0 个 SST 更新，数值收敛 false**。

修正将线性真残差及候选值有限性验证放到状态提交之前；失败记录包含动量/压力残差及 `accepted_state_changed=false`。
新增有限但不准确的压力解、NaN 压力解两个注入测试，验证拒绝后 u、p、q 与历史不被污染。
本次启动失败说明压力系统仍有数值问题；尚未确定是否源于条件数、非正交响应或其他因素，没有放宽门槛。
