# CASE-FVM-DAMBREAK-STOKER · 干床波前**位置**的无解析输入复核

**锚点**: `CASE-FVM-DAMBREAK-STOKER`（算例池·浅水溃坝 Ritter/Stoker 精确解）
**ref**: Ritter (1892) *Z. Ver. Deutsch. Ing.* **36**, 947-954（干床稀疏波）；Stoker (1957) *Water Waves* ch.10（湿床）
**容差**: `|x_meas − x_exact| / x_exact ≤ 5 %`（判据 = 总账 acceptance，先声明后跑）
**本单性质**: 验证欠账 / 对抗性复核（非新算例、非新格式）

---

## ① 案例介绍与「为什么还要复核」

浅水方程（SWE）溃坝黎曼问题：`t=0` 时刻闸门两侧水深 `h0 | h1`，`t=0⁺` 撤门。

| 量 | 值 |
|---|---|
| `h0`（上游） | 1.0 m |
| `h1`（干床） | 0（Ritter 支）/ 0.5 m（Stoker 支） |
| `g` | 9.81 m/s² |
| `x_dam` / 域 | 0 / `[-5, 15]` m |
| `t* = t√(g/h0)` | 2.0（判据时点） |
| 判据量 | `x_f(t)` 波前位置、静水区水位阶跃、波形单调无伪振荡 |
| 格式 | HLL + MUSCL(minmod) + SSP-RK3，CFL 0.4，二阶 |
| 网格 | `n` 单元（`n = 100 … 3200`），判定网格 `n ≥ 800` |

**欠账在哪**（这是本单的出发点，也是本单唯一的新增内容）：

算例已「PASS」，但干床的两个 headline 数字都**把解析解装进了测量本身**，因此不能单独支撑「位置对不对」这条 acceptance：

| 度量 | 是否含解析量 | 问题 |
|---|---|---|
| `front_fan`（原 headline，n=1600 时 **0.017 %**） | 是 | 用精确相似恒等式 `x_f = x_i + 3t√(g h_i)` 反推波前——它测的是 fan 的**形状**误差，前缘由闭式给出 |
| `level_scaled` | 是 | 又加回精确 fan 偏移量 `3t√(g·level·h0)`，等于把答案加回去 |
| `front_wetted`（湿边判定） | 否 | 是**深度地板探测器**：读数由数值地板决定而非 `dx`，实测**不收敛**（n=400…3200: 1.56 % → 2.66 % → 2.89 % → 2.46 %） |

于是：**干床没有任何「测量端不含解析量、且随加密收敛」的位置证据**。总账 acceptance 要的恰恰是位置 `x_f(t)`。本单补上这一条。

> 湿床（Stoker）支已有 oracle-free 复核（`_data_driven_crosscheck`，F4，由剖面自测平台/水跃），故本单**只做干床**，不重复。

## ② 怎么做的

**核心思路**：把「位置」的判定挪到**等深线**上。Ritter fan 在波速上是直线 `c(x,t) = (2c0 − (x−x_dam)/t)/3`，`h = c²/g`，令 `h = level·h0` 得闭式

```
x_level(t) = x_dam + c0 t (2 − 3√level),    c0 = √(g h0)
```

- **测量端**：`x_meas = ` 数值剖面 `h` 穿过 `level·h0` 的亚网格交点（线性插值）。只吃 `(x, h, level)`，**不含解析解、不含尖端位置、不含 fan 恒等式**。
- **参照端**：上面的闭式。它定位的是**不同于尖端**的另一个闭式点，所以"对上了"不等于重复 `x_f`。参照本身还经**独立代码路径** `ritter_state` 反查（`h(x_level) = level·h0`，6 个 level，1e-12 内）。

声明（跑之前定，不从结果里选）：

| 项 | 值 | 理由 |
|---|---|---|
| `LEVEL_POSITION_LEVELS` | `0.5, 0.25, 0.1, 0.04, 0.01` | `level=1` 是未扰动尾部（区间内 `h≡h0`，严格穿越判定无交点，退化）；趋 0 即趋尖端 |
| 分级网格 | `n ≥ 800`（`ACCEPTED_MIN_N`） | 与仓内既有口径一致，本单未改 |
| 序列分辨率 | 等深线距坝 ≥ `1/TOLERANCE = 20` 格 | **误差预算**而非拟合：单格定位误差的相对值 ≈ `dx/x_level`，只有 ≥20 格时单格误差才落在 5 % 门内 |

**新增代码**（最小改动，均为加法，未改既有口径）：

| 位置 | 内容 |
|---|---|
| `src/tensorfvm/shallow_water/exact.py` | `ritter_level_position()`：等深线闭式 + 退化 level 抛 `ValueError` |
| `src/tensorfvm/shallow_water/dam_break.py` | `ACCEPTED_MIN_N`、`LEVEL_POSITION_LEVELS`、`LEVEL_POSITION_SERIES_LEVEL`、`LEVEL_SERIES_MIN_CELLS`、`level_position_metrics()`、`_level_series()`、`level_position_study()` |

## ⑤ 注意点 / 局限

1. **这是一阶度量，比形状度量弱**。等深线位置误差由「剖面被 `O(dx)` 抹平」主导，理论阶 1，实测 **0.96–1.00**；`front_fan` 是二阶量级（0.017 %）。因此本单**不推翻**既有 headline，而是给它补上一条**不共享同一闭式的独立位置证据**——两者互相印证（形状对且位置对），而不是互相替代。
2. **浅等深线（0.04 / 0.01）在 `n ≤ 800` 处于前渐近区**（观测阶 1.8 / 1.5 / 1.3），到 `n=3200` 才回到 1.0。测试里对这两条只断言「阶 > 0.5」，渐近一阶的断言留给 `n=3200` 的 artifact，不在弱网格上假装。
3. **`level=1` 不可用**：未扰动尾部 `h≡h0` 形成一个区间，严格穿越判定无交点（返回 `nan`）。已用 `ValueError` 显式拒绝 `level ∉ (0,1)`。
4. **序列在早期时刻相对误差天然大**：绝对误差约一格，相对误差 `≈ dx/x_level ∝ 1/t`。因此 20 格误差预算把 `t* ≲ 0.17` 的样本排除在分级之外（如实记录 `resolved=False` 与 `series_samples`，不隐藏）。这是**分辨率的物理后果**，不是调参：预算由 `1/TOLERANCE` 推出，与数据无关。
5. 适用范围：干床、平底、无摩阻、一维 SWE。湿床支不走本度量（水跃处 `h` 间断，"等深线"退化为水跃位置，已有 F4 oracle-free 复核覆盖）。
6. `n=100` 只有 6/21 序列样本可分级，故「分级样本占比 ≥ 0.5」的门只对 `n ≥ 800` 施加。

## ⑥ 误差判定（逐项 vs 基准）

基准 = Ritter (1892) 闭式，经 `ritter_state` 独立路径反查。门 = 5 %（总账 acceptance）。

| 关键量（判定网格 `n ≥ 800`） | 误差 | 是否 < 5 % | 是否 < 3 % |
|---|---:|---|---|
| 等深线位置 `level=0.5`（n=800） | 1.386 % | 是 | **是** |
| 等深线位置 `level=0.25` | 0.377 % | 是 | 是 |
| 等深线位置 `level=0.1` | 0.375 % | 是 | 是 |
| 等深线位置 `level=0.04` | 0.054 % | 是 | 是 |
| 等深线位置 `level=0.01` | 1.006 % | 是 | 是 |
| **等深线 max（判定量）** | **1.386 %** | **是** | **是** |
| **`x(t)` 序列 max（判定量）** | **1.557 %** | **是** | **是** |
| 观测收敛阶（非误差量） | 0.957–1.00 | — | — |
| 对照：`front_wetted`（不收敛，不判定） | 2.66 % | 是（但不收敛，非证据） | 是 |

**结论**：位置类判据在判定网格上全部 **< 5 %（也全部 < 3 %）**，且随加密按一阶收敛（阶 0.96–1.00），因此 `CASE-FVM-DAMBREAK-STOKER` 的「位置」部分现在有了**不依赖闭式恒等式的独立证据**。无 honest-FAIL 项；未达成的部分是「一阶而非二阶」，已如实写在 ⑤.1。
