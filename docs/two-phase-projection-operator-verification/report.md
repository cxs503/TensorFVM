# 两相投影压强-泊松算子的矩阵级验证：算子/修正自洽 ≤1.0e-10，交接单遗留缺陷（算子相差 2 倍）已闭合

## ① 案例介绍

两相 VOF 瞬态求解器的 Chorin 投影由两段代码组成：
`TwoPhaseSolver._projection_pressure` 组装变密度泊松算子（以 matvec 形式，未显式成矩阵），
`TwoPhaseSolver._projection_step` 用同一套面系数做速度修正 `u ← u* − dt (1/ρ)_f ∇φ`。
两者若不自洽，解出的 `φ` 就是**另一个算子**的解，散度只能部分消除——这正是
`docs/two-phase-projection-audit.md` §4 交接给后人的缺陷：

> 随机散度场、ρ_l=ρ_g、n=32、dt=1e-5：`max|div|` 修正前 2.07e-1，修正后 4.15e-1，
> 中位几乎不变；求解返回 `dφ ≈ 2 dφ_exact`，"组装算子与修正实际使用的算子相差约 2 倍"；
> 建议显式组装泊松矩阵，逐面对比 `A dφ` 与 `V·div(correction)`。

本单执行该建议，并补上此前从未做过的两件事：

* **各向异性域**（`dx ≠ dy`）：全部既有两相测试都用 `length == height == 1` 的正方形网格，
  于是"面系数把 `dy/dx` 写成 `dx/dy`"这一类缺陷在数学上不可见（`dx == dy` 时两式完全相同）；
* **1000:1 密度比**（分层 α 场）：检验面密度的调和平均在密度间断上是否与算子一致。

## ② 怎么做的

1. **把修正从 `_projection_step` 抽成纯函数** `_velocity_correction(u*, v*, dp, dt) -> (u, v)`
   （`src/tensorfvm/two_phase_solver.py`）。改动为纯重构：原内联代码的索引与符号逐字保留，
   `_projection_step` 现在只调用它；抽出的目的仅是让"算子"与"修正"可以独立互相检查。
2. **独立组装算子**（`tests/test_two_phase_projection_operator_matrix.py::assemble_poisson`）：
   不复用求解器任何数组，按第一原理（面面积 `A_f`、面距 `d_f`、调和面密度）
   在 `p[j,i] → j·nx+i` 排序下组装 scipy 稀疏矩阵：

   ```
   div(u_new) = 0,  u_new = u* − dt (1/ρ)_f ∇dp
   ⇒  A dp = −V div(u*) / dt,   A_PQ = Σ_f c_f (δ_PQ − δ_NQ),
      c_f = (1/ρ)_f A_f / d_f,  V = dx·dy
   ```
   西/东/南墙无通量（无系数）；顶面为**半格距**压强基准
   `c_top = (1/ρ) dx / (dy/2)`（这是"顶行闭合"的关键）。
3. **逐面对比**：把 `_velocity_correction` 实际造成的每条面通量变化与 `−dt c_f (dp_N − dp_P)` 比较，
   并按单元比较 `V·div(u_new) = V·div(u*) + dt·(A dp)`，判据
   `‖A dp − b‖∞/‖b‖∞ < 1e-8`（CG 相对残差目标 1e-10）。
4. **两个变异对照（负控）**证明判据非空：把面几何 `dx/dy` 互换；丢掉顶面基准项。
   两者在**各向异性**网格上必须被检出（残差 > 1e-3）。
5. 数字与图由 `scripts/two_phase_projection_operator_verify.py` 程序化生成
   （`docs/two-phase-projection-operator-verification/summary.json` + `operator-verification.png`），
   报告内不手抄。

## ③ 计算结果

### 算子自洽与散度消除（三配置，n = 32×32 / 32×24，dt = 1e-5，随机无散墙速度场）

| 配置 | 网格 | dx / dy | ρ_max/ρ_min | ‖A dp−b‖∞/‖b‖∞ | max\|div\| 后/前 | 顶面基准冻结时 后/前 |
|---|---|---|---|---|---|---|
| isotropic_uniform | 32×32 | 0.03125 / 0.03125 | 1 | 1.043e-10 | 1.043e-10 | 3.101e-01 |
| anisotropic_uniform | 32×24 | 0.03125 / 0.02500 | 1 | 8.118e-11 | 8.118e-11 | 3.337e-01 |
| anisotropic_stratified | 32×24 | 0.03125 / 0.02500 | 1000 | 9.046e-11 | 9.046e-11 | 3.367e-01 |

* 判据 `‖A dp−b‖∞/‖b‖∞ < 1e-8`：**三配置全部通过**，最好 8.1e-11；
* 生产修正路径把散度从 2.07e-1 压到 **2.16e-11**（比值 1.04e-10），**含顶行在内的每一行**都闭合；
* "顶面基准冻结"一列说明该边界项不是装饰：少了它，残差停在初始散度的 **31–34%**。

## ⑤ 注意点 / 局限 / 适用范围

* **交接单缺陷已闭合，但闭合不是本单之功**：修复来自更早的两相投影修复（体积因子 `V`、
  非对角项符号）。本单的增量是——把它**变成可判定的矩阵级判据**、补上**各向异性 + 1000:1 密度比**
  这一从未被测的维度，并给出两个可失效的变异对照；顺带修好了已无法运行的再生脚本
  （旧脚本读 `solver.cg_info`，该属性早已不存在 → `AttributeError`，文档里的 `reproduce`
  命令实际是坏的）。
* **判据的适用面**：只覆盖变密度泊松算子与速度修正的自洽性；不覆盖对流/粘性离散误差，
  也不覆盖 CSF 表面张力源项（见下）。
* **Young–Laplace 仍不达标（诚实 FAIL）**：20 步（t = 2e-4 s）内 Δp 误差 +4.9% / −12.2% / −7.9%，
  且寄生流 |v| 随时间单调增长（约 1e-4 m/s 量级），说明该瞬态远未收敛：
  这个数字**混入了毛细波瞬态**，不能当作纯离散误差读。3% 判据不通过，不粉饰。
  该缺陷属 `σ` 源项（平衡力 CSF / Brackbill 曲率）范畴，已由另一单（m3376，分支 `agent/m3376`）
  在 MAC 面上做平衡力公式处理，本单不重复、也不改其代码。
* **顶面基准的半格距**是硬约束：`c_top = (1/ρ) dx/(dy/2)` 与修正里 `dp/(0.5~dy)` 必须成对，
  单改一处就会立刻被上面的判据抓住（顶面冻结比 0.31–0.34）。

## ⑥ 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 基准 | 误差 | <3% ? |
|---|---|---|---|
| 算子自洽 ‖A dp−b‖∞/‖b‖∞（各向同性） | 0（精确解满足 A dp = b） | 1.04e-10 | 是 |
| 同上（各向异性 dx≠dy） | 0 | 8.12e-11 | 是 |
| 同上（各向异性 + ρ 1000:1） | 0 | 9.05e-11 | 是 |
