## 1. 案例介绍（物理背景 / 几何 / 参数）

### 1.1 后台阶 Backward-Facing Step
- 几何：下游通道高度 `H = 1`，台阶高度 `H/2`，**扩张比 2**；上游通道 `y∈[0.5,1]`，下游 `y∈[0,1]`；上游段 2H、下游段 10H。
- 入口：上半通道抛物线型 `u(y)=24(y-0.5)(1-y)`，峰值 1.5、均值 1（对半高通道），故 **下游体积平均速度 U_b = 0.5**。
- 雷诺数：`Re_H = U_b H / ν = 800`（Gartling 1990 约定，入口峰值 = 1.5 U_b）。
- 文献基准：Gartling (1990) 同题解 `L_r/H = 6.10`；Armaly et al. (1983) 实验带 5.8–6.4；本节点合同目标 `6.0 ± 0.2`。
- 判据量：底壁（台阶侧壁）切应力零点 = 再附点，取 `L_r/H`。

### 1.2 突扩管 Planar Sudden Expansion
- 几何：入口高度 `D = 1`，下游高度 `H₂ = 4D`，**面积比 AR = 4**；入口位于西边界 `y∈[0,1]`，其余西边界为台阶立面（无滑移）；下游长度 12D。
- 入口：均匀型（主算例，与 Borda-Carnot 的均匀剖面假设一致）与抛物线型（敏感性）。
- `Re_D = U_in D / ν = 100`。
- 判据量：总压头损失系数 `K = [(p+½ρU²)_in − (p+½ρU²)_out] / (½ρU_in²)`；理论值 Borda-Carnot `K_th = (1−1/AR)² = 0.5625`。同时报告静压恢复系数与恒等式 `K = static_recovery + (1−(U_out/U_in)²)` 作为自洽检查。

### 1.3 自然对流方腔 Differentially Heated Cavity
- 几何：单位方腔；西壁 `T=1`（热）、东壁 `T=0`（冷），南北壁绝热；`Pr = 0.71`。
- 无量纲 Boussinesq 集：`ν = √(Pr/Ra)`、`α = ν/Pr`、`gβ = 1`、`ΔT = L = 1`。
- 基准：de Vahl Davis (1983) `Nu = 2.238 / 4.509 / 8.817`（Ra=10⁴/10⁵/10⁶），合同值 `2.243 / 4.519 / 8.800`；`ψ_max = 5.071 / 9.111 / 16.32`。
- 判据量：热壁平均 Nusselt 数（二阶单侧差分）、流函数 `|ψ|_max`、冷热壁能量闭合。

## 2. 怎么做的（数值方法 / 流程 / 工具链）

### 2.1 离散
- **交错 MAC 网格**：`u` 在 x 面 `(nx+1,ny)`，`v` 在 y 面 `(nx,ny+1)`，`p, T` 在单元中心。
- **阻塞单元几何**：固壁由 `fluid` 掩膜表示，触壁面通量置零（阶梯壁）。关键离散细节：由于 `u` 在 x 向位于面、y 向位于单元中心，其动量控制体在 **x 向边界落在单元内部**（到邻面距离 `h`，不可能有壁），在 **y 向边界与单元面重合**（贴壁取半格 `h/2`，电导×2）。这一点写反会让近壁速度偏高 70 % 以上——本项目实测到的第一个精度缺陷（§5 陷阱 1）。
- **对流**：隐式一阶迎风（保证对角占优）+ **冻结延迟修正**（van Leer 谐波限制器）。完全显式延迟修正在 `Pe_cell ≳ 3` 发散（实测：`Pe_cell=6.25` 发散、`0.6` 收敛），故采用「先一阶收敛 → 评估一次限制器面通量 → 冻结源项再解」的缺陷修正（defect correction）流程，`deferred_cycles=1`。
- **压力-速度耦合**：SIMPLE（Patankar）。动量方程含当前压力梯度源；随后解压力修正 Poisson 方程并同时修正面通量。
- **伪时间项**：`a_P += ρV/Δt_p`（`Δt_p = CFL·min(hx,hy)/|u|max`）并加匹配源 `a_P0·φ_old`。这是台阶角点/驻点处 **a_P → 0** 导致 `d = A/a_P` 爆炸的必要稳定化（§5 陷阱 2）。
- **压力 Poisson**：几何多重网格 V-cycle（红黑 Gauss–Seidel 光滑、面电导平均粗化、双线性延拓、**粗层稠密直接解**）。为避免 SciPy 依赖，粗层直接解用 NumPy 稠密 `solve`（粗层仅数百未知数）。掩膜粗化用 **OR**（任一子单元为流体即为流体）——AND 粗化会在凹角生成孤立粗单元，使修正失效（§5 陷阱 3）。
- **能量/浮力**：定常能量方程（`α=ν/Pr`）+ `v` 动量源 `ρ gβ (T−T_ref)`；壁面温度边界按西/东/南/北四面配置（fixed / adiabatic）。

### 2.2 执行与工具链
- 每算例三档网格：后台阶 `H/20, H/40, H/80`；突扩 `D/10, D/20, D/40`；方腔 `32², 64², 96²`。
- 每档执行 `converge()`：一阶迎风阶段 → 冻结延迟修正阶段；收敛判据为归一化连续性残差 + 速度最大改变量。
- `runs/incompressible-baselines/*.json` 保存全部指标、设置、元数据与耗时；最细网格另存场数据 `*.npz`。
- `scripts/report_fvm_incompressible.py` 从 JSON **程序化**生成 `RESULTS.md` 的表格、Richardson 观测阶/外推值与图，报告数字不手抄。
- 图：`matplotlib`（速度型面、壁面切应力、K vs Borda-Carnot、Nu vs Ra、温度场）。

## 4. 判据逐项判定

（判定在 `scripts/report_fvm_incompressible.py` 内由代码计算：`verdict(error, tol)`。）

### 4.1 后台阶
- 目标：`L_r/H = 6.0 ± 0.2`，误差 < 10 %。
- 实测形态：伪时间推进中再附长度**随时间单调增长**（n=20：100→600 迭代，`L_r/H` 0.95→3.37），说明算例物理方向正确（有强回流 `min u ≈ −0.27`、再附点存在），但**在本次预算内未到达 6.0**，且网格加细后所需迭代数进一步增加。
- 判定：**FAIL（未收敛，非物理错误）**——`RESULTS.md` 给出每档的实测值与外推值；不外推掩盖。

### 4.2 突扩管
- 目标：`K` 与 Borda-Carnot 误差 < 5 %。
- **一致性说明（重要）**：Borda-Carnot `(1−1/AR)² = 0.5625` 的前提是两截面**均匀剖面**且忽略壁面摩擦。若上游为**充分发展抛物线**，动量平衡给出的理论损失本身只有 `≈0.46`（差 18 %），这属于**定义差异而非数值误差**，因此主算例采用均匀入口（与理论假设一致），抛物线入口作为敏感性对照。文档因此同时报告总压头 `K`、静压恢复与恒等式检查，避免用错误基准"凑"通过。
- 判定：见 `RESULTS.md`（本次预算内未获得收敛的 K，故为 **WITHHELD/FAIL**，如实记录）。

### 4.3 自然对流方腔
- **关键修正**：Nusselt 三点单侧差分系数最初写错（把第二节点位置当成 `2h`，实际单元中心在 `1.5h`）。错误公式在纯导热极限给出 Nu = 1.0833（偏 8.3 %），修正后为 `Nu = (−8/3·T_w + 3·T₁ − ⅓·T₂)/h`，导热极限精确给出 1.000000。修正前 Ra=10⁴、n=24 的读数 2.4034 需按比例回推到 ≈2.22（落在 de Vahl Davis 2.238 的 1 % 内）——修正后的正式数字见 `RESULTS.md`。
- 判定：见 `RESULTS.md`（逐 Ra 给出 Nu 误差、`|ψ|_max` 误差与是否 < 3 %）。

### 4.4 网格收敛阶
- 内核 Poiseuille：观测阶 > 1（pytest 锁定）。
- 三算例：`RESULTS.md` 用三档 Richardson 给出观测阶与外推值；未达到 1.5 的档位如实标注。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **交错网格壁面电导取向**：`u` 的动量 CV 在 x 向边界位于单元内部（距离 `h`，无壁），在 y 向边界与单元面重合（贴壁半格 `h/2` → 电导×2）。写反后近壁速度偏高 ~73 %、`dp/dx` 偏小 16 %。修正后同一算例降到 0.6 % / 0.15 %。**这是本项目最重要的精度教训。**
2. **出口列的出流项不可置零**：`u` 动量方程在出口列的东面通量若按"邻居面是否自由"掩码会被清零，导致 `a_P` 失去对角占优、末列发散。正确做法是按**所在单元的流体性**掩码。
3. **压力修正 Poisson 的符号**：`∇·u` 与修正方程的符号必须一致（`A p' = +div` 且 `Aφ=Σk(φ_nb−φ_c)`）；写反会让压力修正反向放大质量残差（实测残差 10 分钟内指数增长到 NaN）。
4. **驻点/凹角处的伪时间项是必需的**：纯定常 SIMPLE 在 `a_P→0` 处 `d=A/a_P` 无界；加伪时间项后 `d ≤ Δt/h`，台阶算例从 NaN 变为稳定推进。代价是收敛变成伪时间推进（迭代数 ~ O(流动通过时间/Δt)），这是本节点预算不足的直接原因。
5. **完全显式 van Leer 延迟修正的稳定边界**：`Pe_cell ≳ 3` 发散。采用冻结缺陷修正后稳定，但**修正量在冻结后不再随场更新**，高阶精度只在"冻结源与最终解自洽"的意义上成立；`deferred_cycles` 可增加重算次数（本节点用 1 次）。
6. **掩膜多重网格的粗化策略**：AND 粗化会在凹角产生孤立粗单元（对角为 0），修正彻底失效；OR 粗化后残差可降 10⁶ 倍，但因算子病态，残差小并不等于误差小（相对误差仍 9 %）。压力修正在 SIMPLE 内被松弛，所以可用；**不要**把它当直接解使用。
7. **Borda-Carnot 的剖面前提**：与抛物线入口对比会得到 18 % 的"差异"，其中绝大部分是理论假设不同而非数值误差——报告必须显式声明剖面约定，否则判据无意义。
8. **Nusselt 单侧差分节点位置**：单元中心在 `h/2, 3h/2`，不是 `h/2, 2h`；错误系数在导热极限偏 8.3 %，会把"是否 < 3 %"的判定翻转。
9. **环境**：loong64 计算节点的 torch wheel 无法加载 `libflexiblas`，且**没有 SciPy**。因此内核用纯 NumPy 编写，脚本用 `importlib` 绕过包 `__init__`（其 torch 导入会导致硬失败），粗层直接解用 NumPy 稠密解。torch 在本机同规模逐元素运算比 NumPy 慢 5–100 倍（192k 元素 add：0.68 ms vs 0.13 ms，默认 128 线程时 14 ms），这也是内核选择 NumPy 的实测依据。
10. **未完成部分（如实）**：后台阶/突扩管在本次预算内未收敛，K 与 L_r 的正式判定见 `RESULTS.md`；三档网格的算例级收敛阶因此可能不满足 ≥1.5。后续应：(a) 用局部时间步（按单元 CFL）替代全局伪时间步以把迭代数降一个量级；(b) 给延迟修正做 Picard 重算 2–3 次；(c) 将残差判据改为以 `|ΔU|` 与再附点位置稳定为双判据。

## 8. P19-N03：稳态收敛加速、三档网格基线与当前判定

### 8.1 本轮做了什么（代码层面）

1. **压力修正的稀疏直接解（`SparseDirectPoisson`）**：实测原多重网格路径把 96 %
   （4400 单元：0.23 s 中的 0.22 s）的时间花在**粗层稠密解**上（`np.linalg.solve`，
   长宽比大的算例粗层仍有 ~1200 未知数）。新路径用同一算子组装 CSC 矩阵 + SuperLU
   （`permc_spec="MMD_AT_PLUS_A"`, `SymmetricMode`），并在系数缓慢变化时**复用分解**
   （`refresh`/`min_age`/`stale_tol`），用 1 步迭代精化把陈旧分解解到**当前**算子的
   ~1e−6 相对残差。等价性由 pytest 锁定（残差与多重网格路径对比、`factorizations <
   solves`、pin 边界）。整迭代成本：H/20 从 230 ms → 25 ms（**约 10 倍**）。多重网格
   仍是默认路径（无 SciPy 的 loong64 节点使用它）。
2. **网格序贯（grid sequencing，`inject_coarse_solution`）**：粗糙档解经面拷贝/面平
   均注入加密档（倍频嵌套，注入精确），省掉最贵的一段对流发展暂态。
3. **发现并记录：延迟修正（van Leer）在 `Pe_cell ≫ 3` 不可用**。上一轮用「冻结源
   项」绕过；本轮实测**冻结源在 `Pe_cell ≈ 10`（突扩）与 `≈ 40`（台阶 Re_H=800）
   仍会指数发散**（400→600 次迭代内到 1e107），并且把缺陷修正量按 5 %/迭代松弛
   （`dc_relax`）同样发散——这不是欠松弛能解决的问题，而是**反扩散算子的定常迭代
   稳定性**问题：迭代矩阵失去 M 矩阵性质。因此**台阶与突扩两案本轮只用一阶迎风**
   （二阶路径需要耦合 Newton 或九点/宽模板 + ILU，未实现，见 §8.4）。方腔 `Pe_cell`
   很小，仍用二阶冻结缺陷修正。
4. **`run(max_stall=...)`**：原实现的「改变量 400 个检查块无改进即停」会把仍在缓慢
   推进的回流（`dU` 在衰减均值附近振荡）误判为停滞，导致**假收敛**（实测在 5800 次
   迭代、`L_r/H` 仍差 30 % 时提前退出）。验证驱动改为只受迭代预算约束，并把
   `dU`/连续性残差写入 JSON。
5. **新增摩擦系数后处理**（`wall_friction_profile`）：`C_f = 4 ν u_w / (h U_b²)`，壁
   面切应力取壁邻排（距壁 `h/2`），零点即再附点；报告给出 `C_f(x)` 分布、泡内最小值、
   与充分发展值 `12 ν/(U_b H)` 的对照（**不设为判据**，因为台阶后 4H 处边界层远未
   充分发展，入口段长度 ~0.05 Re_H H = 40H）。
6. **报告与产物程序化**：`scripts/report_fvm_incompressible.py` 现在写出
   `benchmarks/verified/fvm_*/results.json`（逐条判据 id / value / reference / error /
   passed + 产物路径）、三算例 README 与 `RESULTS.md`，并绘制 `C_f(x)`、速度云图、
   `L_r` 收敛、`K` 与 Borda–Carnot、`K(Re_D)` 扫描、`Nu` vs Ra、温度/压力云图。

### 8.2 网格加密预算（为什么网格族改为 H/10、H/20、H/40）

本内核的伪时间步 `Δt_p = CFL·min(hx,hy)/|u|` 是**稳定性**要求而非效率选择：
`d = A/a_P ≤ α_u Δt_p/h`，要网格无关就必须 `Δt_p ∝ h`（见 §5 陷阱 4）。于是
**到达同一定常状态的迭代数 ∝ 1/h**，而单次迭代成本随单元数超线性增长（H/80：
~0.5 s/迭代，且需要约 4 倍于 H/20 的迭代数）——H/80 一档单独就需要约 10 小时。
因此本轮的**三档等比网格族为 H/10、H/20、H/40**（合同建议的 H/20、H/40、H/80
无法在本次会话预算内完成）；这是**判据偏离**，如实记录，不用未收敛的点凑收敛阶。

### 8.3 当前判定

逐条判据（含数值、基准、误差、是否通过）见
`benchmarks/verified/fvm_backward_step/results.json`、
`fvm_sudden_expansion/results.json`、`fvm_natural_convection/results.json` 与
`RESULTS.md`。摘要：

* **自然对流**：三档 Ra 的 Nu 均通过 3 % 门（见 `RESULTS.md` 数字）；`|ψ|_max` 在
  Ra ≥ 10⁵ 仍偏大（已知缺陷：ψ 是 `u` 的壁面积分，累积了近壁速度误差）。
* **后台阶**：H/10、H/20、H/40 三档 `L_r/H` 单调下降（见 `RESULTS.md`），最细网格的
  误差**未达 10% 门**（FAIL，数值在 `results.json`）；但三档的 **h→0 Richardson 外推
  落在 6.0 附近（约 −0.7%）**，说明偏差是**一阶迎风数值扩散**而非物理错误。**观测阶
  ≈0.86 < 1.5**，该子判据 FAIL（原因见 §8.4）。另做了**出流长度敏感性**（20H vs 10H）：
  再附长度变化 ~1.6%，而出口处 `C_f` 由负转正（=解析充分发展值量级），证明 10H 出口的
  负 `C_f` 是出流边界伪影。
* **突扩管**：`K` 三档网格单调上升并以**观测阶 ≈1.08**（非均匀比 2 与 1.5，由代码内
  的非均匀 Richardson 求解器算出）收敛到 `K_∞ ≈ 1.18`，即 **≈2.1×Borda–Carnot**——
  `K` 的 5 % 门（对 0.5625）在该 Re 下**不可能**满足，属物理（层流粘性超出）而非数值误差：
  报告给出 `K(Re_D)` 扫描（Re_D = 100…5000）、**出流长度敏感性**（20D 出口把 D/10 的
  `K` 从 1.026 降到 0.889，说明 12D 出口截断了回流区）、静压恢复与 `K` 分解恒等式
  （自洽闭合到机器精度）。`L_r/D` 三档一致到 0.7%，但无离线可引文献值 → **WITHHELD**。

### 8.4 未完成 / 下一步（如实）

1. **二阶精度**：需把限制器重构纳入隐式（宽模板 + ILU/GMRES）或用**耦合 Newton**
   （`J` 用冻结限制器）——这是把台阶/突扩的观测阶从 ~1 提到 ~2 的正路，本轮未实现。
2. **H/80**：需要局部时间步（按单元 CFL）+ 更好的线性求解器（或 AMG），否则单算例
   ~10 小时。
3. **`C_f` 与实验对比**：Armaly (1983) 的数字化曲线离线不可得（`reference.py` 已把
   它标为 WITHHELD）；当前给出分布收敛性与零点一致性，待有数字化数据后再加硬判据。
4. **`|ψ|_max`**：Ra ≥ 10⁵ 的 10–15 % 偏差未解决；与 Nu 的一致性说明问题在近壁速度
   分布而非整体热量输运，需在壁面附近加密或用二阶对流。
