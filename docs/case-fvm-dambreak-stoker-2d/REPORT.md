# CASE-FVM-DAMBREAK-STOKER — 2-D 算子对 Ritter/Stoker 精确解的复核

**锚点**: `CASE-FVM-DAMBREAK-STOKER`（浅水溃坝 Ritter/Stoker 精确解）
**参考**: Ritter 1892 *Z. Ver. Deutsch. Ing.* **36**:947；Stoker 1957 *Water Waves* ch. 10
**容差**: < 5 %（波前/激波位置、静水区水位阶跃），t\* = 2，波形单调无伪振荡
**任务**: m19944（selfstart，generalist 席），2026-11-14
**工件**: `src/tensorfvm/verification/artifacts/shallow-water-dam-break-2d/`（全部数字由
`scripts/run_shallow_water_dam_break_2d.py` 写入，本文件只引用不复述计算）
**代码**: `src/tensorfvm/shallow_water/dam_break2d.py`
**测试**: `tests/test_shallow_water_2d_dam_break.py`（14 项）

---

## 0. 本单补的是什么缺口（先说清不重复的部分）

锚点此前**只在 1-D 求解器上被分级**：`docs/case-fvm-dambreak-stoker/REPORT.md`
（含 m17055 独立复核的 F1–F7 修订）与 `docs/verification-dam-break-front-metric/`
把 1-D 的证据链做得很完整。但本仓的 2-D 浅水求解器
（`swe2d.ShallowWater2D`）的验证只有 Thacker 盆地（well-balanced / 各向同性 /
岸线），**从未对锚点自己的精确解出过数**。也就是说：2-D 算子若有轴向颠倒、
`dx`/`dy` 标度错、横向通量在均匀态不消失、边界泄漏这类缺陷，锚点的任何数字都
不会报警。

本单把这个缺口补上，并把两个新增的横向检查写成带先验阈值的判据。**这不是新的
物理证据**（通道内沿 y 均匀的初值在数学上与 1-D 问题同解），它是对 2-D 离散算子
实现的证据 —— 报告里按这个口径陈述，不夸大为独立验证。

---

## 1. 案例介绍（物理背景 / 几何 / 参数表）

浅水方程溃坝：坝在 x = 0，左侧 h₀，右侧 h₁，t = 0 撤坝。干床（h₁ = 0）为
Ritter 稀疏波，湿床（h₀ > h₁ > 0）为稀疏波 + 常数态 + 右行水跃（Stoker）。

| 参数 | ritter-dry | stoker-wet |
|---|---|---|
| h₀ | 1.0 m | 1.0 m |
| h₁ | 0.0 m | 0.5 m |
| g | 9.81 m/s² | 9.81 m/s² |
| t\* = t√(g/h₀) | 2.0 | 2.0 |
| t (物理) | 0.638551 s | 0.638551 s |
| 精确前沿/水跃 | x_f = 4.000000 m | x_s = 1.888781 m（U = 2.9580 m/s 级） |
| 精确 h₂ / 阶跃 h₂/h₁ | — | 0.726920 m / 1.453841 |

**三维几何**: x ∈ [−4, 6] m（nx 网格），y ∈ [0, 1] m（ny = 8，dy = 0.125 m）。
`dy/dx` 在 nx = 800 时为 10，**故意让两个方向的间距不同**，否则轴向标度错会被
等距掩盖。边界：x 两端零梯度透射，y 两端零梯度。初始床面平底 z = 0。

## 2. 怎么做的（方法 / 流程 / 关键设置）

1. 同一初值（坝两侧 h₀/h₁，沿 y 均匀）用 `ShallowWater2D` 推进到 t\* = 2；
   离散与 1-D 基准一致：MUSCL/minmod 重构、HLL 通量、SSP-RK3、CFL = 0.4、二阶。
2. 把二维场**降维成 y 平均 x-剖面**，然后用**与 1-D 基准同一批估计子**判据：
   - 干床波前：`fan_front_estimate`（形状一致扇形估计，`FAN_WINDOW=(1e-2,2e-1)`）；
     `wetted edge`（湿润边缘）只作已声明的诊断量（深度地板探测器）。
   - 湿床水跃/平台：`data_driven_plateau`（**无解析 oracle**：最大梯度 + 实测
     平台电平 + 亚格中值穿叉），以及格心读数作负对照。
   - 深度 L1、TV 比、内部极值计数（单调性）、质量漂移、正性。
3. 时间序列 x_f(t)：与 1-D 一致的 25 点采样 + `SERIES_MIN_CELLS = 4` 先验分辨率门。
4. 两个**新增横向检查**（阈值均为模块常量，先于运行声明）：
   - **对称性**：沿 y 均匀初值下 `max|h − ⟨h⟩_y|/h₀` 与横向速度必须在舍入级
     （`TRANSVERSE_ROUNDOFF = 1e-12`）。这是*结构性*检查（横向通量在 y 均匀态
     恒为零），因此明确**不计为精度证据**。
   - **横向扰动**：初值加 1 %（`MODULATION_AMPLITUDE = 1e-2`）沿 y 正弦调制，
     要求横向模不被放大（峰值缺陷 ≤ `TRANSVERSE_GROWTH_MAX = 2` × 幅值）且分级
     波前误差不超出半个容差（`MODULATION_CONTAMINATION_MAX = 2.5 %`）。
5. 2-D vs 1-D 算子对照：同一问题、同一 nx 各跑一遍，比较同一批分级量
   （`ONE_D_AGREEMENT_MAX = 5e-3` = 0.5 pp = 容差的 10 %）。
6. 网格收敛：nx = 200/400/800（ny 固定 8）。
7. 工具链：numpy / matplotlib；artifacts 由脚本写入 `manifest_2d.json`（版本、
   命令行、阈值、git commit）。

### 3.3 横向扰动探针（nx = 400，幅值 1 %）

| 情形 | 基线误差 | 扰动后误差 | 位移 | 峰值缺陷 / 幅值 | v_max | 判定 |
|---|---|---|---|---|---|---|

| stoker-wet | 0.160 % | 0.420 % | +0.260 pp | 0.924 | 2.44e-04 m/s | PASS |

峰值缺陷 / 幅值 = 0.924 < 2（**无放大**，横向模略衰减）；分级误差仍在半个容差内。

所以这个量是"指标对 1 % 扰动的敏感度上界"，不是数值误差。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **无 oracle 水跃探测器有适用区间（本单新发现，已量化）**：在稀疏波扇形还没张开
   到几个单元之前，剖面上最陡的跳变是**被困在初始间断抹平区里的扇形跳变**
   （h₀−h₂ 压缩在 ~4 单元内），而非水跃（h₂−h₁）。此时 `data_driven_plateau`
   锁到扇形上，读数偏差 = O(U t_fan / x_s)，即 **100 % … 140 %**。实测：
   - 交叉点由**精确解的扇形宽度**决定：第一个读数进入 5 % 的样本扇形宽 2.83 单元，
     从 3.76 单元起持续 5 % 内；**nx = 200/400/800 完全相同**（两个梯度都按 1/dx
     标度 → 失效是物理性的，不是网格假象）。
   - 因此新增先验门 `FAN_RESOLVED_CELLS = 4`（与 1-D 基准的 `SERIES_MIN_CELLS = 4`
     同一规则，只是施加在扇形上），被排除样本照实登记（最大 100.1 %）。
   - **含义**：m17055 审计担心的"oracle-guided 度量近乎同义反复"用数据驱动度量修
     对了（t\* = 2 时平台宽 140 单元，读数 0.043 %），但**数据驱动度量不能无条件
     用于早期序列**——这一条此前没人写过。
2. **干床湿润边缘在 2-D 更差**（nx = 800：5.781 %，1-D 同分辨率 2.66 %）：它仍
   是深度地板探测器，只是 2-D 的横向平均让干尖抹平更严重。它是**诊断量**，分级量
   是扇形估计子。这再次说明"发表哪个数字"必须先声明。
3. **横向对称是结构性的**：y 均匀时横向 HLL 通量精确为零，所以 `1e-12` 判据只能抓
   实现级缺陷（轴颠倒、dy 错用、边界泄漏），**不能算精度证据**；真正的横向稳健性
   证据是 §3.3 的调制探针。
4. **适用范围**：静水压浅水方程、平底、透射边界；不含非静压、三维、干湿移动边界
   摩擦。Stoker 湿床仅 h₁/h₀ = 0.5（1-D 报告另有 0.25 情形）。
5. **未做**：ny 加密研究（横向均匀时无意义）、GPU/并行路径、y 方向非均匀流（那需要
   2-D 精确解，超出锚点范围）。

## 6. 误差判定

| 关键量（锚点验收项） | 容差 | 实测（2-D，nx = 800） | 是否 < 5 % |
|---|---|---|---|
| Ritter 波前 x_f（扇形，分级） | < 5 % | 0.040 % | **是** |
| Ritter x_f(t) 序列最大误差 | < 5 % | 1.316 % | **是** |
| Stoker 水跃 x_s（数据驱动） | < 5 % | 0.043 % | **是** |
| Stoker 静水阶跃 h₂/h₁ | < 5 % | 0.001 % | **是** |
| Stoker h₂ 平台深度 | < 5 % | 0.000 % | **是** |
| 深度剖面 L1 | < 5 % | 0.155 % / 0.085 % | **是** |
| 波形单调（内部极值 > 1e-4 h₀） | 0 | 0 / 0 | **是** |
| 横向对称（结构性） | ≤ 1e-12 | 0.0 | **是** |
| 横向调制不放大 | ≤ 2× 幅值 | 0.924× | **是** |
| 2-D vs 1-D 算子一致 | ≤ 0.5 pp | 0.031 pp | **是** |

**结论**：2-D 求解器在锚点两个算例上全部通过 5 % 判据（0.04 % 级），且与 1-D 算子
一致到 0.03 pp；横向方向在舍入级保持安静，1 % 横向扰动不被放大。锚点验收句
（x_f(t)、静水阶跃、t\* = 2、单调无伪振荡）在 2-D 算子上同样被满足。
**诚实记录**：干床湿润边缘诊断量 5.781 % 超容差（已知探测器缺陷，未用于分级）；
湿床 nx = 200 仍有 1 个亚阈值内部极值（与 1-D n = 200 同型，nx ≥ 400 为 0）。
