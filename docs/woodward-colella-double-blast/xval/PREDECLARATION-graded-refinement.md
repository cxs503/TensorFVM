# PREDECLARATION — graded-family refinement (WC double blast, L1 gate)

> **锚点**: `XVAL-FVM-M18737-ROUND2`（TensorFVM 的 m18737-round2 做法）
> **本轮问题**: `CERTIFIED-REF-CLOSURE.md` 把被定级解在 **nx=3200 一个网格上** 判为
> L1 = 1.776 %（>1 %，绑定门未过）。该结论**不能**区分两种情况，而两者结论相反：
> (a) 1.776 % 是 MUSCL/HLLC 族的**离散残差**，加密会继续下降 → 「certified <1 %」
>     只是网格问题；(b) 是**格式地板**，均匀加密降不下去 → <1 % 对本族已死，
>     不得再重复该声明。
> **做法**: 只加密**被定级解本身**（MUSCL-Hancock / MC / HLLC），与**同一份**已
> 自认证的 WENO5@12800 参考比较（参考自认证 L1 0.544 % / 峰值 0.023 %）。

## 预注册的判据与预测（在 6400/12800 结果落地**之前**写下）

**已有梯子（可核实，`ladder/data/`）**

| nx | L1 vs WENO5@12800 | 峰值 % | 观测阶 p |
|---|---|---|---|
| 800 | 6.046 % | 4.137 | — |
| 1600 | 3.299 % | 0.127 | 0.874 |
| 3200 | 1.776 % | 0.758 | 0.894 |

**预注册预测（幂律 `e(n) = C n^-p`，p 取最细相邻档观测值 0.894）**

| nx | 预测 L1 | 预测判定 |
|---|---|---|
| 6400 | **0.956 %** | <1 %（首次过门） |
| 12800 | **0.514 %** | <1 % |

- 若 nx=6400 实测 L1 落在 **0.956 % ± 15 %（0.81–1.10 %）**，幂律无地板读法成立。
- 若 nx=6400 实测 L1 **≥1.10 %** 或在 3200→6400 之间**不再下降（停滞 >2 %）**，
  则读法 (b) 成立：本族在均匀加密下有地板，`certified <1 %` 必须撤回，
  诚实上限改写为该地板值。

**判定规则（不事后改）**

1. `CERTIFIED_UNDER_1PCT_AT_NX<N>`：该档 L1 与峰值**同时** <1 %。
2. `GATE_GRID_LIMITED...`：固定阶地板估计 0 ≤ e_inf <1 %，但梯子内尚未有任何一档 L1 <1 %。
3. `SCHEME_LIMITED_FLOOR...`：固定阶地板估计 ≥1 %。
4. `PURE_POWER_LAW_NO_FLOOR_DETECTED...`：固定阶地板估计 ≤0（未检出地板）。

**CFL 控制（预注册的准入条件）**：nx=6400/12800 的 CFL 0.4 运行若超单作业墙钟，
改用 CFL 0.8 变体；该变体**只在**同一网格上 CFL 0.4 vs 0.8 的互相 L1 距离
**< 0.2 %**（远小于 3200→6400 的期望减量 ~0.8 %）时才准入加密研究，
并作为 config caveat 显式记录（`wc_graded_refinement.py` 的 `cfl_sensitivity`）。

**度量约定**：与前轮 `wc_certified_ref.py` 完全一致——在 [0.4,1] 窗口、
被定级档自身网格上取点、参考剖面线性插值；L1 用梯形积分归一化。
