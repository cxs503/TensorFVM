## ① 问题设定与基准出处

矩形水柱（宽 `a = 0.05715 m`，深 `h0 = 2a = 0.1143 m`）在长水槽中由闸门挡水，`t = 0` 撤门后测量**床面涌潮前锋**（toe）。判据量是前锋位置随时间的发展曲线。

### 1.1 基准的坐标轴（本轮的头号发现）

Martin & Moyce 原文 Fig. 3 的纵轴是 `X = x_f/a`（**X(0) = 1**），横轴是
`T = t·√(2g/a)`（浅水标度；`a` 是柱宽，柱体为 `a × 2a`）。仓内既有锚点
`src/tensorfvm/vof_phase0/anchors.py` 却把同一条曲线当成
`t* = t·√(g/a)`、`x* = (x_f − a)/a`（位移）来消费——**时间轴少了一个 √2，纵轴少了一个 a**。

出处（均可程序化复核）：

| 证据 | 内容 |
|---|---|
| 一次文献 | M&M (1952) Fig. 3 的坐标定义（`T = t√(2g/a)`, `X = x_f/a`, `X(0)=1`） |
| 参考实现（逐字） | Lethe `examples/multiphysics/dam-break/dam-break-2d.py`: `time_list = [x * ((2*g/L1)**0.5) ...]`, `x_list = [x / L1 ...]` |
| 兄弟仓独立复核 | TensorLBM `benchmarks/pending/dam_break_sc/result.json`：把 `T = t√(g/a)` 轴记为 "a factor sqrt(2) too small" 并**撤回**历史误差，冻结检查点 `X = 1.326 / 2.360 / 3.670` @ `T = 1 / 2 / 2.96` |

**旧口径的定量后果**（`anchors_mm.legacy_offset_audit`，测试钉住）：把旧表按代码消费的口径读，同一物理时刻的参考前锋被**高估最多 +46.7 %**；并且旧表首段（`t_old = 0.5`, `x_old = 0.75`）隐含的前锋平均加速度 **6.0 g**，超过重力驱动溃坝在 toe 处的物理上限 `g·h0/a = 2 g`——旧口径不是"换个刻度"，它是把一个静止起步的实验读成了匀速起步。

### 1.3 参考本身的不确定度（诚实交代）

同一张 1952 图有两次独立数字化：

| `T` | 1.0 | 1.5 | 2.0 | 2.5 | 2.96 |
|---|---:|---:|---:|---:|---:|
| 主参考（`anchors_mm`，Lethe 系） | 1.326 | 1.747 | 2.360 | 3.000 | 3.670 |
| 次参考（仓内旧表按原文轴重读） | 1.400 | 1.950 | 2.450 | 2.900 | 3.268 |

**参考的数字化不确定度最大 11.6 %，比 8 % 的判据还宽**。因此本报告对两次数字化**都逐点裁决**（C1 主、C2 次），不挑一个"好看"的当唯一基准。

## ② 方法与实现（方程/格式出处 + 关键代码指针）

### 2.1 方法谱系与选型（第 2 轮调研沉淀）

| 候选路线 | 出处/成熟度 | 选型 |
|---|---|---|
| 浅水方程 + HLL/MUSCL（Ritter/Stoker） | 仓内已成熟（`shallow_water`，Ritter 波前 0.33 %） | **不适用**：Ritter 给出 `X_R = 1 + 2T`，在 `T=1` 处比实验快 100 %，M&M 的早期崩塌是**非静水**的 |
| 单相/势流崩塌解 | 教科书 | 不适用（无自由面演化） |
| **二维不可压 NS + VOF/PLIC + 投影法** | 本仓 `TwoPhaseSolver`（前轮已验证质量守恒 1e-15 级） | **采用**：唯一能同时给出界面输运、变密度投影与重力的路线 |
| 动量对流格式 | 一阶迎风（历史）/ 限幅二阶（本轮新增） | **两条都跑**，用判据比较 |
| 基准口径 | 原文轴 + 参考实现逐字 | **修复**（§1.1） |

**本轮新增能力（代码指针）**

1. `src/tensorfvm/vof_phase0/anchors_mm.py`（新）——原文坐标轴的锚点：`mm_time` / `mm_x` / `mm_front`（线性插值、**禁外插**）、`MM_CHECKPOINTS_T`、`legacy_offset_audit`（旧口径缺陷的量化），并把 `X = 1.326/2.360/3.670` 与兄弟仓冻结值对齐。
2. `src/tensorfvm/two_phase_solver.py` —— `momentum_advection_scheme ∈ {"upwind","limited2"}`：限幅二阶单侧差分
   `∂u/∂x ≈ [Δ⁻ + ½ψ(r)(Δ⁻ − Δ⁻⁻)]/Δx`，`r = Δ⁻⁻/Δ⁻`，`ψ` 为 clip 到 [0,1] 的 van Leer 限幅器，且把反扩散项**钳到 |Δ⁻| 以内**（导数据持迎风符号、不超 2 倍）。边界两层退回一阶。`order=1` 路径与历史逐位一致（有测试）。
3. `src/tensorfvm/vof_threecase/dambreak.py` —— `DamBreakMMConfig.convention="martin_moyce"`（默认）+ `mm_checkpoint_error()`：在原文轴上逐检查点裁决；`momentum_scheme` 透传。旧口径保留可复现。

### 2.2 关键设置

CFL 0.35，`dt ≤ CFL·min(dx,dy)/√(g h0)`（重力波限制，前轮的修复保留），`pressure_form="reduced"` + 逐面井平衡初压（前轮修复保留），VOF = PLIC，`t_end = 0.172 s`（最后一个检查点 + 1 步余量），前锋按床面 3 行 `α=1/2` 亚格插值定位（与实验"toe"定义一致）。

## ⑤ 收敛性与参数敏感性（≥ 两分辨率 / 两参数点）

| 分辨率 × 格式 | 最大 \|误差\|（主参考） | 最大 \|误差\|（次参考） |
|---|---:|---:|
| 50x25 upwind | 22.50 % | 17.89 % |
| 50x25 limited2 | 20.06 % | 17.53 % |
| 100x50 upwind | 14.47 % | 11.29 % |

* **分辨率**：4 mm→8 mm（cells/柱宽 7.1→14.3）把最大误差从 22.5 % 压到 14.5 %，单调改善但**未见收敛平台**——缺口不是纯离散误差，至少还有一个随分辨率变慢的连续效应。
* **格式**：同网格精致二阶在 4/5 检查点改善 0.4–2.4 个百分点，量级小于"分辨率"这一杠杆。
* **参考口径**：两次数字化的差 11.6 %，与剩余缺口同量级（`up_g100` 在主参考 −14.5 %、次参考 −4.0 %@T=2.96）。**这是本节点无法在 8 % 判据上给出确定结论的根本原因。**
