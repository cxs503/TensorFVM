# TensorFVM 验证欠账清偿：环形通道轴向 Poiseuille 后端的独立解析/数值复核

## 1 案例介绍

physics: 充分发展的三维环形通道（同心圆柱间隙）轴向层流，速度只有轴向分量且与 z 无关，严格退化为二维截面上的一维 Poisson 方程 (1/r)d/dr(r du/dr) = -G/mu，内/外壁 r=R_i, R_o 无滑移。

| 参数 | 值 |
|---|---|
| 内半径 R_i | 0.05 m |
| 外半径 R_o | 0.1 m |
| 动力粘度 mu | 0.001 Pa·s |
| 密度 rho | 1.0 kg/m^3 |
| 压力梯度 G | 0.01 Pa/m |
| 峰值速度（闭式解） | 3.155547e-03 m/s |
| 体积流量（闭式解） | 4.947382e-05 m^3/s |

域：同心环，多边形网格 ntheta × nr（周向贴合、径向分层），全部为生产算子组装的全截面稀疏矩阵求解。

## 2 怎么做的

动机（验证欠账）：`tensorfvm/annular.py` 是一个已合并的生产后端，`solve()` 会把解析参考场写进 `fields["reference_axial_velocity_m_s"]`，但全仓 `tests/`、`scripts/`、`verification/` 里没有任何文件 import 过它（本单开工前 grep 结果为空）——参考值从未与计算值比较，等于「有基准、无判定」。

本单新增三项独立复核，均不把后端自带的公式当真实值：

1. **ODE/边界条件证明**：在 30 位十进制（mpmath）下独立重新推导 u(r) = G/(4mu)[(R_o^2 - r^2) - (R_o^2-R_i^2)·ln(R_o/r)/ln(R_o/R_i)]，对其数值微分验证 r u'' + u' + (G/mu) r = 0 与两侧无滑移；再把后端存储的闭式解与该独立推导逐点比较。另加 +5% 扰动作为残差指示器的负控（可证伪性）。

2. **流量独立积分**：Q = 2π∫u r dr 用 scipy `quad`（epsrel=1e-13）独立积分闭式速度剖面，与后端 `analytic_flow` 比较。

3. **网格收敛**：调用生产 `solve()` 三档网格 (16×8, 32×16, 64×32)，计算体积加权 L2 / L∞ 相对误差、体积流量相对误差，并对径向步长 h=R_i/nr 拟合观测阶；再施加 ≥3% 平台判据与负控（2× 误差、5% 参考扰动必须被拒）。

工具链：Python 3.11 / torch 2.7 / scipy / mpmath / matplotlib；入口 `python -m tensorfvm.verification.annular`，产物 `artifacts/annular_verification/annular_verification.json` 与 `.png`。

## 4 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 基准 | 相对误差 | <3%？ |
|---|---|---|---|
| 速度场 L2（64×32） | 独立推导闭式解 | 0.640% | 是 |
| 速度场 L∞（64×32） | 同上 | 0.781% | 是 |
| 体积流量（64×32） | 独立自适应积分 | 0.196% | 是 |
| 后端闭式解自身 | 独立重推 + ODE 证明 | 1.7e-15 | 是（机器精度） |
| 流量闭式 vs 积分 | 独立 quad | 1.9e-15 | 是（机器精度） |

最粗网格（16×8, 128 单元）速度误差 9.70% **不满足** 3% 判据，说明该后端的可用网格下限在 ntheta×nr ≳ 32×16 一侧（其 L2 误差 2.53%，已达标）。

## 5 注意点 / 局限

- 负控实测：把误差放大 2 倍（False）或把参考扰动 5%（False）都不会被 3% 判据放行（False=被拒），判据可证伪、不空转。
- **后端的真实限制**：`AnnularConfig` 强制 `pressure_gradient_pa_m > 0`，反向流动（抽吸）无法表达；本单把它登记为「能力边界」而非缺陷，并写进测试 `test_reversed_flow_is_rejected_by_the_config_guard`。
- 网格是内/外圆的多边形离散，误差里混有多边形贴合误差；因此本审计只用径向 h 拟合阶数，不做「周向单独加密即可收敛」的假设。
- 本单只覆盖层流充分发展环形 Poiseuille；旋转环道（Taylor–Couette）、湍流环道、非牛顿粘度均未覆盖，不作声明。
- 未修改任何求解器数值路径：只新增 `src/tensorfvm/verification/annular.py` 审计模块与 `tests/test_annular_verification.py`。
