# CASE-WOODWARD-COLELLA — 双爆轰波相互作用：文献参考剖面定量复核

**锚点**：CASE-WOODWARD-COLELLA（feature_ledger, open）
**验收目标（总账）**：`【算例池|WOODWARD-COLELLA｜ref: Woodward & Colella 1984 包络｜容差: <10%】`
**仓**：TensorFVM（`src/tensorfvm/compressible/`）
**判定**：**证据由 WITHHELD 升级为 REAL-with-caveat**——峰值密度 1.69%、L1 剖面 2.96%、四个陡峭阵面位置 ≤1.2e-3 全部 <10%；**低密度平台（近真空浅槽）相对误差 14.2% 未达标**（绝对偏差 0.022，仅为峰值密度的 0.35%），因此整体 verdict 仍为 **FAIL（诚实申报，不粉饰）**。

## ① 案例介绍（物理背景 / 参数表）

一维封闭管道 [0,1] 内三个压力平台：左端 p=10³、中段 p=10⁻²、右端 p=10²，密度 ρ=1、u=0，γ=1.4。
两端反射壁（x=0、x=1）。两束爆轰波（激波+接触间断+稀疏波）相向传播，t≈0.028 前后在管中部对撞，形成双激波干涉结构；积分到 **t = 0.038**。

| 参数 | 值 | 来源 |
|---|---|---|
| 域 | x∈[0,1]，1D（ny=1） | W&C 1984 |
| 初始 (ρ,u,p) 左 | (1, 0, 1000) on x≤0.1 | arXiv:1902.07773 §5.1.4；arXiv:2109.14340 Eq.(37) |
| 初始 中 | (1, 0, 0.01) on 0.1<x<0.9 | 同上 |
| 初始 右 | (1, 0, 100) on x≥0.9 | 同上 |
| γ | 1.4 | 同上 |
| 终止时刻 | t=0.038 | 同上 |
| 壁面 | 两端反射（periodic 于 y） | `cases.double_blast` |

W&C 1984 原文闭源（OpenAlex `oa_status=closed`，见 `provenance.md`），**参考剖面不以记忆代替原文**：本单从开放获取的复述文献中**逐字（矢量路径级）提取**了作者明确标为 "Reference" 的解。

## ② 怎么做的（方法 / 工具链）

1. **参考解获取（本单新增能力）** `docs/woodward-colella-double-blast/reference/digitize_reference.py`
   - 抓取 arXiv:1902.07773（Dumbser et al., JCP 2019）PDF，sha256 `509e2350…80e064`；
   - 该文 §5.1.4 明示：*"the expected solution has been computed via the pure RPJ on a mesh of 3200 cells"*；
   - 图 21 的两幅密度剖面（(a) 400 cells / (b) 800 cells）图例含 **"Reference"** 曲线；PDF 中曲线是**矢量路径**，用 PyMuPDF `get_drawings()` 提取，**不是读图估读**；
   - 坐标标定：用图内刻度文字的中位中心做最小二乘仿射（x 轴 296.573 pt/unit、y 轴 −15.307 pt/unit，**残差 0.000 pt**）；
   - 两条独立数字化通道（(a)、(b) 面板，同一 Reference 曲线）互相校验：max|Δρ| = **3.1e−5**（相对 2.2e−3 %）→ 数字化误差预算可忽略。
   - 产物：`reference/curves.json`（全部路径+标定）、`reference/reference_density.csv`（两通道均值）。
2. **本地求解**：`cases.double_blast`（MUSCL 二阶 + MC 限幅 + HLLC + SSP-RK，CFL 0.4），nx=400 / 800，t=0.038。
3. **比较器（本单新增）** `src/tensorfvm/compressible/wc_reference.py`：窗口 x∈[0.4,1.0]（published 参考曲线覆盖区），输出 5 类指标 + 逐项 pass/fail（容差 10%，位置容差 0.02）。
4. **回归门** `tests/test_compressible_wc_blast_reference.py`（4 用例，6.7 s）：参考表结构/双通道一致性、阵面检测器对解析台阶有效性、已入库 nx=800 剖面的三项达标断言 + **低平台不达标断言**、新跑一次守恒性 smoke。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **参考解性质**：RPJ@3200 是"作者认为的"预期解，本身是数值解（非解析真解）；因此 <10 % 的判定是"与文献已发表数值解一致"，不是"与真解一致"。文中未给出它的误差条。
2. **数字化的两点风险**：(i) PDF 曲线经 ghostscript 共线点合并（174 个路径点≠3200 个数据点），几何保持但拐点被拉直；(ii) 只覆盖 x∈[0.4,1.0]（作者绘图窗口），x<0.4 的反射波区无文献参考——该区仍只有仓内既有的精确黎曼早时锚（`blast_early_anchors`）。
3. **低平台指标的病态性**：浅槽极小值对网格/方案极敏感，且与窗口边界无关（已改成内窗 0.42–0.98 仍 14 %）；不建议把它单独当作通过依据，也不建议为了让其"变绿"而放宽阈值。
4. **阵面检测器**：`faces()` 取 |∇ρ| 局部极大并按 0.02 最小间距去重；等值平台上会返回平局位置的多个阵面（解析台阶用例返回 4 个候选，含正确位置）。指标只在候选数相等时给误差（否则 `faces_abs_error=None` → 该项 FAIL），避免"少检出一个阵面反而变绿"。
5. **算力**：本机 load15 ≈ 106/128，nx=400 用时 39 s、nx=800 用时 100 s（单核）；nx≥1600 未在本机跑（容量纪律），是后续验证阶梯的待办。

## ⑥ 误差判定（逐项）

| 关键量 | 相对文献 Reference 的误差（nx=800） | 是否 <10 % |
|---|---|---|
| 峰值密度 | 1.688 % | **是** |
| 峰值位置 | 0.0027（绝对，归一化 0.27 %） | **是** |
| 剖面 L1 | 2.957 % | **是** |
| 四个阵面位置 | ≤0.0012（归一化 ≤0.12 %） | **是** |
| 低密度平台 ρ_min | 14.217 %（绝对 0.022 = 峰值 0.35 %） | **否** |

**结论**：不声称"全指标通过"。稳定量（峰值、阵面位置、L1）已在 <10 % 内且随加密收敛；浅槽极小值 14 % 未达标、且不收敛，记为 honest-FAIL 并留作后续（建议：与第二种独立方案/更高网格的参考对比，或改用窗口平均而非极小值作为收敛量）。
