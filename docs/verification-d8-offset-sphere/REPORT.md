# D8 复核：偏置球平行轴锚「I_zz = 2.05」不一致的根因与结构性消除

- 任务：m16122（selfstart，TensorFVM）——认领 `docs/VERIFICATION_DEBT_LEDGER.md` 条目 **D8**
  （m14901 挂起、自称已入账但实际未入账的待查项）
- 代码：`src/tensorfvm/panel_added_mass.py`（`sphere_offset_axis_added_inertia`
  的 `radius`/`distance` 必填化）、`scripts/verify_d8_offset_sphere.py`（新）、
  `tests/test_d8_offset_sphere.py`（新，5 测）
- 本报告数字全部来自 `summary.json`（驱动脚本程序化写入，零手抄）。

## 1. 案例介绍（物理背景 / 几何 / 参数表）

m14901（`docs/maneuvering-added-inertia/REPORT.md` §4.5）在交付 D7 时挂起一条
不一致：「`added_mass_matrix_6dof` 在球偏置配置下给出 `I_zz = 2.05`（球心 (0,0,1.5)
理论 0；球心 (1.5,0,0) 理论 `m_a d^2 = 4.71`），与 D1 报告 C3 结论不一致」，并称
「登记在账本 §2（D8）」。复核发现：**账本 §2 并无 D8**，该不一致从未被解决。

本单对同一物理问题做独立复核。理想流体中半径 `a`、密度 `rho` 的球，附加质量为
各向同性点质量 `m_a = (2/3) pi rho a^3`（Lamb）。球心在 `r_c`、绕过原点轴以角速度
`Omega` 旋转时，球心平动速度 `U = Omega x r_c`，附加动能 `1/2 m_a |U|^2`，故

- 轴**过球心**：`U = 0` → `I = 0`（球绕直径附加转动惯量恒 0，D1 已证）；
- 轴**距球心 d**：`|U| = Omega d` → `I = m_a d^2`（平行轴锚）。

| 参数 | 值 | 说明 |
|---|---|---|
| a | 1.0 | 球半径 |
| d | 1.5 | 偏置距离 |
| rho | 1.0 | 流体密度 |
| m_a | 2.094395 | 球附加质量 |
| m_a d^2 | 4.712389 | 精确锚（垂直轴） |
| 网格阶梯 | 24x14 / 32x18 / 48x26 | 336 / 576 / 1248 面元 |

两种偏置配置：**A** 球心 (0,0,d)（z 轴过心 → `I_zz=0`，x/y 轴 → `m_a d^2`）；
**B** 球心 (d,0,0)（x 轴过心 → `I_xx=0`，y/z 轴 → `m_a d^2`）。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **判据先于动手**：两配置 × 3 个对角项对精确锚，最细网格 <3%、幂律外推 <1%、
   非对角 <1e-3（相对 `m_a d^2`）。
2. **面元解**：`sphere_panels_offset` 生成偏置球面元，`added_mass_matrix_6dof`
   单 LU 解 3 个转动 Neumann 问题（`directions=(3,4,5)`），取 3x3 转动块。
3. **外推**：`v(N) = v_inf + K N^(-q)` 三点拟合（q 网格搜索，最粗点残差最小化）。
4. **幻影机制复现**：旧版锚点助手 `sphere_offset_axis_added_inertia(radius=1.0,
   distance=1.0, rho=1.0)` 的 `distance=1.0` 默认值 → 锚 = `m_a*1.0 = 2.094`，
   与 d=1.5 的面元值 4.6436 相比 **+121.7%** —— 即 m14901 报告的 2.05 量级幻影。
5. **结构性消除**：`radius`/`distance` 改为必填位置参数（全部 3 处既有调用点均为
   显式传参，零破坏）；回归测钉死两配置锚 + `TypeError` 门 + `yaw_added_inertia_panel`
   自动原点语义。
6. 工具链：驱动脚本 + pytest；零重算力（最细 1248 面元，单核秒级）。

## 3. 计算结果（程序化注入，零手抄）

### 3.2 配置 B：球心 (1.5,0,0)

| 网格 | I_xx（理论 0） | I_yy | I_zz | 非对角 max |
|---|---|---|---|---|
| 24x14 | 1.0e-4 | 4.5531 | 4.5294 | 6.9e-18 |

`I_yy`：最细 **-0.98%**，外推 4.7103（**-0.05%**，q=0.97）；
`I_zz`：最细 **-1.46%**，外推 4.7039（**-0.18%**，q=0.81）。

### 3.3 幻影机制（m14901 的 2.05）

| 量 | 值 |
|---|---|
| 旧默认锚（distance=1.0） | 2.0944 |
| m14901 报告值 | 2.05 |
| 面元值（d=1.5，48x26） | 4.6436 |
| 面元 vs 默认锚 | **+121.7%** |

m14901 把 d=1.5 的面元值对 d=1.0 的默认锚比较，得到「不一致」；**求解器本身
对全部精确锚 PASS**，缺陷在锚点助手的静默默认参数，不在面板法。

## 4. 注意点（踩过的坑 / 局限）

1. **挂起项必须当场入账**：m14901 声称「登记在账本 §2（D8）」，账本里却没有——
   本单补账并结清。教训：报告里声称的账本动作要在同一 commit 里落地。
2. **`yaw_added_inertia_panel` 自动原点陷阱**：自动原点=包围盒 x 中点，偏置球上
   静默落到球心（返回 0 而非 `m_a d^2`）。对 KVLCC2 船体（x∈[0,L]，中点=舯剖面）
   语义正确；偏置体必须显式传 `origin`。已用回归测文档化该语义。
3. 面元值为无界理想流体势流解；与 D1/D6 同族，不含粘/自由面效应。
4. 外推 q≈0.8-1.0 偏低，是球面多面体化（几何）误差主导，非数值格式误差；
   外推值仅作离散不确定度估计。

## 5. 误差判定（逐项 vs 基准，显式回答 <3%）

| 关键量 | 基准 | 结果 | 是否 <3% |
|---|---|---|---|
| A: I_xx, I_yy（最细 48x26） | m_a d^2 = 4.712389 | 4.6436（-1.46%） | **是** |
| A: I_xx, I_yy（外推） | 同上 | 4.7038（-0.18%） | 是 |
| A: I_zz | 0 | 1.0e-32（相对 m_a a^2） | 是 |
| B: I_yy（最细） | 同上 | 4.6663（-0.98%） | **是** |
| B: I_yy（外推） | 同上 | 4.7103（-0.05%） | 是 |
| B: I_zz（最细/外推） | 同上 | 4.6436（-1.46%）/ 4.7039（-0.18%） | **是** |
| B: I_xx | 0 | 2.3e-6（相对 m_a a^2） | 是 |

| 幻影机制 | 旧默认锚 2.0944 | 复现 +121.7% 幻影差 | 机制确认 |

**结论：m14901 的 D8 不一致在当前代码不可复现；根因=锚点助手静默默认参数，
已必填化消除；D8 结清。**
