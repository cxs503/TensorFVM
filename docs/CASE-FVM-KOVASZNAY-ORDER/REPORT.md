# CASE-FVM-KOVASZNAY-ORDER 收敛阶验证报告

## ① 案例介绍（物理背景/几何/参数表）

Kovasznay (1948) 精确解是定常不可压 Navier-Stokes 方程的一个解析解，常用于验证
粘性流求解器的收敛阶。该解在二维域 $[0,1]\times[0,1]$ 上定义：

$$u = 1 - e^{\lambda x}\cos(2\pi y)$$
$$v = \frac{\lambda}{2\pi} e^{\lambda x}\sin(2\pi y)$$
$$p = \frac{1}{2}(1 - e^{2\lambda x})$$

其中 $\lambda = \frac{1}{2\nu} - \sqrt{\frac{1}{4\nu^2} + 4\pi^2}$，$\nu = 1/Re$。

**参数表**：
| 参数 | 值 | 说明 |
|------|-----|------|
| Re | 40 | 雷诺数（文献标准值） |
| 域 | $[0,1]^2$ | 单位正方形 |
| 边界 | Dirichlet（精确解面均值） | 四面固定 |
| 名义阶 | 2 | 二阶混合对流格式 |

**文献锚点**：Kovasznay, L. I. G. (1948). "Laminar flow behind a two-dimensional grid".
*Proc. Camb. Phil. Soc.* 44:58. DOI: 10.1017/s0305004100023999

**验收判据**（feature ledger）：L2 收敛阶 ≥ 1.8（名义二阶），log-log 斜率 on 32/64/128 三套网格。

## ② 方法与流程

### 求解器配置
- **格式**：NativeHybridNavierStokes3D，二阶延迟修正对流（deferred correction）
- **线性求解**：reused_lu（LU 分解复用 + GMRES 精化）
- **对称面闭合**：zero_gradient（切向面自由度与所属单元值绑定，离散法向导数为零）
- **外迭代**：Picard，tolerance=1e-8，relaxation=0.7，max_outer=80

### 验证流程
1. 在 n=8, 16, 32 三套网格上求解（extruded 2D 网格，z 方向 1 层）
2. 计算体积加权 L2 误差（总速度、面内速度、展向速度、压力）
3. 计算两两网格间的观测阶（observed order）
4. 计算全梯度的最小二乘斜率（least-squares slope）
5. 按预声明判据逐项评定（C1-C8）

### 关键发现（历史追溯）
- m16130：首次测量得 1.684 → honest FAIL
- m16396：范数分解发现展向分量 w 仅 1.106 阶（w 解析恒为零）
- m16524：定位根因——对称面切向自由度为自由牵引闭合，产生 O(h) 虚假展向速度
- m16695：引入 zero_gradient 闭合，w 降至机器精度，面内阶 1.808
- 本工作：汇总已有数据，评定判据，指出需 n=64/128 完成 ledger 锚点

## ⑤ 注意点 / 局限

1. **预渐近行为**：8→16 对的观测阶仅 1.588，表明 n=8 仍在预渐近区。16→32 对达到
   1.808，已跨过 1.8 门槛，但仅凭一对网格不足以确认渐近收敛。

2. **最小二乘斜率未达标**：C5（全梯度最小二乘斜率 ≥ 1.8）得 1.698，FAIL。
   原因是 n=8 的预渐近误差拉低了整体斜率。

3. **ledger 锚点要求 32/64/128**：feature ledger 明确要求 "log-log 斜率 on 32/64/128
   三套网格"。当前数据最高仅到 n=32，需补充 n=64 和 n=128 才能完成锚点。

4. **计算成本**：n=32 已耗时 ~1000 秒，n=64 预计 ~8000 秒，n=128 预计 ~64000 秒。
   建议递交集群并行计算。

5. **压力收敛**：压力（均值自由）阶 1.745，略低于速度阶，符合混合格式中压力
   通常比速度低半阶到一阶的预期。

**结论**：最细对（16→32）观测阶 1.808 ≥ 1.8，**锚点 C3/C4 通过**。但 C5（最小二乘斜率）
因 n=8 预渐近行为未达标。按 ledger 要求，需 n=64/128 数据确认渐近斜率 ≥ 1.8。

**下一步**：递交集群计算 n=64 和 n=128 层级，合并后重新评定 C5。预计 n=64/128
的加入将使最小二乘斜率趋近 1.8+（16→32 已 1.808，更细网格应更接近二阶）。
