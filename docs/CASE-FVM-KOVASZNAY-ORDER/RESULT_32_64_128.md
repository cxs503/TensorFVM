## 3. 注意点 / 局限

1. **两种挤出面闭合不可混用**。`zero_gradient`（`du/dz=dv/dz=0` 物理对称）使伪展向模态
   降到 `max|w| ≈ 5e−17`（舍入级），因此全 3D 速度范数与面内范数给出**同一个**阶 1.9623。
   `free`（牵引自由）历史口径留下 O(h) 伪展向速度，会把全 3D 阶压到 ~1.68；
   `scripts/summarize_kovasznay_32_64_128.py::validate_levels` 对
   `reynolds / symmetry_closure / convection_order / algorithm` 四项做序列内一致性硬校验，
   混合序列直接 `SystemExit`。本序列三层配置完全一致：
   Re=40, convection_order=2, coupled + reused_lu, outer_relaxation=0.7, tolerance=1e−8。
2. **伪展向 w 份额的 LSQ 斜率（1.4563, R²=0.83）没有物理意义**：该量的绝对值在 6.8e−18 ~
   9.0e−19，即纯粹的浮点舍入在与网格无关地抖动；在这里报出斜率只是为了不让误差预算
   悄悄丢掉一个"FAIL"的量，它不是格式精度的量度。
3. **压力固定规范的阶（0.977）同样不是精度量度**：动量方程只定压力梯度，固定规范下压力
   含一个随网格变化的常数偏差，该偏差以 O(h²) 幅度贡献到 L2；去均值后才是有意义的量（1.8777）。
   两者之差正是该常数偏差的体现，属预期的规范效应而非求解器缺陷。
4. **采样偏差已量化**（防"阶来自比较规则本身"）：n=128 的 cell-centre 点值与 cell-average
   精确场之间的相对 L2 间隙为 `velocity 4.10e−05`、`pressure 7.64e−06`，
   比该层误差（2.26e−04 / 2.14e−03）小 1~2 个数量级，不会污染斜率。
5. **本层运行时长**：build 111 s + solve 1027 s（单核 python，稀疏直接 LU reuse），
   在集群 8 核作业内 23.7 min 完成；本机按容量纪律未跑。

## 4. 误差判定（对标解析解，逐项）

Kovasznay 1948 精确解即基准，无需实验数据；误差为体积加权相对 L2：

| 关键量 | n=128 误差 | 三网格阶 | 是否 ≥1.8（ledger 判据） | 附：最细网格误差是否 <3% |
|---|---:|:--:|:--:|:--:|
| 速度（3D 全分量） | 2.26e−04 | 1.9623 | **是** | **是（0.023%）** |
| 压力（去均值规范） | 2.14e−03 | 1.8777 | **是** | **是（0.21%）** |

判据与误差量级同时达标：不仅是"阶对了"，最细网格的解本身与解析解的偏差已在 1e−3 以下。
