## 3. 判据判定

`velocity L2 全 3D 三网格斜率 = 1.9623 ≥ 1.8` → **PASS**。
这不是"某两点凑出来的"：两段独立的观测阶（1.9370 / 1.9877）都在阈上且相距 0.05，
整梯几何拟合的阶 1.9194 也在阈上；三层全部数值收敛（Picard 21/21/26 次，divergence_max ≤ 2e−9）。
`tests/test_kovasznay_32_64_128_acceptance.py`：**24 passed / 9 skipped**
（9 个 skip 全属 `anchor` = 历史 free 闭包对照组，n=64/128 的 free 层由 cj2529 在飞，未落盘即为 not-measured，不是 pass）。

## 4. 注意点（局限与踩过的坑）

1. **16/32/64 ≠ 32/64/128**。历史"通过"声明（面内 1.808）是 16/32/64 上的，且 n=16 已在渐近区外，
   与本次证据链不可互换；ledger 直到本次三网格齐备才可 close。
2. **固定规范压力阶 0.9772 不是格式精度**：动量方程只定压力梯度，固定规范的压力含随网格变化的常数偏差；
   有物理意义的是去均值规范（1.8777）。
3. **展向 w 的"斜率"无意义**：`zero_gradient` 闭合把伪展向模态钉在舍入级（max|w| ≤ 4.8e−17），
   对 1e−18 级的量取 log 斜率是在拟合噪声。该列保留只为暴露"没有伪模态"，
   应读作 machine-zero（`summary.verdict` 里由 `spanwise_machine_zero` 语义承担），不得当作阶的证据。
4. **闭包不可混用**：`free` 与 `zero_gradient` 的序列混在一套阶梯里，最小二乘斜率仍会给出"好看的数"，
   但它不是任何格式的阶。`validate_levels` 对此硬报错（`reynolds/symmetry_closure/convection_order/algorithm` 四项一致性）。
5. **三网格没有阶的不确定度**：`f(h)=L+C h^p` 在 N=3 时无残差自由度，`order_stderr` 如实记 `nan`；
   要给出可信区间需第四条网格（建议 256，本单未跑，属明确欠账）。
6. **采样偏置已量化**：`cases.json` 的 `sampling_bias` 记录点值与单元平均的差（n=128 面内 ~1e−4），
   它本身按二阶衰减，故斜率不是采样规则的假象。
