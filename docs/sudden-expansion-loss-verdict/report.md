# 突扩管损失系数 K 的口径裁决：归档 FAIL(101%) 与审计 PASS(+1.5%) 同时不成立 (m7573)

**任务**: m7573 · selfstart 自找活（generalist 席，TensorFVM）
**日期**: 2026-11-09
**性质**: 验证欠账裁决（对已合并/已归档证据做独立复算 + 一次复现算例；轻量，单算例 52 s）
**一句话结论**: 平面突扩管 AR=4、Re_D=100 的 `K` 在**同一标称算例**上，六条后处理口径给出
**0.6717 / 0.7844 / 0.9608 / 1.0260 / 1.0260 / 1.4175**（差 4 倍），对照 Borda-Carnot
`K_BC=0.5625` 全部 **FAIL（19%–152%）**。归档基准的 **101% FAIL** 是「出口站位含发展段摩擦」
的站位伪影；而 m6526 建议的 `k_from_static_recovery` **+1.5% PASS 亦不可复现**为收敛判据
（其值来自另一实现/另一几何的步面外推）。真实结论 **WITHHELD**：12D 通道尚未形成充分发展
摩擦平衡（实测 dp/dx 反号，量级仅为充分发展值的 −65%），任何步面外推都不成立。所需实验：
≥30D 长域 + 由摩擦平衡校验的外推（已登记为后继靶子）。

---

## 1 案例介绍（物理背景 / 几何 / 参数）

二维平面突扩：下游高 `D=1`，入口高 `D/AR`（`AR=4`），入口均速 `U_in=1`，
出口均速 `U_out=1/4`，`Re_D=U_out D/ν=100`（`ν=0.01`），下游长 12D，出口零梯度、
壁面无滑移。参照值 `K_BC=(1-1/AR)²=0.5625`（无粘动量平衡，无壁面摩擦）。

| 参数 | 值 |
|---|---|
| AR | 4 |
| Re_D | 100（ν=0.01） |
| 网格 | D/10（`nx=120, ny=40, hx=hy=0.1`） |
| 域长 | 12 D（归档族 D/10、D/20、D/30 同为 12 D） |
| 离散 | 交错 SIMPLE，一阶迎风，α_u=0.8，α_p=0.5，sparse Poisson，tol=1e-6 |
| 收敛 | 4460 次外迭代，`max|div|=1.05e-8`，墙时 52.3 s |
| 参照 | Borda-Carnot `0.5625`；动量恢复 `Cp=2(1/AR)(1−1/AR)=0.375` |

## 2 怎么做的（方法 / 工具链）

1. **一次复现算例**：`scripts/audit_expansion_loss_verdict.py --mode run` 用仓内
   `run_fvm_incompressible_baselines.run_one` 重跑 D/10，落盘 JSON + 全场
   （`docs/sudden-expansion-loss-verdict/runs/expansion_n010{,_fields}.npz`）。
2. **纯后处理模块**（新增）：`src/tensorfvm/expansion_loss.py` —— 全部为纯函数，
   不重新求解即可对已存场重新判级：
   `station_metrics`（站位口径）、`section_average`（面积/质量通量加权）、
   `kinetic_energy_factor`（`α=<u³>/<u>³`）、`linear_slope` / `step_plane_value`
   （发展段线性斜率 → 步面外推）、`verdict`（3% 门）。
3. **六条口径同源复算**（同一场、同一站位定义）：
   - `station_bulk`：归档口径 `k_total_head`（面积平均 `p` + 平均 `u` 的动压）；
   - `station_flux`：质量通量加权总压（m6390/审计脚本口径）；
   - `static_station`：恒等式 `K = 1 − 1/AR² − Cp`（站位）；
   - `static_step` / `bulk_step` / `flux_step`：把上述三条按末 2D 发展窗线性外推到 `x=0`（步面）。
4. **交叉证据（只读，零手抄）**：归档 12D 三网格与 20D 长域
   （`docs/incompressible-baselines/baseline-runs/expansion_{n010,n020,n030,long_n010}.json`）、
   质量通量口径审计（`docs/verification/sudden-expansion-loss-definition/results.json`）、
   独立 torch MAC 实现（`docs/verification-expansion-symmetry/summary.json`）。
5. **机器门**：`tests/test_expansion_loss_verdict.py`（11 条）——加权恒等（均匀剖面退化）、
   抛物剖面 `α=54/35` 与动压偏置解析值、零斜率外推恒等、3% 判定边界、
   **提交的 results.json 必须由工件逐字节复现**、复算站位 K 必须复现归档 `k_total_head`、
   **发展比 |<1| 机器锁定「WITHHELD」结论依据**、口径散布 >0.5 的负向护栏。

## 3 计算结果

### 3.1 D/10 六条口径（同一场，`results.json` 程序化输出）

| 口径 | K | 对 0.5625 误差 | 判定 |
|---|---|---|---|
| station_bulk（归档 QoI） | 1.0260 | 82.41 % | FAIL |
| station_flux（通量加权） | 0.7844 | 39.44 % | FAIL |
| static_station（恒等式） | 1.0260 | 82.41 % | FAIL |
| bulk_step（外推到步面） | 0.6717 | 19.41 % | FAIL |
| flux_step（外推到步面） | 0.9608 | 70.82 % | FAIL |
| static_step（外推到步面） | 1.4175 | 152.00 % | FAIL |

`station_bulk` 与 `static_station` 逐位一致（`1.0260453667` vs `1.0260453652`，差 1.1e-9，
源于 `u_out/u_in=0.2500000029`），说明恒等式与前处理自洽；**差异全部来自口径，不是求解器分歧**。

### 3.2 为什么站位 `K` 不是损失系数（站位依赖的铁证）

| 证据 | D/10 | 说明 |
|---|---|---|
| 12 D 域，`k_total_head` | 1.0260 | 归档基准 QoI |
| 20 D 域，`k_total_head` | 0.8885 | **同一网格、同一 Re，仅加长 8D，K 掉 0.138（−13%）** |

随管道长度下降的量只能是「发展段壁面摩擦」，不是突扩损失 ⇒ 归档的 101% FAIL 是**站位伪影**。

### 3.3 为什么「+1.5% PASS」也不可复现为收敛判据

| 实现 / 几何 | 口径 | D/10 | D/20 | D/30 | 对 0.5625 |
|---|---|---|---|---|---|
| torch MAC（对称中心入口） | `k_extrapolated`（总压外推） | 0.3446 | 0.3453 | 0.3799 | −39% / −39% / −32% |
| torch MAC | `k_from_static_recovery`（`1−1/AR²−Cp_extr`） | 0.5708 | 0.5359 | 0.5074 | **+1.5% / −4.7% / −9.8%** |
| NumPy SIMPLE（本单 D/10） | `static_step`（同式、自算斜率） | 1.4175 | — | — | +152% |

同一公式在两种实现间差 **2.5 倍**：`Cp` 的外推斜率对**发展窗选择与入口几何**
（底贴 vs 居中）极度敏感（MAC 归档 cp_extr = 0.367/0.402/0.430，单调越过动量平衡 0.375）。
D/10 的 +1.5% 是两个反向误差（摩擦修正过量 vs 动压剖面偏置）的偶然抵消，
网格加密后误差单调跑到 −9.8% ⇒ **不是收敛证据**。

### 3.4 根因：12D 通道没有充分发展（机器可判）

| 量 | 实测（末 2D 窗） | 充分发展值 | 比 |
|---|---|---|---|
| `dp/dx` | **+0.0196** | −0.0300（`−12νU_out/D²`） | −0.65（**符号相反**） |
| 线性拟合 R²（p） | 0.975 | — | 拟合本身良好 |

压力在末 2D 仍在**回升**（尚未进入摩擦主导的线性衰减段），把这段斜率外推 10D
会把「压力回升」放大 5 倍（`ΔCp=0.392`），这正是 `static_step=1.4175` 的来源。
**故步面外推在本算例上不成立**，六条口径的散布（0.67–1.42，另加 MAC 的 0.34）不可裁决。

## 5 注意点（踩坑 / 局限 / 适用范围）

- **坑 1（口径）**：`K` 必须声明「站位 + 加权 + 是否外推 + 入口几何」四元组，否则同名 `K`
  可差 4 倍。本单把四元组写进 `results.json.routes[*].kind`。
- **坑 2（外推）**：线性外推只在**已充分发展**段有效；本案 `dp/dx` 与摩擦平衡反号，
  线性拟合的高 R² 会被误读为「可信」（R²=0.975 却是无效外推）。
- **坑 3（实现分歧）**：NumPy SIMPLE（底贴入口）与 torch MAC（居中入口）在 nominal 同一
  算例上 `k_total_head` 分别 1.026 / 0.661（差 55%），**入口几何必须先对齐**再谈口径。
- 局限：本单只新增 1 个复现算例（D/10）；D/20、D/30 的六口径复算因单进程 ~3 min/~15 min
  超出本单 120 s 单次命令窗而未跑（不是发散或失败，是容量纪律），已登记为后继项。

## 6 误差判定（逐项显式回答「是否 <3%」）

| 关键量 | 参照 | 误差 | < 3%？ |
|---|---|---|---|
| station_bulk K（D/10） | 0.5625 | 82.41 % | **否** |
| station_flux K（D/10） | 0.5625 | 39.44 % | **否** |
| bulk_step K（D/10） | 0.5625 | 19.41 % | **否** |
| flux_step K（D/10） | 0.5625 | 70.82 % | **否** |
| static_step K（D/10） | 0.5625 | 152.00 % | **否** |
| torch `k_from_static_recovery`（D/10/D/20/D/30） | 0.5625 | +1.5 % / −4.7 % / −9.8 % | 仅 D/10 是，但**非收敛**（网格加密单调变差） |
| 恒等式自洽 `static_station` vs `station_bulk` | 归档 1.0260453652 | 1.1e-9 | **是（机器精度）** |
| `u_out/u_in` | 1/AR = 0.25 | 1.2e-8 | **是** |

**结论：本算例对 Borda-Carnot 的 3% 判据 = WITHHELD（不是 PASS，也不是可归因的 FAIL）。**
档案中同时存在的「101% FAIL」与「+1.5% PASS」都不得再作为该算例的能力证据引用；
后者尤其危险，因为它在 D/30 已被自身的 −9.8% 否定。

## 7 给后继的靶子（按可单干度排序）

1. **长域裁决（首要）**：在 30–40 D 长域、D/10–D/20 网格上重跑，直到 `dp/dx` 与
   `−12νU_out/D²` 同号且量级一致（发展比 ∈ [0.8,1.2]），再做步面外推；
   本单脚本 `--mode run` 已就绪，只需改 `length_inlet_heights`（`build_sudden_expansion` 参数）。
2. **入口几何对齐**：底贴与居中两族各出一套 `k_*`，把几何差异从口径差异中分离。
3. **基准 README 重判**：`docs/benchmarks/verified/fvm_sudden_expansion/README.md` 的
   `expansion.K.finest` 判据应改用「步面 + 显式几何」口径并标 WITHHELD，等靶子 1 关闭后再定 PASS/FAIL。
4. 收敛阶：无论哪条口径，D/10→D/30 的 `k_static_recovery` 不单调，收敛阶仍不可计算（与 m6320 同结论）。
