The following are one set of test conditions from the original experiment conducted in NASA Langley LTPT
and used in a workshop conducted in 1993.  See NASA TM 1122858 (Klausmeyer and Lin), May 1997 and
AIAA-93-3137 (Chin et al), July 1993.

Mach number = 0.2
Reynolds number (based on stowed chord length) = 9 million (the Geometry files are provided with stowed chord length = 18 inches)
Corrected angles of attack:  8.10, 16.21, 21.34, and 23.28 deg.

Priority for SRS simulations:  freeair at alpha=21.34 deg.  This corresponds approximately to CLmax in the wind tunnel experiment.


NOTE: The experimental data should be used only as a rough guide.  There are known three-dimensional
effects (especially at higher lift conditions).
