# 浅水方程底摩阻 / 沿程驱动源项：闭式解验证面

**仓库**: TensorFVM · **模块**: `tensorfvm.verification.shallow_water_friction`
**被测**: `shallow_water.swe1d.ShallowWater1D`（+ `ShallowWaterBed1D` 继承路径）
**判据**: 16 条预声明（`criteria.md`）→ **16/16 PASS**（`summary.json`, 8.9 s）
**测试**: `tests/test_shallow_water_friction.py`（12 测全绿，8.1 s）

---

## 1. 案例介绍

浅水方程（depth-averaged hydrostatic）此前在本仓只有**无粘**实现：`swe1d`（平底，
Ritter/Stoker 溃坝）与 `bed`（Audusse 2004 静水重构，well-balanced）。而 1-D 明渠类
问题（正常水深、洪水演进阻尼、冰区渠道输水）都需要**底摩阻闭合**。摩阻项极易通过
目视检查：任何单调动量汇都让瞬态衰减显得"物理"，但漏一个 `h`、漏 `|u|`、或把系数
写成 `n` 而非 `n^2` 依然像在衰减。因此本单不是"加上摩阻"，而是把摩阻项**绑到它应当
积分的 ODE 的闭式解**上。

实现（默认关闭；`manning_n=0, slope=0` 时与原无粘残差**逐位相同**）：
- 底摩阻：Manning 摩阻坡 `S_f = n^2 u|u| / h^(4/3)`（宽矩形渠道 `R ≈ h`），动量汇 `-g h S_f`；
- 沿程驱动：常床坡 `S_0 = -dz_b/dx` 的重力驱动 `+g h S_0`（平底求解器上等价于"常坡 +
  均匀水深"，动量方程只含 `∂z/∂x`）；
- 反流保护：单级摩擦冲量上限 `|Δ(hu)| ≤ |hu|`，逐次计数（`friction_clipped`）。

参数表：`g=9.81`，`h=1 m`，`u0=1.5 m/s`，`n=0.03`，`S0=1e-3`，L=200 m，64 单元，
生产 CFL 0.4，MUSCL+HLL+SSP-RK3。

## 2. 怎么做的

均匀流态是这套验证的关键：一维槽道两端零梯度、初值均匀时**界面通量在两端相等，
通量散度精确为零**，半离散系统退化为标量 ODE，于是闭式解是精确锚而非近似锚：

- 纯摩阻衰减：`du/dt = -C u|u|`，`C = g n^2/h^(4/3)` → `u(t) = u0/(1 + C u0 t)`；
- 正常流松弛：`du/dt = g S_0 (1 - (u/u_n)^2)`，`u_n = h^(2/3)√S0/n` →
  `u(t) = u_n tanh(g S_0 t/u_n)`；
- 静态湖：`u=0 ⇒ S_f=0`，摩擦不得产生任何力（well-balanced 保持）。

工具链：判据先声明（`criteria.md`）后执行；`summary.json` + `results.md` **机器生成**
（报告中没有手抄数字）；`matplotlib` 出三联图。

## 4. 结果图与误差判定

- 图左：纯摩阻衰减，数值点落在闭式曲线上，60 s 相对误差 **3.6e-09** -> **<3%**。
- 图中：正常流松弛，数值点落在 `u_n tanh(gS0t/u_n)`，稳态达 `u_n`，误差 **4.0e-10** -> **<3%**。
- 图右：能量单调耗散，终值与闭式一致（2.6e-11）-> **<3%**。

逐项回答「是否 <3%」：C1/C3/C4/C9b 四项对解析基准的相对误差 ≤ 3.6e-09，**全部 <3%**
（实际是机器精度量级）。唯一 >3% 的是 **C8（刚摩阻 CFL 0.95 的衰减误差 3.69%）**，
但该项判据不是精度而是"不反流"：该工况 dt 由波速 CFL 决定（2.4 s），摩阻时间尺度
`1/(C u)` ≈ 1.5 s 与之同量级，一阶精度不足属预期，已如实标注 "accuracy limited by dt"，
不粉饰为 PASS 精度。

## 5. 注意点 / 局限

1. **`slope` 不是床面几何**：平底求解器上加的是等价的常坡重力驱动 `g h S_0`。真正的
   非常坡床面走 `ShallowWaterBed1D`；那一路已在 `bed.rhs` 接入同一源项与同一反流保护，
   并由 C7 验证"静水湖不被摩擦扰动"（1.6e-13 m/s）。
2. **明示未做（WITHHELD / honest FAIL 不覆盖）**：①带**入流/出流边界**的常坡均匀流——
   1-D 求解器只有零梯度透射端，无法把"常坡 + 定常流量"设为定解问题（零流量时静水湖
   是精确解，实测 1e-13 量级不动，这是正确物理而非缺陷）；②2-D/径向；③科氏力/旋转
   （需引入横向动量分量，仍 WITHHELD）；④Chéron/Manning-Strickler 变体与冰盖糙率的
   Skinner/Beltaos 摩阻形式；⑤湍流摩阻（本项是水力摩阻，不含湍流闭合）。
3. **反流保护是安全网，不是精度手段**：CFL 合法工况下它触发 16 次但几乎不改变答案
   （带保护 0.138470 vs 无保护 0.139575）；`dt` 远超 CFL 时它才是"不反流"的唯一保障
   （C8c vs C8d）。它只截断摩擦冲量、不改通量，故 C6b 的逐位回归不受影响。
4. 摩阻按宽渠道 `R ≈ h` 近似；窄深渠道需 `h^(4/3) → R^(4/3)`（当前**不**支持水力半径，
   已在 docstring 注明）。
