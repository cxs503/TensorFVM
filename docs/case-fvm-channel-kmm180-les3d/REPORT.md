# CASE-FVM-CHANNEL-KMM180 的第三条路线：三维壁面解析 LES（进行中，honest）

## 1. 为什么这一单值得做

锚点此前只有两条路线：1-D 平衡 RANS 诊断（`rans_validation.channel`，**总应力恒等式是强加的**，
动量侧不可能出错）与二维 `channel_periodic`（无展向）、`periodic_mac`（无壁面）。
"FVM 三维求解器能否自己算出对数律"这一问在 `case-fvm-channel-kmm180-fvm-bridge` 里被明确记为
**未做**。本单交付该路线的第一条可用实现。

## 2. 方法

* 交错 MAC，x/z 谱（FFT）、y 壁面 no-slip；体积力驱动，`u_tau`、`u_bulk`、`tau_w` 全是输出；
* 二阶中心通量形式对流（Morinishi 型）、半单元壁面导纳、投影的 Poisson 算子与动量步**同一套**
  div/grad 模板（因此投影后散度到机器零，测试断言 `<1e-10`）；
* 投影：x/z FFT + y 方向按体积加权的对称化特征分解（预分解一次），`(0,0)` 模用伪逆去掉常数模；
* SGS：Smagorinsky + van Driest 阻尼（唯一模型假设，**未**对参考剖面调参）。

网格（默认可运行配置）：`64 x 64 x 32`，`Lx = 2 pi`、`Lz = pi`（半高单位），`y1+ = 0.97`、
`dx+ = dz+ = 17.7`，`dt = 2.5e-3 delta/u_tau`。

## 3. 状态（诚实）

已落地并通过单元测试的：散度算子（对照独立的逐点循环实现，逐元素相等）、`div(grad)` 与 Poisson
算子的一致性（均匀网格 1e-10、拉伸网格与模板精确相等）、投影后 `max|div| < 1e-10`、均匀流对流
加速度精确为零、Smagorinsky 对简单剪切恢复到 `|S| = a/sqrt(2)`、`y1+` 与对称加密、
`Re_tau=180` 下的 CFL/扩散稳定带。

**未完成（open，honest FAIL）**：
1. `Re_tau = 2` 的定常层流抛物解在 4000 步内没有收敛到 2e-3 相对（已标 `xfail`）——说明装配里
   仍有一处不是纯扩散松弛（最可能是 y 向对流/壁面通量的耦合项，或时间推进的显式 Euler 精度）；
2. 60 步湍流冒烟测试仍未全绿（同标 `xfail`）；
3. **因此在 `Re_tau=180` 上没有任何时间平均的 `u+` 剖面，本单不给出任何对锚点判据的读数**——
   既不报 PASS 也不报 FAIL，一律 `not_run`。

## 4. 注意点（踩过的坑，已修）

* Poisson 的 y 算子必须与 `div(grad)` 用**同一组中心距**（`dy_cc`），否则拉伸网格上两者不一致，
  投影后散度反而放大到 1e3 量级（本单实测）。
* `v` 动量的 y 向/ z 向通量必须先把 `u`、`w` **插值到 y 面**再乘：直接 `w[1:-1]` 会少两行，
  与 `_face_z(v)` 的行数不匹配（numpy 会广播静默或抛形状错）。
* 谱解法里 `(0,0)` 模在纯 Neumann 下奇异：用伪逆（丢掉常数特征向量）而不是钉一个自由度。

## 5. 误差判定

无基准读数（见 §3 open）：**不是 <3%**，也不是 >15%——是 `not_run`。任何"LES 复现了对数律"
的说法在本单都不成立。
