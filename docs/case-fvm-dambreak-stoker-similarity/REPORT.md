## ① 案例介绍

锚点是浅水溃坝的经典解析解对：干床 Ritter（`h1 = 0`）、湿床 Stoker（`h0 > h1 > 0`），
坝址 `x_dam = 0`，计算域 `[−4, 6] m`，`g = 9.81 m/s²`，`t* = t√(g h0)/h0 = 2`（`t = 0.638551 s`）。

| 参数 | 值 |
|---|---|
| 干床 `h0 / h1` | 1.0 / 0.0 m |
| 湿床 `h0 / h1` | 1.0 / 0.5 m |
| 湿床星区 `h2`, `u2` | 0.726920 m, 0.923364 m/s（Stoker 匹配条件的根） |
| 湿床水跃速度 `U` | 2.957918 m/s（Rankine–Hugoniot） |
| 求解器 | `swe1d.ShallowWater1D`：HLL + MUSCL/minmod + SSP-RK3，CFL 0.4，order 2（**本单未改一行求解器代码**） |
| 判据网格 | n = 400 / 800 / 1600（锚点接受网格 n ≥ 800） |

**要补的是什么。** 到本单为止，锚点的全部判据都可以归成一类：**某一个时刻的标量**（波前位置、
平台水深、水位阶跃）或**某一个时刻的积分**（深度 L1、动量收支、能量收支）。这些量都不问
两篇参考文献赖以成立的**结构性质**——Ritter 解与 Stoker 解都是**自相似**的：

```
h(x, t) = h(ξ),  u(x, t) = u(ξ),  ξ = (x − x_dam)/t .
```

即：`t* = 2` 的整条剖面与 `t* = 0.4` 的整条剖面，在 ξ 坐标下**必须是同一条曲线**。
一个格式可以命中 `t*=2` 的每一个标量判据，却把前导瞬态做错（收敛速度、启动抹平、
时间步滞后），也可能因为"错得自相似"而全部通过。这两类缺陷在此前的证据包里都无法区分。

| 量 | 是否被锚点既有判据评级 | 本单 |
|---|---|---|
| 波前/水跃位置、水位阶跃、深度 L1、单调性 | ✅ | 不重复 |
| 全局动量（G7）/ 速度场误差预算（G8） | ✅（`docs/CASE-FVM-DAMBREAK-STOKER-MOMENTUM`） | 不重复 |
| 能量收支与激波耗散率 | ✅（`artifacts/shallow-water-energy`，误差 2.6e-9） | 不重复 |
| **ξ 坐标下的剖面塌缩（一致性，不用参考解）** | ❌ | 新判据 |
| **预渐近误差律 `E = C·dx/(c0 t)` 与"需多少格才进 5 % 带"** | ❌ | 新判据 |
| **早期时间读数究竟依赖什么变量（F5 的措辞订正）** | ❌ | 新证据（F11） |

## ② 怎么做的

1. **精确剖面是"解析的解析"**：Ritter/Stoker 闭式解只依赖 ξ，故在 `t = 1, x = x_dam + ξ` 上
   调用闭式即得精确相似剖面（不是两片时间切片的内插）。该恒等式由测试钉住：在
   `t = 0.05 / 0.3 / 1.7` 三个时刻按 `x = x_dam + ξ t` 求值，剖面残差 **4.44e-16**。
2. **两个泛函，缺一不可**：
   * `xi_error`（**精度**，用参考解）：`mean|h_num(ξ) − h_ex(ξ)| / mean|h_ex(ξ)|`，在声明的
     401 点 ξ 网格上（精确波支撑 `[−c0, 2c0]`（干）/ `[−c0, U]`（湿）各外扩 `0.25 c0`）。
   * `collapse_residual`（**一致性**，不用参考解）：多个时刻的 `h(ξ)` 剖面的点散布
     `mean(max_i p_i − min_i p_i)/mean|p̄|`，只取网格中央 90 %（两端是抹平区，
     那里任何有限体积剖面都差 `O(dx/t)`，与是否自相似无关）。
3. **单条轨迹、真实时刻**：每个 `(case, n)` 只积分一次，从上一个样本时刻推进到下一个；
   记录 `solver.time`（状态真正所属的时刻），而不是请求时刻——否则时间采样误差会
   混进一个空间泛函里。
4. **时间轴（此前无人评级）**：同一 n = 800 上取 `cfl = 0.2 / 0.4 / 0.8`，看 `t* = 2` 的
   `xi_error` 是否变化。
5. **可失败性（本单最要紧的部分）**：两条探针
   * **错得自相似**：把精确剖面整体乘 1.01（= 另一个 `h0` 的真相似解）→ 塌缩残差
     **0.0（bit 相同）**、`xi_error = 1.0 %`。这条证明"只用塌缩"是**空洞判据**，
     两个泛函必须成对使用。
   * **非自相似缺陷**：只在 +5 % `h0` 的局部加一个高斯包（幅度 0.05，宽 0.05·支撑宽）→
     塌缩残差与 `xi_error` 同量级地报警（附录 A 的 gate-power 表）。
6. **工具链**：`src/tensorfvm/shallow_water/similarity.py`（新模块，不动 `dam_break.py` 与
   任何既有 verdict 键，遵守 `AUDIT.md` §6 的键锁纪律）→ `scripts/verify_dambreak_similarity.py`
   （工件 + 图）→ `tests/test_dambreak_similarity.py`（18 项）。

## ③ 计算结果

### 3.1 ξ 空间误差服从 `E = C·dx/(c0 t)`（数字见附录 A 全表）

| case | C（`t* ≥ 0.4`，全部网格） | C 波动 | 实测 dx 阶（400→800→1600） | `5 %` 所需行程 `C/0.05` [格] | 末态 `E`（n=400/800/1600） |
|---|---:|---:|---|---:|---|
| ritter-dry | **0.3956** | 2.2 % | 1.002, 1.001 | **7.91** | 4.93e-3 / 2.46e-3 / 1.23e-3 |
| stoker-wet | **0.2685** | 6.8 % | 0.977, 0.968 | **5.37** | 3.33e-3 / 1.69e-3 / 0.87e-3 |

* 一阶于 `dx`（倍率 2.003 / 2.002，干；1.969 / 1.957，湿），`~1/t` 于时间：同一条律，两个方向都验到。
* **锚点被评级的那一点 `t* = 2` 落在渐近区深处**：`n = 1600` 上 `c0 t/dx = 320` 格
  （`5 %` 门槛只需 5.4～7.9 格），即锚点在 `t*=2` 的评级有约 40 倍余量。
* 这条律给的是**先验**能力：任何 `(dx, t*)` 的组合可以先算出 `E`，不需要跑。

### 3.2 与既有先验门槛的形式交叉验证

`dam_break.py` 里声明的 `LEVEL_SERIES_MIN_CELLS = 1/TOLERANCE = 20`（等值线位置判据）
与本单的 `C/TOLERANCE = 5.4 … 7.9`（ξ-L1 判据）**是同一形式**（"行程格数"门槛），
数值上既有声明保守 2.5～3.7 倍。**注意这是形式层面的对齐，不是同一个泛函**（位置 vs 剖面），
故不能说"既有门槛被"验证为最优"，只能说两者不矛盾且既有声明偏安全。

### 3.3 塌缩（一致性）

`t* ≥ 0.4` 窗口内的塌缩残差：干床 2.17e-2 / 1.12e-2 / 5.63e-3（n = 400/800/1600），
湿床 1.35e-2 / 7.39e-3 / 3.72e-3 —— 与 `dx` 同阶收敛，且**不需要参考解**就成立。

### 3.4 时间轴

`n = 800, t* = 2`：干床 `xi_error` = 2.4590e-3 / 2.4603e-3 / 2.5356e-3（cfl 0.2/0.4/0.8，
相对差 ≤ 3.1 %）；湿床 1.6930e-3 / 1.6931e-3 / 1.7048e-3（≤ 0.7 %）。误差来源是空间抹平，
不是时间步——这与 `cfl = 0.4` 的声明一致。

### 3.5 早期读数到底依赖什么变量（F5 订正，见 §5）

湿床水跃位置的早期读数误差是 **`x_s/dx`（行程格数）的单值函数**：把 `(n, t*)` 配成
共享同一 `x_s/dx` 的组，误差复现到 **2.0e-12**（组内最大相对散布）。

| x_s/dx | (n, t*) 组 | 误差 | 组内最大相对散布 |
|---:|---|---|---:|
| 0.1889 | (200, 0.01), (400, 0.005) | 0.7380 %, 0.7380 % | 1.1e-14 |
| 0.3778 | (200, 0.02), (400, 0.01), (800, 0.005) | 0.04505 %, 0.04505 %, 0.04505 % | 2.0e-12 |
| 0.7555 | (400, 0.02), (800, 0.01), (1600, 0.005) | 0.13532 %, 0.13532 %, 0.13532 % | 4.8e-13 |

## ⑤ 注意点 / 局限（照实写）

* **精度半边与既有 `depth_l1` 属同一信息类**：`xi_error` 与 `depth_l1` 只差一个归一化窗口
  （ξ 窗口 = 波区；`depth_l1` 归一在全水槽）。实测同一状态干床 n=1600：`xi_error` 1.23e-3
  vs 工件 `depth_l1` 7.72e-4（比 1.6）。**不宣称这是新的独立物理量**；本单的新内容是
  (i) 显式的 `C·dx/(c0 t)` 律与"需多少格"的先验门槛、(ii) 不用参考解的塌缩半边、
  (iii) F5 的订正。
* **塌缩单独是空洞的**（§2.5 已证）：报告里任何"塌缩通过"都不构成精度证据，二者必须成对读。
* **ξ 网格是声明量**：401 点 + 0.25 c0 外扩；未做 ξ 分辨率收敛研究（`E` 在该分辨率下的
  离散化残差未单独量化）。这是本单的欠账。
* **未做**：`t* < 0.02` 的 ξ 塌缩（此区间剖面仍由一个单元的抹平主导，`ξ` 映射会放大插值误差）；
  n > 1600 的 cfl 扫描；二维/斜向（`artifacts/shallow-water-dam-break-oblique` 已另案覆盖）。
* 阶数由**两个网格的倍率**给出（不是三点拟合），故只作为"一阶确认"，不作为高精度阶数结论。

## ⑦ 对既有证据包的订正（F11）

`docs/case-fvm-dambreak-stoker/AUDIT.md` F5 把湿床 `t* ≲ 0.02` 的序列误差描述为
"**恒为 4.505 %（n=400/800/1600 一致，差异 1e-13）**"，并解释为"初始间断被 HLL 抹平的
直接后果"。本单的测量给出更准确的表述：

1. 4.505 % **不是**该区间误差的"值"，而是 `x_s/dx = 0.3778` 这条等值线上的一个点；
   同一 `x_s/dx` 组内复现到 2.0e-12（表 3.5）。
2. 之所以跨网格"恒定"，是因为**自适应步长让样本时刻 ∝ dx**（`dt = cfl·dx/λ`），
   于是 `dx/(U t_s)` 是网格不变量——**不变量属于采样日程，不属于物理**。
3. F5 因此没有夸大风险：该量本来就只登记在 `unresolved_max_error`，不进任何 verdict；
   但"与网格无关的物理下限"这种说法会误导下一次审计（会让人以为细化网格无用）。
   正确说法：**该读数是行程格数 `x_s/dx` 的单值函数，在 `x_s/dx ≲ 8` 区间为量化噪声
   （0.0014 %…2.2 %，非单调），故必须按行程格数排除，而不是按 `t*` 排除**——这与
   `dam_break.py` 里既有的先验判据 `SERIES_MIN_CELLS = 4`（按行程格数）**一致**，
   反而**支持**该判据的形式选择。
