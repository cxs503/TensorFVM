# CASE-FVM-THACKER-BASIN —— 多周期（2T）失效诊断：被否定的假设与仍然开着的缺口

**任务**: m21251（selfstart / paper 席，2026-11-15）**仓**: TensorFVM **分支**: `agent/m21251`
**对象算例**: `CASE-FVM-THACKER-BASIN`（2-D 抛物碗 Thacker 1981 非线性振荡）
**起因**: `docs/case-fvm-thacker-basin/REPORT.md` §4.4 自记欠账——"以 `--periods 2` 跑满 2 个周期时，
n=40 探针在第 200 步出现非物理速度 `18.2 m/s`，随后 CFL 步长塌缩、推进超步预算"，因此该算例的
全部精度判据被**冻结在 `0 ≤ t ≤ 0.5T`**。本单去把这句欠账变成可判定的事实。
**总判定**: **假设被否定（falsified hypothesis）**。速度失控是真的、可复现的、**但修不了 2T 的精度**；
2T 窗口的失效主因是**相位/幅值漂移**，不是动量注入。`0.5T` 硬窗口不是省事，是**必要**。
**证据**: `artifacts/summary.json`（全部数字程序化生成）+ `artifacts/fig_multiperiod_diagnosis.png`，
复现脚本 `diag_thacker.py` / `try_fixes2.py` / `make_diagnosis.py`（本目录）。

## 1. 设定（与主报告一致，不重述几何）

| 量 | 值 |
|---|---|
| 碗 | `h_bed = H[(x²+y²)/a² − 1]`，`H = 1 m`, `a = 1 m` |
| 初值 | 抛物面振幅 `A = 0.5`，静止 |
| 周期 | `T = 0.709252 s`，窗口 `2T = 1.418503 s` |
| 网格 | `n = 40`（`dx = 0.075 m`），`CFL 0.4`，SSP-RK3，`dry_depth = 1e-8 m` |
| 判据 | 中心水深史 `h(0,0,t)` L2（相对振幅）≤ 3 %；岸线半径史 ≤ 3 % |

## 2. 怎么做的

1. **复现**：n=40 逐时间步记录 `max|u|`、`dt`、裁剪/翻转计数、水量（`diag_thacker.py`）。
2. **定量对照**：与闭式速度场在该周期的**解析包络** `max|u|_analytic = 2.461 m/s` 比。
3. **分离变量**：把"二阶重构（MUSCL）"与"湿/干模型"分开——同一算例跑 `order = 1`
   （一阶重构，其余完全相同）作对照。
4. **试修**：两类标准做法各试 2–4 个参数（`try_fixes2.py`）：
   (a) 薄膜动量截断 `h < r·H ⇒ hu = hv = 0`（`r = 1e-2, 3e-2`）；
   (b) 弗劳德数封顶 `Fr > Fr_max ⇒ 按比例缩 hu, hv`（`Fr_max = 1, 2`）。
   两个试修都只在 `_sanitise` 后处理，**不改守恒量除 hu 以外的东西**（水量漂移仍为 0）。
5. **判定**：对每个变体算 `0 ≤ t ≤ 2T` 与 `0 ≤ t ≤ 0.5T` 两个窗口的中心水深/岸线误差
   （`make_diagnosis.py`，读回逐样本序列 vs 闭式解逐项重算）。

## 3. 结果（数字全部来自 `artifacts/summary.json`）

### 3.1 速度失控是真的，且只属于二阶路径

| 变体 | `max|u|` / 2T 内 | 与解析包络比 | 步数 | 备注 |
|---|---:|---:|---:|---|
| order 2（基线） | **71.16 m/s** | **28.9×** | 618 | `t ≈ 0.7T` 起单调加速，`dt` 由 9.2e-3 塌到 3.4e-5 |
| order 1（对照） | **2.181 m/s** | **0.886×** | 153 | 全程在解析包络内 |

解析包络 `max|u|_analytic = 2.461 m/s`。失控发生的位置是**岸线外侧的薄膜/孤立湿斑**：
在这些单元里 `h ~ 1e-3 m` 而 `hu ~ 5e-2 m²/s`，即 `|u| = hu/h` 被薄膜放大；
面元（重构侧）速度**没有**被放大（实测面速上限 16.7 m/s < 单元速度上限 47 m/s），
所以不是重构把速度外插出去了，而是**薄膜自身被坡度持续加速**（`gdη/dx` 源项没有对应出流）。
水量守恒到 1e-14，正性裁剪与干湿翻转计数**全为 0**——这不是"爆炸"，是干净的动量注入。

### 3.2 两个试修都压不住历史误差

`centre` = 中心水深史 L2（相对振幅），`shore` = 岸线半径史平均相对误差：

| 变体 | 2T: centre | 2T: shore | 0.5T: centre | 0.5T: shore | 步数 |
|---|---:|---:|---:|---:|---:|
| order 2 基线 | 34.87 % | 19.50 % | 2.87 % | 5.69 % | 618 |
| order 1 对照 | **49.28 %** | **17.43 %** | 11.08 % | 7.84 % | 153 |
| 薄膜截断 `r=1e-2` | 33.95 % | 19.57 % | 2.80 % | 5.94 % | 448 |
| 薄膜截断 `r=3e-2` | 30.94 % | 19.57 % | 2.79 % | 5.94 % | 302 |
| 弗劳德封顶 `Fr≤1` | 35.20 % | 17.21 % | 2.77 % | 7.02 % | 177 |
| 弗劳德封顶 `Fr≤2` | 29.16 % | 19.57 % | 2.84 % | 5.94 % | 180 |

三条读数（都是结论性的）：

1. **2T 窗口里没有任何变体接近 3 %**（最好 29 %，比 0.5T 窗口的同变体差 **10 倍以上**）。
2. **速度受控 ≠ 历史正确**：`order 1` 速度全程合规（0.886× 包络），2T 中心水深却是**最差**的
   49.28 %。⇒ 速度失控**不是** 2T 历史误差的主因，**"修掉动量注入就能开 2T 窗口"的假设被否定**。
3. 两个试修把步数从 618 降到 302/177（`dt` 塌缩被抑制），也把 2T `centre` 从 34.9 % 拉到 29–31 %，
   但**仍在容差 10 倍之外**，且 `shore` 几乎不动（19.57 %）——**不足以升格为"修复"**。
   按其自身量级，任何"2T 通过"声明都会是粉饰，故本单**不采纳**这两个补丁进 `src/`，只作诊断证据。

### 3.3 顺带的定量事实

* `0.5T` 窗口（已冻结的验收窗口）在 n=40 上是 centre 2.87 % / shore 5.69 %，明显劣于主报告
  n=160 的 0.73 % / 2.35 %——**窗口本身没问题，是分辨率**；这也说明 2T 的主因很可能是
  **周期误差 × 2 个周期**的相位累积（`0.5T` 的 2.87 % 幅值误差对应 ~1 % 的相位误差，
  两个周期即 ~4 % 相位 → 中心水深史的 L2 放大到 30 % 量级完全自洽）。

## 4. 判据逐项回答（是否 <3 %）

| 判据 | 值 | <3 % ? |
|---|---|---|
| 2T 中心水深史 L2（order 2，基线） | 34.87 % | **否** |
| 2T 岸线半径史平均（order 2） | 19.50 % | **否** |
| 2T 中心水深史 L2（order 1 对照） | 49.28 % | **否** |
| 2T 中心水深史 L2（最好试修 Fr≤2） | 29.16 % | **否** |
| 0.5T 中心水深史 L2（order 2, n=40） | 2.87 % | 是 |
| 速度是否留在解析包络内（order 1） | 0.886× | 是 |

**结论**：CASE-FVM-THACKER-BASIN 的 `0 ≤ t ≤ 0.5T` 验收**不受影响**（本单没有改动 `src/`）；
`2T` 窗口**继续 FAIL，且本次没有修好**。

## 5. 注意点 / 局限

* `n = 40` 是**故意**的：欠账原文就发生在 n=40，且本机 load15 ≈ 60 时只做轻算。n=80/160 的 2T
  网格收敛（判"相位漂移"假设 vs "分辨率"假设）**未做**，需要递交集群（见 §6）。
* 解析包络 `2.461 m/s` 由 240 点时间采样 + 60×60 空间采样得到，采样下界而非严格上界；
  量级（28.9×）不受影响。
* 试修的两种做法都**不是**文献里"正确"的湿/干稳定化（正性保持的 Zhang–Shu / Xing–Shu 缩放、
  或 Kurganov–Petrova 的 desingularization 才是）；本单只把它们当**探针**用来分离变量，
  阳性结果也不足以采用——阴性结果（§3.2 第 2、3 条）才是本单的产出。
* `dry_depth = 1e-8 m`（冻结参数）是薄膜得以存在的直接原因；但把 `dry_depth` 直接抬到 `1e-2`
  会改变算例定义（实测 73488 次干湿翻转），**不是**可接受的修法。

## 6. 下一步（给接单者的具体线索，按性价比）

1. **判定 2T 失效是"相位漂移"还是"分辨率"**（最便宜的判决实验）：
   在集群上跑 `n = 40/80/160` × `periods = 2`，看 2T `centre` 误差随 `dx` 的阶；
   若阶 ≈ 1 → 相位/色散误差主导（需要高阶时间/空间格式或更严 CFL）；
   若不收敛 → 湿/干翻转本质问题（需要正性保持重构）。脚本入口已就绪：
   `scripts/run_thacker_basin.py --periods 2 --resolutions 40 80 160`。
2. **正性保持重构**（Xing & Shu 2011 §3 的 h/surface 缩放）替换当前 `open_face` 掩码，
   这是主报告 §4.2 引用但未实现的那一半。
3. 若 1 判定为相位漂移，则 2T 验收句应改成"周期误差 ≤ x %、幅值包络误差 ≤ y %"这类
   **对相位不敏感**的量，而不是逐点 `h(0,0,t)` 的 L2——现有验收句对 2T 天然苛刻。
