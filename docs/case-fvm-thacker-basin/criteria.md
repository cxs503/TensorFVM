# CASE-FVM-THACKER-BASIN —— 预声明判据（运行前冻结）

缺口：`src/tensorfvm/shallow_water/` 只有 **1-D** 求解器（`swe1d.ShallowWater1D`、
`bed.ShallowWaterBed1D`）与 1-D 精确解（Ritter/Stoker，锚点 CASE-FVM-DAMBREAK-STOKER）。
浅水（depth-averaged）方向**没有任何 2-D 求解器**，也就没有 2-D 的非线性精确解验证面；
总账（feature_ledger）无对应条目 → 本单按【锚点=NEW】立账，建议新条目
`CASE-FVM-THACKER-BASIN`（2-D 抛物碗非线性振荡，Thacker 1981 精确解）。

基准：Thacker (1981, *J. Fluid Mech.* **107**, 499, doi:10.1017/S0022112081001882)
抛物碗（paraboloid basin）非线性振荡。静水深尺度 `H`、碗半径尺度 `a`、
床面 `z_b = -H (1 - r^2/a^2)`，振幅参数 `A ∈ (0,1)`：

```
h(r,t) = H sqrt(1-A^2)/Q - (H/a^2)(1-A^2) r^2 / Q^2 ,   Q(t) = 1 - A cos(omega t)
u = v = beta(t) (x, y) ,  beta(t) = A omega sin(omega t) / (2 Q(t))
omega^2 = 8 g H / a^2            (非线性频率，非 sqrt(gH) 的线性值)
s(t) = a sqrt(Q / sqrt(1-A^2))   (岸线半径，h=0 处)
V    = pi a^2 H / 2              (总水量，与 t 无关 —— 解析守恒量)
```

以上闭式**不是从文献表格抄录**：判据 C2 用有限差分把 `h,u,v` 代回原 PDE 求残差，
公式错了 C2 必红（与仓内 `check_stoker_solution` 同一纪律）。

工具链：`ShallowWater2D`（Audusse 2004 静水重构 + MUSCL/minmod + 三维分量 HLL + SSP-RK3，
自适应 CFL），域 `[-L,L]^2`，`L = 1.5 a`（最大岸线 `a((1+A)/(1-A))^{1/4} = 1.32 a < L`，水不触边界）。

参数（冻结）：`H = 1 m`、`a = 1 m`、`g = 9.81 m/s^2`、`A = 0.5`、`L = 1.5 m`、
`t ∈ [0, 2T]`、`T = 2 pi / omega = 0.7094 s`、CFL 0.4、二阶 MUSCL、`dry_depth = 1e-8 H`。
采样 41 个时刻（`t = k·2T/40`，单频 DFT 去重端点）。
