## ① 案例介绍（物理背景 / 几何 / 参数表）

浅水方程（SWE）溃坝问题有 Ritter/Stoker 精确解。锚点此前的 1-D 与 2-D 证据都**把坝轴线放在网格线上**（`docs/case-fvm-dambreak-stoker*/`）。此时横向通量恒为零，2-D 求解器实际退化为嵌在 2-D 数组里的 1-D 算子：任何只在间断**斜交网格**时才暴露的缺陷（横向通量不一致、dx/dy 混淆、HLL 波速方向偏置、阶梯化导致的波前滞后）都不会出现在那些数字里。本单把同一条精确解**旋转**后放在方形笛卡尔网格上复核——SWE 旋转不变，真解即 h(X,t)=h_1d(s/t)，s = n·(X−X_c)，n 为坝轴线法向。

| 项 | 设置 |
|---|---|
| 域边长 L | 12.0 m（坝线过中心） |
| 评分带 | 沿坝向 |p| ≤ 2.5 m（避开壁面） |
| 网格 | n×n，n=240，dx=0.050 m |
| 坝线角度 | 0°（轴对齐对照）、26.565°（2:1 阶梯）、45°（对角阶梯） |
| 工况 | Ritter 干床 h0=1.0/h1=0；Stoker 湿床 h0=1.0/h1=0.5 |
| g / t* | 9.81 m/s^2 / 2.0（t=0.6386 s） |
| 数值格式 | MUSCL(minmod)+HLL+SSP-RK3，CFL=0.4，well-balanced 静水重构（与 1-D 锚点同族） |
| 先声明门限 | 验收 5%；角度一致性 OBLIQUE_AGREEMENT_MAX=1 pp（单边）；分箱宽 dx；带半宽 2.5 m |

## ② 怎么做的（方法 / 流程 / 关键设置）

1. **几何**：`normal_coordinate()` 给出 (s,p) 旋转坐标；初值 h=h0 (s≤0) / h1 (s>0)；分区性由测试钉住。
2. **降维**：斜交间断在笛卡尔网格上是阶梯，逐格线读数不可用。做法是（a）只保留 |p|≤2.5 m 带内单元，（b）按 s 以 dx 为宽度分箱面积平均；箱界相对最低格心偏移半箱宽，使 0° 时 s=x−x_c 落在箱中央（否则浮点取整会把一列拆到两箱——本单实测踩到并修好，测试钉住）。
3. **评分**：沿用锚点自己的估计子——干床 `fan_front_estimate`（扇区形状一致，逐格 x+3t√(gh) 平均），湿床 `data_driven_plateau`（无 oracle 亚格中值穿越 + 水位阶跃 h2/h1）；另给 `front_level_error`（解析中值水位穿越，与 `dam_break2d.sample_2d` 的序列规则一致）作为 x_f(t) 序列读数。
4. **单调性**：内点局部极值计数（振幅门 1e-4 h0），与 1-D/2-D 锚点同一定义。
5. **估计子零偏**：把估计子作用在解析剖面上（`estimator_zero_bias`），把偏置作为地板报告、不从误差里减掉。
6. **先声明后跑**：上表门限全部是模块常量，跑之前写死。

## ④ 注意点（踩过的坑 / 局限 / 适用范围）

1. **边界是透射（zero-gradient）不是反射**（`swe2d` 文档写明：设计用途是水体不触壁的封闭盆地）。斜置时坝线与壁面相交，相交处壁面法向速度非零 → 全域质量漂移（干床 45° 最大 8.2e-3）。这不是内核算子不守恒：**轴对齐对照**（坝线垂直于壁面）漂移 4.1e-15，机器精度。漂移来自评分带之外的壁面段：带内质量误差 ≤1.6e-3，且带内解与无限域解析解一致到 0.3%——若泄漏污染了带内，这不可能成立。
2. **分箱平均是滤波**：斜置时每箱平均约 50 个单元，阶梯被平滑，故斜置读数有时**优于**轴对齐对照；这是估计子性质、不是物理增益，一致性门因此是**单边**的，并把 improvement 单独报告。
3. **粗网格下的早时刻序列**：初始间断数值抹平约 1 单元，中值穿越偏置 ≈ 1 单元/已行单元数。n=240 实测全部 <5%；n=360 加密作业（cj3154）在本单预算内未落地，如实登记为未完成。
4. **适用范围**：结论只针对静水压 SWE 与该 FV 格式；不含非静压、摩阻、变底坡效应。
