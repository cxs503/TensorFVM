# CASE-FVM-KOVASZNAY-ORDER —— 挤出向 w 的一阶伪速度：根因定位到对称面切向自由度

**锚点**: `CASE-FVM-KOVASZNAY-ORDER`（feature ledger, open）· 前序：交付轮 m16130（FAIL 1.684）、
归属轮 m16396（误差预算三分：面内 1.808 / 挤出向 1.106）、复核 m16173。
**本单**: m16524 · 新增 `src/tensorfvm/verification/kovasznay_extrusion.py`（可复用驱动）
+ `scripts/probe_kovasznay_spanwise_source.py`、`scripts/probe_kovasznay_extrusion_variants.py`
+ `tests/test_kovasznay_extrusion_spanwise.py`（4 测全绿，43.8 s）+ 本目录。

**结论一句话**: 1.106 阶的挤出向伪速度 `w` **不是 z 动量方程的截断误差**——把解析状态代入离散系统，
z 动量的 **cell 行残差恰好为 0.0**；把 z 平面的**切向**面值改为给定解析值（同一网格、同一离散、只去掉那两个
自由面未知量），`w` 直接掉到**机器零**（n=8: 1.86e-17；n=16: 1.14e-17）。即：**O(h) 伪速度 100% 由
对称面切向面自由度（free tangential face dofs）经偏应力 τ_xz 耦合产生**，与内部离散精度无关。

## 1. 案例介绍

二维稳态不可压 Kovasznay (1948) 解析解，Re = 40，κ = 2π，
λ = −2κ²/(Re+√(Re²+4κ²)) = −0.963741：

| 量 | 解析式 |
|---|---|
| u | 1 − e^{λx} cos(2πy) |
| v | (λ/2π) e^{λx} sin(2πy) |
| w | **≡ 0** |
| p | ½(1 − e^{2λx}) |

几何：单位立方体 `n×n×1` 对称挤出（z 为挤出向，单层单元，厚度 1），面三角形化；
速度边界取解析面积均值。**BC 约定（本次定位的关键）**：z 上下面为对称面——法向 `w = 0` 给定，
切向 `u,v` 是**独立的面动量未知量**（`fixed[planes,:2]=False`，零切向 traction）。

## 2. 怎么做的

1. **一致性探针**（`probe_kovasznay_spanwise_source.py`）：把解析值放到 cell 中心与面心，
   压力取解析值（gauge 对齐），直接算离散动量残差，并按 unknown block（cell/face × u,v,w）与
   按项（viscous / convection / pressure / load）分解。若某行在解析状态就残差非零且阶为 O(h)，
   该行就是不一致来源。
2. **对照实验**（`probe_kovasznay_extrusion_variants.py`）：同一网格、同一离散、只改 z 平面切向面值的
   处理方式：`symmetry`（交付口径，自由）/ `dirichlet`（给定解析面积均值）。
   两者解析解都满足（流动与 z 无关），因此差异只可能来自那两个自由自由度。
3. 误差预算沿用 m16396 的同一体积加权 L2 口径（面内 / 挤出向 / 总量），逐格与解析值比对。
4. 全部数字由 `runs/kovasznay-spanwise/*/summary.json` 程序化注入本报告与图；
   该目录不在本仓 sparse-checkout 内，故同内容镜像提交在
   `docs/verification-kovasznay-spanwise-attribution/runs/<case>/summary.json`（本报告所有引用以此为准）。

## 3. 计算结果

### 3.1 解析状态的残差分解（n = 8, h = 0.125, 64 cell / 544 面）

| 项 | cell-u | cell-v | **cell-w** | face-w |
|---|---:|---:|---:|---:|
| viscous | 3.2145e-02 | 4.9359e-03 | **0.0** | 7.0806e-05 |
| convection | 0.0 | 0.0 | **0.0** | 1.6356e-03 |
| pressure | 0.0 | 0.0 | **0.0** | 3.7862e-02 |
| total | 3.2145e-02 | 4.9359e-03 | **0.0** | 3.7897e-02 |

读法：`cell-u` 残差 3.21e-2 ≈ 2h²（h²=1.5625e-2）＝正常二阶截断误差；
**`cell-w` 三个项全为 0.0** ⇒ 对 `w ≡ 0` 的精确场，离散 z 动量方程是**严格满足**的，
没有一阶驱动项。`face-w` 的数只出现在**给定行**（z 平面的 w 受 Dirichlet 约束，残差即支反力），
不是缺陷。附带核验：压力 `p = z`（线性）的离散 traction 在 cell 行给出 h² 量级的 z 向梯度、
在面行**零泄漏**到 u,v；`p = x` 对 cell-w 贡献恰好 0.0 ⇒ 压力路径无挤出向交叉耦合。

### 3.2 决定性的对照实验（n = 8 / 16，同一离散，只改 z 平面切向面值处理）

| 配置 | n | 面内 (u,v) | 挤出向 w | max\|w\| cell | max\|w\| face |
|---|---:|---:|---:|---:|---:|
| delivered `symmetry`（自由切向） | 8 | 4.0092e-02 | 9.0032e-03 | 1.8955e-02 | 2.1713e-02 |
| delivered `symmetry`（自由切向） | 16 | 1.2016e-02 | 3.7077e-03 | 9.4136e-03 | 9.7429e-03 |
| control `dirichlet`（给定切向） | 8 | 3.9458e-02 | **5.7157e-18** | 1.8617e-17 | 3.5773e-17 |
| control `dirichlet`（给定切向） | 16 | 1.3224e-02 | **3.6635e-18** | 1.1449e-17 | 1.9142e-17 |

- 交付口径下 `w` 的观测阶（16→32，前序数字）**1.106**；`max|w|` 从 n=8 到 n=16 减半
  （1.90e-2 → 9.41e-3，比值 2.01）＝**严格一阶**。
- **控制实验里 `w` 是两个 epsilon 的舍入噪声（≤1e-17），在 8 与 16 两级上都是**。
  面内误差几乎不变（4.01e-2 vs 3.95e-2；n=16 时 1.20e-2 vs 1.32e-2，控制组反而**差 10%**）——
  说明那两个自由面未知量并不"提高面内精度"，只是把误差转移成了伪 w。
- 伪 w 的位置：最大面值出现在 `z = 1/3, 2/3` 的**面内（x/y 法向）三角形面**上
  （`face_w_abs_max_on_internal` 量级与 max|w| 相同），不是 z 平面上。

### 3.3 机理解读

对称面上的切向面值 `u_f` 是独立未知量，其方程只是弱的零切向 traction 条件；它与相邻 cell 值之间
只由混合格式的稳定化项（μ·area/height）连接。于是 `u_f − u_cell = O(h)`，cell 内离散
`∂u/∂z = Σ_f u_f S_{f,z}/V` 因此有 O(h) 伪梯度，偏应力 `τ_xz = μ(∂u/∂z + ∂w/∂x)` 非零；
格式用 `w` 的 x 向梯度去平衡该 traction ⇒ **`w = O(h)` 的伪速度**。解析状态（`∂u/∂z = 0`）恰好让
cell-w 行残差为 0，这就是 3.1 与 3.2 一致的原因。

### 3.4 对验证口径的直接后果

- 挤出二维算例的"速度 L2"范数把真正的 O(h²) 面内误差与 O(h) 对称面闭合伪迹混在一起，
  因此交付轮的 1.684 是被伪迹拖下来的，**不是内部离散一阶**（纯面内 1.808 已过 1.8 门）。
- 复现口径建议：挤出算例要么按面内预算判阶（口径已可机检），要么在 z 平面上给定解析切向数据
  并明确声明；两种口径**都必须写清**，不得混用。

## 5. 注意点 / 局限

- 本单**未改求解器**：定位到的是对称面切向自由面自由度的闭合路径，修复（把该自由度改成对
  owner cell 的等式约束，或按镜像规则消去）会动 `NativeVelocitySpace3D` /
  混合粘性算子 / overset 与 wall model 的公共路径，风险远超单席单轮，**建议独立立案**。
- 观测阶只到 n=8/16（控制口径 n=8→16 面内 1.577，仍属前渐近区）；交付口径 16→32 = 1.808 来自
  前序已审计的运行。控制口径的 n=32/64 已递交集群（cj1327 / cj1328），本单收尾时仍在排队
  （队列 ahead ≈ 488），**未取得 → 记 WITHHELD，不写成已完成**。
- 前序 m16396 的 `planar`（n×n×n 无挤出）对照仍未跑通（直接解超时），本单亦未补。
- 三角化面使每个 quad 面有 2 个切向未知量，几何位置 z=1/3、2/3 是三角形形心，不是网格坐标——排障时
  容易被误读成"网格多了一层"。

## 6. 误差判定

| 关键量 | 值 | 基准/门槛 | 判定 |
|---|---:|---|---|
| 解析状态 cell-w 残差（n=8） | **0.0** | 应为 0（`w≡0` 精确） | **PASS** |
| 解析状态 cell-u 残差（n=8） | 3.2145e-02 | ≈2h²（1.56e-2·2） | PASS（二阶量级） |
| 控制口径 max\|w\|（n=8 / 16） | 1.86e-17 / 1.14e-17 | < 1e-12（机器零） | **PASS** |
| 交付口径 max\|w\|（n=8→16 比值） | 1.90e-2 → 9.41e-3（2.01） | 应随 h² 下降（比值 4） | **FAIL（一阶，已定位）** |
| 面内观测阶（交付 16→32，前序） | 1.808 | ≥ 1.8 | PASS |
| 面内观测阶（控制 8→16） | 1.577 | ≥ 1.8 | 未达（前渐近，n=32/64 排队中 → WITHHELD） |

**是否 <3%**：本单是收敛阶/归属判定，不是单点误差判定，故 3% 判据不适用；作为量级参照，
前序同族口径下 n=96 的单点速度误差 0.0579%、压力 2.2918% 已 <3%。本轮新增判据均为
"残差应为 0 / `w` 应为机器零"，逐项列于上表，未闭合项（控制口径渐近阶）如实记 WITHHELD。
