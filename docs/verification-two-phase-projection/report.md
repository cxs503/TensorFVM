# TensorFVM two-phase transient projection: defect remediation and verification

Mission m2903 · branch `agent/m2903` · all numbers generated by
`scripts/verify_two_phase_projection.py` (`docs/verification-two-phase-projection/evidence.json`).

## 1. What was wrong

`src/tensorfvm/two_phase_solver.py` implements a variable-density Chorin
projection for a VOF two-phase flow.  Four defects were reproduced before the
repair; the first three were already registered as `xfail(strict=True)` in
`tests/test_two_phase_solver_verification.py`, the fourth was found by this
mission.

| # | Defect | Symptom |
|---|---|---|
| P | pressure Poisson operator had flipped off-diagonal signs **and** a missing cell volume in the right-hand side | the CG solve never reduced `div(u*)`; the "projection" was inert (divergence 1e0–1e1) |
| A | pure (non-incremental) projection | a resting stratified column free-falls at exactly `g·dt` per step: gravity is a uniform acceleration, `div(g)=0`, so the Poisson RHS vanishes and no hydrostatic pressure is ever generated |
| B | CSF surface tension never entered the momentum predictor | a static drop carried `Δp = 0` instead of `σ/R` |
| C | sealed domain (`top_atmosphere=False`) accepted silently | all-Neumann pressure problem, undetermined level, silent divergence |

## 2. What was changed (minimal, config-gated)

* `_projection_pressure`: off-diagonals are handed to `_neighbor_sum` as the
  *positive* face coefficients (`[-off_e, ...]`) and the RHS is
  `b = -ΔxΔy·div(u*)/Δt`.  The operator is now the volume-weighted
  `-∇·((1/ρ)∇p)`, i.e. SPD, and the solved pressure is the physical one
  (the old scaling made it `1/(ΔxΔy)` too large: 1024× at n=32).
* `_projection_step`: the carried pressure gradient `-(1/ρ)_face ∇p` is added to
  both momentum predictors and `p` is accumulated (`p ← p + p'`), i.e. the
  incremental Chorin/Kim–Moin form.  This is what restores hydrostatic
  equilibrium **without** deleting gravity, so buoyancy survives.
* Step 1c adds the Brackbill CSF acceleration, built with the *same* face
  density (harmonic mean) as the correction, so that the recovered jump is
  `Δp = ∫ f·n dn = σκ` for any density ratio.
* `_validate_well_posed()` rejects the sealed all-Neumann configuration.
* `discrete_hydrostatic_pressure()` / `initialize_hydrostatic_pressure(..., consistent=True)`
  build the hydrostatic datum with the projection's own face density, so
  `-g - (1/ρ)_face ∇p` vanishes to round-off.

With the discrete datum the column stays at rest to **round-off**
(2e-19 … 7e-19).  With the legacy continuum datum (whose liquid branch omits
the gas-column weight `ρ_g g (H − h_i) = 4.905 Pa`, so the initial field is
discontinuous at the interface) the kick is bounded at `≈4.8e-5 ≈ 0.5 g·Δt`
and does **not** grow, whereas the pre-repair solver amplified it without
bound (O(1) velocities within a few steps).

### 3.3 Divergence elimination (compatible curl-free test field, n=24)

`max|∇·u|` before `38.9` → after `0.776`
(**factor 50**).  The residual lives on the top Dirichlet row;
inside the full `step()` path, where the boundary is re-imposed, `div` reaches
`2.0e-18` (see 3.2).

### 3.4 Sealed domain

`top_atmosphere=False, side_outlet=False` now raises
`ValueError: sealed two-phase domain` — gate closed.

## 4. Error verdict

| quantity | reference | error | < 3 % ? |
|---|---|---|---|
| Δp of a static drop, n=32 | σ/R = 0.35 Pa (exact, 2-D Young–Laplace) | 1.79 % | **yes** |
| Δp, n=48 | σ/R | 18.88 % | no |
| Δp, n=64 | σ/R | 6.28 % | no |
| rest state, discrete datum | u = v = 0 exactly | 2.1e-19 m/s | **yes** (round-off) |
| rest state, continuum datum | u = v = 0 | 4.8e-05 m/s vs g·Δt = 9.81e-5 | **no** (documented, bounded) |

The Laplace error is not monotone in `n` (1.80 % → 2.27 % → 6.28 %): the
interface is a fixed one-cell ramp, so the curvature estimate degrades as the
drop is resolved by more cells while the smearing width stays constant.  It is
the *interface thickness*, not the grid, that sets the accuracy — the honest
statement of the scope of this gate.

## 5. Caveats / open items

* **Buoyancy is only verified by the mechanism test**
  (`test_carried_pressure_keeps_buoyancy_alive`: a light spot on a hydrostatic
  datum must feel a net upward acceleration > 1 m/s², and the compatible state
  must feel < 1e-12).  A full bubble-rise benchmark (e.g. Hysing et al. 2009,
  `ρ_l/ρ_g = 1000`, `μ_l/μ_g = 100`, Re = 35/100) is **not** run here: the
  algebraic donor-cell VOF has no interface reconstruction, so the spurious
  currents of the smeared interface would dominate a quantitative rise-velocity
  comparison.  Registered as the next verification debt.
* Surface tension is still a one-cell-diffuse CSF model: parasitic currents of
  order `σ/μ` are expected and were not measured.
* `_projection_step` keeps the momentum diffusion explicit, so `Δt` is bound by
  the viscous limit of the *gas* phase; the tests stay inside it.
