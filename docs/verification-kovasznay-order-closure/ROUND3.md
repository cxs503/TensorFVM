## 1. 案例介绍

Kovasznay (1948, *Proc. Camb. Phil. Soc.* **44**, 58) Re=40 稳态不可压精确解，κ=2π、λ=−0.963741：
`u = 1 − e^{λx}cos(2πy)`、`v = (λ/2π)e^{λx}sin(2πy)`、`w ≡ 0`、`p = ½(1 − e^{2λx})`。

几何：单位方形**对称挤出** `n×n×1`（单层单元、面三角形化）。四条侧面取解析面积均值 Dirichlet；
唯一的判据变量是 z 上下两面的闭包：

| 闭包 | z 平面条件 | 是否需要解析切向值 |
|---|---|---|
| `symmetry`（交付口径） | `w=0` 给定，`u,v` 自由 | 否，但会引入 O(h) 伪 `w` |
| `dirichlet`（对照） | `u,v,w` 全取解析面积均值 | **是**（不能用于任意面） |
| **`zero_gradient`（m16695 能力）** | `w=0`；`u,v` 面值 = 属主单元值（`∂u_t/∂n=0`） | 否 |

离散：hybrid FV，二阶对流，Picard 松弛 0.7，tol 1e-8，`coupled` + `reused_lu`。

## 5. 注意点 / 局限

- **C8 的 FAIL 不是精度回退**：同一份数据里最细对是 1.808、三级拟合是 1.489，差别全部来自 n=8 的前渐近段
  （8→16 只有 1.588，m16695 的 `dirichlet` 对照同一对也只有 1.577）。拟合器自己报 `asymptotic=False`，
  所以**不能用它否证锚点，也不能用它过门**——正确的改法是「C8 只在 `asymptotic==True` 时判级」或改用 4 级。
- **验收句原口径（32/64/128）仍未达到**：本仪器的 `n` 是**挤出算例的面内分辨率**，n=32 已 28 032 dofs、1008 s；
  按实测 15.1×/倍增外推，n=64 ≈ **2.4–3 h/级、内存 3–6 GB**（集群单节点可行、控制面不可行），n=128 更贵 → **WITHHELD**。
- 本单**未改求解器**（只补数据），故 `zero_gradient` 仍是**opt-in** 能力，默认 `symmetry` 口径下伪 `w` 的一阶行为不变。
- 共享机环境影响耗时的可比性：本轮 load15 在 95–134 之间波动，n=32 的 1008.2 s 是"含竞争"的上界；
  m16782 的 660 s 未完成**不构成矛盾**（同机同负载下的进度差异），但**不能**用来做性能结论。
- 三级拟合的 `stderr` 在 3 级时**恒为 nan**（0 自由度），故 C8 实际只判 `p` 与单调性——这点 m16782 已记录，本轮未改。

## 6. 误差判定

| 关键量 | 实测 | 基准 / 门槛 | 判定 |
|---|---:|---|---|
| 速度 L2（n=32，相对体积加权） | 3.8054e-03 = **0.38 %** | 精确解析解 → 0 | **< 3 %：是** |
| 速度 L2（n=16） | 1.3328e-02 = 1.33 % | 精确解析解 | < 3 %：是 |
| 速度 L2（n=8） | 4.0054e-02 = **4.01 %** | 精确解析解 | **< 3 %：否**（粗网格，非验收网格） |
| 最细对收敛阶（锚点验收句） | **1.8083** | ≥ 1.8 | **PASS** |
| 三级拟合阶 | 1.4889（asymptotic=False） | ≥ 1.8 | FAIL（前渐近偏置，见 §5） |
| 挤出向伪速度 `max|w|` | 0（n=8/16/32） | 精确值 0 | PASS（严格为 0，非 1e-17） |

**「是否 <3%」的显式回答**：在最细两级（n=16、n=32）上，离散解对解析解的速度 L2 相对误差分别为 1.33 % 与 0.38 %，
**均 <3 %**；n=8 为 4.01 %，超 3 % 但属粗网格前渐近段，不作为验收网格。收敛阶一项的判据是「≥1.8」而不是 3 % 相对误差，
其机器裁定为最细对 **PASS**、三级拟合 **FAIL(asymptotic=False)**，两者都如实保留。
