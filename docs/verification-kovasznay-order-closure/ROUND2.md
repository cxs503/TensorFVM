# CASE-FVM-KOVASZNAY-ORDER —— 阶梯仪器的可用化与本轮锚点判定（honest FAIL / 部分 WITHHELD）

**锚点**: `CASE-FVM-KOVASZNAY-ORDER`（feature ledger, **仍 open**）
前序：交付轮 m16130（总阶 1.684 FAIL）· m16396（范数三分）· m16524（根因=对称面自由切向面自由度）·
m16584（闭包判据 C1–C5）· m16695（求解器新能力 `zero_gradient_faces`；8→16 阶 1.588 未过门）。
**本单 m16782**: 把阶梯从「一次进程跑完」升级为**可拆级/可合并的验证仪器**（`--levels/--closure/--merge`
+ 三级拟合 C8 + 渐近一致性 C7），补 9 条仪器回归测，并对锚点做了本轮可及范围的判定。

## 0. 结论一句话

**锚点本轮仍未闭合，如实记 FAIL/WITHHELD**：把约束闭包（`zero_gradient`）的阶梯拆级重跑时，
n=32 一级在本机（load15≈104 / 128 核）**660 s 内未完成**，无 payload 落盘，故 C4（最细网格对阶 ≥1.8）、
C7（所有 n_coarse≥16 的对）、C8（三级拟合）**均无法判定，记 WITHHELD**；可判定的仍是 m16695 的
8→16 对：**1.588 < 1.8 → FAIL**。本单的实质增量在**仪器**：
改 `zero_gradient` 闭包后 n=16 一级比交付口径（自由牵引）**慢 3.7 倍**（65.8 s vs 17.9 s），
这正是锚点要求的三套网格（32/64/128）在控制面会话里跑不动的原因——后续必须走集群分片，
而这套 CLI 现在支持这么做。

## 1. 案例介绍

Kovasznay (1948) 稳态不可压解析解，Re = 40、κ = 2π、λ = −0.963741：
`u = 1 − e^(λx)cos(2πy)`、`v = (λ/2π)e^(λx)sin(2πy)`、`w ≡ 0`、`p = (1 − e^(2λx))/2`。
几何 = 单位方形对称挤出 `n×n×1`（单层单元，面三角形化），四条侧面取解析面积均值 Dirichlet，
z 上下两面是唯一的判据变量（闭包见 §2）。离散：hybrid FV、二阶对流、Picard 松弛 0.7、tol 1e-8。

## 2. 怎么做的

1. **仪器改造**（`src/tensorfvm/verification/kovasznay_order_closure.py`，本单）：
   * `solve_levels(pairs)` + CLI `--levels --closure`：**每个网格一次进程**，重级可独立递交；
   * `merge_tables/merge_payloads` + CLI `--merge`：合并各次 payload（按 `(closure, n)` 去重，先到先得），
     在合并结果上重新算阶与判据——合并只是对已测数字做算术，不重解；
   * 新增两条**先声明后跑**的判据：**C7** 所有 `n_coarse ≥ 16` 的对都必须 ≥1.8（不允许靠一对走运过门）、
     **C8** 三级拟合 `f(h)=L+C h^p`（复用 `verification.multi_grid.multi_grid_order`）必须 p ≥1.8 且阶梯单调；
     三级时拟合自由度 0、不动点误差 `nan`，该量**只报告不判**（有第四级时要求 ≤0.1）；
   * 每级记录 `dofs=3(cells+faces)`、`peak_rss_mb`、`seconds`，使"这套仪器能到多细"变成**可量化**的量。
2. **回归测**（`tests/test_kovasznay_anchor_ladder.py`，9 测）：合并不重解、`(closure,n)` 去重、
   8→16/16→32 对名与 `coarse_n`、纯 h² 阶梯过 C1–C8、**一对走运不能过 C7**、一阶伪 w 挂 C2、
   两级时 C8=NOT_RUN、缺对照时 C3=NOT_RUN 而非 PASS、非单调阶梯被 C8 拒判。
   连同既有 `tests/test_zero_gradient_closure.py` 共 **15 passed**（11.6 s）。
3. **本轮实测**：以拆级 CLI 跑 n=8/16/32 全阶梯（tied + 自由牵引对照），观察耗时与收敛。

## 5. 注意点 / 局限

- **不要**把"tied 闭包 8→16 = 1.588"读成"格式只有一阶"：8→16 是前渐近区（m16584 已测自由牵引
  口径 8→16 = 1.577、16→32 = 1.808），前渐近区斜率系统性偏低，故本单不据此改判；
- 本单**未改求解器**（闭包是 m16695 交付的既有能力）；增量是验证仪器 + 判据 + 成本证据；
- `run()` 的 payload 只在阶梯末写入是既有行为，本轮实际暴露为**风险**（一次超时=全部数值丢失）。
  下一轮应改成**每级落盘**（`--closure/--levels` 单级调用已支持，未改 `run()` 的默认行为以免动到已发布的数字）；
- n=32 未完成期间本机 load15≈104（>100），按容量纪律本单未再叠加第二个重算进程；集群通道未用（排队）。

## 6. 误差判定

| 关键量 | 值 | 基准/门槛 | 判定 |
|---|---:|---|---|
| 8→16 总速度阶（tied） | 1.588 | ≥ 1.8 | **FAIL**（前渐近区） |
| 伪 w（n=8/16，tied） | 0.0 / 0.0 | 应为精确 0 | **PASS** |
| C1 约束流形 | 0.0 | ≤ 1e-12 | **PASS** |
| C3 精度不退化（n=8） | 0.9991 | ≤ 1.02 | **PASS** |
| C4/C7/C8（n≥32 判据） | 不可得 | — | **WITHHELD**（n=32 未跑完） |

压力 2.2918%（报告 13305，已 <3%）。锚点验收句（速度 L2 阶 ≥1.8 on 32/64/128）**未闭合，如实记 FAIL**。
