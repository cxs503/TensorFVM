# 对角松弛、每轮仅一次修正的固定黏性对照

同一已绑定 SUBOFF SST 输入，SIMPLEC 对角松弛 α=0.9，100 次外迭代、每轮一次修正；耗时 1321.460 s。源码和字段哈希已由运行器核对，输入 SHA256 与[四组对照](../frozen-momentum-four-way/README.md)一致。

最终当前动量残差 2.410341e-10，但压力相对变化 1.063194e-9 尚未低于 1e-9，冻结内层收敛标志也为 false，因此 numerically_converged=false。全局动量收支 8.491455e-9、能量收支 4.603775e-9。

相同对角松弛下，20 次内层批次的已完成对照为 10 次外迭代、172 次修正、144.442 s。冻结系统的矩阵分解复用减少了本例耗时；外迭代次数代表的工作不同，不能仅按次数计算加速倍数。此处不作 GPU 或大网格性能推断。

所有这些对照固定了 SST 黏性，不推进 k、ω，不是完整 RANS 或实验精度验收。
