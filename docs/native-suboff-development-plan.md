# 原生 TensorFVM → SUBOFF 验收计划

更新：2026-10-13。最终目标是原生求解器的物理精度；任务在最终验收通过前保持进行中。

本计划沿用 [benchmark 规范](../benchmarks/suboff_aff1_validation.json) 的误差定义、参考资格和三维验证要求，不修改实验数据。

## 预先固定的最终验收口径

- 原生 TensorFVM、单独贴体网格优先；随后才进行 overset 和 FVM–LBM。
- Cp：在经过原始资料审核的全部实验测压点，计算 `||Cp_calc−Cp_ref||₂ / ||Cp_ref||₂ < 0.03`。另报绝对 RMSE、最大绝对差及各测点误差，不在 Cp≈0 处计算逐点相对百分比。不选择性删除测点，不拟合实验值。
- Cd：总压力力与黏性力相加，使用明确且相同的参考面积；`|Cd_calc−Cd_ref|/|Cd_ref| < 0.03`。压力、黏性分量分别报告，检查分量误差抵消。
- 每项比较必须匹配模型附体状态、Re、攻角、来流/实验修正和归一化。Cp 和 Cd 来自不同实验工况时，分别计算匹配工况，不强行混合评分。
- 当前项目的 19 点 Cp 表仍需原表审核，Re=12M；既有阻力参考工况约 Re=13.218M。参考数据未认证时，即使名义偏差 <3%，物理验收仍为 false。
- 至少三档有计划的贴体网格研究；报告壁面第一层、层数、增长率、y+ 分布、鼻部/尾部曲面误差、Cp 和各阻力分量的加密变化。只在满足适用条件时给出观察阶/GCI。
- 除线性残差外，检查当前非线性动量/连续性、通量守恒、力与能量收支和迭代后期 Cp/Cd 稳定性。报告数值阈值与实际记录，不能只给“收敛”标签。
- 交付真实几何和网格图、压力/速度云图、表面 Cp 对比、阻力分量与收敛曲线、原场、工况配置、来源和冻结源码。GitHub 同步保留失败结果与限制。

## 开发次序与退出条件

1. **无体力层流与三维算子**：Kovasznay 等独立解析解，核对非零对流、压力、黏性自行平衡；有体力制造解通过不能代替此门槛。见[当前验证](verification-native-kovasznay/README.md)。随后按既有 benchmark 规范补齐真正三维、三个速度分量非零的独立制造解与三档网格；二维挤出不能替代该项。[ABC 初步诊断](verification-native-kovasznay/abc-diagnostics/README.md)已暴露显著压力误差。[梯度跳变修正](verification-native-gradient-jump/README.md)改善了应变控制和压力误差，该阶段 756 单元 NS 压力仍为 55.82%。随后[共享面惯性修复](verification-native-compatible-inertia/README.md)使其降至 13.78%，1,792 单元为 8.83%；无体力三维势流三档网格已通过，756 单元速度/压力为 0.076%/0.318%。[完整 Newton 与分块求解](verification-native-newton/README.md)已将 ABC 加密到 14,336 单元，压力/速度误差为 2.73%/0.0365%，三档网格及守恒证据完成。黏度 0.001 的势流在 224 单元收敛，但 756 单元仍失败。当前版本 Re=40 Kovasznay 的固定参考压力在 9,216 单元降至 2.666%，速度误差 0.0673%，四档误差下降及守恒验证通过。下一步推进 SST/壁面耦合，并持续处理低黏度与求解规模限制。
2. **边界与力**：对称面、混合牵引、变黏度、切向 Robin/壁面律，在简单通道和独立解析算子上分别验证；检查法向约束、剪切符号、积分力与功。
3. **SST 输运**：在新混合后端实现 k/ω 输运、源项、变黏度耦合；验证常量保持、守恒、正值处理、壁距与量纲。[新混合标量与 SST 一步输运](verification-native-hybrid-scalar/README.md)已完成三档标量加密与 19 项回归；[动量—SST 耦合](verification-native-hybrid-rans/README.md)已完成 8 个小型控制计算及 78 项回归，包含当前非线性残差、物理压力、低 Re 壁面条件与 SIMPLEC/Newton 对照。三角面强壁面源项的负面 k 反例仍待解决；四边形正交控制通过不能代替一般多面体正值性或湍流物理精度。旧配点路径的 SST 不能自动视为新后端已有能力。
4. **湍流简单物理案例**：通道/平板的速度律、摩阻、壁面分辨率和网格敏感性；之后再进入轴对称外流。不得通过裁剪解或调整参考值过门槛。
5. **三维求解规模**：SIMPLEC 与联合参考交叉验证、可扩展线性求解和真实残差门槛；至少在实际目标网格上检查内存/耗时。LU 预条件复用只是当前改进，不等同工业规模并行能力。
6. **SUBOFF**：认证参考与匹配工况 → 几何/层网格审核 → 原生收敛 → Cp/Cd/分量审计 → 三档网格 → 完整报告。
7. **后续扩展**：达到单独 FVM 验收后再恢复 overset、FVM–LBM、附体与破冰耦合；兼顾 GPU，先保证物理验证。

## 已知限制保留

旧 `NativeViscous3D` 的偏斜网格增能反例尚未修复，保留已知失败测试。新混合后端的线性迎风尚无一般有界性保证。OpenFOAM SUBOFF 是外部基线，不能记为 TensorFVM 的 Cp/Cd 达标结果。
