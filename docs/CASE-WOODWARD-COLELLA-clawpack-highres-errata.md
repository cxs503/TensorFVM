# CASE-WOODWARD-COLELLA — Clawpack nx≥3200 失效归因更正 + 第三方高分辨率真解

**锚点**：`XVAL-FVM-M18737-ROUND2`（「TensorFVM 的 m18737-round2 做法」交叉验证的验证欠账）
**前序**：`CASE-WOODWARD-COLELLA-round2-xval.md`（残差归属靠三角测量）、
`CASE-WOODWARD-COLELLA-pyclaw-xval.md`（第三方代码 Clawpack，只到 nx=1600）
**仓/改动面**：TensorFVM，只动 `docs/`、`tests/`（**求解器一行未改**）
**一句话裁决**：前序文件里「Clawpack nx=3200 在 t≈0.0285 提前停止，疑为 CFL 步长拒绝或 Roe 正性失败」
**是错的**——真实原因是 PyClaw 库默认 `max_steps=10000` 被耗尽，静默截断且**不抛异常**。
修掉这一行之后，第三方代码的 nx=3200/6400 档都可用，于是第 2 轮欠下的那笔账
「残差到底属于谁」有了**独立代码的实测答案**：TensorFVM 3200 网格与 Clawpack 6400 伪真解的
L1 差 **1.01 %**、峰值差 **0.95 %**（真解自身误差棒 0.90 %，带 [0.11, 1.90]），
而**已发表数字化曲线自己离真解 3.79 % L1**——第 2 轮那 3 % 地板的主体是参考侧，不是求解器。

---

## ① 案例介绍（物理背景 / 几何 / 参数表）

一维闭管 [0,1] 内三个压力平台，两束爆轰波（激波+接触+稀疏）相向传播，t≈0.028 在管中部对撞，
形成双激波干涉结构，积分至 t=0.038（Woodward & Colella 1984 标准算例）。

| 参数 | 值 | 出处 |
|---|---|---|
| 域 | x∈[0,1]，1D，两端反射壁 | W&C 1984 |
| 初始 (ρ,u,p) 左/中/右 | (1,0,1000) x≤0.1 / (1,0,0.01) 0.1<x<0.9 / (1,0,100) x≥0.9 | Dumbser et al. JCP 2019 §5.1.4 |
| γ / t_end | 1.4 / 0.038 | 同上 |
| 被审对象 | TensorFVM MUSCL-Hancock(2 阶)+MC+HLLC，CFL 0.4（`compressible/cases.double_blast`） | 本仓 |
| 第三方代码 | Clawpack 5.14.0 **Classic 波传播法**，Fortran，Roe+熵修正，MC 限幅，CFL 0.4 | `/usr/lib64/python3.11/site-packages/clawpack`（loongarch64 二进制） |
| 数字化参考 | 同文 Fig.21「Reference」PDF 矢量路径数字化 + y 轴 +0.022017 标定 | `reference/reference_density_calibrated.csv` |

**本单要回答的两个问题**：(i) 前序「nx=3200 失效」的归因对不对；(ii) 若把它修好，
第三方代码能否把「残差归属」从推断升级为实测。

## ② 怎么做的（方法 / 流程 / 工具链）

1. **复现与定位**：按 `wc_pyclaw_xval.py` 的原调用重跑 nx=3200 → `t=0.028457`、无异常、状态有限且
   正性（`rho_min=0.1888`、`p_min>0`）→ 排除「正性失败/CFL 拒绝」。加步数计数后得到
   `numsteps=10000`，正好等于 `pyclaw.ClawSolver.max_steps` 的默认值；而 nx=3200、CFL 0.4
   到 t=0.038 **需要 12799 步**（nx=1600 只需 6379 步，所以小档一直"正常"）。
   结论：**库默认步数上限造成的静默截断**，不是格式问题。
2. **修复**：`claw_run()` 显式设 `solver.max_steps = 10**8`，并把「未到 t_end」变成立即 `raise`
   （截断档不再能进结果表）；新增 `decay_probe()` 复现旧行为，作为可回归的门。
3. **第三方高分辨率伪真解**：Clawpack Classic 跑 3200 / 6400，全部断言 `|t−0.038|<1e-12`；
   真解误差棒 = `L1(3200 档, 6400 档)` 实测 0.896 %（不是猜的）。
4. **评级**：TensorFVM 已存剖面（400/800/1600/3200，不重跑求解器）用
   `tensorfvm.compressible.wc_reference.metrics_from_profiles`（未改动的度量族）对伪真解打分；
   另算**同网格两码互差**（完全不涉及任何参考表）作为绝对误差上界。
5. **尝试过但否定**：Clawpack 自带 `SharpClawSolver1D`（WENO5+SSP104）想拿五阶第三方真解，
   nx=1600 上 **Roe 与 HLLE 两种通量都出 NaN**（近真空平台的高阶重构失正），
   不具正性保护 → **本单不采用，记为被否证的选项**（诚实负面结果）。

工具链：`pyclaw/wc_clawpack_highres.py`（跑+分析，写 `pyclaw/highres/results.json` + `profiles.npz`）
+ `pyclaw/wc_clawpack_highres_figures.py`（出图）+ `tests/test_compressible_wc_clawpack_highres.py`（11 例门）。

|---|---|---|---|---|---|
| 旧调用（库默认） | 10000 | **10000** | **0.028458** | 12799 | 有限、正性、**无异常** |
| 修复后 | 1e8 | 12799 | 0.038000 | 12799 | 有限、正性 |
| 修复后 nx=6400 | 1e8 | 25647 | 0.038000 | 25647 | 有限、正性 |

### B. 第三方伪真解与其误差棒

|---|---|---|

| nx | L1（TensorFVM vs Clawpack） | 峰值互差 |

### E. 残差归属：谁离谁多远

| 对象对 | 剖面 L1 | 峰值 |
|---|---|---|
| TensorFVM@3200 vs 真解 | 1.01 % | 0.95 % |
| **数字化曲线（标定）vs 真解** | **3.79 %** | **1.99 %** |
| 数字化曲线（未标定）vs 真解 | 4.65 % | 2.33 % |

**读法**：第 2 轮记在求解器账上的「nx=3200 峰值 3.00 %、L1 3.08 %」是**拿曲线当尺子**量的；
换成独立代码当尺子，同一份解只有 0.95 % / 1.01 %，而**尺子自己的误差是 3.79 % L1**。
方向也对得上：数字化曲线**始终在真解的低密度侧**（§④ 图 e 的峰值：两码从同侧收敛，曲线峰值偏低）。
第 2 轮的 Richardson 峰值外推 6.5148 也一并被否证：Clawpack 6400 实测峰值 6.44628，
外推**高估 1.06 %**——不连续剖面的峰值三点外推在此不可靠（第 2 轮已标注 p=2.74「干净」，实为假象）。

## ⑤ 注意点（局限 / 踩过的坑 / 适用范围）

1. **归因更正（本单核心）**：前序的「CFL 步长拒绝 / Roe 正性失败」是**未经定位的猜测**，已被证伪
   （截断档状态有限且正性、p_min>0）。真实机制是库默认 `max_steps=10000`。
   教训：**第三方库的静默截断必须用「是否到达 t_end」的断言兜住**，否则会产生"看起来很物理"的假故障。
2. **伪真解仍是数值解**：Clawpack Classic 是二阶格式，其"真值"误差棒实测 0.896 %（6400 档），
   所以本单能证明的是 **<3 %（甚至 ≤1.9 %）**，不是 <0.1 %。要更紧必须上更高阶且**带正性保护**的
   第三方代码（SharpClaw WENO5 在本例近真空平台失正出 NaN，已尝试并否定）。
3. **两层证据不能混用**：§③ C 的误差（vs 真解）与第 2 轮 §③ B 的误差（vs 数字化曲线）不可互比，
   二者差一个参考侧误差项；本单没有改第 2 轮文档一个数字，只把归属写在本文。
4. **峰值位置 0.0046（nx=3200）不随网格单调收敛**：Clawpack 的 MC 限幅在极强激波处把峰放在相邻格心，
   该绝对量有 1 格的不确定性（dx=3.1e-4），判据容差 0.02 下仍安全，但不应当作收敛量。
5. **本单未取得 nx≥12800**：单机 6400 档 33 s、12800 档估计 ~140 s（本地 shell 上限 120 s，
   计算门递交的返工件未回填），故真解误差棒停在 0.896 %。补齐只需
   `--grids 12800 25600` 递交计算门，分析脚本会自动改口径（`--truth-nx`）。
6. **适用范围**：结论只覆盖本算例的 t=0.038、CFL 0.4、MC 限幅、闭管反射壁；
   换问题（如辐射边界、强稀疏）结论不可平移。

## ⑥ 误差判定（基准=第三方 Clawpack 6400 伪真解；逐项显式回答「是否 <3 %」）

| 关键量（TensorFVM nx=3200） | 实测 | 伪真解误差棒 | 是否 <3 % | 是否 <15 %（owner 拒收线） |
|---|---|---|---|---|
| 峰值密度 ρ_max | 0.95 % | 0.03 %（峰值自收敛） | **是** | 是 |
| 剖面 L1 | 1.01 % | 0.90 % | **是**（带 [0.11,1.90]） | 是 |
| 窗质量 ∫ρdx [0.4,1] | 0.0044 % | ≪0.01 % | **是** | 是 |
| 峰值位置 | 0.0046 绝对 | 1 格 = 3.1e-4 | 是（容差 0.02） | 是 |
| 低平台 | 0.028 % | — | **是** | 是 |
| 总账判据 <10 %（入池最小网格 800） | 峰值 3.98 / L1 5.39 % | — | 是 | — |

**未取得项（honest）**：真解只到 6400（误差棒 0.896 %）；SharpClaw 五阶第三方解 NaN 不可用；
nx=12800/25600 未跑。
