## 1 案例介绍（物理背景 / 几何 / 参数）

零压梯度光滑平板湍流边界层，Spalart–Allmaras 一方程闭合，平板前缘即完全湍流（人工构造）：

| 参数 | 值 |
|---|---|
| Re_L = U L / ν | 1.0e5（U = 1 m/s, L = 1 m, ν = 1e-5 m²/s） |
| 计算域高 | H = 0.2 m（上边界远场，出口零梯度） |
| 网格 | 64×56 / 128×112 / 256×224（法向拉伸 `flat_plate_stretching = 4.0`） |
| 求解设置 | 伪瞬态 SIMPLE，α_u = 0.3, α_p = 0.2, α_t = 0.3, Δτ = 0.02, tol = 1e-5 |
| SA 远场 | ν̃/ν = 3.0，无转捩/曲率/壁函数修正 |
| 对标量 | 板长平均摩阻系数 C_f = D / (½ ρ U² L) |

证据来源：`docs/verification-sa-refinement/report.md`（三级网格的平均 C_f 0.00691056 / 0.00696384 /
0.00702561，迭代 78 / 99 / 132，均收敛）。原始 `fields.npz` 未入库，本单不重算，只做判据与账目复核。

**为什么审这件事**：这三个数在同一仓里被两套阈值判过——已上线的
`benchmark_flat_plate.ERROR_LIMIT = 0.20`（±20%，CI 闸门）与加密报告正文里的
「经验摩阻 3% 分别验收」（结论「均未达标」）。同一份证据两种结论，必须先对账。

## 2 怎么做的（方法 / 流程 / 工具链）

1. **程序化取证**：脚本用正则解析 `report.md` 的表格（不手抄），记 sha256；
   解析出 3 行即断言成功，产物确定性（两次运行字节一致，含测试）。
2. **交叉复核**：用 `flat_plate_reference.CORRELATIONS` 从零重算相对 Schlichting 误差，
   与报告列出的 6.6141% / 5.8940% / 5.0593% 比对（容差 0.01 个百分点）→ 三条全部一致，
   说明存储列没有抄写漂移，问题只在判据。
3. **双阈值判决**：同一 C_f 分别对 `0.20`（已上线闸门）与 `0.03`（加密报告判据）裁决。
4. **文献带判决**：新增 `band_aware_verdict()`，给出四条公认完全湍流平板关联式
   （Schlichting 0.074Re^-1/5、Prandtl–Schlichting 0.455/(log₁₀Re)^2.58、ITTC-57、
   White）逐式误差、带内/带外、以带宽归一的偏移量——把「单一关联式误差」换成
   「相对参考不确定度的位置」。
5. **壁面分辨复核**：用实测 C_f 反算 u_τ = U√(C_f/2)，壁法向首单元中心高度按仓内
   `FlatPlateMesh` 的聚类律闭式给出（测试用网格类逐位对齐），得三级 y⁺。
6. **加密行为判定**：检查逐次差分是否收缩（渐近区判据），不收缩则**拒绝** Richardson 外推。
7. **参考带算术语义修复**：`docs/verification-flat-plate-qualification/README.md` 的
   带宽百分比与窗/带比值口径纠错（见 §5），并新增 `window_to_band_ratio()` 显式区分
   单侧窗（1.047）与全宽窗（2.094）。

## 5 注意点（踩坑 / 局限 / 适用范围）

1. **判据双标（本单主结论）**：同一组数字在已上线闸门（20%）下三级全 PASS，在加密报告
   正文的 3% 判据下三级全 FAIL，而 3% 从未写进任何代码常量或测试，读者只能看到
   「均未达标」这一句。差值 6.67 倍。建议：把加密/精度类结论绑定到 `ERROR_LIMIT`
   或新增 `band_aware_verdict()` 的口径，报告里显式写「判据来源」。
2. **参考式依赖（可判性边界）**：相对 White 最粗网格误差 0.00%，相对 ITTC-57 为 -17%。
   误差大小由「选了哪条关联式」决定，量级与带宽同阶（19.1%），因此「3% 精度」类主张
   **在原理上不可由这四条关联式裁决**——需逐点实验/DNS（Österlund 1997、Schlatter–Örlü）。
3. **原文参考带算术纠错（已修）**：`docs/verification-flat-plate-qualification/README.md`
   原写「带宽/均值 = 1909.81%」，实为 **19.098%**（100 倍笔误，3 处）；
   「闸门窗口/带宽 = 1.047」是**单侧**口径，全宽为 **2.094**。定性结论（闸门不能授予
   精度资格）不变且更强；已加 `window_to_band_ratio()` 与测试固定两种口径。
4. **未重算（honest scope）**：原始 `fields.npz` 不在库内，只能复核报告表格；本单**未**
   重跑 SA 平板。实测单线程 6.7 s/迭代（本机实跑 6 迭代 40 s，16 线程更慢 11.5 s/迭代），
   78 迭代约 9 min，超出本地 120 s 命令预算 → 列为 not_run，建议走集群
   `run_cluster(stage_dir=…)` 做一次 64×56 复现（同机不可行已实测）。
   y⁺ 用平均 C_f 反算，是**网格级**估计而非局部壁面剪切。
5. **加密不可外推**：差分随加密变大（1.159 倍），说明 64→256 尚未进入渐近区，
   「-5.06% 会收敛到 0」这句话不能由现有三级证据支持；须 ≥4 级且差分收缩后再谈阶。

## 6 误差判定（逐项显式回答「是否 <3%」）

| 关键量 | 基准 | 误差 | 是否 <3% |
|---|---|---|---|
| 平均 C_f（64×56） | Schlichting 0.074Re^-1/5 | **-6.61%** | 否 |
| 平均 C_f（128×112） | Schlichting | **-5.89%** | 否 |
| 平均 C_f（256×224） | Schlichting | **-5.06%** | 否 |
| 平均 C_f（256×224） | Prandtl–Schlichting | **-1.82%** | **是** |
| 平均 C_f（64×56） | White | **+0.00%** | **是** |
| 平均 C_f（256×224） | ITTC-57 | **-15.69%** | 否（>15%，不可接受线边缘） |
| 带内判据 | 文献带 [0.006911, 0.008333] | 三级均带内 | 带内=不可分辨，非精度授予 |
| 壁面分辨 | y⁺<1 | 0.812 / 0.400 / 0.199 | **是** |

**净结论**：三级结果对已上线 20% 闸门全部合格、对 3% 单式判据全部不合格、对文献带全部落在带内；
「是否 <3%」的答案取决于选哪条关联式（0.00% ~ -17%），因此**单关联式 3% 判据不可判**，
正确表述是 WITHHELD（带内、参考不确定度未分辨），而非「未达标」。
