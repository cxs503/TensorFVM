## 1. 案例介绍（物理背景 / 几何 / 参数）

浅水方程一维溃坝：初始 x = 0 处一道坝，左侧 h₀，右侧 h₁，t = 0 瞬间移除。

| 参数 | Ritter 干床 | Stoker 湿床 |
|---|---|---|
| h₀ / h₁ [m] | 1.0 / 0.0 | 1.0 / 0.5 |
| g [m/s²] | 9.81 | 9.81 |
| 计算域 [m] | [−5, 5] | [−5, 5] |
| t* = t√(g/h₀) | 2.0 | 2.0 |
| 解析波前 x_f | 2 t √(g h₀) = 4.0 m | 稀疏波 + 常数区 + 水跃（R-H） |
| 格式 | 有限体积 · MUSCL(minmod) · HLL · SSP-RK3 · CFL 0.4 · 反射壁 | 同左 |

网格：n = 800 / 1600 / 3200 / 6400（dx = 0.0125 → 0.0015625 m）。

## 2. 怎么做的

1. `scripts/run_shallow_water_dam_break_hires.py`（新增）对两算例逐网格跑
   `run_case`，记录：
   * **验收量**：整条 `x_f(t)` 序列最大相对误差（`series_metrics`，含分级样本数
     `24/25`）与 `front_series<5%` 判据的通过状态；
   * **headline @ t*=2**：干床 `front_fan`（形状一致估计子）、湿床
     `shock_position`（解析窗口，AUDIT F4 已记录其为近同义反复）；
   * **湿床无解析量交叉核对**：`data_driven_plateau` 的亚格 `bore_x`、`h2`、
     `step_ratio`，以及作为负对照的格心读数 `bore_x_cell`；

     `verdict` 全部失败键与墙钟。
2. 判定规则（先验、非法拟合）：精化比 `e(n)/e(n/2)`；`> 0.9` 记为"到地板"；
   少于 3 个网格不报收敛阶；最细一级与更粗一级矛盾时如实标为

3. 平台检测器另加**独立合成复核**：直接用解析 Stoker 剖面（不经过求解器）在
   n = 400 … 12800 上运行 `data_driven_plateau`，其 fan/水跃梯度比恰好跨越
   1e-2 判据（5e-2 → 3e-3），用来把"检测器自身"和"解"分开。
4. 纯单核、无 MOCK：所有数字由脚本写入

## 5. 注意点（含新发现 F9，本单已修）

### F9（高，已修）`data_driven_plateau` 的阈值不是网格无关的 —— n = 6400 静默报错 15.5 %

AUDIT §7 修好 F4（无解析窗口的平台/水跃检测）时，其 docstring 断言判据
`|dh/dx| < 1e-2 · max|dh/dx|` "grid-independent (both scale with 1/dx)"。
**这一句只对水跃成立，对稀疏波不成立**：扇区是光滑特征，物理斜率是常数
（实测 0.298 → 0.308 m/m，n = 800 … 12800），而 `max|dh/dx|` 每精化一次翻倍
（5.84 → 50.19）。于是比值 fan/jump 按 dx 下降：

| n | 800 | 1600 | 3200 | 6400 | 12800 |
|---|---|---|---|---|---|
| fan/jump | 5.10e-2 | 2.70e-2 | 1.29e-2 | **6.12e-3** | 3.07e-3 |

判据 1e-2 在 **n = 3200 → 6400 之间被穿过**，平台窗口的向左行走因此穿过整个扇区：

| 量 | n = 3200（修前/修后） | n = 6400（修前） | n = 6400（修后） |
|---|---|---|---|
| 平台 `h2` 相对误差 | 1.08e-4 / 1.08e-4 | **15.53 %** | 9.69e-7 |
| `step_ratio` 误差 | 0.0107 % / 0.0107 % | **15.53 %** | 0.0001 % |
| 平台宽度 | 3.01 m / 3.01 m | **5.88 m** | 2.97 m |
| `bore_method` | mid_level_crossing | **mid_level_crossing（无告警）** | mid_level_crossing |

即：**取证工具在细网格上返回了一个 15.5 % 的错值，且自称有效**。这正是本算例
历史上反复出现的缺陷类（"发表的不是被定义的那个量"，F1/F2/F8 同型），只是这次
出现在"无解析量交叉核对"这件本该救它的工具里。

**修复（最小、可验证）**：

1. 硬闸：窗口向左行走若在找到扇区之前到达域边界，则 `bore_method =
   "plateau_unbounded"`、`h2/h1/level/bore_x = NaN` —— **不再返回"找到一个平台"
   的假象**；
2. 分档重试：判据按 10 倍一档收紧，最多 `PLATEAU_THRESH_MAX_DECADES = 3` 档
   （先验声明；是分辨率环，不是对着答案凑），每次尝试都写进 `attempts`；
3. 软标记：`flatness = max|h − mean(h)| / jump` 与 `bore_valid =
   flatness ≤ PLATEAU_FLAT_FRACTION = 5e-2`，供下游决定能否分级
   （实测粗网格平台其实是斜坡：n = 800 为跳跃的 0.9 %，n = 3200 为 4.0 %，
   n = 6400 为 0.2 %）；
4. 交叉核对字典同步输出 `bore_valid` / `flatness` / `thresh_frac_used` /
   `plateau_width` / `bore_attempts`，并重新生成 `bore_subcell.json`、
   `metrics.json`（`scripts/verify_dambreak_bore_subcell.py`、
   `scripts/run_shallow_water_dam_break.py --n 1600 --resolutions 100,…,1600`，
   两者重跑后 3 项 pass 全部为 True，worst sub-cell 0.121 cells）。

### 其它注意点

* **不宣称序列误差收敛阶**：0.73（干）/ 0.68（湿）显著低于 L1 的一阶，且
  0.425 % → 0.380 %（干，n=1600→3200）只有 1.1×，属估计子效应；本单只声明
  "尚未到地板"（比 0.9 规则），不下阶结论。
* **格心读数 `bore_x_cell` 仍是负对照**：n = 3200 → 6400 由 0.0149 % 反向升到
  0.0265 %，与 F7 同型，不可用于分级。
* **湿床 headline `shock_position` 是近同义反复**（AUDIT F4）：解析窗口给位置，
  幅度由解析 `h2` 定电平；本单只用它对照，不用它作为"位置对了吗"的证据，
  位置证据用亚格无解析量 `bore_x`。
* **n = 12800 只做了合成解析剖面复核**（`tests/test_dambreak_plateau_resolution.py`），
  未跑求解器：本机单条命令上限 120 s，单核 12800 两算例约 140 s；已转为集群
  递交（cj2734，排队中被本席撤单以免阻塞交付）。这是**未运行项**，不是通过项。
* 湿床 n = 800 在 t* ≲ 0.02 的未分级样本偏差 4.505 %（AUDIT F5）本单未重测，
  沿用原记录。
