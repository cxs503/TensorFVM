## 1. 案例介绍（物理背景 / 几何 / 参数）

一维浅水方程溃坝：x = 0 处一道坝，左侧 h₀，右侧 h₁，t = 0 瞬间移除。

* **Ritter 干床**（h₀ = 1 m, h₁ = 0）：稀疏波扇 + 干床波前，波前常速 2c₀。
* **Stoker 湿床**（h₀ = 1 m, h₁ = 0.5 m）：左行稀疏波 → 常数星区 → 右行水跃（R–H）。

格式：有限体积 · MUSCL(minmod) · HLL · SSP-RK3 · CFL 0.4 · 反射壁；
时间到 `t* = t√(g/h₀) = 2`。网格 n = 800 / 1600 / 3200 / 6400。

**几何与参数表见下方数据块 A 节**（域 [−4, 6] m、坝位、`t*` 与 `t` 的换算、
以及 6 条闭式基准值都在那里，由 `CASES` 与 `exact` 模块现场求值）。

## 5. 注意点（F9 与局限）

### F9（高）无解析量平台检测器的切分不是网格无关的

`data_driven_plateau`（AUDIT F4 的无解析量平台/水跃检测器）用**绝对**切分
`|dh/dx| < 1e-2 · max|dh/dx|` 界定平台。这一句只对**水跃**成立：跳跃的
`max|dh/dx|` 随 `1/dx` 增长，而稀疏波扇是光滑特征、物理斜率近常数
（实测值见数据块 D 节 `fan_grad` 列），所以扇/跳跃比值随加密下降，终将穿过 `1e-2`；穿过之后
平台窗口的向左行走会一路走进扇区，**静默**给出错误的平台振幅。

已声明的两级防线（本次实测生效，见数据块 D 节）：

1. `plateau_unbounded` 硬闸：行走在找到扇区前抵达域边界 → 所有量 NaN，不给假值；
2. 十进位重试阶梯：切分按 10 倍一档收紧，最多 `PLATEAU_THRESH_MAX_DECADES = 3` 档
   （先验声明，是分辨率环而不是对着答案凑），每次尝试都写进 `bore_attempts`；
3. 软标记：`flatness ≤ PLATEAU_FLAT_FRACTION = 5e-2` 才算 `bore_valid`，
   粗网格平台其实是斜坡，评分方必须查这个标志。

**这是有条件通过，不是已解决**：穿点处未收紧的切分已经失效，读数靠阶梯救回；
阶梯用尽后检测器按设计整体失效（`plateau_unbounded`）。届时正确做法是先改判据
（例如把切分改成物理长度尺度或直接用扇形解），再上网格 —— 不能靠“再收紧一档”。

### 其它局限与踩过的坑

* **`fan_grad` 的排除窗口必须是物理半宽**。首版用「3 个单元」这种单元数窗口，
  细网格上会被跳跃的抹平区污染到远超扇区真实斜率，于是诊断假报
  「比值仍在切分之上」。现声明为 `max(3 dx, 0.01 L)`，两种窗宽的读数都记在
  数据块 D 节（`fan_grad` 列）与下条「踩坑」记录里。
* **不宣称 `x_f(t)` 序列的收敛阶**：观测阶显著低于一阶，而同一批运行的 `depth_l1`
  稳定在一阶。差别来自波前读数估计子而不是格式，故只主张 L1 的一阶。
* **湿床序列误差在一次精化上会回升**（逐级比 > 1，见数据块 B 节），照实记录，

  指定，位置证据用亚格 `bore_x`。
* **n = 12800 只有合成解析剖面复核**（`tests/test_dambreak_plateau_resolution.py`），
