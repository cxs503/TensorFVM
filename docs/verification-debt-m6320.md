# TensorFVM 验证欠账复核：m6253 失败面再判读 (m6320)

**任务ID**: m6320 (selfstart 自找活·generalist 席)
**日期**: 2026-11-07
**性质**: 验证欠账复核（对已合并功能/失败报告做文献与解析基准再判读，轻量、无重算力）

## 1. 背景与动机

上一张终态单 **m6253**（`docs/incompressible-baselines/MATURATION_REPORT.md`）在
不可压验证面（后台阶 / 自然对流 / 突扩管）上 **HONEST FAIL**。本单对三处失败
做**再判读**，区分「真求解器缺陷」与「参考值/后处理误用」，为后续验证任务
提供可执行的靶子，避免重复踩同一坑。

## 2. 三处失败逐项再判读

### 2.1 突扩管 (Sudden Expansion, AR=4, Re_D=100) —— 参考值误用，非求解器缺陷

m6253 报告给出 `K = 1.026/1.106/1.131 (n=10/20/30)`，对 Borda-Carnot `0.5625`
误差 101% 判 FAIL。**但该 K 是「原始静压差」**，而 `docs/benchmarks/incompressible-verification.md`
§2.2 已明确：*"The raw static pressure difference is not a loss coefficient at
all -- the expansion *recovers* static pressure, so `K_static` is dominated by
the reversible `(1 - 1/AR^2)` term"*。

正确口径是**质量通量加权总压差**（`x/D=-0.4` 与 `+2.0` 两站之间）：

| 网格 | K (总压) | 误差 vs Borda-Carnot 0.5625 |
|---|---|---|
| D/10 | 0.5552 | **-1.3 %（PASS）** |
| D/20 | 0.6052 | +7.6 %（细网格 FAIL） |

**结论**：m6253 的 101% 失败是**用了错误 K 定义**（静压差），不是求解器缺陷。
D/10 总压口径下 K 已 PASS（-1.3%）。真正的欠账是 **D/20 细网格 +7.6%** 与
**回流区不对称**（`L_r/D = 0.20 下 / 11.86 上`，几何与入口完全对称却不对称，
指向台阶角/尾流处理缺陷）——这才是后续要打的靶。

### 2.2 自然对流方腔 (Ra=10⁴/10⁵/10⁶, Pr=0.71) —— Nu 精度达标，收敛阶需细网格

m6253 报告：Nu 误差全部 <3%（Ra=10⁴ 1.2%、10⁵ 1.7%、10⁶ 0.7%），但
Ra=10⁴/10⁵ 收敛阶「无法计算」（非单调）。

`docs/benchmarks/incompressible-verification.md` §3 判据表给出**同一结论的
更精确表述**：观测网格阶 `-0.18`（NC 16/32/64 序列 10.405→9.778→9.070 不在
渐近区），**不是 order 例程的 bug**，而是网格序列不够细。报告明确要求
**N=64/96/128 均匀加密研究**。

**结论**：自然对流的**物理精度已达标**（Nu<3%），欠账是**收敛阶证据**——
需在 N=64/96/128 上做均匀加密（重算力，本单因 load15=154 未起）。

### 2.3 后台阶 (Re_H=800, 膨胀比2) —— 真求解器缺陷，需二阶格式

m6253 与 verification doc 一致：`L_r/H = 0.184` vs 目标 `6.10`（-97%），主回流
区完全未表征。根因：**固壁体积惩罚 + 开放出流**组合（唯一同时含这两者的配置），
`O(kappa)` 质量缺陷在台阶面被投影视为质量汇、一步后回注，抑制了喂主气泡的
剪切层。这是**真求解器缺陷**，需二阶对流格式或改进惩罚/出流处理（重算力）。

## 3. 给后续验证任务的靶子（按可单干度排序）

1. **突扩管回流区不对称**（`L_r/D` 下 0.20 / 上 11.86）：几何与入口对称却不对称，
   指向台阶角/尾流处理。**可单干、可验证**（对称性判据），是当前最值得打的
   求解器缺陷。
2. **突扩管 D/20 细网格 K +7.6%**：需确认是否网格收敛问题。
3. **自然对流 N=64/96/128 收敛阶**：重算力，需在集群跑（本机 load15=154 未起）。
4. **后台阶二阶格式**：重算力，需在集群跑。
