## 1. 案例介绍（物理背景 / 几何 / 参数）

### 1.1 为什么是这四个验证面

两相流 VOF 有三类彼此独立的失效模式，必须分开验证，否则一个"通过了"的数字会掩盖另一个缺陷：

1. **界面输运的守恒性与锐度**（Zalesak 旋转圆盘）：速度场是精确刚体旋转，`n` 圈后解析解=初始场（闭合解）。它同时考查体积守恒（必须回到原位）、界面锐度（扩散格式会抹平圆盘与狭缝）与形状误差。
2. **静水平衡（well-balanced）**：静止平界面下 `p = ρ g (H − y)` 是解析解。任何离散重力与压力梯度不平衡都会把静止流体加速成寄生流——自由面求解器最常见的"看着稳其实在漏"失效。
3. **重力驱动瞬态的自由面演化**（Martin & Moyce 溃坝）：唯一有实验数据的强非线性面，波前位置是可测标量。
4. **界面压缩格式本身**（CICSAM vs PLIC vs FCT）：压缩格式必须"锐而不振"，判据是界面厚度（网格数）与有界性。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 2.1 CICSAM 面值（`src/tensorfvm/vof_cicsam.py`）

归一化变量（donor D、acceptor A、D 的上风 U）：

```
α̂ = (α − α_U)/(α_A − α_U)          α_f = α_U + α̂_f (α_A − α_U)
```

三个成分：

1. **Hyper-C（压缩极限）**：CBC（Gaskell & Lau 1988；Waterson & Deconinck 1995）给显式格式面值的上界 `α̂_f ≤ min(1, α̂_D/C)`，Hyper-C 直接取该上界（有界性允许的最压缩插值），`C=|u_f|Δt/h`。
2. **ULTIMATE-QUICKEST（精确成员）**：把被输运量在面心作二阶 Taylor 展开、用对流方程消去时间导数（QUICKEST 思路）：
   `α̂_UQ = 3/8 + (3/4)α̂_D − (C/2)(1−α̂_D) + (C²/8)(1−2α̂_D)`。
   `C=0` 退化为 QUICK（`3/8+3/4α̂_D`）；`C=1` 精确落在两端点（`α̂_D=0→0`、`=1→1`）；界面中值处反扩散（`α̂_D=0.5, C=0.5 → 0.625>0.5`）。UQ 越出 CBC 则回退 donor 值（CICSAM 的 UQ 修正）。
3. **方位权重**：压缩只在"需要压"处开。`θ` 为界面法向与扫描方向夹角，`(1+cos2θ)/2=cos²θ`，故
   `γ = k_γ n_axis²/|n|²`（`k_γ=1`）：界面沿法向被平流时（θ→0）γ=1 用 Hyper-C；流动与界面相切时（θ→90°）γ→0 用 UQ（此时压缩只会制造褶皱）；`|∇α|≈0` 的纯相区 γ=0。

数值框架：MAC 交错均匀网格，**方向分裂 + 通量形式**：

```
α_i^{n+1} = α_i − (Δt/h)(F_{i+1/2} − F_{i−1/2}),   F = u_f α_f
```

→ 全局守恒是结构性的（逐项相消），与圈数无关；扫描顺序每步交替。

**界修复**：分方向速度场各自不无散，个别单元会被灌过 1（CBC 只约束流出、不约束受主容量），实测单次分裂越界可达 ±27%，必须修复；但 PLIC 用的**全局** `α(1−α)` 重分布会把越界量摊到整条界面，把压缩格式锐利的前沿抹成光晕（实测 L1 0.087→0.331）。本实现改用**局部**修复 `_repair_bounds_local`：只在越界单元的 3×3 邻域内按 `α(1−α)` 权重把体积还回去 → 界面锐、质量到舍入级。

### 2.2 验证门（`vof_cicsam_gate.py`）

- `--task zalesak`：逐方案逐圈数跑刚体旋转，记录质量台账、`relative_l1`（Rider–Kothe，按液相体积归一）、对称差（>0.5 掩膜）、峰值保持、界面厚度统计（`1/max|Δα|` 的中位数/90 分位）。
- `--task hydrostatic`：调用既有 `vof_verification.hydrostatic.run_hydrostatic`（well-balanced），并额外跑一次**非** well-balanced 负对照——不可能挂的门不是门。
- `--task dam`：实例化 `Phase0TwoPhaseSolver` 后把 `solver.vof` 换成 `CICSAMVOF`（求解器零改动，`advect` 是 drop-in 签名），再走 `run_dam_break`；波前沿用求解器自带"最外一个深度>半格的列"定义（与仓库既有证据口径一致），在 t*=1,1.5,2,2.5,3 逐点对数字化 M&M 曲线求相对误差。
- `--task merge`：递归汇总所有 JSON → `summary.json`，按预登记阈值 `ACCURACY` 机器判级（判据先于数据存在，写在代码里）。

工具链：torch float64 CPU；本机 128 核并行跑分片 + `run_cluster` 递交集群队列作交叉复核（见 `docs/p167-n03/cluster_jobs.json`：cj734–cj737 递交后队列积压未派发，本次数字由同一条命令本机跑出）。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **归一化变量的分母符号（本节点最贵的坑）**：NVD 的 `α̂=(α_D−α_U)/(α_A−α_U)` 只在 `|α_A−α_U|>ε` **且** `α̂_D∈[0,1]` 时有意义；**分母为负本身不是病**（"下落型"剖面顺流平流就是镜像情形）。第一版误把 `denom<0` 全部回退到一阶 donor，实测 64² 一圈 Zalesak L1 = **0.734**（比 FCT 还差），改成按 `α̂_D∈[0,1]` 判"可移动"后降到 **0.087**——8 倍差距，症状是"整场出现稳定光晕"。
2. **界修复的作用域**：分裂扫描必然灌过界（实测单扫 ±27%），修复必须**局部**（3×3 邻域）；沿用 PLIC 的全局 `α(1−α)` 重分布会把越界量摊到整条界面 → L1 0.087→0.331，ASCII 场图确诊为"界面外扩光晕"。
3. **周期性边界的通量闭合**：`flux[0]` 与 `flux[n]` 是同一张面，若按壁面把两张面都置零，每个方向每次扫描都漏掉绕回的通量——实测对角平流 60 步掉 **7.4%** 质量。改成"共享面值 + 环绕 ghost"后回到 1e-13。
4. **厚度度量的几何地板**：中心差分 `1/|∇α|` 会给**完美锐利**的 0/1 阶跃报 2.0 格（它看到 (1−0)/2）；改用单侧差分最大值（`1/max|Δα|`）后阶跃=1.0 格。但弯曲界面在粗网格上仍有几何下限：64²（圆盘半径仅 9.6 格）时 PLIC 1.87、CICSAM 2.06，都在地板附近——所以锐度判据在 ≥128² 上判（`GATE_GRID_FLOOR=128`），64² 数据照实列出（不隐藏）。
5. **溃坝波前的口径依赖性**：`surge_front` 用"最外一个深度>半格的列"。压缩格式把前缘做成很薄的膜（厚<半格）时会被阈值截掉，因此**该指标对格式锐度敏感**：越锐的格式越容易"看起来更慢"。这解释了两个反直觉事实：(a) CICSAM 早期比 FCT 快、晚期略慢；(b) 100×30→200×60 密码后最差误差几乎不动（0.590→0.572），说明滞后不是数值扩散而是求解器物理建模 + 前缘度量共同结果。判据按既定口径判，**未做口径调整**。
6. **适用范围**：CICSAM 实现在均匀 Cartesian MAC 网格、方向分裂、方向 CFL≤1 下有效；不做界面几何重构，无法给界面曲率二阶精度（表面张力曲率仍应走 `height-function` / `two_phase_curvature` 路线）。强变形界面/非结构网格仍首选 PLIC。
7. **性能**：64² 一圈 PLIC ≈40 s、CICSAM ≈2.4 s（同机同线程）；128² PLIC 单圈 >5 min（Python 逐单元裁剪），CICSAM 9 s。这也是本次 128² 只跑 CICSAM/FCT、PLIC 对比放在 64² 的原因（如实说明范围收窄）。

## 6. 误差判定（逐项 vs 基准，显式回答"是否 <3%"）

| 关键量 | 基准 | 实测误差 | 是否 <3%？ | 本节点判据 |

| CICSAM 界面厚度（≥128²） | <2 格判据 | 1.937 格（90 分位） | — | 是（G2 PASS） |
| 静水压力分布 | ρ g (H−y) | **0.0**（机器零；负对照 1.56%） | **是** | 是（<1%，G4 PASS） |

| 溃坝液量 | V₀ | 8.1e-16 | **是** | 附带 |

**honest FAIL 声明（不可覆盖）**：溃坝波前 vs Martin & Moyce 的 10% 判据 **未通过**。最差点在 t*=1（模拟 −59%），随 t* 递减到 t*=3 的 −24%。加密一倍（100×30→200×60）最差误差仅 0.590→0.572，**无收敛趋势**，因此不能归因于网格不足；结合 §5.5 的口径分析，真实原因是"初期竖直坍塌阶段（M&M 的 3D 水柱在 2D 无黏模拟中下落/铺展不同步）+ 半格深度前缘阈值对薄膜的截断"，属求解器物理建模与实验几何差异，本节点范围内未修复。作为独立佐证：Ritter 浅水极限（图 4 点线）与实验曲线本身相差 2.8 倍，M&M 早期点远离浅水渐近（仓库历史证据 `docs/vof-chain-anchor/report.md` 已记录同一困难），这是文献公认的 2D 对标难点区间。
