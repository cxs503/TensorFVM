## ⑤ 注意点 / 局限

1. 144×72 梯级为 log-only（npz 不可取回），剖面未评；不影响定性结论。
2. 96×48 两 dt 的时均场均**未通过平稳性门**（spread 0.155 > 0.05）：2-D 层流
   解的分离泡本身非定常，这是物理（2-D 层流泡振荡）而非数值噪声。
3. 2-D 层流解有两个逆流泡（冠后 + 谷中），DNS 只有一个主泡——对象结构都不同。

## ⑦ 结论与给下次的线索

1. **定性完成**：dt 效应 0.4 %、网格效应 5 %、外推后仍 +29 % → 误差是
   **2-D 模型形式误差**（2-D 层流/2-D SST 均无法再现 3-D 湍流再附），不是
   离散误差。round 29 悬置的问题就此关闭。
2. 锚点 <10 % 门需要 3-D 非定常模型（LES/DES）——超出单干范围，建议派战役单
   （3-D 周期山丘 LES，可复用 `channel_les3d` 基线）。
