# CASE-FVM-PERIODIC-HILLS 第二十四回合（m22380, selfstart）

## 问题：已发布的 `x_r/H` 是壁面法向导数的截断误差吗？

round 17 认证了「壁面剪切零点」这个**算子**，round 21 用 `mean_u` 这条
独立数据通路对账，round 22 钉死了「哪个气泡」。三者共用的输入——
`tau_b(x)` 本身，即**壁面法向一阶单侧导数**——从未被审计过。

`PeriodicHillSolver.wall_shear` 用的是

```
tau_b(x) = (u_0 . t) / dn_0(x)      # 两点单侧差分
```

其中 `dn_0` 是壁面到第一层网格中心的投影法向距离（96x48 上约 0.018–0.032 H）。
本轮把同一套几何、同一套切向投影、同一套零点算子固定住，**只改壁面法向
导数的阶数**（1/2/3 阶单侧，全部钉死 `u_t(0)=0` 的无滑移精确值），
在全库 **8 个可用 artefact** 上量化「后处理能贡献多少 `x_r/H`」。

零算力：只读已存盘的时均场，不重跑任何算例。

## ① 阶数不是自称的：解析标定

平壁（`hill_amplitude=0`）+ 平面 Poiseuille，壁面梯度有精确闭式，剖面对法向距离是二次的：

| ny | 精确 `du/dn` | 1 阶 | 1 阶相对误差 | 1 阶误差 / (`s_0/h`) | 2 阶相对误差 | 3 阶相对误差 |
|---|---|---|---|---|---|---|
| 12 | 42.504000 | 40.733000 | 4.167 % | 1.000000 | 0.0e+00 | 1.7e-16 |
| 24 | 42.504000 | 41.618500 | 2.083 % | 1.000000 | 0.0e+00 | 1.7e-16 |
| 48 | 42.504000 | 42.061250 | 1.042 % | 1.000000 | 0.0e+00 | 1.7e-16 |

2/3 阶到机器精度；1 阶误差**恰等于** `s_0/h`（最后一列恒为 1），
`ny` 每翻倍误差减半 —— 一阶收敛是量出来的，不是声明的。

## ② 关键前提：常数标度**不可能**移动零点

`tau = du_t/dn` 里没有 ν、没有 ρ，即使整个剖面被乘上一个未知常数，
`x_s`/`x_r` 也逐位不变（`crossing_scale_invariance`，单位测试钉住）。
所以真正需要审计的只有**随 x 变化**的那部分截断误差。

## ④ 对锚点结论的影响

锚点算例（`round20_laminar_Re2800_96x48`，冠后气泡，Breuer 2009 基准 `x_r/H = 5.41`）：

| 壁面导数阶数 | `x_r/H` | 相对基准误差 |
|---|---|---|
| 1 阶 | 1.254 | -76.82 % |
| 2 阶 | 1.230 | -77.27 % |
| 3 阶 | 1.224 | -77.37 % |

用收敛后的高阶格式，误差从 -76.82 % 变成 -77.37 %，即 **-0.55 个百分点**。
后处理不是 honest FAIL 的原因。

## ⑤ 量级（不是零点）要小心

| artefact | `max abs tau3` | 1 阶-3 阶 偏差 max / mean（相对 `max abs tau3`） | 2 阶-3 阶 偏差 max |
|---|---|---|---|
| `round9_96x48` | 70.393 | +33.16 % / +5.29 % | +12.06 % |
| `round20_laminar_Re700_96x48` | 43.041 | +27.96 % / +2.82 % | +9.26 % |
| `round20_laminar_Re2800_96x48` | 47.079 | +32.41 % / +4.88 % | +11.72 % |
| `round20_laminar_Re2800_96x48dt01` | 48.786 | +32.44 % / +5.19 % | +11.73 % |
| `round11_sst_r18_72x36` | 44.944 | +33.54 % / +5.91 % | +12.30 % |
| `round11_sst_r18_96x48` | 55.075 | +32.91 % / +5.21 % | +11.93 % |
| `round11_sst_96x48` | 52.420 | +27.19 % / +2.59 % | +8.88 % |
| `round11_sst_r12-96x48` | 91.615 | +33.22 % / +5.53 % | +12.14 % |

零点只对剖面的**符号结构**敏感，量级却直接吃这份偏差：局部最大可达 33.54 % 的 `max abs tau`。
因此：**任何摩擦速度 / 阻力 / 壁面切应力量值结论，必须用 ≥2 阶壁面导数**；
只有「零点位置」类结论可以沿用求解器的两点差分。

## ⑦ 局限（明示，不粉饰）

1. 三阶格式共用同一条 eta 线近似：壁面附近 eta 线并不严格垂直于壁面
   （`|beta/alpha|` 可达 O(0.6)），所以这里的阶数只消掉了**剖面曲率**误差，
   没有消掉斜交误差 ⇒ 报出的是后处理不确定度的**下界**，不是上界。
2. 只有 8 个 artefact 有时均场（加密后的 laminar 阶梯 rung 在启动段发散、
   `samples=0`，其 npz 全零，按「平均零不是测量」排除，见 `excluded`）。
3. 本轮不改求解器默认路径：`wall_shear` 保持一阶（零点算子已认证、
   改动会打断 round 17–23 的可比性），高阶只在 `verification` 侧提供。
4. 收敛比 1.76–6.91 说明三条阶梯在收敛，但**不能**据此外推真值：
   三个格式的误差系数不同族，Richardson 不适用。

## ⑧ 误差判定（逐项，显式回答「是否 <3 %」）

| 量 | 值 | 判定 |
|---|---|---|
| 1 阶壁面导数的解析相对误差（ny=48，平壁 Poiseuille） | 1.042 % | <3 % 是 |
| 2/3 阶解析相对误差 | 机器精度 | <3 % 是 |
| 锚点 `x_r/H` 的后处理带 | 2.37 % | <3 % **是**（全库最大 3.64 %，出现在 `round11_sst_96x48`） |
| 锚点 `x_r/H` vs 基准 5.41 | -77.37 % | <3 % **否**（honest FAIL 未改变） |

**结论**：后处理（壁面法向导数阶数）对已发布 `x_r/H` 的贡献 ≤ 3.64 %（锚点自身 2.37 %），锚点的 honest FAIL 不能归因于它；但壁面切应力的**量级**结论必须升到 ≥2 阶。

## ⑨ 给下次的线索

1. 上表的时间相干性仍是空白：只有**时均**场能审计阶数，无法审计
   「逐样本零点」的阶数敏感性（需写出端按块存剪切剖面）。
2. eta 线斜交误差可用 `mesh.beta_n` 做一次显式一阶修正，
   把「下界」变成真值估计 —— 这是本模块最直接的下一步。
3. `wall_shear(order=2)` 建议在 SST 的 u_tau / 壁面律诊断（round 15）
   里替换现用两点差分，那里量级敏感。
