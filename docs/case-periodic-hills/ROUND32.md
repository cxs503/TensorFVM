# ROUND 32 — 周期山丘 CASE-FVM-PERIODIC-HILLS：31 轮综合裁决与模型形式误差分解

**锚点** `CASE-FVM-PERIODIC-HILLS`（feature_ledger, open）· 本单 m23225 · TensorFVM
**一句话**：31 轮迭代后给出**综合裁决**——2-D 层流/2-D SST 均无法在 10 % 容差内复现 Breuer 2009 DNS 的再附长度与速度剖面；误差来源经网格阶梯、时间步控制、Richardson 外推与 Re=700 层流姊妹算例**四路交叉验证**，确认为**模型形式误差**（2-D 平均场无法再现 3-D 湍流再附物理），非离散误差。锚点维持 OPEN，达标路径为 3-D LES/DES 战役。

## ⑤ 注意点 / 局限

1. **honest FAIL**：31 轮中**没有任何物理量达到 <3 % 或 <10 % 容差**。这是诚实的 FAIL，不是数值噪声。
2. **模型形式误差确认**：四路交叉验证（时间/空间/Re 数/模型）一致指向模型形式误差。
3. **2-D vs 3-D**：Breuer DNS 是三维湍流，2-D 层流/2-D RANS 无法再现湍流再附物理——这是物理局限，不是求解器缺陷。
4. **Re=700 网格阶梯**：cj4630/cj4631 仍在队列，落盘后可补全 Re=700 的网格收敛趋势，但不改变定性结论。
5. **求解器质量**：几何验证 0.17 %、通量不变性 0.017 %、壁剪算子一致性通过、平面 Poiseuille 验证通过——求解器本身是可靠的。

## ⑦ 裁决与建议

### 裁决
- **锚点状态**：OPEN（未达标）
- **误差性质**：模型形式误差（2-D vs 3-D 湍流），非离散误差
- **求解器状态**：验证通过（几何、通量、壁剪、平面通道）
- **honest FAIL**：是

### 建议路径
1. **3-D LES/DES 战役**（推荐）：复用 `channel_les3d` 基础，扩展为 3-D 周期山丘 LES
   - 展向宽度 ~4.5H（Breuer DNS 展向周期 4.5H）
   - 网格 ~192×96×64（展向 64 点）
   - 预期：x_r/H 误差 <10 %（文献报告 LES 可达 5–10 %）
2. **改进 SST 闭合**（次优）：尝试 SST-SAS 或 DDES，可能改善再附预测
3. **网格继续加密**（不推荐）：Richardson 外推已证明网格收敛到 6.99（+29 %），继续加密无济于事

### 派单建议
若平台决定推进 3-D LES 战役，建议拆分如下 mission：
- `CASE-FVM-PERIODIC-HILLS-3D-LES`：3-D 周期山丘 LES，验收 x_r/H <10 % + y/H=0.5 剖面 6/8 站 <10 %
- `FEAT-FVM-LES-3D`：3-D LES 求解器扩展（若 `channel_les3d` 不足以直接复用）
