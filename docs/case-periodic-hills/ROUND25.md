# CASE-FVM-PERIODIC-HILLS 第二十五回合（selfstart）：斜交误差

**锚点** `CASE-FVM-PERIODIC-HILLS`（feature_ledger，open）· TensorFVM
**一句话**：round 24 只能把后处理不确定度报成「下界」，因为所有阶数都沿 *eta 线*读壁面法向导数，而山丘壁上 eta 线并不垂直于壁面。本轮把这条被点名的斜交误差轴**量化**出来（并给出两个不看 eta 线的独立算子）：斜交/修正轴对已发布 `x_r/H` 的影响最大 1.23 %（全库），五算子总带最大 4.09 %；而对壁面切应**量级**的偏置峰值达 4.60 %，与截断阶数偏置互为同级项，必须分别消掉。

## ① 案例介绍

| 项 | 值 |
|---|---|
| 算例 | 周期山丘 ERCOFTAC UFR 3-30 = Breuer et al. 2009, *Computers & Fluids* 38:433 |
| 几何 | `H=1`，`Lx/H=9`，槽顶 `y/H=3.036`，x 向周期，地形贴合网格 |
| 工况 | 体速度 `U_b=1`（积分控制器）；被审计的是已存盘时均场（不重跑） |
| 基准 | 冠后气泡再附点 `x_r/H = 5.41`（Breuer 2009 / ERCOFTAC KB） |
| 容差 | 锚点 10 %；平台论文级 3 % |
| 被测 artefact | 全库 **8** 个有时均场的 artefact |

## ② 怎么做的

1. **先证分解，再谈误差**。壁面中心 `W` 到壁邻单元中心 `C` 的向量在贴体网格上精确分解为 `d0 = alpha n + beta t`（`alpha = d0·n`、`beta = d0·t`，`n ⊥ t`）。因此求解器的两点格式恒等于

   ```
   (u_t(C) - u_t(W)) / alpha  =  (grad u_t . n)  +  (beta/alpha)(grad u_t . t)
   ```

   斜交项 `(beta/alpha)(grad u_t . t)` 就是 round 24 只敢说「未消掉」的那一项。
2. **三个/五个算子**（同一几何、同一壁邻数据，只改法向导数）：
   * `o1`：两点 eta 线一阶（求解器 `wall_shear` 的算子，= 已发布值）；
   * `o2`/`o3`：round 24 的二次/三次单侧格式（仍是沿 eta 线）；
   * `deferred`：`o1 - (beta/alpha) d u_t/d s`，用壁平行方向的投影速度方向导数扣掉斜交项；
   * `lsq`：壁点（无滑移，`u_t = 0`）+ 三个壁邻单元中心做二维最小二乘梯度，**完全不看 eta 线**，因此没有斜交偏置。
3. **机精度标定（不是「差不多」）**：在真实山丘网格上取一个在 `(x,y)` 中仿射的速度场，解析梯度闭式已知 —— 斜交恒等式、`lsq` 的精确性、`deferred` 的修正量都被钉到舍入误差；平壁 Poiseuille 则给出「无斜交时三者必须重合」的对照。
4. **零手抄**：本文件所有数字由 `scripts/round25_wall_obliquity.py` 从 `docs/case-periodic-hills/*.npz` 直接生成，同时落 `round25_wall_obliquity.json`。

## ⑤ 注意点 / 局限

1. `deferred` 的斜交项用的是**壁邻行**的 `d u_t/d s`，而两点格式实际在壁与壁邻中心之间的中点上取样，所以它略为**过修正**；仿射标定下它把偏置从 64.3 % 降到 1.04 %（残余来自弦向与壁切向不严格平行）。`lsq` 才是真无斜交的那一个。
2. `lsq` 无斜交偏置，但**保留了** `O(alpha)` 的壁法向剖面截断误差（平壁 Poiseuille 三方误差同为 1.04 % @ ny=48，随 ny 翻倍减半）——它不是更高阶，只是更少假设。
3. 仿射标定只取内部列：制造场在 x 向非周期，跨缝列不能作最小镜像差商。跨缝列的正确性由几何测试（`d0 = alpha n + beta t` 含缝）保证。
4. 本轮**不改求解器**：`PeriodicHillSolver.wall_shear` 仍是一阶两点格式（round 17–24 的可比性依赖它），新算子只存在于 `verification` 侧。
5. 只有有时均场的 artefact 可审计（`samples=0` 的加密 rung 时均场为零，「平均零不是测量」，按 `excluded` 排除）。

## ⑥ 误差判定（逐项，显式回答「是否 < 3 %」）

| 量 | 值 | 判定 |
|---|---|---|
| 斜交恒等式残差（仿射场，机精度） | 3.14e-14 | <3 % 是 |
| `lsq` 对仿射场的残差 | 4.63e-14 | <3 % 是 |
| 斜交/修正轴对 `x_r/H` 的最大影响（全库） | 1.23 % | <3 % **是** |
| 五算子总带（全库最大，`round11_sst_96x48`） | 4.09 % | <3 % **否**（3.6 % 阶数轴主导） |
| 锚点 `x_r/H` 的五算子总带 | 2.37 % | <3 % **是** |
| 锚点 `x_r/H` vs 基准 5.41（`lsq` 口径） | -76.93 % | <3 % **否**（honest FAIL 未改变） |
| 斜交对壁面切应**量级**的最大影响 | 4.60 % | <3 % **否**（必须修正） |

**结论**：斜交不是 `x_r/H` 的解释项（最大 1.23 %，两个数量级小于 −77 % 的 honest FAIL），但它是壁面切应**量级**的第二大误差源（约为截断阶数的 1/7，绝非可忽略），**同一归一分母下**才可比：以 `max|tau|` 归一化，斜交偏置峰值 4.60 %、阶数偏置峰值 33.54 %；以 `rms(tau)` 归一化，斜交 15.56 %、阶数 128.33 %。斜交偏置铺满整个回流区而阶数偏置集中在切应峰值处（均值项只有 5.91 %），因此两者不可用一个因子互相换算，量级结论必须分别消掉。round 24 的「下界」由此升级为**两条独立的实测轴**：阶数带 0.5–3.6 %、斜交/修正带 0.02–1.23 %。

## ⑦ 给下次的线索

1. 逐样本（而非时均）零点敏感性仍是空白：需要写出端按块存 `tau_b` 剖面（round 24 线索 1 原样保留，本轮未覆盖）。
2. `lsq` 算子只在 96x48 一族上有 8 个 artefact；若加密 rung 能跑出时均场，可检验 `lsq` 的 `O(alpha)` 收敛是否正确（当前只有平壁解析证据）。
