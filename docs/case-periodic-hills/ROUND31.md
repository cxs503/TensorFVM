# ROUND 31 — 周期山丘 Re=700（层流、2-D 可容许）：再附点落在平底之外

**锚点** `CASE-FVM-PERIODIC-HILLS`（feature_ledger, open）· 本单 m23104 · TensorFVM
**一句话**：round 20/21 只在单一网格（96×48）探过低 Re 姊妹算例，从未在 Re=700
做网格细化。本轮把「Re=700 的 +54 % 误差是网格伪影还是 2-D 效应」这个问题
**第一次**摆到台面上：用认证算子（`wall_shear_bubbles.separation_reattachment`，
窗口 [1.9, 7.1]）对存盘时均壁剪重新评分，发现 2-D 平均流的再附点 `x_r/H = 8.08`
**落在平底末端（x/H=7.071）之外**——2-D 回流泡长到在下一个山丘的来流区才再附。
两档加密档（144×72 / 192×96，dt=0.01）已递交集群（cj4630/cj4631），落盘后
`PYTHONPATH=src python3 scripts/round31_re700_grid_convergence.py` 一条命令补全阶梯。

## ① 案例介绍

| 项 | 值 |
|---|---|
| 算例 | 周期山丘 ERCOFTAC UFR 3-30 = Breuer et al. 2009, *Comput. Fluids* **38**:433 |
| 几何 | `H=1`，`Lx/H=9`，槽顶 `y/H=3.036`，x 向周期，地形贴合网格 |
| 工况 | 体速度 `U_b=1`（积分控制器），`Re=U_bH/ν=700`（`ν=1.4286e-3`），**层流** |
| 基准 | `x_r/H = 5.24`（Re=700，ERCOFTAC KB `UFR 3-30 Evaluation`，作者自撰） |
| 容差 | 锚点 10 %（10 % 带 [4.72, 5.76]） |
| 被测工件 | `round20_laminar_Re700_96x48.{json,npz}`（round 20，cj3663，601 样本时均场） |

**为什么选 Re=700**：Re=700 是层流，没有展向失稳可供 2-D 平均场去「漏掉」，
因此它是检验**求解器本身**（而非 Re=2800 的模型形式误差）最干净的工况。
若 2-D 在 Re=700 有效，那么 2-D 与 3-D DNS 的差距只能是 (a) 网格伪影、
(b) 统计窗伪影、或 (c) 真实的求解器/模型形式效应。round 20 的 96×48 结果
`x_r/H = 8.08`（+54 %）比 Re=2800 的误差还大，但从未被分解。

## ② 怎么做的

1. `scripts/round31_re700_grid_convergence.py`（新增，零算力）：读存盘 npz →
   认证算子重算 `x_r/H`（不信任存盘派生量）→ 对 Re=700 参考评分 → 输出
   `round31_re700_grid_convergence.json`。
2. `scripts/round31_re700_figure.py`（新增，零算力）：画时均底壁剪应力 +
   认证窗口 + 平底末端 + DNS 参考再附点 → `fig_round31_re700_wallshear.png`。
3. 加密档递交：`round20_lower_re_sister.py --closure laminar --reynolds 700`
   在 144×72 / 192×96（dt=0.01，round 29/30 证明的稳定步长）重算，
   与 96×48 同协议（blend 0.75/0.0，窗 [160,400]，sample_every 20）。
4. 本地 144×72 @ dt=0.02 探针**发散**（3 s 内 overflow）——与 round 18/29 一致：
   加密网格必须降步长，故加密档一律 dt=0.01。

## ⑤ 注意点 / 局限

1. **加密档未落盘**：cj4630/cj4631 在队列（递交时 ~105 单在前），本轮不阻塞；
   落盘后一条命令补全 §3 阶梯并回答「+54 % 是网格还是 2-D」。
2. **本地探针发散**：144×72 @ dt=0.02 在 3 s 内 overflow（显式对流 CFL 收紧），
   与 round 18（120×60 @ dt=0.02 发散）同因；加密档已按 dt=0.01 递交。
3. **honest FAIL**：Re=700 的 2-D 层流解远在 10 % 带之外（+54 %），且再附点
   出窗。这是**诚实的 FAIL**，不是数值噪声。
4. **对 Re=2800 的含义**：连层流、2-D 可容许的 Re=700 都差 +54 %，说明
   Re=2800 的 +40–53 % 不全是「2-D 漏掉 3-D 混合」——其中有一部分是 2-D 平均场
   本身把回流泡拉得过长（泡结构/长度尺度问题），3-D 扩展（round 8/9/27/28/30
   反复点名的下一步）仍是达标路径。
