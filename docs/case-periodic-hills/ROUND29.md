`H = 1`，`Lx/H = 9`，顶壁 `y/H = 3.036`，x 向周期，上下壁无滑移，体动（积分控制器）把
体积平均速度钉在 `U_b = 1` ⇒ `Re = U_b H / ν = 2800`（`ν = 3.571e-4`）。
基准 `x_r/H = 5.41`（ERCOFTAC KB UFR 3-30 Evaluation，作者自撰），±10 % 带 =
[4.87, 5.95]；参考值由 `tensorfvm.verification.periodic_hill_reference` 单源。

## ② 怎么做的

1. **重跑两档**（`scripts/round17_measure.py`，与 round 17/18/19 同一驱动，闭包/混合/
   采样协议逐字节一致）：
   - `--nx 96 --ny 48 --dt 0.01 --steps 40000 --burn-in 16000 --tag r24_96x48_dt0.01`
   - `--nx 120 --ny 60 --dt 0.01 --steps 37000 --burn-in 16000 --tag r24_120x60_dt0.01`
2. **离线重打分**（`scripts/round24_ladder_completion.py`，零算力）：复用 round-19 的
   `classify_level`（发散 > 无交点 > 可测 的优先级）与 round-18 的 `fit_grid_law` /
   `score_from_npz`，对**存盘时均场**重算 `x_r/H`（不信任存盘派生量），并做
   (h, dt) 稳定域图与 96×48 步长控制对比。
3. **判定**：认证算子给 `x_r/H`，与 5.41 比较，逐项回答「是否 <3 %」；网格律
   `x_r(h) = x0 + C h^p` 只在 ≥3 档可测且序列单调时拟合。

## ⑤ 注意点 / 局限

1. **120×60 档时均窗缩短**：[160, 370] 而非协议 [160, 400]，已在 artefact 标记。
2. **2-D URANS 维度限制**：即便步长与网格都收敛，2-D SST 的再附长度仍系统性偏长
   （~7.6 vs DNS 5.41）——这是模型/维度问题，不是离散误差。
3. **144×72 仍未测**：`dt = 0.01` 下 40000 步 > 3 h，超单作业上限；本轮不追。
4. 基准 5.41 来自 ERCOFTAC KB 作者自撰页（主论文付费墙），旧值 5.34 差 1.3 %，不改裁决。
