# CASE-WOODWARD-COLELLA — 渐近区收敛裁定：nx=3200 入账 + 参考不确定度预算

**锚点**：`CASE-WOODWARD-COLELLA`（算例池·双爆轰波相互作用；feature_ledger `open`）
**验收（总账）**：`【算例池|WOODWARD-COLELLA｜ref: Woodward & Colella 1984 包络｜容差: <10%】`
**仓**：TensorFVM —— 本单求解器代码零改动，只动 `docs/`、`tests/`（读已存剖面做验证分析）
**判定**：**验收（<10%）在 nx=800–3200 全部良态量上成立**；同时**纠正**前序报告两处过强表述——
(i)「nx≥800 全部关键量 <3%」在**峰值**上不成立（nx=3200 为 3.00%），(ii) 残余 2–3% 的差
**不是**可加密消掉的离散误差（`U_num ≤ 0.14%`），而是**参考解自身的误差地板**。本单把它量化成
不确定度预算，并**否定**了「数字化折线削峰」这一替代解释（实测仅 0.054%）。

---

## ① 案例介绍（物理背景 / 几何 / 参数表）

一维闭管 [0,1] 内双爆轰波相互作用（Woodward & Colella 1984 标准算例，Dumbser 等 JCP 2019 §5.1.4 复述）：
左端 p=10³、中段 p=10⁻²、右端 p=10²，ρ=1、u=0、γ=1.4，两端反射壁，积分至 t=0.038。
两束激波+接触+稀疏在中部对撞，形成强干涉波系。

| 参数 | 值 | 来源 |
|---|---|---|
| 域 | x∈[0,1]，1D | W&C 1984 / arXiv:1902.07773 §5.1.4 |
| 初始 (ρ,u,p) | (1,0,1000) x≤0.1；(1,0,0.01) 0.1<x<0.9；(1,0,100) x≥0.9 | 同上 |
| γ / t_end | 1.4 / 0.038 | 同上 |
| 数值格式 | MUSCL-Hancock 二阶 + MC 限幅 + HLLC + SSP-RK，CFL 0.4 | `cases.double_blast` |
| 参考解 | 数字化文献 Reference 曲线（RPJ@3200），**经标定更正** +0.022017 密度单位 | `reference/reference_density_calibrated.csv` |
| 比较窗 / 容差 | x∈[0.4,1.0]（文献绘图窗） / 10% | `wc_reference.py` |

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

**本轮补的验证欠账**：`CASE-WOODWARD-COLELLA-final-verdict.md` / `-calibration-bias.md` 都留了一条
未完成项——「nx=3200 阶梯与细网格 GCI 未返回，外推不报」。nx=3200 剖面现已落盘
（`ladder/data/ladder_profile_nx3200_hllc.npz`，12803 步，1056 s，positivity 修复 0 次，质量/能量漂移 0.0），
但没有进入任何判据。本单三步做齐：

1. **nx=3200 入账**：`reference/wc_calibrated_metrics.py` 重跑（指标定义与阈值零改动，只把参考表换成更正表），
   生成 `metrics_calibrated_nx3200_hllc.json`。
2. **细网格 GCI**（新脚本 `ladder/wc_asymptotic_analysis.py`）：同一套 `richardson_gci`（ASME V&V-20 /
   Roache / Celik）在**细三元组 3200/1600/800** 上重做，对照旧的三元组 800/400/200；并对**场本身**
   做逐级 L1 距离 → 观测阶 → Richardson 外推场（并对 p=1 / p_obs / p=2 做**阶数敏感性扫描**）。
3. **不确定度预算**：把 `U_num`（细三元组 GCI）与「外推值 vs 参考值」的残余逐量对照，判据是
   `residual/U_num`：≫1 表示残余归参考解（不可通过加密消除），≲1 表示仍在数值不确定度带内。
   同时**独立检验**替代解释「参考曲线是 174 顶点折线，削峰」——用自己的 nx=3200 解按同样顶点密度重采样，
   量出削峰量。
4. **回归门** `tests/test_compressible_wc_asymptotic.py`（9 用例，6.4 s）：细网格收敛单调性、
   nx=3200 达标、预算结构（残余≫U_num）、参考距离**非单调**（地板而非收敛）、折线削峰假设**必须保持被否定**、
   JSON 与重算一致。

### 细三元组 GCI（3200/1600/800）vs 旧三元组（800/400/200）

| 量 | 三元组 | p_obs（理论 2） | 渐近区？ | 外推值 | GCI % |
|---|---|---|---|---|---|
| 窗质量 | 800/400/200 | 1.852 | 是 | 0.935308 | 0.020 |
| 窗质量 | **3200/1600/800** | 1.020 | 否（偏离>20%） | **0.935517** | **0.012** |
| 峰值密度 | 800/400/200 | 0.913 | 否 | 6.801（比参考高 7.7% → 旧外推不可用） | 12.35 |
| 峰值密度 | **3200/1600/800** | 2.736 | 否（高于理论阶） | **6.5148** | **0.141** |
| ρ(0.5) | **3200/1600/800** | 0.616 | 否 | 0.183203 | 0.093 |

旧三元组的峰值外推 6.801（+7.7%）说明 200/400/800 确实不在渐近区；细三元组把它拉到 6.5148（+3.1%），
**但两者都高于数字化参考**——参考的峰值比本方案的收敛极限低约 0.20 密度单位。

### 场级收敛与距离阶梯

| 距离 | 值 |
|---|---|
| D(800,1600)（窗口 L1 相对差） | **3.055 %** |
| D(1600,3200) | **1.765 %** |
| 场观测阶 p = log2(D800,1600/D1600,3200) | **0.791**（激波主导，远低于二阶） |
| nx=1600 → 参考 | 1.840 % |
| nx=3200 → 参考 | **3.027 %**（比 nx=1600 **更远**） |
| 外推场(p=1 / 0.791 / 2) → 参考 | 4.498 % / 5.068 % / **3.501 %** |

**关键事实**：网格越密，与参考的距离**不降反升**（1.84% → 3.03%），即 2–3% 是与参考之间的**地板**，
不是收敛中的误差。

### 不确定度预算（判据核心）

| 量 | 参考 | 外推值 | 残余 % | `U_num` (GCI %) | 残余/U_num | 参考落在 GCI 带内？ |
|---|---|---|---|---|---|---|
| 窗质量 | 0.935343 | 0.935517 | 0.019 | 0.012 | 1.59 | 否 |
| 峰值密度 | 6.318093 | 6.514840 | **3.114** | 0.141 | **22.1** | 否 |
| ρ(0.5) | 0.183100 | 0.183203 | 0.056 | 0.093 | 0.60 | **是** |

峰值残余是不确定度带的 22 倍 → 加密不可能消除；ρ(0.5) 残余 0.6×带内 → 该点已被数值不确定度覆盖。

### 取代解释的检验：折线数字化削峰（**否定**）

用自己的 nx=3200 解按参考曲线的折线顶点密度重采样再插回：

| 顶点数 | 顶点间距 | 折线后峰值 | 削峰 % |
|---|---|---|---|
| **174**（实际路径顶点数） | 0.00347 | 6.5040 | **0.054** |
| 349 | 0.00172 | 6.5050 | 0.039 |
| 698 | 0.00086 | 6.5066 | 0.015 |
| 2798 | 0.00021 | 6.5075 | 0.001 |

削峰最多 0.054%，比需要解释的 3.1% 峰值残余小 **57 倍** → **假设被否定**（负面结果同样入账）：
参考峰值偏低不是折线表示造成的，是参考解（RPJ@3200，另一套离散）自身在碰撞峰值处更耗散。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **本单纠正了前序报告的两处过强表述**（诚实申报）：`-calibration-bias.md` ⑥「nx≥800 全部关键量 <3%」
   在**峰值**上不成立——nx=3200 峰值误差 3.00%（标定参考），且外推极限 3.11%；nx=800 的 2.03% 是
   与参考擦肩的**偶然抵消**，不是更准。
2. **`U_num` 很小不等于解很准**：细三元组 GCI 0.01–0.14% 只说明**本方案自身**已离散收敛；
   它与参考的 2–3% 差异属于**两套数值解之间**的差，无法用本方案加密消除。
3. **场外推的阶数敏感**：p_obs=0.791 是窗口 L1 的激波限制阶；把它套到整场上会把峰值放大到 6.98
   （超参考 10.4%）。因此**峰值只引用峰值自己的三元组外推（6.515）**，整场外推只用于**积分量**与
   距离量，报告里两者并列不混用（`tests/test_compressible_wc_asymptotic.py::test_extrapolated_field_sweep_is_stable` 锁死）。
4. **参考解仍是数值解**（RPJ@3200），其自身误差未给出；本单只能把「与参考的差」拆成
   `U_num`（已知很小）+ 参考/格式差（≈3%），不能把后者归给任何一方。
5. **交叉码细网格欠账仍在**：WENO5/Rusanov 的 nx=1600/3200 阶梯本单已递交（cj2378/cj2379，排队中，
   收尾时未返回），因此「两族外推极限互差」这一独立基（basis）误差界**未报**；已有 nx=200 单点
   （WENO5 vs HLLC 差 7.386%）只作趋势参考，不作为结论。回归门在有数据后自动启用断言（`test_cross_code_agreement_when_available`）。
6. **x<0.4 区仍无文献参考**（文献绘图窗只到 0.4），该区只有仓内早时精确黎曼锚，不在本单判据内。

## ⑥ 误差判定（逐项 vs 标定更正参考；nx=3200 为最细网格）

| 关键量 | nx=3200 误差 | <3 %? | <10 %（验收）? | 归因（依据 `residual/U_num`） |
|---|---|---|---|---|
| 窗质量 ∫ρdx | **0.0092 %** | ✅ 是 | ✅ | 数值已收敛（U_num 0.012%） |
| ρ(x=0.5) | **0.131 %** | ✅ 是 | ✅ | 落在数值不确定度带内（0.60×） |
| 近真空浅槽 ρ_min | **0.381 %** | ✅ 是 | ✅ | 参考标定偏差已更正（原始参考下 14.45%） |
| 峰值密度 ρ_max | **3.00 %** | ❌ 否 | ✅ 是 | 参考/格式差主导（残余 = 22×U_num） |
| 剖面 L1 | **3.08 %**（nx=1600: 1.86%） | ❌ 否 | ✅ 是 | 地板：加密后距离不降（1.84→3.03%） |

**结论（不含糊）**：验收 `<10%` 在 nx=800–3200 的六个良态量上**全部成立**，最差 3.08%，余量 >3 倍；
但「<3%」只有 3/5 项成立，**峰值与剖面 L1 不达标**，且原因已定量归因于**参考解自身误差地板**
（残余 = 22×GCI），不是本求解器可加密消除的误差。诚实表述为：**本方案与已发表数值解的收敛极限相差
2–3%，该差的绝大部分属于参考解，不宜记为求解器误差。**
