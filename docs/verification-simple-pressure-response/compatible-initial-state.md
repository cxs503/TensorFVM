# Compatible collocated initialization on the SUBOFF diagnostic mesh

The original scalar-potential projection corrected only the shared face flux. The first SIMPLE sweep consequently inherited a large difference between that flux and the flux reconstructed from the initial cells. Uniform damping carries this difference into the next state with the factor `1 - pressure_relaxation` when the coefficients are frozen.

`--project-initial-state` instead holds the initial pressure fixed and computes a minimum-norm velocity increment with the solver's own discrete continuity matrix. The accepted face flux is reconstructed from the corrected velocity with the same frozen Rhie–Chow operator. The projection checks every cell's volume-normalized divergence and preserves the prescribed boundary flux. Subsequent momentum and SST updates rebuild their coefficients as usual. The legacy `--project-initial-flux` remains available for reproducing archived results.

## Same-mesh checks

The regenerated Gmsh 4.15.2 mesh has 9,068 cells and SHA-256 `afebe7d4b6f96eae92810debfa485f591d58323c477b28cda83a60df59ac70e1`, matching the [archived mesh](../verification-suboff-single-domain-mesh/coarse-tail-transition/report.md). All comparisons use the same SST-2003 and Spalding wall model, CPU, (Re_L=1.2\times10^7), first-order convection, velocity relaxation 0.05 and speed guard (5,U). The two initialization methods were first checked over six momentum sweeps with the SST coefficients frozen, then with SST updated every outer iteration.

| Diagnostic | Face-only initialization | Compatible initialization |
|---|---:|---:|
| Frozen SST, first sweep reconstructed divergence at pressure relaxation 0.03 | 1,465.12 | 0.00042590 |
| Frozen SST, sixth sweep reconstructed divergence at pressure relaxation 0.03 | 1,258.21 | 0.00811488 |
| Coupled SST, first sweep reconstructed divergence at pressure relaxation 0.03 | 1,465.12 | 0.00022782 |
| Coupled SST, after sixth SST update, reconstructed divergence at pressure relaxation 0.03 | 1,260.66 | 0.00953733 |
| Coupled SST, full pressure correction | Speed guard at step 2, peak 15.91 U | Six momentum and six SST updates, peak 1.12 U at the final step |

The compatible initializer took 155 LSMR iterations to reduce maximum reconstructed divergence from 1,510.43 to `1.34e-9`. Its largest fixed-boundary flux change was zero. On the full-pressure run the frozen-coefficient face ledger at step six agreed within `2.26e-15 U`, while rebuilding the momentum mobility changed the reconstructed face-normal velocity by up to `0.00165 U`. The maximum reconstructed divergence following the sixth SST update was 0.939, compared with a stored-flux divergence of `2.16e-12`. Restarting from that saved state for 14 more updates gave a maximum speed of 1.269 U and a reconstructed divergence of 11.432 after the final SST update. The discrepancy after reassembly therefore remains an open numerical issue. All runs retained a false numerical-convergence flag and the physical acceptance status remains open.

## Viscous energy gate

The audit can now constrain its witness to the null space of the actual collocated continuity operator, with zero velocity on all domain boundaries. On the same mesh and under constant viscosity, the constrained direction has reconstructed divergence `4.50e-13` and a normalized energy growth rate of **+0.04594222**, independently reproduced by integrating the shared face tractions. This is a counterexample to discrete viscous dissipation within the tested zero-divergence subspace. It isolates viscosity with no pressure, advection or forcing. The link to high-Re nonlinear stability requires a separate coupled analysis.

## Reproduce

Use the mesh generated by the [archived recipe](../verification-suboff-single-domain-mesh/coarse-tail-transition/report.md) and assign its path to `BENCH_MESH`. Each output directory starts empty. On this mesh the six-step run returns 2 because the numerical tolerance is not met. The strict audit returns 2 because it finds energy growth and writes the witness and its JSON diagnostics.

```bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src
python scripts/run_native_suboff_rans.py --mesh "$BENCH_MESH" \
  --reynolds 12000000 --algorithm simple --wall-treatment spalding \
  --inner-iterations 1 --outer-iterations 6 --pseudo-dt .0001 \
  --convection-order 1 --relaxation .05 --pressure-relaxation .03 \
  --project-initial-state --maximum-speed 5 --output results/suboff-compatible-init
python scripts/audit_native_solver_consistency.py --mesh "$BENCH_MESH" \
  --constrain-cell-divergence --fail-on-energy-growth --output results/suboff-kinetic-energy
python -m pytest -q tests/test_native_collocated3d.py tests/test_native_simple3d.py \
  tests/test_native_rans3d.py tests/test_suboff_validation.py \
  tests/test_suboff_validation_integration.py tests/test_thin_layer_viscous_passivity.py
```
