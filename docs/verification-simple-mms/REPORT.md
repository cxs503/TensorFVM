## ① 案例介绍（物理背景 / 几何 / 参数表）

本单将三网格 log-log 斜率阶验证方法从已有的**可压 Euler 求解器**（`cellcentre_loglog`）和**线性 Helmholtz 求解器**（`loglog_order`）扩展到**不可压交错网格 SIMPLE 求解器**（`staggered_simple`）。这是船舶水动力（阻力、推进、操纵）的主要求解器类型，此前缺乏同等严谨的制造解阶验证。

**制造解**：二维周期域 `[0,1]×[0,1]` 上的无散速度场：

```
u(x,y) = sin(2πx) cos(2πy)
v(x,y) = -cos(2πx) sin(2πy)
p(x,y) = sin(2πx) sin(2πy)
```

该场严格满足 ∂u/∂x + ∂v/∂y = 0（解析验证残差 <1e-14），且光滑有界。Navier-Stokes 源项由解析公式给出：

```
f_u = u·∇u - ν∇²u + ∂p/∂x
f_v = u·∇v - ν∇²v + ∂p/∂y
```

其中 ν = 1/(2π·Re)，Re = 100。

**交错网格参考值**：SIMPLE 求解器在 MAC 网格上存储：
- u 在 x-面 `(i+½,j)` → 参考值 `u(x_{i+½}, y_j)`
- v 在 y-面 `(i,j+½)` → 参考值 `v(x_i, y_{j+½})`
- p 在单元中心 `(i+½,j+½)` → 参考值 `p(x_{i+½}, y_{j+½})`

| 参数 | 取值 |
|---|---|
| 方程 | 不可压 Navier-Stokes（带制造源源项） |
| 制造解 | 上述 u,v,p（无散、光滑） |
| 网格 | 均匀交错网格 8×8, 16×16, 32×32, 64×64 |
| Reynolds | 100（粘性项 O(1)，对流项 O(1)） |
| 参考值 | 解析面中心/单元中心值（非求积） |
| 范数 | 体积加权 L1/L2（u 和 v 合并） |
| 声明阶 | 2（SIMPLE 二阶格式） |

## ② 怎么做的（方法 / 流程 / 关键设置）

1. **制造解验证**：解析验证无散性（∂u/∂x + ∂v/∂y = 0 残差 <1e-14）；源项与解析 Navier-Stokes 残差互校（<1e-14）。
2. **交错参考值**：`staggered_references(nx,ny)` 返回 u/v/p 在正确网格位置上的解析值；边界值验证（x=0,1 处 u=0；y=0,1 处 v=0）。
3. **误差范数**：`velocity_error_norm` 和 `pressure_error_norm` 使用体积加权（x-面权重 hy，y-面权重 hx，单元中心权重 hx·hy）。
4. **三网格 log-log 斜率**：复用 `cellcentre_loglog.loglog_slope` 和 `three_grid_readout`，确保跨求解器的一致性。
5. **负对照**：合成二阶/一阶误差序列必须被正确读回（测试锁定）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **交错网格参考值必须在正确位置计算**：u 在 x-面、v 在 y-面、p 在单元中心。用错位置会注入 O(h) 的参考误差。
2. **体积加权对交错网格的意义**：x-面和 y-面的"体积"不同（分别是 hy 和 hx），必须分别加权。
3. **制造解的源项必须解析计算**：不能用数值差分近似源项，否则源项误差会污染解误差。
4. **局限**：本模块验证的是制造解框架和误差度量，不包含完整 SIMPLE 求解器运行（求解器运行需单独的性能测试）。完整求解器阶验证需运行 `staggered_simple` 并收敛到残差 <1e-8。
5. **适用范围**：光滑解、均匀网格、层流 Re=100。激波/湍流/非结构网格需各自专门的验证。
