## 1. 案例介绍

`maneuvering/dynamics.py` 的横摇/纵摇/艏摇惯量需要**转动附加惯量** `M_44..M_66`，此前只有细长体占位公式，
没有任何第一性原理数值可对标（账本 D1）。本报告给出：闭式解析锚 + 独立半解析参考 + 面元 BEM 三路交叉验证。

物理设定（教科书问题）：不可压、无粘、无旋流场中一封闭物体做定常转动（任意坐标系下等效于势流绕流问题），
流体动能 `T = 1/2 I_ij Ω_i Ω_j`：

```
I_ij = -rho ∮_S phi_i (V_j · n) dS ,      V_j(x) = e_j × (x - x0) ,        (1)
∇²phi_i = 0 ,   ∂phi_i/∂n = +(V_i · n) on S ,   phi_i → 0 at infinity     (2)
```

`n` 指向流体（物体外法向）；`V_j` 是广义速度 `q_j=1` 时的刚体表面速度场。与平移附加质量
（`panel_added_mass.added_mass_matrix`，`V_i = e_i`）同一套离散与积分，只是速度场换了。

几何/参数表（rho = 1 无量纲）：

| 量 | 值 |
|---|---|
| 球（严格零锚） | a = 1，网格 16×12 / 24×18 / 32×24 / 40×30 |
| 长球（主验证） | a = 2, b = c = 1；体积 V = 4/3·π·a·b² = 8.37758 |
| 面元网格 | 24×18(432)、40×28(1120)、60×42(2520)、80×56(4480) 四边形面元 |
| 求积 | 每面元 3×3 双线性 Gauss；面元奇异性（主值 +1/2 跳跃）按 `panel_potential` 惯例 |
| 纵横比扫描 | a/b = 1.05 / 1.5 / 2 / 3 / 6 |

## 2. 怎么做的

1. **BEM 路线**：把 `solve_sources` 的右端从常数 `U` 换成空间变化的 `V_i = e_i × (x-x0)`
   （该函数本来就接受 `(n_panels,3)` 数组），解出源强 → `source_potential` 取表面势 → 按 (1) 积分。
   实现：`panel_added_inertia.rotational_added_inertia`。
2. **独立半解析参考**（不依赖任何查表公式）：长球坐标 `x=fμζ, ϱ=f√((1-μ²)(ζ²-1))`，f=√(a²-b²)，ζ0=a/f。
   横向转动（绕 z）的不可穿透右端角向结构是 `μ√(1-μ²)cos φ ∝ P₂¹(μ)cos φ`，故精确势是
   `m=1、偶阶 n` 的外部球谐级数 `Σ A_n P_n¹(μ) Q_n¹(ζ) cos φ`，系数由 `ζ=ζ0` 上的法向条件配点求得；
   `Q_n` 用超几何表示独立计算（`Q_n¹ = n(ζQ_n - Q_{n-1})/√(ζ²-1)`）。
   **自证**：法向残差在独立加密点集上 ~1e-15 → 由外部 Neumann 问题唯一性定理，该级数即精确解；
   另外检查远场按 r⁻² 衰减。
3. **闭式锚**：Lamb (1932 §114) 椭球转动附加惯量闭式（`lamb_rotational_inertia`），与 (2) 互校。
4. **收敛性**：面元网格四级加密 + 幂律拟合 `I(N) = I∞ + K N^{-q}` 做 Richardson 外推。

## 5. 注意点（踩过的坑 / 局限）

1. **账本 D1 的球体解析锚写错了**：原文称球绕任意轴 `I_add=(5/8)πa⁵`。正确结论是球在理想流体中
   **转动附加惯量严格为零**——球面上的转动速度处处与表面相切（`(Ω×r)·n ≡ 0`），故 `phi ≡ 0`。
   面元（4 级网格单调趋于 1e-5·a⁵）与半解析两路都确认零。已在本单修正账本条目（见 §7）。
2. **模式阶数坑**：横向转动对应 `m=1` 的**偶阶** `n`（最低为 `P₂¹ ∝ μ√(1-μ²)`），最初误用奇阶导致
   基与右端严格正交（最小二乘解恒为 0、残差恰为 1.0、而"数值"仍像模像样地给出 0）。残差自证是唯一能抓住它的手段。
3. **符号约定坑**：面元求解器返回的是"运动体坐标系"势，实测球体平移偶极子 `phi = -Ua³cosθ/(2r²)`，
   即 `∂phi/∂n = +(V·n)`；半解析参考最初按绕流体固定系取 `-(V·n)`，两路数值仅差一个整体符号
   （相关 −0.997），因"附加惯量必须为正"才发现。报告保留该发现作为约定记录。
4. **收敛阶低**：观测阶 q≈0.65（面元数意义下），即 h~N^{-1/2} 的约 1.3 阶——常值源面元的经典行为；
   最细网格 1.67%、Richardson 0.25%。要求 1% 以内须 Richardson 或加密网格（4480 面元已 ~40 s/例）。
5. **适用域**：只覆盖**无界**理想流体、封闭物体、绕物体中心转动；自由面/双体镜像的转动附加惯量
   （账本 D2）仍为欠账；也未覆盖粘性与非定常记忆项（那是 `M_44(ω)` 频域问题）。
6. 未做性能优化：`influence_matrix` 为稠密 O(N²) 组装，>1 万面元需分块或 FMM。
