## ① 案例介绍（物理背景 / 几何 / 参数表）

一维闭管 [0,1] 内三个压力平台，两束爆轰波（激波+接触+稀疏）相向传播，t≈0.028 在管中部对撞，
形成双激波干涉结构，积分至 t=0.038（Woodward & Colella 1984 标准算例）。

| 参数 | 值 | 出处 |
|---|---|---|
| 域 | x∈[0,1]，1D | W&C 1984 |
| 初始 (ρ,u,p) 左 / 中 / 右 | (1,0,1000) x≤0.1 / (1,0,0.01) 0.1<x<0.9 / (1,0,100) x≥0.9 | Dumbser et al. JCP 2019 (arXiv:1902.07773) §5.1.4；arXiv:2109.14340 Eq.(37) |
| γ / t_end / 壁面 | 1.4 / 0.038 / 两端反射 | 同上 |
| 基准曲线 | 同文 Fig.21「Reference」（= pure RPJ @3200 网格），PDF 矢量路径数字化 | `reference/curves.json`，PDF sha256 `509e2350…e064` |
| 基准标定偏差 | y 轴 **+0.022017**（密度单位，常量加性） | `reference/axis_calibration.json`（前轮已定，本单**不改**） |
| 格式（本仓） | MUSCL-Hancock 二阶 + MC 限幅 + HLLC + SSP-RK，CFL 0.4 | `compressible/cases.double_blast` |
| 交叉码 | WENO5 + SSP-RK3 + Rusanov（不共享离散） | `xcode/wc_crosscode.py` |

**本单要回答的问题**：不是「算例对不对」（前轮已给 PASS），而是
**「与参考解那 ~2–3 % 的残差里，哪一部分是我们的离散误差、哪一部分属于参考解自己」**——
两个数字相减永远回答不了这个问题，必须引入**不依赖参考解**的度量。

## ② 怎么做的（方法 / 流程 / 工具链）

工具：`docs/woodward-colella-double-blast/xval/wc_xval.py`（纯 numpy，**不调用求解器**，6 s 跑完）
+ `wc_xval_figures.py`（出图）+ `tests/test_compressible_wc_xval.py`（9 例回归门）。
输入只有仓内已存工件：阶梯剖面 `ladder/data/ladder_profile_nx{200,400,800,1600,3200}.npz`
（nx=400/800 在 `artifacts/`）与两套参考表。

五项度量，逐一对应一个可证伪的假设：

| # | 度量 | 回答什么 |
|---|---|---|
| A | **参考解无关的自收敛**：`d_nx = ∫|ρ_nx − ρ_2nx|dx / ∫ρ dx` | 我们自己的离散误差有多大（不需要参考解） |
| B | **误差预算**：`total² = own² + ref_side²` | 逐点残差里属于参考解的上限是多少 |
| C | **刚体平移扫描 + 逐阵面局部位移** | 残差是相位（波速）错还是幅值/形状错 |
| D | **分辨力对比**：`max|dρ/dx|`、TV、平滑地板扫描 `L1(width)` | 逐点比较是否已经超出参考表的表征能力 |
| E | **峰值三点外推**（800/1600/3200，Richardson） | 我们收敛到多少，与参考峰值差多少才算「参考侧的错」 |

**新增计算**（v3 计算门递交，非本机）：独立格式 WENO5 的 nx=1600（cj2375）、nx=3200（cj2376），
两个作业 rc=0，工件已回填 `ladder/data/`。用途：把「MUSCL 特有缺陷」这条路堵死。

## ③ 计算结果（程序化注入，零手抄）

### A. 参考解无关的自收敛（MUSCL/HLLC，窗口 [0.4,1]）

| 相邻档 | 窗口 L1 | 全域 L1 | 峰值差 |
|---|---|---|---|
| 200→400 | 8.078 % | 8.114 % | 11.381 % |
| 400→800 | 5.330 % | 5.330 % | 8.724 % |
| 800→1600 | 3.054 % | 3.054 % | 4.272 % |
| **1600→3200** | **1.765 %** | 1.654 % | **0.637 %** |

观测阶 0.60 → 0.80 → 0.79（激波主导的 L1 不进入二阶渐近区）；以 p=0.79 折算，
**nx=3200 处我们自己的误差估计 ≈ 2.417 %**。

### C. 误差预算（nx=3200，标定参考）

| 量 | 实测 total | 我们自己的（A 给） | 归到参考侧（正交分解） |
|---|---|---|---|
| 剖面 L1 | 3.079 % | 1.765 % | **2.523 %** |
| 峰值密度 | 2.998 % | 0.637 % | **2.929 %** |

### D. 分辨力：我们的解已经比参考表更锐

| 量 | 参考表 | nx=800 | nx=1600 | nx=3200 |
|---|---|---|---|---|
| `max|dρ/dx|` | **2696** | 1140 | 2111 | **4463** |
| 总变差 TV | 16.214 | 16.110 | 17.101 | 17.155 |

即 **nx≥1600 起，我们的解比数字化参考更锐**：把我们的解用顶帽核平滑到各种宽度，
与参考的 L1 最低只降到 **2.699 %（w≈9.2e-3，仅降 10.8 %）** ——
**「锐度不匹配」不是残差主因**（该假设被本项否证），残差是真实的剖面差异。

### E. 峰值外推（800/1600/3200，Richardson）

| 项 | 值 |
|---|---|
| ρ_max(800/1600/3200) | 6.190 / 6.466 / 6.508 |
| 观测阶 p | **2.736**（渐近区，单调） |
| 连续极限 ρ_max∞ | **6.5148** |
| 标定参考峰值 | 6.3181（x=0.778） |
| 极限 vs 参考 | **+3.11 %** |
| nx=3200 峰值残余误差估计 | 0.0064（0.10 %） |

**含义**：我们的峰值已经收敛，而它比参考解峰值**高 3.1 %**——参考解（RPJ@3200）自身的峰值被其
离散耗散压低 ~3 %。这一项是**参考侧误差**，不该记在求解器账上（也不能反过来被当作通过的理由）。

### F. 相位 vs 形状

- 全局刚体平移扫描（±0.008，161 点）：最优 δ=**0.0000**，L1 3.027 %→3.027 %（**无全局相位错**）。
- 逐阵面局部位移（窗口 ±0.012）：x=0.6469 δ=0（局部 L1 0.0606）；x=0.7619 δ=−0.0007（−1.4 个参考采样，
  局部 L1 0.614→0.582，仅降 5 %）；x=0.7990 δ=−0.0001（0.743→0.733）；x=0.8660 δ=+0.0004（0.023→0.007）。
- L1 残差的空间分布（占归一化积分）：0.40–0.55 0.006 %｜0.55–0.70 **1.172 %**（max|Δρ|=0.789@0.6467）｜
  0.70–0.76 0.345 %｜0.76–0.80 **1.160 %**（1.047@0.7998）｜0.80–0.90 0.345 %（1.171@0.8002）｜0.90–1.00 0.000 %。
  → 残差全部集中在**两处间断的亚毫米邻域**，量级等于跳跃幅值本身：这是「同一间断被两种离散/数字化
  以不同锐度放置」的签名，不是平台区幅值错。

### G. 交叉码（独立格式，排除 MUSCL 特有缺陷）

| nx | MUSCL vs WENO5 L1 | 峰值互差 | 各码峰值（标定参考误差） |
|---|---|---|---|
| 200 | 4.600 % | 1.008 % | 20.75 % / 19.95 % |
| 1600 | 1.475 % | 0.092 % | 2.34 % / 2.44 % |
| 3200 | **0.972 %** | **1.046 %** | 3.00 % / 1.93 % |

两套互不共享离散的格式随网格加密**互相收敛**（4.60 %→0.97 %），且都与参考差 2–3 %：
说明该 2–3 % 不是某一种格式的病，而是「与这份参考解比较」的共同地板。

## ⑤ 注意点（局限 / 踩过的坑 / 适用范围）

1. **前轮结论被部分推翻**：`CASE-WOODWARD-COLELLA-calibration-bias.md` 的「nx≥800 全部关键量 <3 %」
   是在 nx=3200 尚未返回时下的；该档返回后峰值/L1 为 3.00 / 3.08 %。总账 <10 % 仍 PASS，
   但**更硬的 <3 % 声明必须收缩为「nx=800/1600 档成立」**。本单不改前轮文档（honest 并列保留）。
2. **参考解本身是数值解**：Fig.21「Reference」= RPJ@3200，其峰值按本单外推被低估约 3 %；
   所以任何「<x % vs 参考」的判据都混入了参考侧误差，只能当一致性判据，不是真解误差。
3. **逐点 L1 不是收敛量**：参考表是印刷曲线经 ghostscript 共线点合并后以 5e-4 重采样的折线，
   其 `max|dρ/dx|`=2696 已低于我们 nx=1600 的解（2111→4463）；网格再加密，L1 会收敛到一个
   **非零地板**（本单实测 3200 档 3.08 %）。要 certified <1 % 必须换基准（独立高分辨率参考）。
4. **平滑地板假设被否证**：原先怀疑「锐度不匹配」是主因，实测只能解释 10.8 %，已如实记录
   （`falsified_hypothesis` 侧证据）；残差主因是两处间断的局部形状/位置差异（§③ F）。
5. **观测阶只有 0.6–0.8**：L1 被激波主导，三网格 GCI 安全因子法在此不可用（前轮 GCI 带宽 57–405 %、
   外推值 9.02 荒谬），本单因此改用「峰值三点外推」（p=2.74，干净）。GCI 不要再用在 L1 上。
6. **质量/积分量是良态的**：窗质量 ∫ρdx 在 [0.4,1] 上全部 ≤0.16 %（nx≥1600 为 0.00–0.01 %），
   nx=200 的 minmod+CFL0.2 变体也只有 0.21 % → 守恒性结论不依赖格式与网格。
7. **WENO5 只跑到 3200**：独立格式更细的档（6400）未递交（成本/收益不划算），所以「参考侧误差 3 %」
   的归因靠的是「两码互相收敛且都离参考 2–3 %」这一三角测量，不是直接算出真解。
