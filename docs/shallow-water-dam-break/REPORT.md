## 1. Case, physics, reference provenance

**Physics.** A dam at `x = 0` separates still water of depth `h0` from still
water of depth `h1`.  With a hydrostatic pressure assumption, no viscosity and a
frictionless flat bed, the flow is governed by the shallow-water equations

```
h_t + (h u)_x = 0
(h u)_t + (h u² + g h²/2)_x = 0
```

and the dam-break initial-value problem has closed-form solutions:

| case | downstream bed | exact structure |
|---|---|---|
| `ritter-dry` | dry, `h1 = 0` | one rarefaction fan; front `x_f = 2 t sqrt(g h0)`, `h(x=0) = 4h0/9`, `u(x=0) = 2c0/3` |
| `stoker-wet` | wet, `h0 > h1 > 0` | left rarefaction + constant state `(h2, u2)` + right-moving bore of speed `U`; the still-water level steps from `h1` to `h2` across the bore |

**References.**
* Ritter, A. (1892). "Die Fortpflanzung der Wasserwellen." *Zeitschrift des
  Vereins Deutscher Ingenieure* **36**, 947–954 — dry-bed rarefaction solution
  (front speed `2 sqrt(g h0)`, the `4h0/9` depth at the dam).
* Stoker, J. J. (1957). *Water Waves: The Mathematical Theory with
  Applications*, Interscience, New York — chapter 10, the dam-break problem
  with a bore on a wet bed (`h1 > 0`); secondary DOI 10.1002/fld.3865 restates
  the same two closed forms for CFD validation.

**Zero-transcription statement (honest scope).** No table or digit is copied
from a paper: every reference value is evaluated from the closed forms inside
`src/tensorfvm/shallow_water/exact.py`, and those closed forms are then
*certified numerically* against their own defining conditions
(`src/tensorfvm/verification/artifacts/shallow-water-dam-break/exactness.json`):

| certification | residual |
|---|---|
| Stoker Riemann invariant `u2 + 2c2 - 2c0` (relative) | 0.0 |
| Stoker bore mass jump `U(h2-h1) - h2 u2` (relative) | 0.0 |
| Stoker bore momentum jump `U h2 u2 - [g(h2²-h1²)/2 + h2 u2²]` (relative) | 1.12e-16 |
| Ritter `h(dam)/h0` vs `4/9` | 5.6e-17 |
| Ritter `u(dam)/c0` vs `2/3` | 0.0 |
| Ritter fan mass `∫h dx` vs `h0 c0 t` | 1.25e-13 |

*Limitation*: the original Ritter 1892 / Stoker 1957 pages could not be opened
from this worktree (no scan in the repo, no online access), so page-level
citation of a specific table is not claimed.  The certification above replaces
it: the residuals prove that the numbers used are the exact solutions of the
stated jump/invariant conditions, which is strictly stronger than a copied
table would be.

(head at `−c0 t = −2 m`, bore at `+1.89 m`), so the finite domain is exact.

## 2. Method and implementation

The repository had **no shallow-water solver**: a grep for
`shallow water / hll / riemann` over `src/` returns only the compressible Euler
and VOF modules, and `src/tensorfvm/twophase_bench/ritter.py` is a *VOF
advection* benchmark that imposes the analytic state as a prescribed velocity
field — it does not solve momentum and therefore cannot answer this node.  The
existing Riemann/vof code was therefore extended with a small, classical
shallow-water module rather than a new project:

| file | contents |
|---|---|
| `src/tensorfvm/shallow_water/exact.py` | Ritter and Stoker closed forms; bisection solve of the bore state; jump/invariant certification; `t*` scaling |
| `src/tensorfvm/shallow_water/swe1d.py` | 1-D cell-centred FV solver: MUSCL (minmod) reconstruction of `(h, u)`, HLL flux with Einfeldt/Roe wave speeds, SSP-RK3 in time, adaptive CFL, wet/dry handling, conservation/positivity counters |
| `src/tensorfvm/shallow_water/dam_break.py` | case definitions, predeclared metrics + verdicts, grid-convergence and sensitivity studies, figure, artefact writer |
| `scripts/run_shallow_water_dam_break.py` | one-command reproduction of every artefact |
| `tests/test_shallow_water_dam_break.py` | 14 tests (closed-form certification, conservation, monotonicity, 5 % acceptance, convergence) |

Key implementation decisions, each with the defect that motivated it:

1. **SSP-RK3, not RK2.**  With a second-order reconstruction the limiter cancels
   the first-order HLL diffusion in smooth regions, so the semi-discrete
   operator is almost skew symmetric; SSP-RK2 has
   `|G|² = 1 + (ωΔt)⁴/8 > 1` there and a smooth test field drains to zero within
   0.05 s.  This was observed, not assumed (see §6).
2. **`½·Δx·h′` reconstruction.**  The first implementation extrapolated with
   `½·h′` instead of `½·Δx·h′`, i.e. by `1/Δx` too much; the face states then
   overshot by `O(Δx)` and the scheme produced a spurious depth spike
   `h/h0 = 1.24` behind the dam.  The fix is one line (`half = 0.5 * self.dx`)
   and is covered by `test_first_order_is_less_accurate_than_second_order`
   plus every metric test.
3. **Dry fronts** are handled inside the HLL wave-speed estimates
   (`sqrt(g h)` vanishes on the dry side) with reconstructed depths clipped at
   zero and dry-cell momentum zeroed.  Both interventions are **counted**
   (`clipped_cells`, `dry_momentum_flips`) and are asserted to be **zero** in
   `test_mass_is_conserved_and_depth_stays_positive`, so no metric can be met by
   silent clipping.
4. **Mass** is conserved to machine precision by construction (telescoping
   fluxes, both boundaries still water): observed drift `3.2e-14` (dry) and
   `1.3e-14` (wet).

**Predeclared metrics** (fixed before looking at results, `dam_break.py`
docstring): wetted-edge front (dry), half-level bore crossing (wet), mid-plateau
`h2` and `h1` means for the level step, depth `L1`/`L∞`, total variation and
interior local extrema (monotonicity), mass drift, positivity counters;
tolerance = 5 % on every headline metric.

| ritter-dry | front position `x_f` [m] | 4.000000 | 3.884375 | 2.891 % | ✓ |
| ritter-dry | depth `L1` | — | 7.72e-04 | 0.077 % | ✓ |
| stoker-wet | bore position `x_s` [m] | 1.888781 | 1.889178 | 0.021 % | ✓ |
| stoker-wet | post-bore depth `h2` [m] | 0.726920 | 0.726921 | 0.000 % | ✓ |
| stoker-wet | still-water step `h2/h1` | 1.453841 | 1.453842 | 0.000 % | ✓ |
| stoker-wet | depth `L1` | — | 4.27e-04 | 0.043 % | ✓ |

Monotonicity: `ritter-dry` TV ratio 1.000000, 0 interior extrema;
`stoker-wet` TV ratio 1.001005 (0.1 % over the exact `h0 − h1 = 0.5`, i.e. the
small amount of numerical dissipation in the bore cell), 0 interior extrema —
no spurious oscillation in either case.  Depth never exceeds `h0` (dry:
`h_max/h0 = 1.000000`), never goes negative.

Front history (25 samples, `metrics.json → front_series`) tracks the closed form
from `t* = 0` to `2` with the same ≈ 2.9 % offset throughout, i.e. the front
speed is right and the offset is the smeared zero-depth tip, not a phase error.

**How to read the 2.891 %.**  The dry front is a zero-depth cusp; any FV scheme
smears it over a few cells, so *where* one puts "the front" matters:

| front measure (dry, `front_definitions.json`) | n = 400 | n = 800 | n = 1600 | n = 3200 |
|---|---|---|---|---|
| wetted edge, `h > 0` (primary, no analytic input) | 1.562 % | 2.656 % | 2.891 % | 2.461 % |
| depth crosses `h0/100` (raw) | 17.159 % | 15.855 % | 15.441 % | 15.220 % |
| depth crosses `h0/100` + exact fan offset `3t√(g h_lvl)` | 2.159 % | 0.855 % | 0.441 % | 0.220 % |

The primary measure is threshold-free and is the one quoted in the verdict; the
raw threshold crossing of a smeared tail is *not* a front position (the tail
holds `≈3e-4 m` of water at 0.1 m behind the exact tip), which is exactly why
the offset-corrected crossing converges to 0.3 % while the raw one does not.
All three are reported rather than the flattering one only.

## 4. Convergence and sensitivity

Grid convergence (`convergence.json`):

| case | n = 100 | 200 | 400 | 800 | 1600 | observed order |
|---|---|---|---|---|---|---|
| ritter-dry, depth `L1` | 1.26e-2 | 6.23e-3 | 3.08e-3 | 1.54e-3 | 7.72e-4 | 1.01 |
| stoker-wet, depth `L1` | 6.66e-3 | 3.42e-3 | 1.73e-3 | 8.51e-4 | 4.27e-4 | 0.99 |

First order, as expected for a shock-dominated problem with a minmod limiter
(the limiter clips to first order at both the fan head and the bore; the
second-order path pays off in the *smooth* fan, see the `order=1` row below
where wet `L1` is 4.6× larger).  The dry front (wetted edge) is *not* monotone
in `n` (8.75 % → 1.88 % → 1.56 % → 2.66 % → 2.89 %; 2.46 % at `n = 3200`): it is quantised by `dx` and
sensitive to how much water the HLL tail spreads, so it is reported as a
2–3 % band rather than as a convergent sequence.  This is the honest weakness of
that metric and the reason the offset-corrected crossing is reported beside it.

|---|---|---|---|---|---|
| CFL 0.2 | 2.66 % | 0.044 % | 0.000 % | 8.51e-4 | 0 |
| CFL 0.4 (benchmark) | 2.66 % | 0.043 % | 0.000 % | 8.51e-4 | 0 |
| CFL 0.8 | 2.97 % | 0.039 % | 0.000 % | 8.57e-4 | 0 |

Worst headline error over all variants: 2.97 % (< 5 %).  Two readings worth
recording: (i) the solution is CFL-insensitive over a factor 4 — the time step is
not what limits accuracy; (ii) the first-order run has a *smaller* dry-front
error because extra numerical diffusion lengthens the wetted tail — another
reminder that a diffusion-favouring metric must never be the only evidence, and
why depth `L1` and the wet-bore metrics are in the verdict as well.

## 6. Failure modes, limits, and ecosystem friction

**Failure modes found (and fixed) while building this benchmark.**
1. `½ h′` instead of `½ Δx h′` in the MUSCL extrapolation → face states overshoot
   by `O(Δx)`, spurious `h/h0 = 1.24` spike behind the dam, then divergence.
2. SSP-RK2 with second-order reconstruction → smooth test field drained to zero
   (`|G| > 1` on a skew-symmetric operator).  Fixed by SSP-RK3; documented in the
   solver docstring so the next agent does not "optimise" it back to RK2.
3. Coarse grids produce one small interior extremum in the wet-bed profile
   (`n = 100, 200`: `local_extrema = 1`, TV ratio 1.003): the near-bore cell
   oscillation is grid-limited and disappears at `n ≥ 400`.  Reported as data,
   not hidden, and the accepted grid (`n = 1600`) has zero extrema.

**Limits of the result.**
* The shallow-water model itself is an approximation: hydrostatic pressure, no
  viscosity, no bed friction, no surface tension, no vertical acceleration.
  The exact solutions are for that model, so a 0.02–3 % match verifies the
  *solver*, not the model's validity for a real dam break (where bed friction
  and non-hydrostatic effects matter; compare the VOF/Navier–Stokes Ritter
  comparison in `tests/test_ritter_dam_break_comparison.py`, which accepts up to
  40 % deviation for exactly this reason).
* 1-D only, flat bed only; wet/dry is handled but a bed-slope source term and
  well-balancedness for a wet/dry *shore* are not implemented (not needed here).
* The dry-bed front metric has a 2–3 % bias from tip smearing (§3); it is not
  grid-convergent in the usual sense and should not be quoted as a convergence
  rate.

**Ecosystem friction (recorded as-is).**
* *Capability gap*: no shallow-water / Saint-Venant solver existed in TensorFVM
  (`src/` grep).  The nearest asset, `twophase_bench/ritter.py`, is a VOF
  advection benchmark that prescribes the analytic velocity — it cannot run this
  case; hence a new module rather than reuse.
* `knowledge_base` search for `shallow water`, `dam break`, `Ritter`, `Stoker`,
  `TensorFVM` returned `total: 0` for every query (store reachable, empty) —
  the pre-work capability/negative-knowledge check produced *no* prior art,
  neither a capability entry to reuse nor a negative result to avoid.
* `negative_knowledge_ledger` and `oss_solutions` endpoints are not served at
  `/api/v1/...` (`HTTP 404` on `/negative_knowledge`, `/knowledge/negative_ledger`,
  `/oss_inventory`, `/oss/solutions`), and `/openapi.json` is 404 as well, so the
  two remaining legs of the mandated three-way pre-check could not be executed;
  only `/knowledge/search` answered.
* Reference access: no offline copy of Ritter 1892 / Stoker 1957 in the tree (§1).

**Scope note (deviation declared).** The task frame names one case
(`CASE-FVM-DAMBREAK-STOKER`) with two metrics (front position and still-water
level step).  The frame mixes the dry-bed reference (Ritter: front position)
with a wet-bed metric (level step), so both families were implemented and are
reported: Ritter as `ritter-dry` (front), Stoker as `stoker-wet` (bore position,
`h2` and `h2/h1`).  Nothing was relaxed: every headline metric in both cases is
within 5 % at `t* = 2` with a monotone waveform.
