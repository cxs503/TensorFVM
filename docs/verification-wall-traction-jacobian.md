# Wall Traction Jacobian Verification (m3356)

## 案例介绍

**物理背景：** Spalding 壁面定律是 RANS 求解器中壁面函数的核心。`wall_traction_linearization` 
提供了壁面剪切应力对切向速度的解析 Jacobian，用于隐式时间推进和 Newton 求解器。

**数学问题：** Spalding 定律是隐式的：

    y⁺ = u⁺ + (1/E)[exp(κu⁺) - 1 - κu⁺ - (κu⁺)²/2]

其中 u⁺ = U/u_τ, y⁺ = y·u_τ/ν。摩擦速度 u_τ 通过二分法隐式求解，然后 
traction = -ρ·u_τ²·direction。解析 Jacobian 需要对隐式方程求导，涉及链式法则、
径向/切向分解，是一个非平凡的推导。

**验证目标：** 证明代码中的解析 Jacobian 与函数本身的有限差分近似一致。

## 怎么做的

**方法：** 中心差分有限差分验证

```python
J_fd[i,j] = (traction(v + ε·e_j)[i] - traction(v - ε·e_j)[i]) / (2ε)
```

**测试覆盖：**
- 速度范围：0.001 ~ 10.0 m/s（覆盖粘性底层、缓冲层、对数律层）
- 维度：2D 和 3D
- 零点极限：J → -μ/y · I
- 对称性：J = J^T（耗散势的梯度）
- 广播正确性：批量 vs 逐点
- 能量耗散：v · (J @ v) ≤ 0（壁面做负功）

**工具链：** NumPy, pytest, tensorfvm.wall_functions

## 注意点

1. **有限差分精度：** 使用 ε=1e-6 的中心差分，理论精度 O(ε²) ≈ 1e-12。
   高速时 Spalding 定律的指数项放大舍入误差，实际精度降至 1e-7。
   
2. **隐式求解稳定性：** 摩擦速度的二分法求解在 90 次迭代内收敛到机器精度，
   但高速时 y⁺ 很大，exp(κu⁺) 接近溢出边界（代码用 clamp(z, max=700) 保护）。

3. **对称性的物理意义：** Jacobian 对称性源于壁面剪切应力是耗散势 
   Φ = ρ·u_τ² 的梯度（traction = -∂Φ/∂v）。这是热力学一致性的离散类比。

4. **零点极限：** 当 U→0 时，u_τ → √(νU/y)，Jacobian 退化为纯粘性 -μ/y·I，
   与湍流模型无关。这是壁面函数的正确渐近行为。
