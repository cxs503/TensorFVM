### ① 案例介绍

### ② 怎么做的

1. `cases.sod(nx=..., order=...)` 建同一 `EulerSolver` 表面（HLLC + MUSCL-Hancock）；
2. 跑 t=0.2，取 `solver.primitive()` 的 ρ/u/p 与精确黎曼解（`ExactRiemann.sample(xi)`，xi=(x−x₀)/t）逐格比对；
3. L1 相对误差 = mean|q−q_exact| / mean|q_exact|，三量取**最坏值**当判据标量；
4. 同一批 runs 上报守恒账：`U(t) + outflow(t) − U(0)`，相对量与绝对量都取（动量初始积分恰好为 0，相对量在数学上无定义，见 ⑤.3）；
5. 阶次率用相邻网格 log-log 斜率，两阶各三对；
6. 阈值 `THRESHOLDS` 在模块顶部**跑前写死**并原样写入工件 `thresholds_declared_before_run`。

### ⑤ 注意点 / 局限

1. **时刻口径**：本轮 t=0.2 是论文作图时刻、也是判据字面时刻；锚点前几轮的 0.14 判决（C1 波位置 / C2 星区）不因本轮改变，两套时间站的数字不可混引（激波位置相差 ~43 %）。
2. **判据标量**：3 % 判在用「三量最坏值」上，比逐个量分别判更严；单个量全部低于 3 % 时最坏量自然低于 3 %，故这是保守口径。
3. **动量相对漂移为 NaN 是定义缺陷而不是守恒缺陷**：Sod 两侧静止，初始动量积分恰为 0，相对量无分母。上一轮（oracle 报告摩擦表）把它归因成「边界通量未计入预算」，该归因**不成立**：`outflow` 已累计，nx=400 二阶的绝对残差为 +2.22e-16（舍入地板）。本轮给 `budget_drift(..., absolute=True)` 补了绝对量出口并把这条写进 docstring，测试里同时断言「相对量 NaN + 绝对量闭合」，避免读者把 NaN 当失败（或当通过）。
4. **只测 HLLC + MUSCL(mc)**：其它通量/限制器的率与常数会不同，本轮不外推。
5. t=0.2 时激波在 x=0.8504、稀疏扇头在 x=0.2634（均由 `exact_star_state()` 的波速算出），距 x=1 / x=0 分别还有 0.1496 / 0.2634，故测量窗内出流边界未被到达。
