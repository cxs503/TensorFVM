两组实际 TensorLBM BGK 剪切波对照32²/64²通过精度门。独立 NumPy 审计重建230个MAC步和324个BGK步。

只对实际同网格、同物理工况作误差比较；不以二维LBM比较三维ABC，也不推论普遍性能排名。
