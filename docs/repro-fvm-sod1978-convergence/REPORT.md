# REPRO-FVM-SOD1978 第 2 轮：收敛性诊断（调研→选型→实现）

## ① 案例介绍
Sod (1978, *J. Comput. Phys.* 27:1-31) 标准激波管：1-D，x∈[0,1]，膜片 x₀=0.5，
左 (ρ,u,p)=(1,0,1)，右 (0.125,0,0.1)，γ=1.4，判据时刻 t=0.14，两端 outflow。
无量纲：CFL=0.4、激波马赫数 1.6556（精确解波速算出）、p*/p_L=0.30313、
ρ*ₗ/ρ_L=0.42632、ρ*ᵣ/ρ_R=2.12459。
前轮 m15142：C1（四波位置 <2 %）与 C2（星区 <5 %）全过，**C3（L1 阶 ≥1）字面 FAIL**；
m15289 同锚点 honest-FAIL 未留 fail_stage。本轮先调研再实施。

## ② 方法与实现
- 格式：HLLC + MUSCL-Hancock，限制器 mc / vanleer / **superbee（本轮新增，Roe 1986 TVD 最低耗散）**；
  精确解 `exact_sample()`（Toro ch.4 五段波结构 + p* 迭代）。
- 新增诊断层 `src/tensorfvm/verification/sod1978_convergence.py`：三种误差范数
  （whole-field / 单元平均 / 解析区内缩窗）+ 四道波位置收敛率 + 最短 3 网格 log-log 指数拟合；
  入口 `scripts/sod1978_convergence_study.py`；判据阈值在扫描前写死于模块顶部并写入工件
  `thresholds_declared_before_run`（不改判据、不调容差）。
- 文献：Toro 2009(ch.4/10/14)；LeVeque 2002(ch.8)；**Banks, Aslam & Rider, JCP 227 (2008)
  6985-7002（线性退化波次线性收敛）**；Engquist & Sjögreen, SIAM J. Numer. Anal. 35 (1998) 2464。
- 开源横向（实读 `/root/oss-cache`，65 MB/3 仓）：只有 LBM 仓；唯一同类是 pylbm
  `demo/1D/riemann_problems/euler.py`（D1Q(2,2,2) 动理学格式解 Sod + `exact_solvers` oracle），
  `grep -c error` = 0 —— **开源侧没有可借的量化判据**，判据只能出自收敛性分析文献。
