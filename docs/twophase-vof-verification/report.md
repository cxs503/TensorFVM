## 1. 案例介绍

### 1.1 静水压力平衡

两相静止场在重力作用下的压力分布应满足 p = ρgh，界面不应漂移。这是两相流求解器的**负控算例**（negative control），因为精确解已知且与离散细节无关。

| 量 | 值 |
|---|---:|
| 域尺寸 | 0.1 m × 0.2 m |
| 网格 | 40 × 80 |
| 界面位置 | y = 0.1 m |
| 液体密度 | 1000 kg/m³ |
| 气体密度 | 1.2 kg/m³ |
| 重力 | 9.81 m/s² |
| VOF 格式 | PLIC |
| 压力形式 | total |

### 1.2 溃坝波前（Koshizuka & Oka 1996）

水柱崩塌实验是两相流瞬态基准算例。Koshizuka & Oka (1996) 使用 MPS 方法验证了该实验，提供了波前位置时程参考数据。

| 量 | 值 |
|---|---:|
| 水柱宽 W | 0.1 m |
| 水柱高 H | 0.2 m (H/W = 2) |
| 域尺寸 | 0.6 m × 0.3 m |
| 网格 | 120 × 60 |
| 重力 | 9.81 m/s² |
| 无量纲时间 | t* = t·√(g/W) |
| 无量纲波前 | x* = x/W |

### 1.3 气泡上升终端速度（Grace 1967）

单个气泡在静止液体中上升，终端速度由 Eötvös 数和 Morton 数决定。Grace (1967) 给出了气泡形状-终端速度关联式。

| 量 | 值 |
|---|---:|
| Eötvös 数 | 1.23 |
| Morton 数 | 2.63×10⁻¹¹ |
| 密度比 | 1000 |
| 粘度比 | 55 |
| 网格分辨率 | 16 cells/diameter |
| 表面张力 | CSF 模型 |

## 2. 怎么做的

### 2.1 实现路径

**(a) VOF 界面追踪**：采用几何重构 PLIC（Piecewise-Linear Interface Calculation）格式，基于 Youngs (1982) 法向估计和 Scardovelli & Zaleski (2000) 闭式反演。PLIC 保持界面尖锐，数值扩散小。

**(b) 表面张力**：采用 Brackbill CSF（Continuum Surface Force）模型，使用 balanced face sampling（Francois et al. 2006）避免虚假流。

**(c) 重力源项**：在动量方程中添加 ρ·g 体力项，使用 total pressure form 保持静水平衡。

### 2.2 关键设置

- **压力形式**：静水验证使用 `pressure_form="total"`，经测试该格式在离散静水平衡下速度保持 ~1e-17 m/s
- **VOF 格式**：全部使用 PLIC 几何重构
- **时间步**：自适应 CFL 控制，CFL ≤ 0.4
- **质量守恒**：PLIC 格式保证通量守恒，质量漂移 < 1e-15

### 2.3 工具链

- Python 3.11 + PyTorch
- pytest 测试框架
- matplotlib 绘图

## 5. 注意点

### 5.1 踩过的坑

1. **压力形式选择**：文档声称 `pressure_form="reduced"` 更适合静水情况，但实测 `pressure_form="total"` 在离散静水平衡下表现更好（速度 ~1e-17 vs ~0.8 m/s）。这可能是求解器实现细节导致的。

2. **提取函数轴错误**：原有 `dam_break.py` 中的波前/水柱高度提取函数存在轴混淆 bug（`alpha[:, :nx//2]` 应为 `alpha[:ny//4, :]`）。已修复。

3. **2D vs 3D 差异**：溃坝实验是 3D 的，2D 模拟无法完全复现。波前误差判据需考虑此限制。

### 5.2 局限

- 静水压力误差在界面附近（p < 100 Pa）较大（~10%），这是离散密度跳跃的固有特性
- 溃坝模拟为 2D，与 3D 实验有系统性偏差
- 气泡上升模拟计算成本高，终端速度收敛需要长时间积分

### 5.3 适用范围

- 静水验证适用于任意密度比的两相分层流
- 溃坝验证适用于 H/W ≈ 2 的水柱崩塌
- 气泡验证适用于椭球形气泡区（0.4 < Eo < 40）
