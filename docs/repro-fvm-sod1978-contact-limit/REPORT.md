### ① 案例介绍

Sod (1978) 激波管（外部锚点 Sod, *J. Comput. Phys.* **27** (1978) 1–31）为锚点
`REPRO-FVM-SOD1978` 的被测算例：1-D Euler，γ=1.4，x∈[0,1]，膜片 x₀=0.5，
左 (ρ,u,p)=(1.0,0.0,1.0)，
右 (0.125,0.0,0.1)，
判据时刻 t=0.14；HLLC + MUSCL-Hancock，限制器 mc，CFL=0.4，两端 outflow。

本轮新增**对照算例（纯接触）**：ρ 阶跃 1.0→0.125，
全场 u=0.5、p=1.0 均匀，t=0.14。
其精确解只有一道匀速平移的线性退化波，u/p 均匀性是精确不变量（本轮逐网格核验，见下表 drift 列），
因此该算例上的误差**只能**来自接触波捕获。

网格集：nx ∈ {200, 400, 800, 1600}；阶数 1 与 2；分区容差见 `thresholds_declared_before_run`
（**跑前写死**，写入工件）。

### ② 怎么做的

1. 在同一 `EulerSolver` 上跑两类算例：Sod（原锚点）与纯接触对照；
2. 对 Sod 做**互斥区域误差预算**：以四道波（稀疏波头/尾、接触、激波）各 ±24 单元
   划出互斥单元集，剩余为平台区——集合互斥且并集为全城，故 `Σ 区域误差 == 全域 L1 误差`
   （工件内 `budget_residual` < 1e-10 逐网格核验）；
3. 定义**接触涂抹宽度** `w = ∫|ρ−ρ_exact|dx / |Δρ|`（纯接触）与接触区 L1 质量/星区密度跃（Sod），
   把「波被抹多宽」变成可收敛的量；
4. 全域误差同时用**点采样**与**精确单元平均**两种口径，排除采样假象；
5. 逐相邻网格对算 log-log 率，最细 3 网格做最小二乘指数拟合；
6. 阈值在模块顶部写死后运行，判定由阈值计算，事后不改。

`tests/test_sod1978_contact_limit.py`（11 项性质测试）+ 本发布脚本（表格与图全部由工件程序化生成，零手抄）。

### ⑤ 注意点

- 判据不改：C3 字面值仍是 ≥ 1.0；本轮只补机制证据，不重判为 PASS。
- 纯接触的均匀性不变量逐网格核验（drift ≤ 1e-10），故该对照确实只测接触波误差。
- 接触涂抹是**数值微分**的必然结果（一阶格式 ν∝h → 宽度∝√(h t)），因此接触 L1 误差本身次线性；
  全域阶不可能超过它——这是判据设计的物理下限，不是实现缺陷。
- 仅测 HLLC+MUSCL(mc)；其它通量/限制器的率会不同，未做全域限制器扫描（上一轮已做粗网格 sweep）。
- 局限：t=0.14 单时刻；未做长时间演化（接触宽度随 t 增长会使率进一步下降）。

### ⑥ 误差判定

- 机制判定（本轮主结论，见上表 C3 列）：字面 C3 → **FAIL（诚实申报，不粉饰）**。
- 对照一致性：Sod 全域率与纯接触 L1 率之差 ≤ 0.2（判定列 `率与对照一致`）。
- 均匀性：u/p 相对漂移 ≤ 1e-10 → 远优于 3%。
- 预算自洽：`Σ区域误差 − 全域误差` ≤ 1e-10。
- 位置：接触位置相对误差最细网格见上表（阈值 1.0%）。
- 「是否 <3%」：**判据本身不是 3% 型容差**（C3 是无量纲收敛阶），故这里回答的是机制一致性——率差 ≤ 0.2，
  位置/均匀性误差均在 3% 内；C3 字面未达如实申报。

字面判据 C3（全域 L1 阶 ≥ 1.0）**仍然 FAIL**（未见任何一档达到 1.0），本轮不改判据。同时给出机制证据：把**同一求解器**（HLLC + MUSCL-Hancock，同限制器/CFL）用在纯接触（线性退化波）对照问题上，其 L1 阶与 Sod 全域阶在容差内一致，说明全域阶由接触波捕获误差支配，属 Banks/Aslam/Rider (2008) 所述次线性收敛机制，而不是二阶格式的实现缺陷（解析区/平滑熵波仍达设计阶，见 R3/R5）。
