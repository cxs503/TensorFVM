# 螺旋桨空泡判据量的独立校验器（TensorFVM propeller_oracle）

## 1. 案例背景与目的

ship-performance-platform 的 `/api/v1/cavitation-detailed` 端点把判据量声明为
单源实现（`backend/api/cavitation_criteria.py`，m1938）。2026-11-13 复核发现其中
**五个名字被引用但全仓无定义**（`burrill_verdict`、`keller_min_area_ratio`、
`screen_cavitation_regime`、`tau_c`、`vapour_pressure`）：端点被 `_cav_wiring_pending`
桩化以保证 backend 可启动，判据量路径一调用即 `NotImplementedError`。
要"接受"这五个量返回真值，需要一个**独立**仪器：按已发布定义重新推导同一批量，
既可手算复核，又可与平台返回值对拍。本报告就是该仪器（`propeller_oracle`）
的自检与量化分析。**它不是生产路径**：平台的单源实现不动，本模块只做对拍。

设计点（平台 check 案例）：T = 300 kN，D = 3.0 m，n = 3 rps，Va = 6.17 m/s
(J = 0.6856)，桨轴浸深 h = 4.0 m，Ae/Ao = 0.65，
P/D = 1.0，Z = 4，水温 20 °C，ρ = 1025 kg/m³。

## 2. 方法与工具链

判据量全部为闭式，无拟合、无查表：

* `σ_0.7R = (p_0 − p_v) / (½ ρ V_0.7R²)`，`V_0.7R = sqrt(Va² + (0.7πnD)²)`，
  `p_0 = p_atm + ρgh`；`p_v` 用 NIST Antoine（与 `tensorfvm.cavitation.inception`
  同一式，20 °C → 2339 Pa 对蒸汽表 0.4%）；
* `τ_c = T / (½ ρ A_p V_0.7R²)`，`A_p = (Ae/Ao)·A0·(1.067 − 0.229 P/D)`（Taylor 1933），
  `A0 = πD²/4`；
* Keller (1966)：`(Ae/Ao)_min = (1.3 + 0.3Z)·T / ((p_0 − p_v)D²) + ΔA_o`，
  ΔA_o = 0.0/0.1/0.2（快双桨/单桨/慢双桨）；
* Burrill 判据：`margin = (σ_0.7R − σ_lim)/σ_0.7R`。**极限线 σ_lim(τ_c) 为 WITHHELD**
  ——本工作区没有 Burrill 图（5%/10%/20% 背空泡线）的可信数字化数据，因此默认沿用
  平台的旧占位线 `σ_lim = τ_c + 0.2`，且在返回值里显式带 `provenance=LEGACY_PLACEHOLDER`。
  数字化误差对结论的影响由解析灵敏度 `d margin/dσ_lim = −100/σ` 量化（第 3.4 节）。

工具链：numpy + matplotlib + pytest；`python scripts/run_cavitation_criteria_oracle.py`
一键复现（表格与图全部程序化注入）。

## 4. 平台端点探针（观测值，不假设）

| 项 | 值 |
|---|---|
| URL | `http://127.0.0.1:8002/api/v1/cavitation-detailed/check` |
| 状态 | `not_wired` |
| HTTP | `500` |

状态语义：`ok` = 200 且返回判据量；`not_wired` = 5xx（`_cav_wiring_pending` 桩）；
`rejected` = 4xx（载荷契约变了）；`unreachable` = 连不上。本仪器只记录观测值，
**不**把探针结果升级成"通过"；验收要求的是 `ok` 且逐量对拍 `rel_error ≤ 1%`。

## 5. 注意点与局限

1. **Burrill 极限线仍是 WITHHELD**：本报告只量化了它缺失的后果，没有编造曲线。
   "Burrill 图谱特征点核对"要真做，必须先拿到可引用的数字化数据（含出处、手数、
   适用 5%/10%/20% 哪条线），否则任何"通过"都是伪造证据。
2. **不做空泡类型判定**：面空泡/梢涡空泡/泡状空泡的划分需要弦向 Cp 分布或图谱色带，
   两者本工作区都没有，因此 `screen_regime` 把这些量列入 `withheld` 而不是猜。
3. **本模块刻意与平台单源实现重复**：这是验证所需的独立性（对拍仪器），文档与
   模块 docstring 都禁止平台 import 它。
4. 判据量对输入敏感的是 `p_v` 与浸深：20 °C 与 15 °C 的 `p_v` 差 634 Pa，在本设计点
   只改变 σ_0.7R 约 0.45%，
   远小于极限线缺失带来的不确定度——所以优先级判断是"先补线、再纠结水温"。

## 6. 误差判定

| 关键量 | 基准 | 最大相对偏差 | <3%? |
|---|---|---|---|
| τ_c, σ_0.7R, (Ae/Ao)_min, A_p, V_0.7R | 手算定义值 | 0.008% | 是 |
| p_v (20 °C) | 蒸汽表 2339 Pa | 0.40% | 是 |
| 占位线判据 σ_lim | 文献数字化 Burrill 线 | — | **无基准（WITHHELD）** |

结论：**闭式判据量对基准误差 < 0.01%，满足 <3% 要求**；
占位线判据本身**没有基准可比**，故其"通过/不通过"不声明 <3%，只声明不可用。

（验收条件：`state=ok` 且五量逐一对拍 `rel_error ≤ 1%`）。
