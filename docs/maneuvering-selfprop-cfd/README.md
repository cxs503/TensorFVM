# KVLCC2 自航 · 舵力 · 回转/之字 — 操纵性 CFD 验证面（IN63-N02）

**结论先行（honest verdict）**：本节点把 KVLCC2 的**自航点闭合**、**舵力导数（解析有限展弦比 + 2D RANS 尝试）**、
**3-DOF 回转/之字预报链**与**度量提取**做成了可运行、可自检的能力面；

## 1. 案例介绍

### 1.1 物理背景

操纵性是船舶总体性能的「宏观闭环」：螺旋桨把扭矩变成推力，舵把推力差变成首摇力矩，
船体在斜流中提供侧向力与阻尼。三个环各自需要不同层次的流体力学：

* **自航点**（V, n, τ）：推力 = 阻力/(1−t)，需要阻力链 + 螺旋桨敞水特性 + 船身交互；
* **舵力**：舵剖面升力随攻角的变化，2D 剖面 + 有限展弦比修正 + 桨尾流加速；
* **回转/之字**：把上述力代入水平面 3-DOF 方程积分，得到战术直径、进距、横距、超越角。

## 2. 怎么做的

### 2.1 工具链

纯 Python/numpy + 仓内已有能力，无外部 CFD 依赖：

1. **阻力**：`tensorfvm.resistance_chain` 的 ITTC-1957 摩擦线、Holtrop–Mennen (1982) 形状因子、
   ITTC-1978 粗糙度补贴（模型光滑面取 0），波浪项由**阻力锚 C_T 的残差**给出——见 §5.2 的审计；
2. **螺旋桨**：`maneuvering.propeller` 的 BEMT（叶片元 + 动量理论 + Prandtl 梢损），
   弦长分布由**扩展面积比精确约束**（AE/A0 = 0.800 复现到 1e-9），剖面升力 `Cl = Clmax·tanh(a0α/Clmax)`；
3. **船身**：`maneuvering.hullforces` — 低展弦比升力（Helmbold，AR = 2T̄/L = 0.119 →
   C_La = 0.186/rad，quarter-chord 压力中心 x_p' = 0.25）+ Hoerner 横流阻力（Cd = 1.2）
   沿真实侧投影面积 ∫T_e(x)dx = 2.909 m² 积分；
4. **舵**：`maneuvering.rudder` — 解析有限展弦比极线 + Kose (1982) 法向力律 + Yoshimura 尾流收缩；
5. **动力学**：`maneuvering.dynamics` — 3-DOF（纵荡-横荡-首摇）RK4，含细长体附加质量；
6. **CFD**：`tensorfvm.body_fitted.BodyFittedSolver`（稳态 SIMPLE + C 网格 + Spalart–Allmaras）
   跑 2D 舵剖面，脚本 `scripts/run_rudder_section_cfd.py`，在 **外协方 loong64 集群 node315** 上并行 7 例。

### 2.2 流程

```
几何门(Cb/Cwp/LCB) ─→ ITTC-78 阻力链 + 锚审计 ─→ BEMT KT/KQ ─→ 自航点 (V,n,τ)
                                                        │
                            舵极线(解析 | 2D RANS 尝试) ─┤
                                                        ↓
                        3-DOF RK4 ─→ 回转 δ=5/10/20/35 ─→ A_D, A_T, D_T, β_ss
                                  └→ 之字 10/10 ────────→ ψ1, ψ2, A_TE
                                  └→ 时间步 GCI（dt = 1.0 / 0.5 / 0.25 s）
                                  └→ MMG 有效导数模型互裁（δ=10, 35）
```

关键设置：舵速限幅 2.33 °/s（模型尺度）、n 固定（定转速推进，非扭矩调速）、
附加质量细长体 m_y/m = 1.17（**上界**，见 §5.4）、k_zz = 0.25 L。

## 5. 注意点（坑、局限、适用范围）

### 5.1 踩过的坑（可复用）

1. **设计航速自相矛盾**：`U = 0.771 m/s` 与 `Fn = 0.142` 不能同时成立（见 §1.3）。任何引用
   仓内旧文档的 Re / 阻力数字都要先做 Froude 换算校验。
2. **BEMT 不动点法在叶根/叶梢炸掉**：`a = K/(1−K)` 在 K > 1（重载叶梢）产生负感生速度并被限幅，
   残差卡在 1.0、K_T(J) 非单调。改为**对入流角 φ 二分**（一次解全部叶元，200 次向量运算），
   残差降到 1×10⁻¹¹。另校正两处动量系数：轴向 `a/(1+a) = σCn/(4F sin²φ)`、切向 `a'/(1+a') = σCt/(4F sinφcosφ)`
   （推导时漏掉 `1−a'` 会让扭矩差 (1−a') 倍）。
3. **舵进流漏了桨尾流收缩 η = (D/h_R)²**：少了它，船在回转掉速时 C_T = 8K_T/(πJ²) 暴涨，
   加速因子平方放大到 ~10 倍，舵阻力把船刹停、仿真溢出。补 η 后 u_R/u = 0.92 量级合理。
4. **锚点低于粘性链**：锚 C_T = 4.00×10⁻³ < (1+k)C_F = 4.285×10⁻³，波浪项必为负。
   本模块不掩盖：波浪项置零 + 打旗标 + 报出 shortfall（2.85×10⁻⁴），提示锚值/形状因子/摩擦线三者之一有 ≥7 % 问题。
5. **零漂角线性化把阻尼吃掉**：二次横流阻力在 v = 0 处导数为 0，因此**零漂角**导数集 N_r' = +0.0004（无阻尼），
   回转瞬时过度、之字超越角 37.8°。改用**操纵点（v' = −0.13, r' = 0.22）有效导数**后 N_r' = −0.022，仍偏小；
   真正的阻尼来自艏艉两端载荷分布，需要 CFD 压力场（见 §5.6）。
6. **2D RANS 舵剖面在粗 C 网格上不可用**：96×32 的 C 网格 + SA、y⁺ ≫ 1，给出 cl 随攻角变负、
   cd = 0.58–0.67（应 ~0.01–0.03）。留证于 `artifacts/rudder_section_cfd.json`。

### 5.2 基准的诚实状态

* 仓内**没有**可溯源的 SIMMAN 2008 操纵性 EFD 表（无原始 workshop 表格、无网络通道）；
* 仓内 `tensorfvm.simman2021_reference` 的导数表已被节点 IN40-N04 审计为自相矛盾（漂移表与导数表差 3.5–6.3 倍、
  附加质量隐含 m22/ρ∇ = 6.6 %），**本节点不把它当基准**；
* 本节点只提供**文献量级带**（D_T/L 2.8–3.8、A_D/L 2.6–3.6、ψ1 4–15°），带 `withheld_band` 旗标，
  落在带内只能称「一致」，不能称「验证」。

### 5.3 模型适用范围

* 直接力模型在 δ ≤ 35°、β ≤ 20° 范围内给出单调、收敛的回转解，可用于趋势/量级判断；
* 之字预报**不可用**（阻尼不足，超越角高 3 倍）——这是模型的确定性缺陷，不是数值问题；
* 阻力链以锚 C_T 定级，自航点转速继承其不确定度（约 ±3 %，主要来自 w 与 C_T）。

### 5.4 已声明的主要假设

| 假设 | 值 | 影响 |
|---|---|---|
| 压力中心 x_p' | 0.25 L（quarter-chord） | 直接决定 N_v、N_r 量级 |
| 横流阻力系数 C_d | 1.2（Hoerner 钝体） | 大漂角侧向力 |
| 附加质量 m_y | 细长体（上界，m_y/m = 1.17） | 主要影响瞬态，非稳态直径 |
| 舵船交互 a_H, x_H', t_R, w_R, γ_R, κ | 0.19, −0.42, 0.28, 0.35, 0.40, 0.60 | 舵力量级（经典 MMG 值，非本节点推导） |
| 舵型值 | 0.18 厚对称剖面、AR = 1.85 | 舵力斜率（Helmbold 2.43 /rad） |
| 推进方式 | 定转速 n（非扭矩调速） | 回转掉速 63 %（偏大） |

### 5.5 下一步（最小可证路线）

1. 用 **3D 体拟合 RANS 静态漂角**（β = 0/±4/±8°，双体）取船身压力场 → 直接得到 Y_v/N_v/Y_r/N_r 与压力中心，
   替换 §5.4 的全部假设；这是补齐 (b)(c)(d) 的唯一现实路径；
2. 舵剖面改用**混合 gmsh 网格 + 壁面加密（y⁺ ≈ 1）**（仓内 NACA 案例已证明可行），再做三点 GCI；
3. 得到可靠导数后重跑 (e) 互裁；当前导数模型发散本身已说明「用零漂角/单点线性化替代非线性力模型」不可行。

| 2D RANS 舵 cl/cd | 物理极线 | cl 变负、cd 高 ~20× | **否** |

**没有基准就声明原因，不含糊**：判据 (b)(c)(d) 需要 SIMMAN 2008 EFD 表，本工作区无该表且无网络通道；
仓内替代表已被 IN40-N04 审计为不可信，故不以「碰巧接近」冒充通过。

## 7. 证据分级汇总

| 能力 | 等级 | 依据 |
|---|---|---|
| 船型几何 Cb/Cwp/LCB/∇ | **REAL** | 三重积分 + 测试断言（偏差 <0.01 %） |
| 阻力链 C_F/(1+k) | **REAL / EMPIRICAL** | ITTC-57 解析线 + Holtrop 回归；锚 residual 带 `withheld` |
| 螺旋桨敞水 K_T/K_Q/η_0 | **REAL（BEMT，自洽验证）** | 叶片元–动量残差 ≤1e-11、Betz 界、几何面积比精确；**无 EFD 敞水表》，不称验证 |
| 自航点 (V, n, τ) | **REAL（闭合）/ EMPIRICAL（w, t）** | 残差 3.6e-11；w、t 为回归 |
| 舵力导数 F_y'δ, M_z'δ | **ANALYTIC + EMPIRICAL 交互系数** | Helmbold 有限展弦比 + Kose 律；a_H 等为经典 MMG 值 |
| 2D RANS 舵剖面 | **FAILED / WITHHELD** | cl 变负、cd 高两个量级、网格未收敛（留证 JSON） |
| 回转/之字度量提取 | **REAL** | 合成轨迹（解析圆/合成之字）反演误差 <0.2° / <2 % |
| 回转 T_D、A_D、A_T（δ=35） | **ENGINEERING MODEL** | 稳态半径路线 3.26 L 落带内；瞬态路线 4.61 L 带外 |
| 之字 ψ1, ψ2 | **NOT SUPPORTED（模型缺陷）** | 37.8° 高 3 倍；根因 = 偏小的首摇阻尼 N_r' = −0.022 |
| MMG 有效导数互裁 | **FAIL** | δ=10°、35° 均发散（边界守卫捕获） |
| 与 SIMMAN 2008 实验对标 | **WITHHELD** | 无溯源基准，见 §5.2 |
