# KVLCC2 PMM 虚拟试验：TensorFVM 运动网格（ALE morphing）能力 —— 进展与审计报告（IN52-N06）

**结论先行（honest verdict）**：本节点交付的是 **REAL 的运动网格（ALE morphing）能力 + 严格数值验证**，
以及 **KVLCC2 双体（double-body）贴体 ALE 网格与 PMM 运动学全周期网格有效性验证**；
**但没有**产出 KVLCC2 的 PMM 水动力导数（Yv、Nv、Yr、Nr、Yv|v|、Nv|v|）。
机器判据 **C1（导数 vs SIMMAN 15 % 带）FAIL、C2（相位 5° 带）FAIL、C3（网格收敛）FAIL**；
几何门 **PASS**，ALE 四个数值判据 **全部 PASS**（数值见下表）。
不达标的根因不是"没做完就跑"，而是**单块 O 网格拓扑不允许开口进出流边界**：
前向速度 PMM 必须有 inlet/outlet，需要多块 H-O 拓扑，本轮未实现；
尝试中的不可压 ALE 投影求解器**未通过它自己的附加质量验证，已整体撤下**（不留"看起来能跑"的假求解器）。

`tensorfvm.pmm_cfd.KVLCC2Hull().calibrate()`（仅用几何形状参数三重二分标定公开积分量），

网格覆盖长度 6.985 m（L 的 99.8 %）。−4 % 的来源是两端在"半宽 = 3 % B/2 站位"处截断
（尖瘦艏艉段未进网格）＋截面包络多边形化，**该残差如实报告、未做任何调参补偿**。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 2.1 新增能力：`moving_mesh.py`（morphing，非 overset）

- **`StructuredCurvilinearMesh`**：单块逻辑矩形有限体积网格，节点坐标 (NI+1, NJ+1, NK+1, 3)，
  支持逐方向周期性；**每步从节点坐标重算全部度量**（面矢、面心、法向距离、单元体积/质心），
  因此不存在"存储度量与网格不一致"这类经典 ALE 缺陷。
- **`ALEGeometry` / `swept_volumes`**：面扫掠体积用**线性运动三角形棱柱的三四面体精确分解**
  （`_(a,b,c,a') + (b,c,a',b') + (c,a',b',c')`），保证离散**空间守恒律（Demirdžić & Perić 1988）**：
  `Σ_faces dV_face ≡ V(new) − V(old)`，对平移/旋转/morphing 均成立。
- **`ale_advection_residual`**：ALE 对流项取**散度形式**
  `(V^{n+1}φ^{n+1} − V^nφ^n)/Δt + Σ_f (u_f − u_mf)·S_f φ_f`；
  因为 `Σ_f u_mf·S_f ≡ dV/dt`（上一条的直接推论），均匀场残差**精确为零**（自由流保持）。
- **`morph_nodes`**：混合刚体运动——物面层 (w = 1) 严格刚体平移 + 绕舯竖轴刚体旋转，
  远场 (w = 0) 固定，中间层按 `(1−s)^2` 吸收变形；平移与转角用**同一个**混合因子，
  保证物面不相对流体"滑动"。
- **`ale_scalar_step`**：隐式扩散 + 显式迎风的标量 ALE 步（守恒、自由流保持、Galilean 不变）。
- **`build_cylinder_ogrid` / `build_kvlcc2_double_body_ogrid`**：解析 O 网格生成器；
  船体截面 = **双体截面**（水线下船体 + 关于水线面的镜像，即 Fn→0 刚性盖/双体模型），
  外边界为矩形远场（|y| = 0.5L、|z| = 0.4L），径向几何拉伸（首层 0.4 %、比 1.15）。

### 2.2 PMM 运动学

`PMMKinematics` 给出 pure sway / pure yaw / static drift 的位姿与速率
（sway/δsway_rate、yaw/yaw_rate），`pose(t)` 的振幅-相位关系在测试里逐条核对
（sin 峰位、速率峰位相差 90°、drift 常值角且角速率为零）。

### 2.3 工具链与验证口径

Python 3.11 + NumPy 2.4（几何/度量）、SciPy 1.16（稀疏线代）、pytest 8、Ruff 0.15（lint 门）、
matplotlib（出图）。pytest 判据写在测试里（容差随断言逐条给出），
`scripts/pmm_ale_artifacts.py` 把同一代码路径跑一遍并**程序化注入** JSON 与图，
报告数字零手抄。

### 2.4 本轮**未**交付的部分（并已撤下）

不可压 ALE 投影求解器（分步法 + 压力 Poisson）曾实现并试跑：
圆柱受迫横荡的**附加质量**验证（解析基准 ρπa²·L_span）未通过——投影步在共位网格上
出现奇偶失耦（压力 Poisson 的棋盘零空间与单元梯度算子不匹配），速度修正反而放大散度，
若干步内发散。按"不留未验证求解器"的纪律，**该模块与其验证脚本已从分支删除**，
仅在此如实记录。要闭合它需要 face-flux 形式 + Rhie–Chow 插值（约再一轮工作量）。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **拓扑硬约束**：单块 O 网格只能覆盖"船体 + 两端封盖"，封盖面法向为 ±x 且关于 y 对称，
   故只影响纵向力、对 Y/N 一阶无贡献；但**前向速度不存在**（无 inlet/outlet）。
   真正的 KVLCC2 PMM 必须多块 H-O（或重叠网格）—— 这是下一节点的第一件事。
2. **不再是条带理论**：与上一节点不同，本轮的运动网格是**三维真实贴体 + ALE**，
   只是**没有流场求解器**；两者不可混为一谈。
3. **双体/刚性盖假设**：Fn = 0.142 下忽略自由面抬升，只保留水线面对称性（双体模型）。
   对操纵导数的一阶影响通常 <5 %，但没有本轮的数值证据证明这一点（WITHHELD）。
4. **尖端截断**：网格在"半宽 = 3 % B/2"处截断，`n_radial > 10` 会在截断站位出现退化面
   （构建器抛 `non-positive face normal distance`）—— 生产网格需要专门的艏艉极区处理。
5. **面板/单元级 vs 总体 GCL**：首摇 morphing 下单元级 GCL 残差非零（1.9e−5）但总体精确；
   这是非平面四边形面的三角化口径问题，数值上是被控制的，但不能宣称"处处机器精度"。
