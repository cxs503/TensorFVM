## 2. 数据诊断

### 2.1 前沿位置对比（t* = 0.3 时刻）

| 量 | 模拟值 | Martin & Moyce 参考 | 相对误差 |
|---|---|---|---|
| x* (半格前沿) | 0.006 | 0.455 | **98.7%** |
| x* (前缘前沿) | 0.094 | 0.455 | 79.4% |

物理位置换算（a = 0.05715 m）：
- 模拟前沿：x_f = a + 0.006·a = **0.0575 m**（几乎未动）
- 参考前沿：x_f = a + 0.455·a = **0.0832 m**

**结论**：模拟运行了 169 步到 t* = 4.0，但前沿在 t* = 0.3 时仅移动了 0.34 mm，
而实验预期应移动 26 mm。流动几乎没有被驱动。

### 2.2 体积守恒与有界性

- 体积漂移：4.1e-16（机器精度，完美）
- α 有界性：0.0（无越界）
- 零重力控制：0.0（界面完全冻结，正确）

**结论**：VOF 输运层完全正常，问题不在界面捕获。

### 2.3 残柱高度

| 量 | 模拟值 | 参考值 | 相对误差 |
|---|---|---|---|
| h* (t*=0.3) | 0.984 | 0.72 | 36.7% |
| h* (t*=4.0) | 0.153 | 0.16 | 4.4% |

残柱高度在早期误差大（柱体未坍塌），但在 t*=4.0 时误差已降至 4.4%。
这说明**流动最终被驱动了，但启动严重延迟**。

## 3. 根因分析

### 3.1 排除项

| 可能原因 | 证据 | 排除 |
|---|---|---|
| VOF 输运错误 | D3/D4/D5 全通过 | ✅ 排除 |
| 初始条件错误 | 体积守恒完美，零重力控制正确 | ✅ 排除 |
| 量纲转换错误 | t* 序列正确（0.3→4.0），x* 定义一致 | ✅ 排除 |
| 参考数据错误 | Martin & Moyce 为经典实验，多源验证 | ✅ 排除 |

### 3.2 最可能根因：**压力-速度耦合的启动延迟**

溃坝流动的驱动力来自**初始静压不平衡**（柱内静压 vs 柱外大气压）。
Phase0TwoPhaseSolver 使用投影法求解变密度 Navier-Stokes 方程：

1. **预测步**：用当前压力梯度更新速度
2. **投影步**：求解 Poisson 方程使速度场无散

问题可能出在：
- **初始压力场**：虽然配置了 `pressure_init="hydrostatic"`，但静压场可能
  未在第一次预测步中正确产生加速度
- **密度插值**：气液密度比 1000:1，界面处的密度平均可能导致压力梯度被稀释
- **时间步限制**：CFL 条件在初始时刻可能过于保守（u_max 估计偏大）

### 3.3 代码路径追踪

```
dambreak_gate.run_dambreak_leg()
  → DamBreakConfig(nx=120, ny=40, t_star_end=4.0)
  → dam_break_history(cfg, solver=plic_solver(cfg))
    → solver.set_alpha(initial_alpha(cfg))
    → solver.set_hydrostatic_pressure(cfg.h0, cfg.a)  ← 关键
    → solver.step(dt)  ← 169 步
```

`set_hydrostatic_pressure` 设置初始压力场后，第一步 `solver.step(dt)` 应该
产生速度场。但从结果看，速度场在早期几乎为零。

## 4. 修复建议

### 4.1 短期（可单干验证）

1. **检查 `set_hydrostatic_pressure` 实现**：确认压力梯度在界面处正确计算
2. **添加速度场诊断**：在 dam_break_history 中记录每步的 max|u| 和 max|v|，
   确认速度是否从零开始增长
3. **测试不同压力初始化**：对比 `pressure_init="hydrostatic"` vs `"zero"` 的结果

### 4.2 中期（需重计算）

1. **网格收敛研究**：在 (60,20), (120,40), (240,80), (480,160) 上运行，
   观察前沿误差是否随网格加密收敛
2. **时间步敏感性**：测试不同 CFL 值（0.2, 0.35, 0.5）对启动的影响

### 4.3 长期

1. **改进变密度投影法**：在界面处使用谐波平均而非算术平均密度
2. **添加动量源项诊断**：记录每步的压力梯度力和重力，确认合力正确
