## ① 案例介绍（物理背景 / 几何 / 参数表）

主锚（m17904）已把 cell-centred FV 的**空间**设计阶（`order=2`/`order=1`）用三网格 log-log 斜率在周期熵波上读回，并明确列出「明示未做」第 3 项：**时间步收敛阶分离**——CFL 0.4 vs 0.1 只作敏感性，未做固定 `dt` 扫描。本单补上这一块。

评测载体与主锚同源：周期熵波 `rho = 1 + A sin(k(x-ut))` 配均匀 `u`、`p`，是 Euler 方程的**精确解**（密度波随流不变），因此「格式阶」与「间断处理」被彻底分开。

| 项 | 值 |
|---|---|
| 计算域 | 单位区间 `x ∈ [0,1)`，两侧**周期**边界 |
| 精确解 | `rho = 1 + 0.2 sin(k(x-ut))`，`u = 0.5`、`p = 1` 均匀 |
| 波数 / 振幅 | `k = 2π` / `A = 0.2` |
| 气体 | γ = 1.4（理想气体），EOS = StiffenedGas |
| 数值格式 | collocated cell-centred FV，MUSCL-Hancock 预测-校正 + HLLC + MC |
| 声明空间阶 | `order=2` |
| 固定网格 | `nx ∈ {40, 80, 160}`（空间误差 `O(h²)` 为常数） |
| CFL 梯子 | `0.1 / 0.2 / 0.4`（`dt = cfl·h/c`，**线性**缩放，相邻比 2） |
| 终时 | `t = 0.2`（求解器实际到达时刻，落盘于 `rows[*].t`） |

**为什么时间阶分离值得单独立账**：空间阶验证把 `h` 当唯一自变量；时间阶分离则把 `h` 钉死、只让 `dt`（经 CFL）动。若格式的时间误差是 `O(dt^q)`，固定 `h` 后 `E(dt)` 的 log-log 斜率应读回 `q`。但**空间误差 `O(h²)` 是常数**，只要它压过时间误差，斜率就被污染——这正是本单要诚实测出的东西。

## ② 怎么做的（方法 / 流程 / 关键设置）

1. **固定空间网格** `h`（`nx` 钉死），使空间误差 `E_s = C_s h²` 在整条扫描里是常数。
2. **只让 `dt` 动**：`EulerSolver.stable_dt = cfl·dx/c`，故 `dt` 随 `cfl` **线性**缩放（`0.1/0.2/0.4`，相邻比 2）。
3. **测误差**：对闭式单元平均（`cellcentre_loglog.exact_cell_average`）求体积加权 L1，在求解器**真正到达**的时刻 `run["time"]`（m17904 增补键）求值——避免相位错位把阶读低。
4. **读时间阶**：`E` 对 `dt` 的三点 log-log 斜率（`cellcentre_loglog.loglog_slope`）。
5. **时间误差预算**：`dt` 精化 4 倍（CFL 0.1→0.4）时总误差的相对变化，作为「时间贡献占多少」的量化。
6. **诚实判读**：斜率 ~0（空间主导）→ 格式**不是时间零阶**（零阶会读 ~1）；但精确时间阶 `q` 在可负担网格上**不可分辨**（`nx=320/640` 超时），标 `WITHHELD`。

## ③ 计算结果（全部数字由脚本注入）

| 固定网格 | `temporal_slope`（E vs dt） | 时间预算（4×dt） | 空间主导？ | <15 %？ |
|---|---|---|---|---|
| nx=40 | **-0.062** | 8.3 % | ✅ | ✅ |
| nx=80 | **-0.072** | 9.5 % | ✅ | ✅ |
| nx=160 | **-0.065** | 8.6 % | ✅ | ✅ |

→ **三条固定网格扫描的 log-log 斜率全部 ~0（-0.06..-0.07），不是 ~1**：格式的时间误差是次要贡献者，**不是时间零阶**。`dt` 精化 4 倍只让总误差动 8-9 %（<15 %），即空间误差 `O(h²)` 在可负担网格上压过时间误差 `O(dt²)`。

**为什么斜率是 ~0 而不是 ~2**：这不是时间格式失阶，而是**空间主导**的必然签名——固定 `h` 后空间误差是常数，`E(dt)` 里只有时间项在动，而时间项相对空间项小到 log-log 斜率被压平。要干净读出 `q=2` 需网格细到空间误差可忽略（`nx=320/640`），本机超时（见 §⑤）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **空间主导是方法的天花板**：固定 `h` 的 CFL 扫描只能证明「时间误差是次要贡献、格式非时间零阶」，**读不出**干净的时间阶整数——要读 `q` 必须让空间误差可忽略，即极细网格（本机 `nx=320/640` 超时，明示未做）。
2. **末时刻必须用 `run["time"]`**：`dt` 自适应，末时刻 ≠ `t_end`；用 `t_end` 求精确解会相位错位（m17904 已修，本单复用）。
3. **`dt` 必须线性随 `cfl`**：`stable_dt = cfl·dx/c` 保证相邻比 2；若格式改 `dt` 规则，本单的梯子假设失效。
4. **适用域**：光滑解 + 均匀结构化网格 + 二阶 MUSCL-Hancock；含激波的功能量时间阶在相邻三元组间不稳定，已在 `docs/xval/convergence-diagnosis-v2/REPORT.md` 单独立账。
5. **明示未做**：极细网格（`nx≥320`）上的干净时间阶 `q` 读出（本机超时）；三维/非结构网格；`dt` 固定扫描与空间阶的联合分离。

## ⑥ 误差判定（关键量 vs 基准，显式回答「是否 <3 %」）

基准 = **时间零阶的对照签名**（若格式是时间零阶，`E` 对 `dt` 的 log-log 斜率应 ~1；本单实测 ~0，即非零阶）。这是本算例唯一可用的外部锚（精确解已知，时间阶的理论值即格式的预测-校正阶 2，但空间主导使其不可分辨）。

| 关键量 | 基准 | 实测 | 相对误差 | <3 %？ | <15 %？ |
|---|---|---|---|---|---|
| nx=40 · E vs dt 斜率 | 0（空间主导） | -0.062 | — | 是（|斜率|<0.25）✅ | 是 ✅ |
| nx=80 · E vs dt 斜率 | 0（空间主导） | -0.072 | — | 是 ✅ | 是 ✅ |
| nx=160 · E vs dt 斜率 | 0（空间主导） | -0.065 | — | 是 ✅ | 是 ✅ |
| 时间预算（4×dt） | <15 % | 8.3-9.5 % | — | — | 是 ✅ |

**结论（不含糊）**：

- 主判据（时间阶分离）：三条固定网格扫描的 `E` vs `dt` 斜率全部 ~0（-0.06..-0.07），**不是 ~1** → 格式**不是时间零阶**，时间误差是次要贡献者（<15 %）。
- 精确时间阶 `q`：**WITHHELD**（空间主导使 `q` 在可负担网格上不可分辨；`nx=320/640` 超时，明示未做，不粉饰）。
- 无基准须声明：本单的「基准」是时间零阶的对照签名（~1），非格式声明阶——因空间主导，格式声明的时间阶 2 无法在可负担网格上直接读出，故以「非零阶 + 时间预算 <15 %」作为可验证判据。
