## ① 案例介绍（物理背景 / 几何 / 参数表）

被验证的对象**不是**某个新算例，而是「怎么给一个 cell-centred 有限体积解读出观测收敛阶」这一动作本身。评测载体取周期熵波：`rho = 1 + A sin(k(x-ut))` 配均匀 `u`、`p` 是 Euler 方程的**精确解**（密度波随流不变，无压力耦合、无激波），因此「格式阶」与「间断处理」被彻底分开，误差序列就是格式设计阶的干净读数。

| 项 | 值 |
|---|---|
| 计算域 | 单位区间 `x ∈ [0,1)`，两侧**周期**边界 |
| 精确解 | `rho = 1 + 0.2 sin(k(x-ut))`，`u = 0.5`、`p = 1` 均匀 |
| 波数 / 振幅 | `k = 2π`（一个波长铺满域）/ `A = 0.2` |
| 气体 | γ = 1.4（理想气体），EOS = StiffenedGas（双空气组分） |
| 终时 | `t = 0.2`（求解器实际到达时刻，落盘于工件的 `rows[*].t`） |
| 数值格式 | collocated cell-centred FV，MUSCL-Hancock 预测-校正 + HLLC 通量 + MC 限制器 |
| 声明阶 | `order=2`（主）与 `order=1`（对照） |
| CFL | 0.4（主）与 0.1（CFL 敏感性） |
| 网格 | 40/80/160（主三元组）、80/160/320（细三元组）、50/100/175（非均匀）、10/20/40 与 20/40/80（粗三元组对照） |

**为什么 cell-centred 这件事值得单独立账**：FV 的未知量是**单元平均** `u_h = (1/|V|)∫ u dV`，不是格心点值。`|V| = 1/nx` 的单元上，闭式平均为

```
avg_i(u) = 1 + A[cos(k(a_i-ut)) - cos(k(b_i-ut))] / (k h),   a_i = i h, b_i = a_i + h
```

用格心点值 `u(x_c)` 代替它，等于给误差额外注入限制误差 `avg - u(x_c) = -(h²/24) u'' + O(h⁴)`——**同为 O(h²)**，于是它既能把二阶格式的误差常数抬高，也能把任何 >2 阶的读数**压在 2 以下**（本单 §③D 实测）。

## ② 怎么做的（方法 / 流程 / 关键设置）

1. **精确解两个面**：闭式单元平均（上式）与格心点值都由 `cellcentre_loglog` 程序给出；闭式平均与 256 子格中点求积互校到 `1e-7`，且整周期平均恰为 1（`1e-14`）。
2. **三种估计器，同一批误差序列**（都是「三网格 log-log 斜率」的做法，但用三种等价/近似等价的口径，互相校验）：
   - `p_loglog`：`ln e` 对 `ln h` 的三点最小二乘斜率（教科书 log-log 图斜率）；
   - `p_adjacent`：相邻两网格对 `ln(e_i/e_{i+1})/ln(h_i/h_{i+1})`；
   - `p_richardson`：`tensorfvm.verification.richardson.observed_order`，即对非均匀网格比也成立的**精确三网格解**（求解 `(e3-e2)/(e2-e1)` 的超越方程）。
3. **两种度量**：`cell_average`（对闭式单元平均求误差，FV 的正确口径）与 `point`（对格心点值求误差，采样偏置口径），另把**采样偏差本身** `point - avg` 作为第三条序列。范数一律体积加权：`L1 = Σw|e|`、`L2 = sqrt(Σw e²)`、`L∞ = max|e|`。
4. **五条梯子 + 三条对照梯子**（见 §① 表）：覆盖设计阶 2/1、均匀/非均匀网格比、CFL 0.4/0.1、以及「粗到非渐近」的 10/20/40。
5. **两个负对照**（证明度量与估计器「会出错」，而不是只会点头）：
   - **采样地板**：合成单元场 `u = avg + c h^p sin(k(x-ut))`，真阶 `p ∈ {2,3,4}`、系数 `c ∈ {1,10}`。cell-average 度量必须读回 `p`；格心度量对 `p>2` 必须读成 ≈2。
   - **均匀比陷阱**：非均匀梯子 `50/100/175`（`r21=1.75`、`r32=2.0`）上，教科书单 `r` 公式 `|ln(e21/e32)|/ln r` 与精确三网格解对比。
6. **渐近区门**：Celik et al. (2008) 的 eq. (17) 在「p 由同一三元组算出」时是恒等式，没有鉴别力；本单用**重叠三元组一致性**（两套三元组独立求 p，相对差 ≤15 %）代替，并对全部 6 个 (度量, 范数) 组合各报一次。
7. **闸门**：`tests/test_cellcentre_loglog_order.py`（26 个用例，17 s）锁住度量代数、负对照、以及求解器实际阶；驱动与工件分离（`run_study.py` → `artifacts/study.json` → 本文件由 `render_report.py` 渲染）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **末时刻必须用求解器真正到达的时间**：`EulerSolver.run(t_end)` 的 `dt` 是自适应的，末时刻不一定等于 `t_end`；本单给 `run_smooth_wave` 增补了 `time` 键（纯增量），否则精确解相位错位会把阶读低——这是最容易「静默出错」的一处。
2. **`avg` 与 `point` 的差别不是小量**：`nx=160` 时等于 38 % 的误差量级（§③C），且随 `h²` 同步衰减，因此**看起来收敛得很好**但读数偏高 2–6 %。
3. **范数选择比 ±0.05 的拟合技巧重要得多**（§③B）：L1 读 2.04、L∞ 读 1.68，同一份解。任何「阶」的结论必须写清范数与度量。
4. **一致性门有盲区**：15 % 带下它放行了偏差 9.2 % 的粗三元组（§③F），因此门只能筛掉「明显出区」，标定仍须与设计阶直接比。
5. **非均匀网格比**：`r21≠r32` 时单 r 公式不可用（阶偏差 34 %/53 %），必须用 `richardson.observed_order` 的超越方程解。
6. **适用域**：结论针对**光滑解 + 均匀/规则结构化网格 + 二阶 MUSCL-Hancock**；含激波的功能量（波位置/平台窗）阶在相邻三元组间本身不稳定，已在`docs/xval/convergence-diagnosis-v2/REPORT.md` 单独立账，本单不复用其结论。网格为非均匀尺寸时 `error_norms` 支持体积权重，但本仓 `EulerSolver` 只吃均匀网格，故此项仅由单元测试覆盖，未在求解器上实测（明示未做）。
7. **明示未做**：>2 阶格式的真实求解器验证（本单只用合成场证明地板效应）；三维/非结构网格；时间步收敛阶分离（CFL 0.4 vs 0.1 只作敏感性，未做 `dt` 固定扫描）。

## ⑥ 误差判定（关键量 vs 基准，显式回答「是否 <3 %」）

基准 = 格式**声明阶**（`order=2` / `order=1`），这是本算例唯一可用的外部锚（精确解已知，观测阶的理论值即设计阶）。

| 关键量 | 基准 | 实测 | 相对误差 | <3 %？ | <15 %？ |
|---|---|---|---|---|---|
| order2_uniform · cell_average/l1 的观测阶 | 2.0 | 2.0369 | 1.84 % | 是 ✅ | 是 ✅ |
| order1_uniform · cell_average/l1 的观测阶 | 1.0 | 0.9754 | 2.46 % | 是 ✅ | 是 ✅ |
| order2_fine · cell_average/l1 的观测阶 | 2.0 | 2.0609 | 3.05 % | 否 ❌ | 是 ✅ |
| order2_nonuniform · cell_average/l1 的观测阶 | 2.0 | 2.0081 | 0.40 % | 是 ✅ | 是 ✅ |
| order1_nonuniform · cell_average/l1 的观测阶 | 1.0 | 0.9791 | 2.09 % | 是 ✅ | 是 ✅ |
| order2_cfl010 · cell_average/l1 的观测阶 | 2.0 | 2.0342 | 1.71 % | 是 ✅ | 是 ✅ |
| order2_uniform · point/l1 的观测阶 | 2.0 | 2.0773 | 3.86 % | 否 ❌ | 是 ✅ |
| order2_uniform · cell_average/l2 的观测阶 | 2.0 | 1.7901 | 10.50 % | 否 ❌ | 是 ✅ |
| order2_uniform · cell_average/linf 的观测阶 | 2.0 | 1.3973 | 30.13 % | 否 ❌ | 否 ❌ |

**结论（不含糊）**：

- 主判据（`order2_uniform`，cell-average/L1）：观测阶 2.0369 vs 设计阶 2，偏差 1.84 % → **<3 % 成立**。
- 一阶对照：0.9754 vs 1.0，偏差 2.46 % → **<3 % 成立**。
- 细网格梯子 `80/160/320`：偏差 3.05 % → **>3 % 但 <15 %**（诚实记录，不粉饰：三点拟合在细梯子上并不必然更准）。
- L∞ 范数：偏差 30.13 % → **>15 %，判 FAIL**；该 FAIL 归因于限制器局部降阶被 L∞ 放大，非格式整体失阶（L1/L2 同解均 <15 %）。
- 六条设计阶梯子 <15 % 全通过：`True`；<3 % 全通过：`False`。
