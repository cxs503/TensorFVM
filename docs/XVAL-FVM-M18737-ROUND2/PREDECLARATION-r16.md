## 0. 欠账来源与本轮要回答的问题

`W1-NORM-CERTIFICATION.md`「给下一手」第 3 条（= 欠账账 D21 的「下一手可检验预测」，
判据在 `PREDECLARATION-r7.md` / `PREDECLARATION-r10.md` 的 **E2** 中冻结）：

> 若残差是净质量通量缺陷，那么在更细的参考上 `max|D|` 应精确按 `h^1` 收缩
> （R5 单 0.004509→0.002352→0.001078，比值 1.917/2.181）。若 WENO5@25600 回填后
> 该比值仍显著偏离 2，则说明残差里混入了非 `O(h)` 成分，需重新归因。

参考阶梯并过 E1r6400 入场门），但 **E2 本身从未被测量**。本轮把它测掉。

## 3. 机械口径（与 R5/R7 完全一致，不重新定义）

1. `max|D|`、`w_eff`、`rel_net_mass` 一律调用 `wc_w1_norm.localize`（同一份实现）。
2. `d_W1` / `d_L1` 一律调用 `wc_w1_percent` / `d_l1_percent`（同一份实现）。
3. 观测阶 `p = log2(d_粗/d_细)`；不引入 GCI 安全系数。
4. 求解器一行不改；本轮**零新算力**（全部由已存 npz 重新积分）。
