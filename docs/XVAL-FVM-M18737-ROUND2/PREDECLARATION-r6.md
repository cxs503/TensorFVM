## 为什么需要这一轮

`CERTIFIED-REF-CLOSURE.md`：MUSCL/HLLC@3200 vs WENO5@12800，L1 = **1.776 %**（>1 %，honest FAIL）。
`REF-ATTRIBUTION.md` 能给出的参考侧地板只是**同族**差 `WENO5@12800 vs WENO5@6400 = 0.548 %`，
它测的是「参考族还在动多少」，**不能**回答「参考族的极限离被定级解有多远」——同族加密总是收敛到
同一个（可能带偏的）极限。
`R4/R5` 两轮把这条写成了「下一手」：在接触间断/平台区，均匀加密收益递减（观测阶 0.81 < 1），
真正的替代路线是**换重建阶**而非换网格。`xcode/wc_weno7.py` 已就位（7 阶、系数推导非抄写、
熵波观测阶 6.00），但从未在 blast 数据上跑过。本轮把它跑成阶梯，并回答一个二选一：

* 若被定级解对 **WENO7** 的残差仍 >1 % ⇒ 1.776 % 主要是**被定级侧**的，certified<1 % 换参考不能解决；
* 若残差掉到 <1 % ⇒ 1.776 % 主要是**参考侧**的，则 certified<1 % 是被参考族抹平带（O(h) 常数）
  而非被定级解的二阶精度卡住的。

## 预测（Q1–Q6，逐条量化）

阶的机制依据：含激波/接触间断的 L1 误差 ∝ h^p，p < 1 由抹平带宽度（以**格数**计）与位置误差
共同决定。提高重建阶主要**缩小抹平带占用的格数**（WENO5 约 5 格、WENO7 约 7 格但色散更小、
有效抹平带按 3200 档实测峰值 6.4401 vs 6.4722 更高可推更窄），故预计**常数**下降、
**阶 p 不变**（仍 ~0.8–1.0）。

| 编号 | 量 | 点预测 | 冻结带 | 机制 |
|---|---|---|---|---|
| Q1 | WENO7 自认证阶梯的观测阶 p（用最细一对 3200→6400） | 0.85 | [0.60, 1.20] | 抹平带主导，阶 p 不随重建阶变；低于 0.6 说明 WENO7 在 blast 数据上被正性/限幅回退污染 |
| Q2 | 同网格跨阶差 L1(WENO7@3200 vs WENO5@3200) | 1.20 % | [0.60, 3.00] | 同分辨率下参考截断误差按常数缩，量级应与 WENO5 自认证 3200→6400（0.9554 %）同量级或更大 |
| Q3 | WENO7@6400 的自身不确定度 `U_ref^W7(6400)` = ½·L1(W7@3200 vs W7@6400) | 0.40 % | [0.15, 0.60] % | 必须 **小于** WENO5 的 `U_ref(12800)`=0.7181 %，否则「换阶更高效」这条动机不成立 |
| Q4 | **决定性**：L1(MUSCL@3200 vs WENO7@6400) − L1(MUSCL@3200 vs WENO5@12800)，即参考侧份额 | −0.45 pp | [−0.80, −0.10] pp | 参考侧地板 0.72 %→0.40 %，被定级侧误差不变 ⇒ 差值应约等于两参考不确定度之差的一半到全额 |
| Q5 | L1(MUSCL@3200 vs WENO7@6400) 的诚实上界（点估计 + `U_ref^W7(6400)`）是否 <1 % | 否（≈1.6–1.9 %） | 判据：**certified 仍 False** | 被定级解的 1.78 % 中若最多 0.5 pp 属参考侧，余量不足以跨过 1 % |
| Q6 | 峰值差相对改善：peak(MUSCL@3200 vs WENO7@6400) ÷ peak(MUSCL@3200 vs WENO5@12800)=0.758 % | 0.85 | [0.50, 1.10] | 峰值收敛快（WENO5@6400 vs 12800 只差 0.023 %），故换 WENO7 对峰值几乎无影响 ⇒ 比值应 ≈1 |

## 失败/回退纪律（预先声明）

1. 若 WENO7 在 6400 档未产出（超时/OOM/非有限值），Q1/Q3/Q4/Q5/Q6 记 **not_measured**，
   绝不改写为 PASS，也绝不用 WENO5 的数字顶替。
2. 若 `positivity_fallbacks` 在任一档 >1 % 的步数占比，则该档的解**降级为诊断用**，
   不作为定级参考（回退上限阶的守恒性以此为准）。
3. 判定「WENO7 是可信参考」需要它自己的自认证 <1 %（同 WENO5@12800 的口径）；
   若 WENO7 自认证 >1 %，则即使被定级解残差变小，也只能报「上限」，不得报 certified。
4. 本轮的「certified」口径**不放松**：`certified = 参考自认证<1% ∧ 地板移除 ∧ 被定级解<1%`

## AMENDMENT 1（冻结后、测量前：Q3 的定义错误修正）

**时刻**：调度作业 `cj3733`（WENO7@1600,3200,6400）状态仍为 `queued`，**未开始**；
worktree 内 `ladder_profile_nx*_weno7.npz` 仍为 0 个（仅一次 `nx=400` 的冒烟运行，见下）。

**发现的问题**：Q3 原文把 `U_ref^W7(6400)` 写成 `½·L1(W7@3200 vs W7@6400)`，
这是我自己临时造的比例；代码里的既有约定（`wc_ref_uncertainty.u_ref_from_pair`）是

```
U_ref = e_selfcert / (2**p − 1)        # p 为观测阶；p≈0.85 时 2**p−1 ≈ 0.80 ⇒ U_ref ≈ 1.25·e
```

两者差 2.5 倍。冻结时我没想到要看这个约定就写数——属**定义错误**，不是数据驱动的改动
（Q3 的两个输入 3200/6400 档当时都不存在）。按「未中不改判据、但定义错误必须留痕修正」
的原则，此处只改**量的定义与由此推出的带**，Q1/Q2/Q4/Q5/Q6 一字不动。

**修正后的 Q3**：`U_ref^W7(6400)` ≡ `u_ref_of_reference(DATA, 6400, "weno7")` 的数值。

**带的机械推导**（只用冻结时点已存在的数字）：`nx=400` 冒烟跑显示峰值亏损
WENO5 12.0 %（5.689/6.46）vs WENO7 4.9 %（6.147/6.46），即同网格下 WENO7 的间断误差常数
约为 WENO5 的 1/2.4。若 L1 的常数改善相同量级（1.5–2.0×），则
`e_W7(3200→6400) ≈ 0.9554 % / 1.5…2.0 = 0.48…0.64 %`，
代入 `U_ref = e/(2^0.85 − 1)` 得 **0.60…0.80 %**。故

| 编号（修正） | 量 | 点预测 | 冻结带 |
|---|---|---|---|
| Q3' | `U_ref^W7(6400)` [%] | 0.69 | **[0.30, 0.95]** |

原文的 [0.15, 0.60] 作废并保留于此以便对账（不删）。Q3 的**动机判据**不变：
若 WENO7@6400 的 `U_ref` 不低于 WENO5@12800 的 0.7181 %，则「换阶比加密便宜」不成立。
