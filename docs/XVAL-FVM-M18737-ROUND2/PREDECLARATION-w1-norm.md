## 新度量的定义（冻结）

对窗口 `[0.4, 1]`（长 `L = 0.6`），把粗网格剖面线性插值到细网格上（与前轮
`l1_percent` 同方向，避免细剖面被抹平），令差值 `e = ρ_c − ρ_f`：

| 记号 | 定义 | 含义 |
|---|---|---|
| `d_L1` | `100·∫|e| dx / ∫|ρ_f| dx` | 前轮的逐点相对 L1（% ） |
| `D(x)` | `∫_{0.4}^{x} e dx'` | 累计（通量）差 |
| `d_W1` | `100·∫|D| dx / (mass_f · L)`，`mass_f = ∫_{0.4}^{1} ρ_f dx` | 归一化 CDF 的 W1 距离，以窗长为单位（%） |

`d_W1` 即负范数 `s = −1` 的误差（Banks & Hittinger 型 negative-norm 估计），
在 1D 守恒律里等价于**归一化 CDF（累积质量分布）的 W1 距离**，物理读作
「剖面整体被搬错了多长的距离」。它也直接给出**激波位置误差的等价上界**
（1D 中阵面位移 ≤ W1）。

**数学不变式（可机检）**：`∫|D| ≤ L·∫|e|` ⇒ **`d_W1 ≤ d_L1`** 恒成立。
若实测违反，说明实现有 bug（不是物理结论）。

**诚实边界**：`d_W1 < 1 %` 是**较弱**的声明——它说的是「质量分布被搬错不超过窗长的 1 %」，
**不是说**逐点值误差 <1 %。逐点 L1 与 `d_W1` 必须双报；只有两者都成立才可称点态收敛。

## 预测（冻结，先于任何计算）

理论期待：激波主导解中，L1 误差由「抹平带宽度 × 幅值」主导（`O(h)`），
而累计量 `D` 把带内误差积掉，故 `d_W1` 应比 `d_L1` 多约**一阶**。

| id | 判据（冻结） | 理由 |
|---|---|---|
| P1 | 参考族 `p_W1(6400 vs 12800 对 3200 vs 6400)` ∈ **[1.3, 2.6]**，且 `p_W1 ≥ p_L1 + 0.5` | 负范数增益一阶；带宽给 ±0.5 容差 |
| P2 | `eps_ref_W1(@12800) ≤ 0.20 %`（即比 L1 的 0.7076 % 至少小 3.5×） | 同上，`eps = d/(2^p−1)`，p≈1.8 ⇒ 除 2.5，`d` 本身也降一档 |
| P3 | 被定级 `d_W1(nx=6400 vs WENO5@12800) ≤ 0.30 %` | 逐点 0.8931 % 降一阶量级 |
| P4 | **诚实上界** `d_W1(6400) + eps_ref_W1 < 1.0 %` ⇒ 该范数下 **certified < 1 %** | 总账 `<1 %` 只有在**可证明**时才算 |
| P5 | 同时 `d_L1(6400) 与 d_L1(3200)` 仍 **> 0.5 %** | 防「换度量当免费午餐」：弱范数不改善逐点 |
| P6 | `d_W1 ≤ d_L1` 对**所有**被检对成立（含 p、u 两个变量） | 数学不变式，违反=实现缺陷 |
| P7 | 积分方向敏感度 `|d_W1^fine − d_W1^coarse| ≤ 0.25·d_W1` | 与 R4 的 `interp_sensitivity` 同口径 |
| P8 | `d_W1(nx)` 对固定参考 WENO5@12800 **单调下降**（800>1600>3200>6400） | 度量必须是收敛量 |
| P9 | 压力 `p`、速度 `u` 的 `d_W1` 与 ρ 同量级（差 ≤ 5×），不出现单变量偶然 | 防「ρ 碰巧小」 |

**判据若失败，如实记 FAIL，不调阈值、不改定义。** P4 若失败，则本路线不能收口，
须回到 R4 的结论（需要 `nx_ref≈1.33e5`）并在报告中写明。
