## 0. 为什么走第三条路线（不改判据，换成本路线）

round-5 起悬空的欠账是：扩展参考档 `WENO5@25600` 算不回来（`cj3710` 8 天未回）。
round-7 的办法是**放松时间步**（CFL 0.8，`steps ∝ 1/CFL`），代价是需要一个「仪器等价性」入场门
E1。round-7 自己的 A0 先验探针已经实测出：峰值指标对 CFL 的响应**不按 `dx^3` 收缩**，
1600→3200 反而变大（见 `cfl_scaling_local.json`），因此那条路线的合法性从先验上就存疑。

本轮走第三条路线：**不放松时间步**，直接在 CFL 0.4（= 其余各档的同一台仪器）上把 nx=25600
在**单个作业**内跑完。成本核算（按 round-7 作业 cj3782 的实测单步成本）：CFL 0.8 时
`51462` 步 / `2574.54` s ⇒ ~`0.0500` s/步；CFL 0.4 步数加倍到 ~`102924`，预计 ~`5150` s，
小于单作业墙钟 `7200` s。若超时，则分段重启（写 checkpoint 后二段续跑），不得降 CFL。

## 2. 冻结的机械口径（与 round-4/5/6/7 完全一致，不重新定义）

1. 窗口 x∈[0.4, 1.0]，守恒限制比较（coarse 单元均值 = 其内 r 个 fine 单元均值），
   逐点 L1 相对误差以 fine 参考的 `Σ|ρ_ref|` 归一。
2. 阶梯只允许「自收敛距离」`d(细)`、观测阶 `p = log2(d_粗/d_细)`、误差棒
   `eps_ref = d_细/(2^p − 1)`（Richardson，不加 GCI 安全系数）。
3. `certified` 三门口径不变：参考自认证 <1 % ∧ 跨族地板移除 ∧ 被定级解 <1 %。
4. E1–E5 的实现**直接调用** `ref25600_r7.py` 的同一份函数（`instrument_control` /
   `reference_ladder` / `regrade`），不复制、不改写，防定义漂移。
5. 所有数字由 `docs/XVAL-FVM-M18737-ROUND2/ref25600_r10.py` 程序化注入（零手抄），
   由 `tests/test_compressible_wc_ref25600_frozen.py` 回归；若该档发散（NaN），
   必须写 `status="diverged"`、不产出 profile，下游一律记 `not_measured`。
