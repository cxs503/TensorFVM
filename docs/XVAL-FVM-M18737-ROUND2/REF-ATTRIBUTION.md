## ① 案例介绍

Woodward & Colella (1984) 双爆轰波：一维闭管 x∈[0,1]，γ=1.4，初始压力平台
p=1000 / 0.01 / 100（x≤0.1 / 0.1<x<0.9 / x≥0.9），两端反射壁，积分到 t=0.038，两束爆轰波在管中部对撞。

| 量 | 值 | 出处 |
|---|---|---|
| 被定级解 | TensorFVM MUSCL-Hancock 二阶 + MC 限幅 + HLLC + SSP-RK，CFL 0.4，nx=3200 | `compressible/cases.double_blast` |
| 独立参考 | 有限体积 WENO5 + SSP-RK3 + Rusanov，nx=12800（另有 6400） | `xcode/wc_crosscode.py` |
| 比较窗 | x∈[0.4,1.0]（已发表 RPJ@3200 数字化参考的有效窗） | `tensorfvm.compressible.wc_reference` |
| 总账容差 | <10 %（本锚点验收 <15 %）；本轮目标 <1 % | ledger |

## ② 怎么做的（三项测量）

1. **参考地板**：参考族自身还在动多少？用 `WENO5@12800 vs WENO5@6400`。
   这是「参考侧误差上界」的实测代理量（不再靠断言）。
2. **度量带**：`l1_percent` 只做一种插值方向（细→粗）。同一对数在**两个方向**都算
   （细网格上比较 / 粗网格上比较），给出插值带，避免把 1.78 % 写成假精度。
3. **逐区域归因**：用最细参考自身的 `|∂ρ/∂x|`（≥20 % 窗内最大值）与 `p<0.1` 把窗切成
   shock / plateau / smooth，把**被定级侧误差**与**参考侧差值**在**同一套区域**上积分，
   份额可比。区域是划分（宽度和=1、残差份额和=100 %，测试门保证）。
   另加一项**免参考**交叉校验：TensorFVM 自己 800/1600/3200 阶梯的自收敛阶与自误差估计。

高阶参考探针（`xcode/wc_weno7.py`）：有限体积 WENO7 + SSP-RK3 + Rusanov。
系数**推导而非抄写**——面值系数由原函数 `W'` 的插值微分给出（三格 → `(1/3,-7/6,11/6)`），
线性权重由「线性组合必须复现 7 格面值」的最小二乘解给出（→ `(1/35,12/35,18/35,4/35)`，
7 格残差 1.8e-15）。该探针用于回答「参考族换更高阶重建后还动多少」，本身**不**作为定级基准
（它与 WENO5 共享时间积分与界面通量，不是独立代码）。

## ⑤ 注意点（局限 / 适用范围）

1. **「平台区拖累」这句话被证伪（按本轮定义）**：t=0.038 时窗内**没有** p<0.1 的点
   （plateau 掩码宽度 0），残差 95.9 % 落在 smooth 区、4.1 % 落在激波区。此前文件里
   「L1 受接触间断/平台区域拖累」的表述**缺乏证据支持**，应改为「残差分布在光滑区，
   激波区按宽度折算的密度显著更高」。
2. **参考地板仍是同族代理量**：0.548 % 是 WENO5 族 6400↔12800 的差，不是真误差；
   真误差需 nx=25600 或异族参考（见 B 段末尾）。
3. **归因是三角不等式上界**：被定级侧 ∈ [L1 − 参考侧上界, L1] = [1.24 %, 1.79 %]；
   本轮报告保守取上界 1.79 % 作为「我们自己的误差」，与免参考阶梯反推的 2.42 % 同量级
   （同量级即一致；阶梯反推偏大是因为观测阶 0.80 由两档差算出，含噪声）。
4. **WENO7 探针的三次定位（可复用教训）**：把「点值插值系数」用于有限体积更新 → 实测
   2.0 阶；换有限体积（原函数）系数但 β 矩阵差一次转置 → 4.0 阶；修正 β 转置 → 6.0 阶。
   也就是说 β 的转置错误白丢两阶，且**只有做收敛阶实测才能发现**（残差图看起来完全正常）。
5. 观测阶 0.80 < 1：L1 在含激波解上低于一阶是常态（激波位置误差 + 平台幅值误差叠加）。

## ⑥ 误差判定（逐项显式回答）

| 关键量 | 实测 | <15 % | <3 % | <1 % |
|---|---|---|---|---|
| 被定级解 L1（vs WENO5@12800） | 1.787 %（带 1.776–1.799） | ✅ | ✅ | ❌ |
| 被定级解 峰值 | 0.743 % | ✅ | ✅ | ✅ |
| 窗质量 | 0.00093 % | ✅ | ✅ | ✅ |
| 参考地板（12800 vs 6400） | 0.548 % | ✅ | ✅ | ✅ |
| 参考自身阶（熵波） | 5.10–5.21 | ✅（真 5 阶） | — | — |

**结论（honest）**：`certified <1 %` 仍未达成，且**绑定约束在被定级侧**——参考族自身的
移动量（0.548 %）小于残差（1.787 %）的一半，TensorFVM 自己的阶梯观测阶 0.80 反推的自身
误差（2.42 %）与残差同量级。按 p=0.80 外推，nx≈**6600** 才可能让 L1 落到 1 % 附近
（可测的下一档正是 nx=6400）。因此下一手应做**被定级侧**：nx=6400 的 MUSCL/HLLC 跑一档
（或换更高阶重建），而不是继续加密参考。

**给下一手的建议条目**：`XVAL-FVM-M18737-NX6400-HONEST` —
验收「TensorFVM MUSCL/HLLC nx=6400 vs WENO5@25600（若可得）否则 @12800：L1 <1.0 % 且峰值 <1 %，
参考自认证 <1 %」，域：TensorFVM 可压缩验证。
