## ③ 冻结的判据（先于数字，跑完不回改）

### E0 工件真伪（三道，逐档）

- E0a：`dx == 1/nx`（相对误差 <1e-12）、`len(x) == nx`（或窗口内 0.6·nx，容 1 个单元）；
- E0b：`ρ > 0` 全成立且有限、`steps > 0`、`seconds_solver > 0`；
- E0c：`mass_drift < 1e-10`（闭管守恒），且 metrics json 里 **`cfl` 必须是 0.8**
  （防「档名说 0.8、实际跑 0.4」）。
- 任何一条不过 ⇒ 该档 `not_measured`，不得进裁决。

### E1 入场门（同格 CFL 0.4 vs 0.8 的互相 L1）

- E1（被定级族，nx=6400）：`L1[hllc vs hllc_cfl0.8] < 0.2 %`
  ——阈值来自前轮预注册（远小于 3200→6400 的减量 0.883 %）。
- E1r（参考族，nx=12800）：`L1[weno5 vs weno5_cfl0.8] < 0.2 %`（同一量级阈值，
  用于把 CFL-0.8 的参考侧一对档接到 CFL 0.4 的既有档上）。
- 门不过 ⇒ nx=12800 档仍记 `not_measured`，本轮只交「控制实验」的负面结果。

### E2 预测命中（幂律 `e(n)=C n^-p`，p 取最细相邻档观测值 0.991）

| 量 | 预注册预测 | 预注册命中带 |
|---|---|---|
| `L1[12800 vs WENO5@12800]` | **0.449 %** | ±15 % ⇒ 0.382–0.517 % |
| 观测阶 `p(6400→12800)` | ≈ 0.991 | ≤ 1.15 且 `L1` 必须继续下降 |

`L1(12800) ≥ 0.517 %` 或 `p > 1.15` ⇒ 幂律读法**不命中**，按预注册的
`GRID_LIMITED/SCHEME_LIMITED` 分支重判，不得反向调参。

### E3 certified 门（`<1 %`，沿用 `CERTIFIED_PERCENT = 1.0`，不变）

- `CERTIFIED_UNDER_1PCT_AT_NX12800` 成立 ⇔ `L1(12800) < 1 %` **且** 峰值 <1 %。
- 这条只说明「vs 自认证参考」，**不**说明「对精确解 <1 %」（`CERTIFIED-NX6400-ERRATA.md` 的教训）。

### E4 诚实上限（本轮的主问题）：参考侧误差棒换了档位之后还越不越线

`eps_ref(ref 档位=12800)` 由同仪器一对 `d = L1[WENO5@12800 vs WENO5@25600]` 给：
`eps_ref = d/(2^{p_ref} − 1)`（B0），另有四种合法口径 B1(p±0.25)/B2(GCI Fs=1.25)/
B3(Fs=3)/B4(无阶 Cauchy，须过「差值比不增」才可判) —— 口径定义与
`ref25600_r11_robust.py` **同一份实现**，不复制不重写。
- **E4 成立 ⇔ `L1(12800) + eps_ref(B0) < 1 %`**（诚实上界首次进 1 %）。
- E4r 稳健性：B0–B3 各口径的存亡表（哪几个口径下 <1 %）。
- 若 B0–B3 全部越线 ⇒ 记 **honest FAIL**：`certified <1 %` 在 nx=12800 仍不可证，
  并把「还差多少 / 需要什么」写清楚。

### E5 预注册的预期（写在这里，允许被打脸）

按 `eps_ref` 随档位减半（参考侧 `p_ref = 0.8327`，`d(12800→25600) ≈ 0.5527·2^-0.8327 = 0.310 %`）：

| 口径 | 预测 `eps_ref(12800)` [%] | 预测诚实上界 = 0.449 + eps_ref [%] | 预测 <1 % |
|---|---|---|---|
| B0 点阶 | 0.397 | **0.846** | ✅ 首次进线 |
| B1 p±0.25 | 0.623 | 1.072 | ❌ |
| B2 GCI Fs=1.25 | 0.496 | 0.945 | ✅（边缘） |
| B3 Fs=3 | 1.190 | 1.639 | ❌ |

即：**预注册的预期是「B0/B2 进 1 %，B1/B3 不进」**，与 R11 在 nx=6400 上「五口径全不进」
形成档位对比。若实测与这张表相反，照实写并把它当本轮结论。
