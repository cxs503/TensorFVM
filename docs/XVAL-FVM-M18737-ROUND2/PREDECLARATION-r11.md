# XVAL-FVM-M18737-ROUND2 · Round-11 预声明：误差棒的**口径稳健性**（在计算之前冻结）

> 锚点 `XVAL-FVM-M18737-ROUND2`（TensorFVM 的 m18737-round2 做法），验收 <15 %。
> **冻结时点**：本文件在任何 R11 数字产生之前写入。此后只能「命中/未中」，判据不改。
> **与 R1–R10 的关系**：R1–R10 复核「数字对不对」；R11 复核「**误差棒本身的口径**」——
> 即 `eps_ref` 与 `honest upper bound` 在**换一种同样合法（更保守）的口径**之后还站不站得住。
> 不改写任何前轮裁决文本。

## 0. 为什么这是欠账

R10 预声明 §2.2 把口径**冻结**为

```
eps_ref = d_细 / (2^p − 1)      （Richardson，p = 观测阶，不加 GCI 安全系数）
honest upper bound = L1_被定级 + eps_ref
```

这个口径有三个**未被检验的承重假设**：

1. **观测阶 `p` 当精确数用**。R5 已把 p 的带传进预算（`u_ref_order_band`），但带只覆盖
   「拟合误差」，不覆盖「序列根本不在渐近区」这件事。
2. **渐近区成立**。ASME V&V-20 / Roache 要求先验检查收敛比 `R = d_细/d_粗`，且只在
   渐近区才允许用 `Fs = 1.25`；不在渐近区时必须用更大的安全系数（Roache 的 `Fs = 3`）。
   本项目 WENO5 的实测 `p ≈ 0.81`（形式上应是 5），这已经不是「渐近区内的拟合噪声」。
3. **几何衰减可用**。若只想避免任何阶假定，可退到三角形不等式给出的
   `eps ≤ d_细/(1 − r)`（`r = d_细/d_粗`），但这条**只在差值比不增**时才合法。

R11 的任务就是把这三条逐个量出来：**同一个 L1 数字，在 B0–B4 五种口径下的误差棒、
以及被定级判据 E4(<1.5 %)/E5(<1 %)/总账(<15 %) 各自还成不成立。**

## 1. 冻结口径（B0–B4，五种，全部程序化）

设参考族最细**可测**档的相邻差 `e = L1(fine_pair)`、其观测阶 `p`、比值 `r = e / e_prev`
（`e_prev` 为上一对的 L1 差），被定级解对参考的 L1 记 `L1_g`。

| 编号 | 口径 | 公式 | 依据 |
|---|---|---|---|
| **B0** | 点阶 Richardson（=R1–R10 现行口径） | `eps = e/(2^p − 1)` | 现行基线 |
| **B1** | 阶带传播 | `p ∈ [p−0.25, p+0.25]` ⇒ `eps_hi = e/(2^(p−0.25) − 1)` | R5 `u_ref_order_band` |
| **B2** | GCI + 安全系数 `Fs = 1.25` | `eps = 1.25 · e/(2^p − 1)` | ASME V&V-20（**假定**渐近区） |
| **B3** | 非渐近安全系数 `Fs = 3` | `eps = 3 · e/(2^p − 1)` | Roache：观测阶与形式阶差一个量级以上 |
| **B4** | 无阶几何界（三角形不等式） | `eps = e/(1 − r)`，**仅当** `r` 序列不增时标 `licensed` | 不假定 p |

`r` 序列的「不增」判据：对全部相邻对 `r_k = d_k/d_{k−1}`，要求 `r_k ≤ r_{k−1} + 1e-12`。
任一处增大 ⇒ B4 记 `not_licensed`，只报数值不参与判定。

## 2. 冻结判据（R1–R6）

| 编号 | 判据 | 阈值 | 若不中怎么办 |
|---|---|---|---|
| **R1** | 口径可复算：B0 与 `u_ref_of_reference()` 给出的 `u_ref_percent` 一致 | 相对差 < 1e-9 | 口径漂移 ⇒ 本文件数字作废，查因 |
| **R2** | 阶带 B1 是否仍能支撑 E4 | `L1_g + eps_hi(B1) < 1.5` | 记实测；不中 ⇒ E4 的通过依赖「p 是精确数」 |
| **R3** | GCI(Fs=1.25) 下 E4 是否成立 | `L1_g + eps(B2) < 1.5` | 记实测 |
| **R4** | 非渐近 Fs=3 下 E4 是否成立 | `L1_g + eps(B3) < 1.5` | 记实测 |
| **R5** | B4 是否 licensed，及 licensed 时 E4 是否成立 | `r` 不增 ∧ `L1_g + eps(B4) < 1.5` | 记实测；`not_licensed` 时明写「不构成上界」 |
| **R6** | 总账 15 % 在**最保守**口径下是否成立 | `L1_g + max(eps(B0..B4 licensed)) < 15` | 若不中 ⇒ 总账 PASS 只是口径产物 |

**预测（冻结，先于测量）**：R1 命中；R2 取决于 `p`；R3 不中；R4 不中；R5 `not_licensed`
（R10 已实测 `r` 从 0.529 涨到 0.569）；R6 命中。若实测与预测不符，**如实记 miss**。
