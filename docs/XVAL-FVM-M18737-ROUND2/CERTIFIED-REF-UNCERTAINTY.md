## ① 案例介绍

Woodward & Colella (1984) 双爆轰波：一维闭管 x∈[0,1]，三压力平台（左 p=1000 / 中 p=0.01 / 右 p=100），
t≈0.028 双波对撞，积分至 t=0.038，γ=1.4，两端反射壁；考验激波捕捉、接触间断分辨与守恒性。

| 项目 | 值 |
|---|---|
| 被定级解 | MUSCL-Hancock 二阶 + MC 限幅 + HLLC + SSP-RK，CFL 0.4 |
| 独立参考族 | WENO5 + SSP-RK3 + Rusanov（不共享离散，`xcode/wc_crosscode.py`） |
| 比较窗口 | x∈[0.4, 1.0] |
| 参考阶梯 | WENO5 @ [3200, 6400, 12800] |
| 被定级阶梯 | MUSCL/HLLC @ [800, 1600, 3200] |

## ② 怎么做的

1. 参考族**三级**自收敛：相邻档 L1 距离（均在更细网格上积分），观测阶 `p_ref = log2(d粗/d细)`，参考自身误差 `eps_ref = d细/(2^p_ref−1)`（Richardson，GCI 安全系数 1.25 另列）。
2. Richardson 外推参考场 `rho_inf = rho_12800 + (rho_12800 − rho_6400)/(2^p_ref − 1)`，用窗口质量守恒 <0.1 % 证明外推不漂移。
3. 每档被定级解同时对 WENO5@12800（原始门）与 `rho_inf`（去参考误差）算 L1/峰值，并给三角区间 `[d−eps, d+eps]`。
4. 完全不依赖参考的第二条路：族内 Richardson `E_own = d(nx/2→nx)/(2^p_m − 1)`；两路在 eps_ref 内一致则点估计可信。
5. 对称检验：两族各自外推到 h→0 后互比，残余是任何外推都去不掉的部分。

## ⑤ 注意点（局限 / 适用范围）

1. **两级自收敛不能认证**：`<1 %` 自洽只说明两档接近，不说明细档离真解多远；无观测阶时上界就是 d 本身（0.5527 %，比观测阶修正的 0.7076 % 更松）。
2. **低观测阶放大外推**：p_ref≈0.83 时 1/(2^p−1)≈1.28，外推场放大 6400→12800 差异，故加族内第二条路交叉验证。
3. **已发表数字化曲线不是锚**：其对 WENO5 的残差随加密变大（4.54 % → 5.17 %），带自身标定偏差，仅作诊断。
4. **L1 场度量对激波抹平敏感**（趋近一阶）；把「分辨率」与「误差」混谈会带偏结论，故峰值与 L1 分开定级。
5. **nx=6400 的 MUSCL 档**本单递交集群（cj3314，`wc_ladder.py --plan 6400:hllc`），交付时未返回；工具在该档存在时自动用作最细档，返回后重跑即得，无需改代码。**本判定基于 nx≤3200 的完整阶梯。**
