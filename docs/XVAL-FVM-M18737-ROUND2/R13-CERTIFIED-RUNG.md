## ⑥ 裁决

`本轮不裁决：入场门或工件门未过（见 E0/E1）`


- `E4 (<1.5 %)`：**B0/B1/B2 三个口径首次过线**（前轮五口径全不过），`B3/B4` 仍越线；
- `E5 (<1 %)`：**五口径全部仍越线**（最乐观 B0 = 1.2581 %）⇒「certified <1 %」在 nx=6400
  依然**不可证**，R12 的 honest FAIL **不被覆盖**，只是把差距从 0.61 个点压到 **0.258 个点**；
- 反解所需：`p* = 1.9247`（`L1_g` 不动时）或「被定级 L1 ≤ 0.635 %」——正好落在预注册的
  `L1(12800) ≈ 0.449 %` 之外判据：若 12800 档落地且命中预注册带，
  B0 上界 ≈ 0.449 + 0.365 ≈ **0.814 % < 1 %**（预注册 E5 表已列此预期，未改）。

## 局限（明示）

1. **本轮没有 12800 档的实测**，因此「<1 % 是否在 12800 档首次可证」仍是**待验**问题，
   本文只给出「需要什么」的定量门槛与被收紧的误差棒，不给结论。
2. `eps_ref(12800)` 是**混合仪器探针**（`licensed=false`），因为 25600 档只有 CFL 0.8 版本；
   干净的棒需要 25600（CFL 0.4）或 12800/25600 同口径两档，两条路都记在预注册里。
3. 观测阶 `p_ref = 0.8631` 仍远低于 WENO5 形式阶 5（`order_ratio = 0.173`）⇒ 按 ASME V&V-20
   不进渐近区，`Fs=3`（B3）才与证据相符，B0/B2 只是「同样合法但乐观」的口径。
4. 全部结论只对「以自认证数值解为参考」的度量有效，不得说成「对精确解」。
