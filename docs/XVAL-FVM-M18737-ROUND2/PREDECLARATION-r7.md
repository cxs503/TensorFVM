## 0. 为什么这一轮换「仪器成本」而不是换「物理问题」

冻结仪器（`xcode/wc_crosscode.py::weno5_solve`，WENO5 + SSP-RK3 + Rusanov，CFL 0.4）
在 nx=25600 上的成本 ~ `steps × cells` ≈ 2.6e9 cell-update，单核 ~2.3 h，**超过单作业墙钟**，
这正是 `cj3710` 交不回来的原因（不是数值问题）。SSP-RK3 的显式步数 `steps ∝ 1/CFL`，
所以把 CFL 从 0.4 放到 0.8 可把成本减半，使该档能在单作业内跑完。

代价是时间积分误差变大。明确记录：`dt ∝ dx`（固定 CFL），SSP-RK3 时间误差 `O(dt^3) ∝ dx^3`，
故 CFL 效应在 1600 档最明显、在 6400 及以上按 64×/256× 衰减。**先验本机实测**（写本文件前，
nx=1600，CFL 0.4 存储档 vs CFL 0.8 新跑）：窗口 L1 差 **0.0534 %**、峰值差 **0.0236 %**，
而该档参考自收敛距离是 1.807 %——即 CFL 效应约为该档格距效应的 3 %，且按 `dx^3` 收缩。

## 2. 冻结的机械口径（与 round-4/5/6 完全一致，不改定义）

1. 窗口 x∈[0.4, 1.0]，守恒限制比较（coarse 单元均值 = 其内 r 个 fine 单元均值），逐点 L1 相对误差以 fine 参考的 `Σ|ρ_ref|` 归一。
2. 参考阶梯只允许「自收敛距离」`d(细)`、观测阶 `p = log2(d_粗/d_细)`、误差棒 `eps_ref = d_细/(2^p − 1)`（Richardson，不加 GCI 安全系数；GCI×1.25 另列）。
3. `certified` 三门口径不变：参考自认证 <1 % ∧ 跨族地板移除 ∧ 被定级解 <1 %。
4. 所有数字由 `docs/XVAL-FVM-M18737-ROUND2/ref25600_r7.py` 程序化注入（零手抄），
   并由 `tests/test_compressible_wc_ref25600.py` 回归。
5. 若 25600 档发散（NaN），必须写 `status="diverged"`、不产出 profile，下游一律记 `not_measured`——不得读作 PASS。
