## ① 案例介绍（物理背景 / 参数表）

Woodward & Colella (1984) 双爆轰波：一维闭管 x∈[0,1]，初始三压力平台 p=1000 (x≤0.1) / 0.01 (0.1<x<0.9) / 100 (x≥0.9)，ρ=1、u=0，γ=1.4，两端反射壁，
积分到 t=0.038（两束爆轰波在管中部对撞之后）。无解析解 ⇒ 「误差」永远是两个数值解之差，
**参考解自身的截断误差必须计入**。

| 项 | 值 |
|---|---|
| 被定级解 | TensorFVM MUSCL-Hancock 二阶 + MC 限幅 + HLLC + SSP-RK，CFL 0.4，nx=3200 |
| 参考族 A | WENO5 + SSP-RK3 + Rusanov（`xcode/wc_crosscode.py`），nx=1600…12800 |
| 参考族 B（本轮新增） | WENO7 + SSP-RK3 + Rusanov（`xcode/wc_weno7.py`），nx=1600/3200/6400 |
| 比较窗 | x∈[0.4,1.0]，粗格守恒限制（粗格均值 = 其内 r 个细格均值） |
| 认证门 / 总账容差 | 1.0 % / 15.0 % |

参考族 B 与 A **共享时间积分与界面通量**，因此不是独立代码，而是独立**重建阶**探针；
跨代码独立性仍由 A 对 TensorFVM 提供。这一点在判据里写明，不当独立性宣称。

## ② 怎么做的（先冻结、再算、再对账）

1. **冻结**：`PREDECLARATION-r6.md` 在 worktree 内 WENO7 blast 剖面数 = 0 时写下 Q1–Q6；
   `AMENDMENT-1` 修掉 Q3 的一次定义错误（原文用了自造的 ½·L1 比例，代码约定是 `U_ref = e/(2^p−1)`），修正发生在作业 `cj3733` 仍排队、3200/6400 档不存在时，原文保留不删。
2. **算参考族 B**：`xcode/wc_weno7_ladder.py --rungs 1600,3200,6400`，递交调度系统（作业 `cj3733`，
   1 核，本机不起重算力）。产物 `ladder_profile_nx{1600,3200,6400}_weno7.npz` + 指标 json。
3. **同网格跨阶差**：WENO7@nx vs WENO5@nx（nx=1600/3200/6400），剔除「加密」这一维，只留「阶」这一维；
   两个插值方向都算并报带（同网格下正反向归一化分母不同）。
4. **重定级**：同一个 MUSCL/HLLC@3200 剖面分别对每一个可用参考（WENO5@6400/12800、
   WENO7@3200/6400）定级，每个参考带自己的 `U_ref`（由同族自认证阶梯算，不是假设）。
5. **判据机检**：Q1–Q6 逐条对账，命中/未中一律记；缺工件记 `not_measured`，不改写为 PASS。

### 仪器稳健性：WENO7 探针能不能当参考（本地单核扫描，程序化）

| nx | 有限解 | 峰值 ρ_max | 相对收敛峰 (6.4595) 偏差 [%] | 正性回退 | 秒 |
|---|---|---|---|---|---|
| 200 | False | — | — | 39 | 2.00 |
| 400 | True | 6.1472 | 4.8348 | 65 | 6.44 |
| 600 | True | 6.6431 | -2.8422 | 68 | 11.40 |
| 800 | False | — | — | 30 | 12.41 |
| 1600 | True | 6.7114 | -3.9003 | 55 | 48.12 |
| 400 (WENO5) | True | 5.6886 | 11.9339 | 43 | 5.15 |
| 1600 (WENO5) | True | 6.4720 | -0.1937 | 46 | 32.71 |

结论（**否定性**，如实记）：这套 WENO7 探针**不能**当高阶参考用——
① 在 nx=200 与 nx=800 直接发散（NaN，正性回退计数器仍在计数但没有兜住负压态）；
② 在能跑的档位上峰值**越过**收敛峰（@600 6.643、@1600 6.711 vs 收敛 6.4595，
   偏差 +2.8 %/+3.9 %），而 WENO5 同档只在 −0.19 %/−0.19 %；
③ 因此「提高重建阶 ⇒ 更可信参考」这条假设在本实现上**被证伪**，
   在修好边界/正性处理之前，WENO7 只能作诊断，不得作定级基准。

## ⑤ 注意点（局限 / 适用范围）

1. **WENO7 不是独立代码**：与 WENO5 共享 SSP-RK3 与 Rusanov 通量，只有重建阶不同。
   因此它测的是「参考族的重建截断误差」，不能替代跨代码验证（那一层仍由 WENO5 对 TensorFVM 提供）。
2. **阶的观测值仍 <1**：含激波/接触间断的 L1 误差按 h^p（p≈0.8）收缩，提高重建阶改变的是**常数**。
   所以「换阶」的收益是降到某个地板，不是「多得一阶」。
3. **正性回退**：WENO7 在强激波处会触发回退（次数见上表），该档解因此仍受守恒性检查约束；
   回退比例若失控，该档只能作诊断，不能作定级参考（判据里已预设）。
4. **认证口径未放松**：`certified = 参考自认证<1 % ∧ 地板移除 ∧ 被定级解<1 %`。
5. **作业未回**：WENO7@3200/6400 的调度作业 `cj3733` 在本文生成时仍在排队（集群 95 个在飞作业），
   因此 Q1–Q6 全部记 `not_measured`——**不得**读作 PASS，也不得用 WENO5 的数字顶替。
6. **仪器被证伪**：见上表，WENO7 探针在 blast 数据上发散 + 峰值越限，故即使 3200/6400 档回来，
   也必须先修仪器才能用于归因。这一条是本轮最硬的产出（负面结果）。
7. **未做**：WENO7@12800（本机/集群成本约 2 h 单核）未排；`d_W1` 输运范数在换阶参考下的重算未做。
