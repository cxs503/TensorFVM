# XVAL-FVM-M18737-ROUND2 — 预声明：加密被定级解而非参考解

> **冻结时刻**: 在 cj3325（MUSCL/HLLC nx=6400、nx=12800 两档）工件回填**之前**写成。
> **目的**: certified-<1% 的三道门中，第 2 道（被定级解 L1 = 1.7685 % > 1 %）是唯一绑定项。
> 上一轮只加密了**参考解**（WENO5 6400/12800），被定级解停在 nx=3200。本轮问的是：
> **继续加密被定级解能不能把 L1 压到 <1 %？需要多少格点？** 先冻结预测，再测。

## 1. 冻结输入（全部来自已入库工件，非本轮新算）

| 量 | 值 | 来源 |
|---|---|---|
| e(1600) = L1[MUSCL/HLLC@1600 vs WENO5@12800] | 3.2513 % | `ladder/data/ladder_profile_nx1600_hllc.npz`（守恒限制口径，见 §2） |
| e(3200) = L1[MUSCL/HLLC@3200 vs WENO5@12800] | 1.7685 % | `ladder_profile_nx3200_hllc.npz` + `ladder_profile_nx12800_weno5.npz` |
| 观测阶 p = log2(e16/e32) | **0.8785** | 两档比率 |

## 2. 预测（误差模型 e(nx) = e(3200)·(nx/3200)^(-p)）

| 目标网格 | p=0.79（round-2 自收敛阶，保守） | p=0.8785（本轮实测阶） | p=1.05（乐观） |
|---|---|---|---|
| nx=6400 | 1.0228 % | **0.9620 %** | 0.8541 % |
| nx=12800 | 0.5915 % | **0.5233 %** | 0.4125 % |

**可证伪判据**

- **F1（点值）**: e(6400) 落在 [0.854, 1.023] % 内 → 一阶渐近误差模型成立。
- **F2（阶）**: 三段序列（1600/3200/6400）的 log--log 最小二乘阶 ∈ [0.70, 1.20] → 激波主导的 ~一阶收敛。
  若实测阶 < 0.5 或 L1 出现平台（>1.5 % 不降）→ F2 被证伪，说明 L1 里有一块不随网格收敛的成分
  （接触间断/参考侧残余），「加密被定级解」路线作废，须改高阶格式。
- **F3（裁决）**: nx=6400 处 L1 < 1 % → certified-<1 %（L1 门）在 nx=6400 首次达成；
  否则在 nx=12800 处裁决，若 12800 仍 ≥1 % 则**诚实 FAIL**，并给出「按实测阶需要 nx≈…」的定量结论。

## 3. 同时预声明的方法学审计（adversarial 自审）

被质疑点：`wc_certified_ref.py::l1_percent` 把**细参考插值到粗格点**再逐点比，混了「单元平均 vs 点值」。
替代口径：**守恒限制**（fine 的 r 个子单元平均 = coarse 单元平均），两者都是单元平均，不插值。
**预测 M1**: 两口径差 <0.05 个百分点（即上一轮 L1=1.776 % 不是度量假象）；
若差 ≥0.5 pp 则上一轮数值需作废重算。
