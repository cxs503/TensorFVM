# 浅水方程变床面（well-balanced）能力与静止湖精确保持验证（m16596）

**锚点**: `NEW:浅水求解器只有平床面（flat bed），无床面源项、无 well-balanced 验证面`
**仓**: TensorFVM · **分支**: `agent/m16596` · **域**: 求解器 / 浅水（耐波-浅水效应基础）

## ① 案例介绍（物理背景 / 几何 / 参数）

`src/tensorfvm/shallow_water/` 此前只有**平床**求解器（`swe1d.ShallowWater1D`，其 docstring 明确
"flat bed here"），配 Ritter（干床溃坝）与 Stoker（湿床溃坝）两个闭式解基准（m16208 交付）。
一切工程浅水问题（港口假潮、疏浚航道、海啸爬坡、堰顶溃坝）都需要**床面坡度源项**，而床面源项
恰好是最容易写错的一项：`h + z = const, u = 0`（静止湖，lake at rest）是连续方程的**精确稳态解**，
任何床面，所以正确离散必须把它保持到舍入量级；写错的离散会静默制造 `O(g dz/dx dt)` 的伪流。

本单交付并验证的能力：

| 项 | 内容 |
|---|---|
| 新求解器 | `shallow_water.bed.ShallowWaterBed1D`（Audusse et al. 2004 静水重构 + HLL + MUSCL + SSP-RK3） |
| 原语保留 | `z = 0` 时**逐位**退化为已发布的平床求解器（F1），保证旧基准不受影响 |
| 验证驱动 | `verification/shallow_water_well_balanced.py`，19 条预声明判据 + 3 条舍入复判 |
| 测试 | `tests/test_shallow_water_well_balanced.py`（11 测全绿） |
| 附带缺陷修复 | `ShallowWater1D.cfl_number()` 原文返回波速（量纲错），现为真实 Courant 数 |

## ② 怎么做的（方法 / 流程 / 关键设置）

1. **先立判据后跑数**：`MAX_REST_VELOCITY = 1e-10 m/s`、`MAX_SURFACE_DRIFT = 1e-12 m`、
   `NAIVE_MIN_VELOCITY = 1e-2 m/s`（负对照必须**超过**才能证明门能失败）、
   `MASS_TOLERANCE = 1e-13`、`FLAT_REDUCTION_TOLERANCE = 0.0`（逐位）。阈值写在 `run()` 之前，
   不做跑后调参。
2. **离散（Audusse 2004 静水重构）**：重构**水面** η = h+z 与 u（minmod，边胞零斜率），
   床面分片常数；面上 `z_f = max(z_L, z_R)`，星深 `h*_side = max(0, η_side - z_f)`；
   HLL 通量用星态；动量通量按"胞自身一侧"加压力修正 `+g/2 (h_side² - h*_side²)`。
   于是水体体积守恒、动量不守恒（床面本来施力），这是 well-balanced 的代价，与原文一致。
3. **静止湖保持的证明（也是实测的判据）**：η 常数 ⇒ minmod 斜率 0 ⇒ `η_side = η`，u = 0 ⇒
   `h*_L = h*_R = η - z_f` ⇒ 质量通量 0，动量通量 `g/2(η-z_f)²`，加本侧修正后 = `g/2 h_i²`，
   胞两侧相同 ⇒ `d(hu)/dt = 0` **逐位**。
4. **负对照**（对抗性复核要求）：同一初值改用"无重构 + 中心差分床面源项 `-g h dz/dx`"的朴素格式，
   必须破坏静止湖，否则判据为空。
5. 工具链：`numpy` 手写 1-D FV；`PYTHONPATH=src python -m tensorfvm.verification.shallow_water_well_balanced`；
   图 `matplotlib`。全程本机 CPU，单例 <1 s（轻量，未压控制面）。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **"逐位相等"在浮点里做不到**（F2 的教训）：`η = h+z` 再 `η - z` 不还原 h（`|Δ| ≤ eps·|h|`），
   所以"常床面偏移不改变解"只能在舍入量级成立（实测 1.8e-15 / 9.7e-15）。把它写成判据必须用
   推导出的舍入界，不能写成 `==0`；`z = 0` 那一侧能逐位成立（加 0.0 是精确的），这是 F1/F2 的差别。
2. **动量通量刻意不守恒**：静水重构的压力修正两侧不同，故格式只守恒水体体积。任何"动量通量差
   应逐位相消"的直觉在此处不成立；实测 W2 的 `d(hu)/dt` 却恰为 0，因为静止时两侧修正给出同一个
   `g/2 h_i²`。
3. **负对照必须留**：朴素格式在台阶床上制造 0.39 m/s 伪流、并把体积漂移抬到 3.6e-04（well-balanced
   为 0），若把它删掉，"静止湖保持"测试会退化成"跑通即通过"。
4. **干湿掩码**：W3 有 22 个干胞，`dry_flips` 计数 126120（每个 RK 级把干胞里的舍入级 hu 归零），
   这是簿记量而非失稳信号——判据看的是 max\|u\| 与掩码不变。
5. **适用范围/未做（WITHHELD）**：
   - 无摩阻项（Manning/Chezy）、无科氏力、无二维/球面；本单只做 1-D 无摩阻。
   - **堰顶溃坝无闭式解**（D1 只判正性与体积，不判形状精度）；有解析锚的变床面非平凡流
     （如 Goutal–Maurel 跨临界堰流 case 2 的半解析解）**未做** → WITHHELD，不冒充覆盖率。
   - 二阶重构的时间精度仍受 SSP-RK3 限制，未做变床面光滑解的空间收敛阶研究（需制造解）。
