# 平面突扩（AR = 4, Re_D = 100）对称性复核与损失系数账目审计 (m6390)

**任务**: m6390 · selfstart 自找活（TensorFVM） · 日期 2026-11-08
**性质**: 验证欠账复核 + 验收判据缺陷定位（轻量：单核 ~111 s 总机时，load15≈125 未起集群）
**触发线索**: `docs/verification-debt-m6320.md` §3 靶子 #1「突扩管回流区不对称 = 当前最值得打的求解器缺陷」

---

## 1. 案例与目标

平面突扩，面积比 `AR = 4`（入口高 `h1 = D/4`，下游高 `D = 1`），入口在中心
`y ∈ [0.375, 0.625]` 均匀 `U_in = 1`，其余为阶面固壁；两壁无滑移，出口零梯度。
`Re_D = U_out D/ν = 100`（当前实现 `ν = 0.0025`）。物性 `ρ = 1`。

被复核的三件事：

| # | 待复核主张 | 出处 |
|---|---|---|
| A1 | 解是**不对称**的（`L_r/D = 0.20` 下 / `11.86` 上），指认阶角/尾流处理缺陷 | benchmarks §2.2, debt m6320 §3 |
| A2 | 损失系数 `K` 与 Borda-Carnot `0.5625` 相差 **-1.3 %（PASS）** | benchmarks §2.2 表 |
| A3 | 再附长度 `L_r/D` 状态 **WITHHELD**（无可靠值） | study.py 判据 |

## 2. 方法

脚本 `scripts/expansion_symmetry_audit.py`（新增），三网格 `D/10`、`D/20`、`D/30`，
显式 MAC 求解器 `StaggeredMAC` 推到定常（与 `study.run_expansion` 同一停机判据：
`|ΔL_r| ≤ 2e-3 L_r` 连续两块）。

记录三类**可机器裁**的量：

* **镜像对称残差**：`max|u − flip_y(u)|`、`max|v + flip_y(v)|`、
  `max|Cf_lower − Cf_upper|`。离散算子、按面积分数加权的入口、DCT 压力解都与镜像
  `y → H − y` 交换，故残差必须在舍入级；任何不对称都是数值缺陷。
* **解析锚**：下游发展段壁面摩擦必须趋于平面 Poiseuille 解析值 `12/Re_H`；
  同时记录压力梯度解析值 `dp/dx = −12 μ U/H²`。
* **两套损失系数口径**：|u| 加权总压列均值路线（`k_corrected`/`k_extrapolated`）
  与精确控制体恒等式路线 `K = 1 − 1/AR² − Cp`（本轮**新增**于
  `SuddenExpansionCase.diagnostics()`：`k_from_static_recovery`）。

**先修一个取样陷阱**：本工作树未安装，`python3 script.py` 会 import 到
**别的 worktree 的 editable 安装**（实测为 `/root/tp-agent/work/m5435/src/tensorfvm`），
即测量的是旧代码。首轮结果（入口通量 0.2 = 整格分配、离散 AR = 5）因此作废；
脚本现内置 `assert_local_package()` 守卫，必须 `PYTHONPATH=src` 运行。

## 3. 结果

### 3.1 解是镜像对称的（A1 被否定）

| 网格 | `max|u−flip(u)|` | `max|v+flip(v)|` | `max|Cf_b − Cf_t|` | `L_r/D` 下 | 上 |
|---|---|---|---|---|---|
| D/10 | 1.89e-12 | 1.7e-13 | 1.2e-14 | 3.229534 | 3.229534 |
| D/20 | 1.10e-13 | 3.1e-14 | 1.8e-15 | 3.330754 | 3.330754 |
| D/30 | 2.00e-15 | — | — | 3.347562 | 3.347562 |

三网格全部在**舍入级**对称（最差 1.9e-12，随网格加密单调下降）。因此
`L_r/D = 0.20 / 11.86` 的所谓「不对称解」**不能**由当前
`internal_flow.sudden_expansion` 复现。

对 `L_r` 的出现给出的旁证：等价的入口通量为 `U_in·H_in = 0.25`，实测入口/中部/
出口列通量 `0.250000 / 0.250000 / 0.250000`（相对偏差 3.3e-16），即离散面积比与
`Re_D` 都是标称值。

> 与 m6374 的关系（避免重复计功）：m6374 针对**遗留几何**
> `incompressible_baselines.build_sudden_expansion`（入口贴底壁，出口高 4）证明了
> 历史不对称是几何造成的；本单针对**当前** `internal_flow` 的中心入口几何，给出
> 解场的镜像残差与解析锚。两者结论互补、互不重复。

### 3.2 再附长度：可给出网格序列（A3 部分升级）

`L_r/D = 3.2295 (D/10) → 3.3308 (D/20) → 3.3476 (D/30)`，单调、增量 3.1 % → 0.5 %，
两级网格的估计变化 0.5 %。仍**没有**可引用的文献值 → 状态从 WITHHELD 升级为
「自带网格序列的实测值，文献锚仍缺」。

### 3.3 发展段解析锚（求解器粘性算子可信）

| 网格 | `Cf` 实测 | `12/Re_H` 解析 | 误差 |
|---|---|---|---|
| D/10 | 0.00724 | 0.0075 | **2.4 %** |
| D/20 | 0.00743 | 0.0075 | **0.9 %** |
| D/30 | 0.00745 | 0.0075 | **0.6 %** |

同时实测 `dp/dx` 与解析 `−12μU/H²` 同量级同号。故下游「发展段摩擦」这一环
（`k_friction_correction` 的基础）是可信的。

### 3.4 损失系数：两条路线的口径差 20 %——A2 不能复现（honest FAIL）

| 网格 | `k_corrected` | `k_extrapolated` | `k_from_static_recovery` | `Cp`(外推) |
|---|---|---|---|---|
| D/10 | 0.3779 (−32.8 %) | 0.3446 (−38.7 %) | **0.5708 (+1.5 %)** | 0.3667 |
| D/20 | 0.4033 (−28.3 %) | 0.3453 (−38.6 %) | **0.5359 (−4.7 %)** | 0.4016 |
| D/30 | 0.4497 (−20.1 %) | 0.3799 (−32.5 %) | **0.5074 (−9.8 %)** | 0.4301 |

（误差对 Borda-Carnot `0.5625`；`Cp` 的动量平衡参考值 `0.375`。）

* **A2 的 -1.3 % 无法用当前代码复现**（沿 `k_extrapolated` 口径为 −38.7 %）；
  `docs/benchmarks/incompressible-verification.md` §2.2 的表格与随树工件同样过期：
  两个工件带 `upstream_length = 3.0`、`pressure_stations_x_over_D = [−0.4, 2.0]`、
  `nu = 0.01`，当前 `SuddenExpansionConfig` 没有这些字段（几何已改成阶面在
  `x = 0` 的单一通道）。
* **口径差是真实的判据缺陷**：`pressure_profiles` 的列均值按 `|u|` 加权，得到的是
  `⟨p_t⟩` 而非一维意义的 `p + ½ρU²`，在非均匀剖面（`⟨u³⟩/⟨u⟩` 偏置）下把下游
  动压抬高，于是总压路线系统性低估 `K`；静态压力路线 `K = 1 − 1/AR² − Cp` 与之相差
  最多 20 % 的 `K`。本单已在 `diagnostics()` 中并列输出 `k_from_static_recovery*`。
* **可控量的残留偏差**：`k_from_static_recovery` 随加密从 +1.5 % 走到 −9.8 %（不单调
  收敛），指向入口动压参考值本身随网格变化——见下。

### 3.5 根因线索：按面积分数加权的入口剖面在网格上是「非均匀」的

分数加权修好了**通量/面积比/Re**（这是对的），但入口剖面对给定网格成了
`{0.5, 1, 1, …, 0.5}`，其**动量通量**低于均匀 `U_in` 覆盖 `H_in`：

| 网格 | 开格数 | 入口动量通量比 | 入口动能通量比 |
|---|---|---|---|
| D/10 | 4 | 0.85 | 0.8125 |
| D/20 | 6 | 0.90 | 0.8500 |
| D/30 | 8 | 0.95 | 0.9125 |
| D/40 | 10 | 1.00 | 1.0000 |

Borda-Carnot `(1−1/AR)²` 的前提是「均匀入口的动量通量」，因此在 D/10…D/30 上把
`K` 参考到 `0.5ρU_in²` 本身就带 5–15 % 的网格相关偏置。这与 3.4 中
`k_from_static_recovery` 的残余偏差方向一致。

## 4. 判定（逐项显式回答）

| 关键量 | 基准 | 误差 | <3 % ? |
|---|---|---|---|
| 镜像对称残差（全部网格） | 0 | ≤ 1.9e-12 | **是**（舍入级） |
| 入口通量 `U_in H_in` | 0.25 | 3.3e-16 | **是** |
| 发展段 `Cf`（D/30） | 0.0075 (12/Re_H) | 0.6 % | **是** |
| 发展段 `Cf`（D/20） | 0.0075 | 0.9 % | **是** |
| `K`（静态压力恒等式，D/10） | 0.5625 | +1.5 % | **是** |
| `K`（静态压力恒等式，D/20） | 0.5625 | −4.7 % | 否（<5 % 但 >3 %） |
| `K`（总压加权口径，D/20） | 0.5625 | −38.6 % | **否** ← 判据缺陷，非物理解误差 |
| `L_r/D` | 无认证文献值 | — | 无法判定（WITHHELD） |

## 5. 注意点 / 局限

1. **未修**：入口剖面的动量通量偏置（3.5）与总压列均值口径（3.4）。本轮只把两条
   路线并列输出 + 定性根因，未改入口加权方案（改动会动 `AR`/`Re` 的标定口径，
   必须与 `benchmarks` 判据表同步，超出本单轻量边界）。
2. `L_r/D` 的文献锚仍缺；`D/30` 只证明两级增量 0.5 %，不是渐近阶。
3. 单核、三网格、总机时 111 s；未跑 D/40（需要时用集群 `run_cluster`）。
4. 坐标/单位：`K`、`Cp` 全部参考 `0.5ρU_in²`，`L_r` 参考下游高度 `D`。
