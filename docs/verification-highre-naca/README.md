# NACA0012 高 Re 验证：计算与验收方案

## 状态（2026-10-15）

**计算已启动，尚未合格。** 本目录目前保存参考原始数据、网格生成参数、启动记录和验收方法；不能把开发记录中的力系数平台视为已收敛结果。

本次合并 GitHub `fc596c8` 与本地 SST 壁面修复，新增生产驱动 `9bb9e8d`。先完成 Re=6,000,000、0° 的三网格验证，同时计算 10° 的中网格诊断。0° 案例检验阻力、压力分布和对称性；10° 案例检验升力、逆压梯度及尾部边界层。后续 SUBOFF、SST、overset 和 GPU 仍需各自验证。

## 1. 问题与参考资料

单位弦长的 TMR 尖尾缘 NACA0012，U∞=1、ρ=1、ν=1/6,000,000。远场半径 500c，充分湍流 SA，入口 ν̃=3ν。无体力、无解析内部解、无系数修正。

参考来自 [TMR NACA0012 定义](https://tmbwg.github.io/turbmodels/naca0012_val.html)和 [CFL3D SA 数据](https://tmbwg.github.io/turbmodels/naca0012_val_sa.html)。保存了网页、原始 Cl/Cd、完整 Cp/Cf 数据及下载地址和 SHA256，见 `reference/manifest.json`。

TMR 定义为近似不可压缩案例；CFL3D 采用 M=0.15、有升力时使用远场点涡修正。本计算采用不可压缩方程、500c 远场、无点涡修正。该差异必须随结果报告；没有用 Prandtl–Glauert 或其他经验修正调整系数。此处首先是公开 CFD 参考的代码对照，实验验证范围另行说明。

参考原始力系数：

| 攻角 | Cl | Cd |
|---|---:|---:|
| 0° | -0.0000068553224298 | 0.0081924676041 |
| 10° | 1.0909146672 | 0.012310544747 |

## 2. 共用数值方法

调用 `SkewPressureMultiElementSolver`，与三段翼共用非结构有限体积、SIMPLE、SA、Gauss 偏斜修正压力梯度、有限制线性迎风动量对流、完整黏性应力及稀疏线性求解。SA 对流保持一阶迎风。没有新增专用于拟合 NACA 力系数的离散算子。

速度/压力/SA 松弛为 0.85/0.3/0.9；前 100 步采用 0.02 的伪时间步，动量对流在第 40–100 步从一阶渐变到完整线性迎风。线性残差预算缩放保持 1。外层最多 2500 步；到达迭代上限不算收敛。

此路径使用解析至壁面的 SA，必须检查实际 y+；原生三维 SST+Spalding 是另一个已合并的开发路径，本案例不会替它背书。

## 3. 网格族

表面四边形边界层厚度固定为 0.04c，外部三角形网格。远场渐变距离为 400c。壁面切向尺寸、首层高度、层间增长量、尾迹尺寸、远场尺寸、尾缘分段长度均按 1.5 的比例细化。

| 网格 | Gmsh 原始单元 | 求解器实际单元 | 首层高度/c | 尾缘分段上限/c |
|---|---:|---:|---:|---:|
| 粗 | 45,984 | 45,972 | 3e-6 | 1.5e-3 |
| 中 | 101,486 | 101,474 | 2e-6 | 1e-3 |
| 细 | 223,544 | 223,532 | 1.333333e-6 | 6.666667e-4 |

求解器合并了 12 个退化扇形顶点三角形，故实际计数减少 12。10° 中网格实际为 101,434 单元。

发现并修正：旧脚本的尾缘分段上限在所有等级均固定为 1e-3c，不能用于完整的系统加密研究。旧粗、细网格启动试算被中止并保留日志；当前改用 `scripts/mesh_highre_naca.py`。

中网格重新生成后 Gmsh 节点编号顺序不同，文件哈希不同；逐点坐标完全相等，映射为双射，单元连接及物理标签相同。见 `medium-mesh-equivalence.json`。运行中的中网格继续使用最初文件，保留其真实哈希。

## 4. 预先固定的验收门槛

以下条件必须同时满足，不因结果不佳而降低：

1. **数值收敛**：生产求解器正常终止并报告收敛；由保存场重建的动量、SA、连续性、质量不平衡及 Rhie–Chow 最大法向速度缺陷均低于 1e-5，Rhie–Chow 通量相对缺陷低于 1e-7。最终速度变化低于 1e-6。
2. **力系数稳定**：最近约 100 步、至少 10 个采样的 Cd 极差低于参考 Cd 的 0.1%；非零攻角 Cl 同理，0° 的 Cl 极差低于 1e-4。系数稳定不能代替方程残差。
3. **参考误差**：Cd 相对误差 <3%；10° Cl 相对误差 <3%；0° 因 Cl≈0，采用绝对误差 <0.001，不能计算接近零分母的相对误差。
4. **表面 Cp**：上下表面分别计算沿 x/c 积分的相对 L2 误差，均 <3%。采用完整原始参考数据与表面面心压力，在共同覆盖区对分段线性曲线的平方误差精确积分；每一面的弦向覆盖必须 >99.9%。不把过零点逐点相对误差当作整体误差，不外推补齐缺失曲线。Cf 另作诊断曲线。
5. **壁面分辨率**：实际最大 y+ <1。
6. **网格收敛**：至少三个独立网格的上述数值门槛通过；Cd 随加密单调、相邻差值减小，中细网格差相对参考 Cd <1%；上下表面 Cp 的相邻网格 L2 差均减小，中细差 <1%。最细网格必须满足参考误差门槛。
7. **证据完整**：保存网格、原始场、检查点、全部当前残差、源代码快照、依赖版本、原始参考与哈希。报告从检查点重建残差，不仅读取日志末行。

`report_highre_naca.py` 的单网格报告始终保留 `qualified=false`；最终三网格判定由 `qualify_highre_naca.py` 生成。未结束、失败、重复网格、缺失原场均不得冒充通过。

## 5. 使用与重现

在仓库根目录设置 `PYTHONPATH=src`，固定 `OMP_NUM_THREADS=1`、`OPENBLAS_NUM_THREADS=1`。依赖版本见 `launch-record.json`。

```bash
python scripts/mesh_highre_naca.py --output MESH --level 0 --alpha 0
python scripts/verify_highre_naca.py --mesh MESH/mesh.msh --output RUN --alpha 0 --iterations 2500
python scripts/report_highre_naca.py RUN --reference docs/verification-highre-naca/reference --output REPORT
```

粗、细网格分别采用 `--level -1`、`--level 1`。10° 网格与计算均指定 `--alpha 10`。输出目录必须为空。续算仅允许增加迭代上限，并添加 `--resume`；网格、源代码、数值设置、检查点哈希必须一致。

```bash
python scripts/qualify_highre_naca.py REPORT_COARSE REPORT_MEDIUM REPORT_FINE --output qualification.json
```

报告提供实际网格、压力场、速度场、涡黏度场、上下表面 Cp、上表面 Cf、残差与力系数历史的 PNG/PDF，以及数值 CSV/NPZ。单网格图片中明确标记迭代数与诊断状态。

本次完整运行目录为 `/data/backups/TensorFVM-highre`；检查点每 50 步保存，日志每 10 步输出。独立监控脚本等待生产计算结束后自动重建报告并执行三网格验收，过程状态保存在 `suite-status.json`。生产源码在这组计算期间冻结；运行目录与源码快照保存在数据盘。

## 6. 已完成的软件验证与尚缺证据

合并后的网格、生产离散、SST 壁面耦合及后端测试 25 项通过。报告误差积分、上下表面对应、覆盖不足、重复网格与未收敛状态拒绝测试 5 项通过。101,434 单元的启动与续算冒烟测试通过，保存场残差重建一致；该两步试算正确判定为不合格。

尚缺：四个正式计算的终态；参考误差与 y+ 的最终测量；三网格收敛结果。**本文件不宣称已获得高 Re 合格案例。**

### 启动阶段发现的局部壁面问题

0° 中网格第 50 步的保存场残差重建通过。报告进一步按生产力积分使用的完整分子黏性应力重建 Cf、y+ 和压力/黏性力分量，合力与求解器一致。此时 y+ 的 99 分位约 0.321，但两个尾缘新增短壁面出现大值，最大约 85.46。使用 U切向/壁面距离的简化剪应力估计会漏掉这两个异常。

因此，报告现在使用完整应力计算 y+；保留“最大 y+ <1”的原门槛，不能只报告 99 分位并声称全壁面通过。该结果仍是启动阶段，需要继续确认稳态下的尾缘局部网格、梯度及壁面处理。正式计算继续保留这一诊断，不把异常截断或从验收面集合删除。
