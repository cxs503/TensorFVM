# CASE-FVM-KOVASZNAY-ORDER —— 挤出向 w 伪速度的驱动源定位（z 动量探针）

**锚点**: `CASE-FVM-KOVASZNAY-ORDER`（feature ledger, open）· 前序 m16130（FAIL）/ m16173（审计）/ m16396（误差预算归属）。
**本单**: m16552 · 新增 `scripts/probe_kovasznay_z_momentum.py`（z 动量残差分解探针）
+ `tests/test_kovasznay_z_momentum_probe.py`（3 测全绿）+ 本目录。
**结论一句话**: m16396 留下的开放问题——「挤出向 w 伪速度的 O(h) 驱动力来自哪个离散项」——
**已定位并证伪**：**z 动量方程在精确解（w≡0）上被平凡满足（残差机器零）**，w 自由度经
对称-偏斜粘性算子**完全不耦合**进面内 (x,y) 动量；面内 (x,y) 粘性一致性误差是 **O(h²)**
（n=8→16 比值 3.65≈2²），与已过 1.8 门的面内阶 1.808 自洽。**w 伪速度不是 z 动量离散的缺陷**，
而是挤出 (n×n×1) 验证配置里被耦合系统放出的**寄生跨向分量**。

## ① 案例介绍（物理背景 / 几何 / 参数表）

Kovasznay (1948) 二维稳态不可压解析解（Re=40，κ=2π，λ=-0.963741），域 [0,1]² 对称挤出
`n×n×1`：`u = 1 - e^{λx}cos(2πy)`、`v = (λ/2π)e^{λx}sin(2πy)`、`p = (1-e^{2λx})/2`、
**w ≡ 0**。速度全域 Dirichlet（精确边界面均值），耦合直接解（`reused_lu`），二阶对流，
Picard 松弛 0.7，tol 1e-8，压力 gauge 钉首单元。对称挤出：z 平面 (z=0/1) 的 x,y 分量
放开为牵引、z 分量钉 0（对称面）。

| 参数 | 值 |
|---|---|
| Re | 40 |
| κ | 2π |
| λ | -0.963741 |
| 网格 | n×n×1（n=8/16） |
| 对流阶 | 2 |
| 耦合线性法 | reused_lu |
| 松弛 | 0.7 |
| 容差 | 1e-8 |

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. 用 `kovasznay_solver(..., symmetry_extrusion=True)` 建 n=8/16 挤出求解器并收敛；
2. 构造「精确混合态」：单元未知=解析速度（w=0），Dirichlet 面=精确边界均值，
   自由面=精确面心场（O(h²) 一致）；
3. 在精确态上求**全三分量动量残差** `R = (viscous+convection)@st + source - divᵀp - load`，
   并按粘性/对流/压力/载荷分解；
4. 测 w 自由度经粘性算子对面内 (x,y) 动量行的耦合（`full_matrix @ w_dof`）；
5. 全部数字由 `scripts/probe_kovasznay_z_momentum.py` 从求解器自身状态程序化注入，
   零手抄；`tests/test_kovasznay_z_momentum_probe.py` 钉三条不变量。

## ⑤ 注意点 / 局限 / 适用范围

- **本单只做定位，未改求解器**：z 动量离散被证明正确（平凡满足），故无需修；w 伪速度
  是挤出配置的寄生分量，正确处置是**在验证口径里把 w 预算单列**（m16396 已提供分解工具），
  或改用真正 2D/planar 配置（w 非自由度）。
- **面内粘性缺陷 O(h²) 与面内阶 1.808 自洽**：面内 u,v 的 2 阶收敛正是对该 O(h²) 一致性
  误差的响应；w 的 O(h) 寄生来自耦合系统对 u,v 误差的放大（经 z 动量行非对角耦合），
  与 z 动量离散本身无关。
- **n=64 未跑**：三级（含 n=64）面内阶将把不确定度收到 ~0.05；受本机负载（load15≈94）
  限制未跑，留给后续。
- **`planar`（真 2D）对照**：m16396 的 `planar` 配置实为 n×n×n 全 3D 立方（`channel_mesh(n)`），
  非真 2D，其耦合直接解在 9600×9600 超时；本单未重试，记 WITHHELD。

## ⑥ 误差判定

- **关键量 vs 基准**：本单无外部数值基准——它是对**已交付求解器**的离散一致性诊断，
  基准是「精确解应被离散算子平凡满足」这一数学恒等式。判定：
  - z 动量精确态残差 = 0.0（机器零）→ **满足**（<1e-14，远小于 3% 量级）；
  - w→面内粘性耦合 = 0.0 → **满足**（完全解耦）；
  - 面内粘性缺陷 O(h²)（比值 3.65≈2²）→ **满足**（与面内阶 1.808 自洽）。
- **显式回答「是否<3%」**：本单判据是「残差是否机器零 / 是否 O(h²)」，非「误差<3%」；
  机器零（<1e-14）与 O(h²)（比值 3.65）均以数量级满足，无含糊。
- **honest 边界**：w 伪速度的**具体放大路径**（z 动量行非对角耦合如何把 O(h²) 的 u,v 误差
  放大成 O(h) 的 w）未逐项拆到系数级——只证明了「不是 z 动量离散缺陷」这一归属，
  放大路径本身记 WITHHELD。
