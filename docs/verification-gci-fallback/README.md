# 两点回退（Fs=3）GCI 带的保守度审计

## 0. 结论速览

`richardson_gci` 在三点网格序列非单调时走「两点回退」：假定阶 + 安全系数 `Fs = 3`。
docstring 承诺这样的破序列「不可能报告一个自信的带」。本审计用一个**解析的极值族**
把这条承诺证伪，并给出最小修复：

* **缺陷**：回退带宽度只用细化对（fine/medium）的相对差，并按 `|f_ext|` 缩放。
  「假收敛」（两项误差在细网格与中网格之间相互抵消）时，细化对差值恰好是**最小的**
  那个，带在离散误差最大处塌缩；不动点附近的 `f_ext` 还可能穿过零，把带再压小一个量级。
* **量化**：信息完备子集（真值落在三个计算值张成的区间内，`N = 112`）上，
  修复前覆盖真值 **0.2321**，最差 Roache 效率指数 **90.168**（带宽度只有真误差的 1/90，
  即「自信地错」）；修复后覆盖 **1.0000**，最差效率 **0.870 ≤ 1**，带重新成为上界。
* **代价**：回退带中位加宽 2.66×（最大 1514×，即原来塌缩最严重的那批），
  一致（单调）序列的带**逐位不变**（`consistent_unchanged = true`）。
* **残留局限**：真值落在三值区间之外时（占回退例 76.1%），三个数对极限不含信息
  （假收敛序列可以任意远离），任何数据驱动的带都不可能覆盖——正确结论是
  「该研究不合格」，不是「未覆盖」。

## 1. 物理/统计背景与判据

GCI 是本仓所有基准报告里 `±x %` 的来源（Roache 1994；Celik et al. 2008,
*J. Fluids Eng.* 130:078001）。前一轮审计（`docs/gci-band-coverage/report.md`）关闭了两个问题：

* T1 纯单误差项序列的带是否恰含真值、宽度是否合适；
* T2 双误差项（真实格式的常态）下两种惯例（本仓外推中心 vs Celik/ASME 细网格中心）的覆盖率。

它明确留下的欠账是：

> 未审计两点回退（`Fs = 3`）的保守度是否足够。

本单即还这笔账。判据先于动手，且机器可裁：

| 判据 | 定义 | 通过条件 |
|---|---|---|
| J1 覆盖（信息完备子集） | `band[0] <= E <= band[1]` | 覆盖率 `= 1.0000` |
| J2 带是上界 | Roache 效率指数 `E_eff = |f_ext - E| / half_width` | `max E_eff <= 1` |
| J3 无回归 | 单调序列上修复前后 `band` 与 `gci` | 逐位相等（`rel=0`） |
| J4 不塌缩 | 回退带半宽与三个计算值相对中心的最大偏距 | `half >= max_i |v_i - f_ext|` |

「信息完备子集」是判据的分母：真值落在 `[min v, max v]` 之外时，三格数据对极限
没有任何约束力，覆盖与否反映的是构造族而不是估计器，因此单列、不混入 J1。

## 2. 方法：解析极值族（无求解器、无采样误差）

单调 `C h^p` 误差无法产生非单调序列；用**两个反号误差项**构造，其驻点可以精确放在
任意位置 `h*`：

```
f(h) = E + A h^p - (A p / q) h*^(p-q) h^q        (f'(h*) = 0)
```

取 `h_fine < h* < h_coarse` 即得「先降后升」的三点序列：观测阶不存在 → 走回退，
而 `E` 是解析真值，可逐例精确比较。参数网格：`E ∈ {1,10,100}`、
`(p,q) ∈ {(2,1),(1.5,1),(3,1),(2,0.5)}`、`(r21,r32) ∈ {(1.5,1.5),(2,2),(2,1.5),(1.5,2)}`、
`h*/h_fine ∈ {1.3,1.6,2.0,2.6,3.2}`；另有 300 个随机解析例（随机 `p,q,r,E,A,符号,h*`，
只保留回退触发且三值同号者）与 168 个**单调双误差项对照例**（回退不应触发）。

两种带比较（同一批案例）：

* `legacy`：修复前公式 `Fs|(f2-f1)/f1| / (r21^p - 1)`，带 = `f_ext (1 ± GCI)`；
* `implementation`：修复后 `richardson_gci`。

修复（`src/tensorfvm/verification/richardson.py`，仅回退分支）：

1. 相对差取**两对相邻网格的较坏者**（换算到细化对标度），使粗网格对上的分歧无法被隐藏；
2. 相对带的参考量改为**研究中最大的 `|v|`**，而不是含义已失效的 `|f_ext|`；
3. 带半宽不得小于三个计算值相对中心的最大偏距——非一致研究不能宣称比自己的数据更准。

单调路径（`fallback = False`）代码路径未改。

## 4. 误差判定（逐项，是否 < 3%）

本单的「关键量」是覆盖率与效率指数，二者都是**解析真值下的离散判定**，不是近似量：

| 关键量 | 基准 | 修复前 | 修复后 | 判定 |
|---|---|---|---|---|
| J1 覆盖（信息完备，N=112） | 解析真值 `E`（闭式） | 0.2321 | 1.0000 | 通过；与基准的偏差为**离散判定，重跑逐位一致（0%）**，远优于 3% |
| J2 `max E_eff` | 上界 1.0 | 90.168（违反 90×） | 0.870 | 通过（0.870 ≤ 1，余量 13.0%） |
| J3 一致序列无回归 | 修复前 `band`/`gci` | — | 逐位相等 | 通过（`rel=0, abs=0` 断言） |
| J4 不塌缩 | 数据张成宽度 | 存在半宽 = 0.033 而张成 7.23 的例 | `half >= spread` 逐例成立 | 通过 |

显式回答「是否 < 3%」：**是**——本审计的所有数字由确定性脚本生成，重复运行逐位一致
（无随机性；随机族固定种子 20261105），因此与「基准」的差异是 0，不存在 3% 容差问题。
唯一带随机性的部分是随机解析族，但其抽样由固定种子完全确定，且仅用于扩大覆盖面，
不用于判定阈值。

## 5. 注意点 / 踩过的坑 / 局限

1. **单调 ≠ 安全**：抽样中另有 24 例「被判单调但带远窄于数据张成」——它们观测阶被
   抬高到 4–5（真阶 2），带塌缩。本次**未改**这条路径（改动会波及所有已发布报告的带），
   但已用门禁钉死其缓解措施：这 24 例**全部** `asymptotic = False`，即
   `RefinementStudy.asymptotic` 会拒绝它们，报告引用时必须先看该标记
   （`tests/test_gci_two_grid_fallback.py::test_narrow_monotone_bands_are_flagged_non_asymptotic`）。
2. **判据分母必须诚实**：最初用「全体回退例」算覆盖率，修复后也只有 0.69——这不是
   估计器的失败，而是族里 76% 的例真值在数据区间之外，任何带都不可能覆盖。
   把不可判定的例单列，才使 J1 成为有意义的判据。
3. **加宽 ≠ 有效**：`Fs = 3` + 最坏对 + 数据缩放使信息完备子集覆盖到 1.0，但带中位加宽
   2.66×，最大 1514×（原塌缩例）。这是保守性的代价，属于预期；不要把它当作精度提升。
4. **适用范围**：结论针对本仓 `richardson_gci` 的回退分支，不外推到其他 GCI 实现；
   双误差项解析族不覆盖激波、界面等非光滑误差行为。
5. **回退带仍不是万能上界**：全体回退例上 `max E_eff = 7.08`（真值在数据区间外时无解），
   因此报告引用回退带时必须同时给出 `convergence` 与 `asymptotic` 两个字段。
