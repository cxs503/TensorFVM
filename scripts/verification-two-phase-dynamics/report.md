**结论：** 三个阻塞性缺陷中 A（σ 不生效）、C（适定性未守门）已闭合，

## ① 案例介绍（物理背景 / 几何 / 参数）

`TwoPhaseSolver` 是交错 MAC 上的变密度两相 VOF 求解器：Chorin 投影
（显式扩散+体积力预测 → 变密度压强 Poisson → 速度修正 → 施主格 VOF 输运）。
计算域：单位正方形 1 m × 1 m。参数：ρ_l=1000.0 kg/m³、ρ_g=1.0 kg/m³、
μ_l=μ_g=10⁻³ Pa·s（静液滴 10⁻²）、g=9.81 m/s²、σ=0.07 N/m、液滴半径 R=0.2 m
（二维圆界面，解析 Δp=σ/R=0.35 Pa，不是三维球面 2σ/R）。

## ② 怎么做的（根因定位 → 最小修复 → 解析复核）

1. **根因 B（投影算子双重取负）**：`off_e/off_w/off_n/off_s` 存的是 `−ce`，
   `matvec = diag*q − Σ(coeffs·neighbours)` 又减了一次 → 实际求解的算子是
   `diag + Σce·p_N`（一个平移后的正定矩阵，没有 Laplace 结构）。CG 照样收敛，
   但解不是 Laplacian 逆：压强修正量级错、散度压不下去。用人造二次解
   （p=x²+0.3y²）做算子对表，`matvec/⟨V·∇·((1/ρ)∇p)⟩ = 290`——当场判死。
   修复：off-diagonal 存正值，`matvec` 保持减法。
2. **根因 B′（Poisson 右端少乘单元体积/符号错）**：`b = div(u*)/dt` 应为
   `−(dx·dy)·div(u*)/dt`。16×16 网格上原式使压强解大约 256 倍，
   正是首轮报告里「p_max=1.2e5 Pa 而量级应为 ρg·dy≈6e2」的来源。
3. **缺陷 A（表面张力不生效）**：新增 `_csf_force()`，把 `csf_surface_tension`
   的体积极力 f=σκ∇α 面插值后以 f/ρ 加到动量预测（u/v 分别)，σ=0 时返回零，
   保证单相回归逐位不变。
4. **缺陷 C（适定性）**：新增 `_require_pressure_datum()`，全 Neumann
   （`top_atmosphere=False` 且 `side_outlet=False`）在 `step()` 入口抛 `ValueError`。
5. 三条解析锚点写成 pytest（`tests/test_two_phase_solver_verification.py`）：
   Young–Laplace 与封闭域由 `xfail(strict)` **升格为硬断言**；静止水柱保持
   `xfail(strict)`，并加了一条「1e38 发散不得回归」的回归守卫（`|v|<1e-2`）。
6. 证据脚本 `scripts/verify_two_phase_dynamics.py` 程序化产出
   `scripts/verification-two-phase-dynamics/evidence.json` 与三张图（零手抄）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **算子对表是人造解判据**：先造「人造二次解 + 解析 ∇·((1/ρ)∇p)」把算子里外
   比一遍（290 倍当场暴露双重取负），再谈物理锚点——比直接跑物理算例省一个数量级。
2. **CG 收敛不等于方程解对**：错算子仍是 SPD，CG 会"漂亮地收敛"到错误答案，
   这是本缺陷能活着合并的机制。判据必须落在物理/守恒量上，不能落在残差上。
3. **剩余缺陷的定位**：残差与界面无关（纯液相、纯气相、分层三种情形逐步增量
   完全相同），因此不是混合密度/界面处理的锅；压力梯度比解析值弱约 2.4 %
   （底部面 dp/dy=−9570 vs −9810 Pa/m），指向顶部 Dirichlet 行（p=0 钉在顶层
   单元中心而非顶面）与零梯度顶部速度的相容性。这是下一步的单点工作。
4. **适用范围**：本轮只按时序推进（无对流项、无 Rhie–Chow 动量插值），
   Δt 固定，网格 ≤32²，步数 ≤20；**不外推**到动态两相算例（溃坝、气泡上升）。
5. 未覆盖：`initialize_hydrostatic_pressure` 与投影解之间的压强基准约定
   （p 是总压还是修正压）在本模块里含混，修复后总压一致，但仓内其它调用方
   若有旧约定需复核。
6. 稀疏检出（cone: `src/ tests/ scripts/`）下 `docs/` 不可写，故证据与报告
   落在 `scripts/`。

## ⑥ 误差判定（逐项 + 显式回答「是否 <3%」）

| 关键量 | 基准 | 相对误差 | <3 % ? |
|---|---|---|---|
| Young–Laplace 压差 Δp | σ/R（二维精确） | 1.80 % | **是** |
| 液滴初始面积 | πR² | 0.201 % | 是 |
| 投影后散度（守恒性） | 0（机器精度） | 3.39e-14 量级 | 是 |
| 静止水柱 max\|v\| | 0（精确） | 归一化后 ≥ 1（残余 8.6e-4 m/s） | **否**（honest-FAIL） |
| 全封闭域适定性 | 必须抛错 | 抛 `ValueError` | 是（定性门） |

**显式回答：整体不是全绿。** 表面张力与适定性两条锚点误差远优于 3 %，
但静止静水平衡锚点未达标，本轮判定为**部分清偿**：能力等级由 `MOCK`
（σ 标志位不生效）升到 **REAL（表面张力）/ 部分 REAL（静水平衡仍不可信）**。
后续把顶部 Dirichlet 界面的相容性修好、把该 `xfail` 升格为硬断言，才算完全闭合。
