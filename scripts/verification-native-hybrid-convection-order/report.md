## 1. 案例介绍（物理背景 / 几何 / 参数）

`NativeHybridConvection3D` 是可压缩有限体积 3D 求解器
（`native_hybrid_ns3d.py` 等）的对流项载体：在共享面上以体积通量 `q_f=u·S_f` 迎风取上游值，
可选 `order=2` 的**延迟线性迎风**修正（用当前梯度把上游格心速度外推到面心）。
模块文档声称"一阶有非负迎风能量项、二阶修正有符号功，且能量账严格闭合"，
但仓库测试（`tests/test_native_hybrid_ns3d.py`）只核对了：全局守恒、能量恒等式、
仿射场重构精确、以及"零通量矩阵为零"。**截断阶——即"线性迎风"四字所依据的性质——从未被测过。**

几何：单位立方体 `[0,1]³` 上的一致加密族，三族单元：

| 族 | 构造 | n=2/4/8 单元数 |
|---|---|---|
| hex | 结构化六面体 | 8 / 64 / 512 |
| wedge | 每个六面体沿 0-2-4-6 对角面切成 2 个三棱柱（x/y 面保持整四边形 → 协调） | 16 / 128 / 1024 |
| tetra | 每个六面体沿主对角 0-6 切成 6 个四面体（各面的对角一致 → 协调） | 48 / 384 / 3072 |

场：`native_manufactured3d.abc_fields` 的解析 ABC 场（幅值 0.5、波数 k=0.7、无散、ρ=1），
含解析速度梯度 `velocity_gradient`（用于"解析梯度"通道）。

## 2. 怎么做的（方法 / 流程 / 工具链）

1. **独立参考解**：对每张面用 Duffy 张量 Gauss（每三角形 6×6 点，`leggauss`，
   权重含 `2r` 雅可比）直接对解析场积分 `F_f = ∮_f (u·n)u dA`，
   面的多边形由 `native_face_geometry3d.polygon_triangles` 三角化。
   该参考只依赖几何与解析场，不经过求解器任何代码路径。
   交叉校验：把面通量按 `owner−neighbor` 装配回格心，与 `V_K·∇·(u⊗u)|_K` 相差 2 % 以内
   （h=1/2 下 O(h²) 的格心-vs-积分差），确认参考无比例因子错（见第 ⑤ 节踩坑）。
2. **被测路径**：`operator.assemble(volume_flux, gradient)` 返回的
   `transport @ u_cell + face_source` 即面通量，与 `diagnostics(...)['momentum_flux']` 同源；
   解析速度同时供给格心与面心，误差因此是纯离散误差。
3. **三条格式通道**：`order=1`（纯迎风）、`order=2` 配解析梯度、`order=2` 配产线高斯梯度
   （`Σ_f u_j S_i / V`）。
4. **收敛阶**：`p = log(e_{2h}/e_h)/log 2`，n=2→4→8；误差取内部面通量的相对 L2 范数。
5. 回归：`tests/test_native_hybrid_convection_order.py`（19 项，22 s）把阶次、
   仿射精确性、能量账、网格族协调性与体积守恒全部钉死；工具链 PyTorch float64 numpy/scipy、
   pytest、matplotlib(Agg)，全 CPU 单进程，总耗时 <1 min（遵守 load15≥100 只做轻量算力）。

复现：`PYTHONPATH=src python scripts/verify_native_hybrid_convection_order.py`

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **两个自造踩坑**：(a) Duffy 权重里 `2r` 的因子与"三角形面积 2A"的因子重复乘了 2，
   第一次实测误差恒≈0.5 且不收敛；靠"参考解 vs V·∇·(u⊗u)"的独立交叉校验抓到（因子 2）。
   (b) 直接用**格心残差**做误差范数是错的：`Σ_f q_f u_K = u_K Σ_f q_f`
   在离散无散通量下恒等于零，等于拿"恒零算子"去比非零的连续项，必然量出 O(1) 的假误差；
   所以本题改成量**面通量**——这也正是模块用面均值 `R U` 而非格心值做输运的原因。
2. **局限**：只测了通量截断阶，未测非线性求解的整体阶（Newton 收敛、限制器、激波）；
   三族网格皆为均匀、近正交，强畸变/Skew 网格上的阶次可能下降（Gauss 梯度通道已提示这一点）；
   场取无散 ABC 场，未覆盖强可压/带激波场；n 最大 8，属渐近前段（tetra 二阶 2.05/2.06 略超 2
   即为此）。
3. **适用范围**：结论支撑"`order=2` 在光滑无散场、协调混合网格上确为二阶"这一声明；
   不支撑任何工程精度声明，也**不构成**对流项在 RANS/壁面受限算例中的精度证据。
