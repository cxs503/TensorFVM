# 2-D mesh-quality metrics: analytic closed-form audit of a geometric acceptance gate

Scope: `src/tensorfvm/mesh_quality.py::mesh_quality` and the 70° non-orthogonality
gate it exposes (`quality_gate_passed`). Evidence is generated by
`scripts/verify_mesh_quality_metrics.py` into `results.json`, `report-table.md`
and `nonorthogonality-vs-shear.png`; the tables below are **not** transcribed by
hand — `report-table.md` is emitted from the same audit run as the JSON
(sha256 of `results.json` is printed by the script).

## 1. Why this audit exists (the verification debt)

`mesh_quality` decides whether a generated case mesh is admissible for the
production cases: positive cell areas, positive projected centre–face distances,
and `nonorthogonality_max_deg < 70`. Its only executed coverage lived inside
`tests/test_gmsh_external.py` / `tests/test_hybrid_gmsh.py`, which
`pytest.importorskip('gmsh')` — and `gmsh` is absent from this environment, so
those tests **skip**. In other words: the gate that admits or rejects every
external-flow mesh had no mesh-generator-independent test, and no analytic
reference value at all. This audit closes that gap with closed forms and
negative controls.

## 2. Method

Definitions verified are the standard finite-volume reading (also used by
OpenFOAM `checkMesh`): non-orthogonality angle = angle between the face area
vector and the vector joining the two cell centres (cell centre → face centre on
boundary faces); skewness = distance from the face centre to the intersection of
that connector with the face, normalised by the connector length.

The reference geometry is a **parallelogram (uniformly sheared) grid**, where
every metric has a closed form: the centres form an affine lattice, so the
connector passes exactly through the face centre (`skewness = 0`) and the normal
deviates from the connector by exactly the shear angle
(`nonorthogonality = arctan γ`), while the projected distance stays `dy`.

Implementation points that matter for honesty:

* The sheared grids are built by the **shipped** `CurvedChannelMesh`
  constructor (topology, ownership and outward orientation come from production
  code); only its bottom-wall profile is replaced by the linear map
  `(x, y) → (x + γ y, y)`. `γ = 0` is the regular channel. No mesh code is
  re-implemented in the audit, so a topology bug could not be masked by the test.
* `independent_metrics` re-derives every reported scalar from the raw tensors
  with its own numpy expressions — the module is audited against an independent
  implementation, not against itself.
* Grid independence of *coordinates* is checked by rigid rotation
  (0/17/43/90°), a symmetry the metrics must satisfy exactly.
* Negative controls: one flipped face orientation, and one inverted cell area —
  both must be **rejected**, otherwise the gate is decorative rather than
  discriminating.

noise level (`NOISE_DEG = 1e-5`), not an unphysical `1e-12`.

## 4. Error judgement (against closed form / independent recomputation)

| quantity | reference | measured | relative error | <3%? |
|---|---|---|---|---|
| non-orthogonality, 5–69° shear | `arctan γ` | equal to 1e-12° | < 1e-13 (abs error ≤ 5.8e-11°) | **yes** |
| non-orthogonality, 0° shear | 0 | 8.5e-7° | `√ε` float floor, not a metric error | **yes** (within the documented 1e-5° noise) |
| internal skewness, parallelogram grid | 0 | ≤ 8.0e-13 | abs only | **yes** |
| gate flip angle | 70° (documented) | 69.9999999996° | 5.4e-12 | **yes** |
| shipped vs independent metrics | identical | identical | 0.0 | **yes** |

## 5. Caveats and limits

* Geometric pre-condition only. A mesh that passes the gate is *admissible by
  this criterion*; nothing here claims that a 69°-non-orthogonal mesh gives
  accurate answers — that is a discretisation-error question (non-orthogonal
  correction, see the curved-channel order verification), not a quality-metric
  question.
* 2-D metrics only (`mesh_quality`); the 3-D `hybrid_mesh_quality` layer
  extraction is unchanged and remains `gmsh`-gated.
* The gate is a hard 70° threshold with no percentile option; the audit verifies
  the threshold it claims, it does not endorse the value.
* The sheared family is affine, so skewness closed form is only tested at zero.
  The non-zero skewness path is covered by the curved channel — verified against
  an independent recomputation rather than a closed form.
