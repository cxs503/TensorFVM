The following data files (used in the 1993 workshop described in NASA TM 1122858) are provided here:

cf_exp.dat          = surface skin friction coefficients (limited data)
clalpha_exp.dat     = lift coefficient as a function of corrected angle of attack
cp_exp.dat          = surface pressure coefficients
velprofiles_exp.dat = velocity profiles taken normal to airfoil upper surface, provided at:
                        x/c=0.45
                        x/c=0.85
                        x/c=0.8982
                        x/c=0.9750
                        x/c=1.0321
                        x/c=1.0752
                        x/c=1.1125
Plots               = directory of Tecplot layout files for plotting some of the quantities

Mach number = 0.2
Reynolds number (based on stowed chord of 22 inches) = 9 million
Corrected angles of attack:  8.10, 16.21, 21.34, and 23.28 deg.
See also AIAA-93-3137 (Chin et al).

Information regarding measured transition locations on each of the three elements of the airfoil can be 
found in AIAA-93-0703 (Bertelrud).


NOTE: The experimental data should be used only as a rough guide.  There are known three-dimensional
effects (especially at higher lift conditions).
